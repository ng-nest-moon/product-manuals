# 立马造 — 产品功能说明书

## 一句话定义

上传一份产品功能说明书（Markdown），系统自动拆解任务、生成代码并部署上线，输出一个可直接分享的链接。

---

## 一、系统架构总览

```
用户层
 └── Web 端 —— 上传说明书 / 查看计划 / 确认执行 / 查看进度 / 获取链接

核心流程
 ├── 解析器 —— 读取 Markdown 说明书，提取功能模块、页面、数据
 ├── 规划器 —— 生成可执行的开发计划（依赖关系 + 执行顺序）
 ├── 生成器 —— 按计划依次创建项目文件
 └── 部署器 —— 将生成的项目部署上线，返回访问链接

状态层
 ├── 解析完成 → 等待确认
 ├── 生成中 → 实时进度
 ├── 已完成 → 可访问链接
 └── 失败 → 错误原因 + 重试
```

---

## 二、核心功能清单

1. **说明书上传** — 支持粘贴 Markdown 文本或上传 .md 文件，系统自动识别结构
2. **智能解析** — AI 读取说明书，提取功能模块、页面数量、数据模型、用户角色
3. **计划预览** — 以清单形式展示将要生成的内容：包含几个页面、几个功能模块、数据存储方式
4. **人工确认** — 用户可在执行前调整计划（删除/合并某些模块），确认后开始生成
5. **实时进度展示** — 用大白话加进度条展示当前执行到哪一步，非技术用户也能看懂
6. **一键部署** — 生成完成后自动部署，产出可直接在浏览器打开的链接
7. **分享产物** — 生成的链接任何人打开即可使用，无需安装、无需登录
8. **模板启动** — 内置多套产品模板，用户可选择模板快速开始，不必从空白文档写起
9. **历史记录** — 记录每个说明书生成的产物链接，方便回看和管理

## 三、用户流程

### 3.1 首次使用

```
打开网站
  │
  ├─ 选择「从模板开始」或「上传说明书」
  │
  ├─ 如果从模板开始：
  │    选择模板（如"内容展示页""信息收集表单""工具类单页"）
  │    填写几个关键信息（标题、功能描述）
  │
  ├─ 如果上传说明书：
  │    粘贴 Markdown 或上传 .md 文件
  │
  ├─ 系统解析（约 3-10 秒）
  │    展示解析结果：发现 X 个功能模块、X 个页面
  │
  ├─ 用户确认计划：
  │    ☑ 模块 A（保留）
  │    ☑ 模块 B（保留）
  │    ☐ 模块 C（去掉）
  │
  ├─ 点击「开始生成」
  │
  └─ 等待（约 30 秒 - 3 分钟）
       进度条 + 当前步骤说明
       完成 → 弹出链接：「你的产品已上线」
```

### 3.2 查看产物

生成的产物是一个可直接在浏览器中使用的 Web 页面：

| 类型 | 示例 |
|------|------|
| 信息展示页 | 产品介绍、个人主页、项目文档 |
| 工具页 | 计算器、打卡器、记账本、待办清单 |
| 表单页 | 报名表、反馈收集、预约登记 |
| 内容页 | 博客、笔记、相册 |
| 管理面板 | 数据看板、状态管理 |

产物本身包含：
- 完整的页面交互
- 数据可保存（刷新不丢失）
- 在手机上也能正常使用

## 四、核心模块详解

### 4.1 说明书解析器

| 功能 | 说明 |
|------|------|
| 格式识别 | 自动识别 Markdown 标题层级（# ## ###）作为模块划分依据 |
| 功能提取 | 从列表、表格、段落中提取产品的功能点 |
| 页面推断 | 根据功能点数量、关联关系，推断需要的页面数量 |
| 角色识别 | 从描述中提取用户角色（如"游客""管理员""创作者"） |
| 数据识别 | 识别描述中提到的数据实体（如"订单""用户""文章"） |

**解析结果示例：**

```
📄 识别到 3 个页面：
  首页 → 展示功能列表
  详情页 → 查看单个项目详情
  管理页 → 增删改操作

📦 识别到 2 个数据实体：
  项目（标题、描述、时间）
  分类（名称、图标）

🔗 页面关系：
  首页 ↔ 详情页（点击进入）
  管理页 → 首页（发布后展示）
```

### 4.2 计划预览与调整

解析完成后，用户看到的是一个可勾选的清单：

```
你的产品包含以下内容：

📄 页面
  ☑ 首页
  ☑ 详情页
  ☑ 管理页

📦 数据
  ☑ 项目数据
  ☑ 分类数据

🔧 功能
  ☑ 浏览列表
  ☑ 新增项目
  ☑ 编辑项目
  ☑ 删除项目
  ☑ 按分类筛选

用户可取消勾选不需要的部分，系统不会生成被去掉的内容。
```

### 4.3 实时进度展示

生成过程中，用户看到的是这样的信息，不是日志：

```
■ 正在搭建项目框架……
■ 正在创建首页……
■ 正在创建详情页……
■ 正在添加数据存储……
■ 正在配置分享功能……
■ 正在部署上线……

━━━━━━━━━━━━━━━━━━━━━━ 85%  ■■■■■■■■■■■■■■■■■■■□□□

预计还剩 30 秒
```

每一个步骤完成后会短暂变绿，然后进入下一步。

### 4.4 产物访问

生成完成后，用户获得一个链接，例如：

`https://项目名-随机字符.specrun.app`

这个链接的特点：

| 特性 | 说明 |
|------|------|
| 无需注册 | 任何人打开即可使用 |
| 无需登录 | 不需要账号密码 |
| 数据独立 | 每个链接的数据互不干扰 |
| 手机可用 | 自动适配手机屏幕 |
| 可反复使用 | 关闭后数据仍在，下次打开还在 |

## 五、产物示例

以下是几种典型说明书生成的产物形态，帮助用户理解"我能得到什么"：

### 5.1 从「展示型」说明书生成

**说明书示例：** 一个个人作品集页面，展示我的 6 个项目，每个项目有标题、描述、截图和链接，支持分类筛选。

**生成的产物：**
- 一个单页网站，顶部是个人简介
- 中间是项目网格，点击可展开详情
- 顶部有分类标签可筛选
- 底部有联系方式

### 5.2 从「工具型」说明书生成

**说明书示例：** 一个团队午餐投票工具，每人选一家餐厅，投票结束后显示结果。

**生成的产物：**
- 发起投票：输入几个选项
- 分享链接给同事
- 每人点选一个选项
- 所有人投完后显示结果

### 5.3 从「管理型」说明书生成

**说明书示例：** 一个简单的书单管理工具，可以记录读过的书、评分和读后感，按分类查看。

**生成的产物：**
- 首页：分类列表
- 书籍列表页：显示每本书的封面、标题、评分
- 新增页：填写书名、作者、评分、读后感
- 详情页：显示完整信息和编辑入口

## 七、边界声明

| 不做 | 原因 |
|------|------|
| 登录注册系统 | MVP 零门槛，打开即用 |
| 数据库存储 | MVP 产物的数据存在浏览器本地 |
| 多人实时协作 | 产物是单人使用或分享查看 |
| 自定义域名 | MVP 使用统一子域名 |
| 支付/计费 | MVP 完全免费 |
| 移动端 App | 产物是 Web 页面，手机浏览器可用 |
| 导出源代码 | MVP 产出的是可用的产品，不是开发工具包 |
| UGC 编辑器 | 不提供界面拖拽编辑，改需求请改说明书重新生成 |
| AI 对话式生成 | 不做聊天窗口，坚持"说明书驱动" |

## 八、开发优先级

### 第一阶段 —— 核心闭环

- 说明书上传与解析（Markdown 输入 + AI 解析）
- 计划预览与人工确认
- 单页产物生成（信息展示/表单/工具类）
- 自动部署与链接返回
- 实时进度展示

### 第二阶段 —— 体验完善

- 模板启动（6 套内置模板）
- 历史记录
- 产物形态扩展（管理面板等）
- 移动端适配优化

### 第三阶段 —— 能力扩展

- 多页产物支持
- 说明书质量反馈（告诉用户怎么写更容易生成好产品）
- 产物数据分析（访问量、使用情况）
- 用户反馈通道
