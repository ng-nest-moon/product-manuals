# 有啥吃啥 · 产品说明书

> 不用想，拍了就做。

---

## 一句话

对着冰箱拍一张，AI 给你配好一桌菜，附带做法，做了就完事。

---

## 用户流程

### 首次设置（一次）

```
设定吃饭人口
  ├─ 大人：2
  └─ 小孩：1（5岁）
```

系统记住，以后每天出菜自动按人数算道数、按小孩口味调。

### 每日使用

```
打开 App → 对着冰箱/厨房拍一张 → 等 3 秒
                                    ↓
                          看到一桌菜：荤素搭配好了
                          每道菜点开有做法
                                    ↓
                                  做完 → 点「搞定」
```

没有「选一个」的步骤。没有第二屏。没有收藏、没有评分、没有社区。

今天人数有变化？点一下改就行（「今晚多一个朋友」）。

---

## 核心规则

### 输入
| 方式 | 说明 |
|------|------|
| 拍照 | 拍冰箱/台面/橱柜，一次最多 3 张 |
| 语音 | 说「有鸡蛋番茄青椒」也行 |
| 手动补 | 识别错了？拍完直接打字补一两个词「还有葱」 |

### 硬约束

- **只出家常菜** — 排除烘焙、西餐、复杂料理（如需要高汤/特殊香料/30 分钟以上的）
- **每道不超 30 分钟** — 从开火到上桌
- **调料不超过 6 样** — 油盐酱醋糖料酒这类常备的不算，但「蚝油」「豆瓣酱」「番茄酱」算
- **全部菜合计不超 45 分钟**
- **可以用剩菜/隔夜饭改造**

### 推荐逻辑（按优先级）

1. **昨天做了啥** → 今天不重复
2. **冰箱里最快要过期的** → 优先用掉
3. **上次做完你点了👍的** → 相近的优先
4. **今天天气** → 热天偏凉拌/冷天偏炖汤
5. **今晚时间** → 如果日历显示有会到 8 点 → 做 20 分钟内搞定的
6. **家里有小孩** → 排除辣菜、刺多的鱼、整颗坚果，优先好入口的
7. **以上都没命中** → 随机出一道能做的

> 有小孩时不减份量，但多配一个清淡素菜或蒸蛋。

### 输出

按人数出一桌菜：

| 人数 | 道数 | 搭配 |
|------|------|------|
| 1 人 | 1 道 | 盖饭/炒面类一锅出 |
| 2 人 | 2 道 | 1 荤 1 素 |
| 3~4 人 | 3 道 | 1 荤 1 素 1 汤 或 2 荤 1 素 |
| 5+ 人 | 4 道 | 2 荤 1 素 1 汤 |

每道菜附带：

- **菜名**
- **预计用时**
- **做法**（3~5 句话，不超过 60 字）
- **还缺啥**（可选，如「还差一根青椒，楼下买就行」）

## 反馈循环

| 用户动作 | 系统学到 |
|----------|----------|
| 点「搞定」 | +1，以后类似优先 |
| 没点搞定，关掉 App | -1，以后少推 |
| 手动说「今晚做的水煮鱼」并拍照 | 更新偏好 |
| 连续 3 次没反馈 | 降低频次，问是否不准 |

没有评分、收藏、踩。用户要么做完点一下，要么不做关掉。

---

## 不做的事

| 不做 | 理由 |
|------|------|
| 社区/分享 | 跟省脑子矛盾 |
| 自建菜谱库 | 对接现有 API 即可 |
| 一周规划 | 跟每天拍每天做矛盾 |
| 营养计算 | 用户没要 |
| 购物车/买菜 | 可后加，初版不做 |
| 多选凑菜 | 出一整桌，不让用户凑 |

---

## 技术备忘

- 视觉识别：GPT-4o / Gemini Vision，不自己训模型
- 菜谱源：下厨房 / 豆果美食 API
- 推荐引擎：纯规则 + 用户历史，不需要 ML
- 存储：本地优先，账号可选
