# 出海风云 — 产品功能说明书

## 一句话定义

2D 俯视地图上的全球化商业模拟游戏——从深圳华强北的一间小办公室起步，到横跨五大洲的跨国集团，经历供应链选品采购、跨境品牌建设、地缘政治博弈三阶段，每一个决策都在世界地图上留下你的商业足迹。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：喜欢策略经营的模拟游戏玩家（25-40 岁）**

| 维度 | 描述 |
|------|------|
| 游戏习惯 | 玩过模拟经营、策略类、大亨类游戏 |
| 典型游戏 | 开罗系列、海岛大亨、维多利亚3、Offworld Trading Company |
| 单次游戏时长 | 30-60 分钟，可存档断点续玩 |
| 底层心理 | 享受"从零到一"的创业叙事 + 全球布局的掌控感 |

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 模拟经营缺乏"中国企业出海"的现代题材 |
| **刚需** | 现有贸易游戏多聚焦历史（大航海/丝绸之路），缺乏当代商业语境 |
| **改善型** | 大亨类游戏后期容易无聊，缺乏阶段转换带来的新鲜感 |
| **改善型** | 玩家希望体验真实的商业决策——供应链、品牌、地缘，而非简单的"买低卖高" |

---

## 二、解决方案与核心循环

### 2.1 解决方案概述

出海风云是一个三阶段渐进式全球化商业模拟游戏。玩家从深圳起步，经历"供应链→品牌→地缘"三个阶段，每个阶段解锁新的玩法深度。

**核心设计：**

- **三阶段引擎** — 每个阶段解锁新模块和决策维度，避免中期无聊
- **真实世界地图** — 2D 俯视世界地图，城市节点具有真实经济数据特征
- **双货币经济** — 人民币（国内采购）+ 美元（国际结算），汇率波动影响利润
- **随机事件系统** — 港口罢工、关税调整、爆款突现等事件持续挑战策略

### 2.2 三阶段总览

| 阶段 | 时间跨度 | 核心玩法 | 解锁条件 |
|------|---------|---------|---------|
| 一·草莽出海 | 第 1-5 年 | 选品 → 采购 → 跨境物流 → 清关 → 上架 | 游戏开局即开启 |
| 二·品牌扎根 | 第 5-15 年 | 产品研发 → 品牌定位 → 营销投放 → 本地化运营 | 月营收稳定 + 品牌知名度达标 |
| 三·全球博弈 | 第 15 年+ | 跨国并购 → 汇率对冲 → 政府游说 → 供应链重组 | 跨国营收占比达标 |

## 四、核心功能清单

1. **三阶段引擎** — 供应链→品牌→地缘三个阶段自动解锁，每个阶段引入全新玩法模块
2. **品类选品系统** — 电子/服饰/家居/玩具/配件五大品类，各有利润率、运输成本和竞争烈度参数
3. **供应商管理** — 多家供应商可选，价格、质量、交期、账期四个维度动态变化
4. **跨境物流规划** — 海运/空运/铁路/海外仓四种方式组合，成本与时效权衡
5. **多平台渠道** — 亚马逊、独立站、当地电商平台三种销售渠道并行运营
6. **品牌定位与研发** — 设定品牌调性，投入研发改款、认证、包装升级
7. **营销投放** — 社交媒体、KOL、广告投放、本地PR四类营销手段
8. **本地化适配** — 语言翻译、包装调整、文化禁忌规避、本地售后体系建设
9. **地缘风险系统** — 关税变动、贸易制裁、汇率波动、政局变化影响业务决策
10. **跨国并购** — 收购海外品牌、渠道、产能，快速进入新市场
11. **双货币经济** — 人民币采购+美元结算，汇率管理直接影响利润
12. **随机事件** — 港口罢工、原材料暴涨、爆款突然出现等事件打破均衡

## 五、核心模块详解

### 5.1 品类与选品系统

**职责：** 提供五大品类的参数模型，玩家基于数据分析选品决策

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 品类参数 | 电子/服饰/家居/玩具/配件五类 | 每类有利润率、运输成本占比、退货率、竞争烈度四项参数 |
| 选品池 | 每季度刷新可选产品列表 | 每次 10-15 款产品，价格和预估销量动态生成 |
| 选品决策 | 玩家选择上架哪些产品 | 最多同时运营 6 款产品，超出需淘汰或扩仓 |
| 品类趋势 | 各品类热度随季节和事件波动 | 如年底电子品类热度+30%，服饰换季时需求变化 |

品类基准参数：

| 品类 | 利润率 | 物流成本占比 | 退货率 | 竞争烈度 |
|------|-------|------------|-------|---------|
| 电子 | 15-25% | 8-12% | 5-8% | 高 |
| 服饰 | 40-60% | 15-20% | 15-25% | 极高 |
| 家居 | 30-45% | 25-35% | 3-5% | 中 |
| 玩具 | 35-50% | 10-15% | 2-4% | 中低 |
| 配件 | 50-70% | 5-8% | 1-3% | 低 |

### 5.2 供应商管理

**职责：** 管理供应商关系，在价格、质量、交期、账期之间权衡

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 供应商列表 | 每个品类 3-5 家供应商可选 | 分布在义乌/深圳/广州/东莞等产地城市 |
| 四维评分 | 价格/质量/交期/账期各 1-5 分 | 价格低则质量可能低，存在 trade-off |
| 关系值 | 长期合作提升关系等级 | 累计采购额达标→关系升级→解锁更优条件 |
| 独家协议 | 达到一定关系后可签独家 | 独家享 10% 价格优惠但不可更换供应商 |

### 5.3 物流链路

**职责：** 管理货物从中国工厂到海外消费者的全链路

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 运输方式 | 海运/空运/铁路/海外仓四种 | 海运最便宜(30-45天)/空运最快(5-7天)/铁路居中(15-20天) |
| 海外仓 | 在目标市场租用仓库提前备货 | 月租成本 + 库存占用资金，但配送时效快(2-3天) |
| 清关管理 | 每批货物需通过海关 | 随机抽检率，品类合规文件影响清关速度 |
| 物流追踪 | 实时查看每批货物状态 | 地图上显示货物当前位置，支持异常预警 |

### 5.4 品牌系统

**职责：** 管理品牌定位、研发和用户心智（第二阶段解锁）

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 品牌定位 | 性价比/品质/设计感/科技感四选一 | 定位影响目标客群、定价区间、营销方式 |
| 产品研发 | 改款升级/包装设计/认证申请/专利申请 | 每次研发消耗资金 3-6 个月，成功后提升产品评分 |
| 品牌知名度 | 各市场独立计算品牌知名度 | 受营销投放、产品质量、口碑累积影响 |
| 品牌溢价 | 知名度越高，可定价越高 | 知名度和售价线性关系到上限（定位上限约束） |

### 5.5 地缘风险系统

**职责：** 模拟国际政治经济环境对业务的影响（第三阶段解锁）

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 关税变动 | 目标市场突然调整关税税率 | 每 6-12 个月可能触发，幅度 5-25% |
| 汇率波动 | 美元兑人民币汇率每日波动 | 月波动范围 ±3%，极端事件可达 ±10% |
| 贸易制裁 | 特定品类或国家被限制贸易 | 小概率事件，但影响极大，需要提前布局分散风险 |
| 政局变动 | 目标市场选举/政策转向 | 每 4 年大选年触发，政策方向随机 |
| 风险对冲 | 远期结汇/期权/跨境保险 | 消耗资金成本，降低风险敞口 |

### 5.6 事件系统

**职责：** 生成随机和周期性事件，打破均衡提供策略挑战

| 事件类型 | 示例 | 触发频率 |
|---------|------|---------|
| 利好事件 | 某产品突然爆火/物流成本下降/汇率利好 | 每季度 0-1 次 |
| 利空事件 | 港口罢工/原材料涨价/差评风波/竞争对手降价 | 每季度 1-2 次 |
| 周期性事件 | 黑五/Prime Day/圣诞旺季/返校季 | 每年固定时间 |
| 宏观事件 | 关税调整/大选年/贸易协定/疫情 | 1-3 年一次 |

  │    ├─ 供应链重组：全球产能布局分散风险
  │    └─ 终局：达成任一胜利条件
  │
  └─ 胜利条件（任选其一）

## 七、应用场景

### 场景一：新手开局——从华强北到美国

玩家 A 第一次玩。开局选"电子配件"品类——门槛低、利润中等、退货率低。对接深圳一家手机壳供应商，走海运发到美国亚马逊仓库。定价 $12.99，扣除成本和运费单件利润 $4。前三个月慢慢出单，第四个月迎来黑五，销量暴涨 3 倍。第一次体验"看数据面板上的营收曲线往上飙"的快感。

### 场景二：品牌玩家的精准打击

玩家 B 已经玩过两轮，选择"家居"品类开局。第一阶段专注打磨供应链，找到一家佛山优质家具供应商签了独家协议。进入第二阶段后定位"设计感"路线，请设计师改款，拿德国红点认证。营销策略选择 Instagram + 家居 KOL 组合，在日本市场打开局面。一年后成为日本站"家居"品类前三。

### 场景三：地缘老手的避险之道

玩家 C 已进入第三阶段，在中美关税升级中面临挑战——美国市场占营收 60%，关税从 8% 涨到 25%。玩家做三件事：(1) 用远期结汇锁定当前汇率；(2) 在越南设组装厂规避关税；(3) 收购一家欧洲品牌降低对美国市场的依赖。三个季度后，美国市场占比降到 35%，总营收恢复增长。

## 八、经济系统

### 8.1 双货币体系

| 货币 | 用途 | 获取方式 | 管理要点 |
|------|------|---------|---------|
| 人民币(¥) | 国内采购/供应商付款/员工工资/国内运营 | 银行兑换/国内销售回款 | 国内日常运营资金 |
| 美元($) | 海外仓租金/广告投放/国际物流/海外运营 | 跨境销售回款/海外融资 | 汇率波动直接影响利润 |

### 8.2 利润计算

单笔订单利润 = 售价 - 采购成本 - 物流成本 - 平台佣金 - 关税 - 广告摊销 - 汇率损失

### 8.3 现金流管理

| 指标 | 影响 |
|------|------|
| 应收账款账期 | 平台回款周期 14-45 天，影响可用资金 |
| 应付账款账期 | 供应商账期 30-90 天，延后付款可缓解资金压力 |
| 库存周转率 | 库存积压占用资金且产生仓储成本 |
| 融资渠道 | 银行贷款(低息但需抵押)/风险投资(稀释股权)/供应链金融(高息) |

### 8.4 风险仪表盘

实时显示四项风险指数（0-100），玩家需保持四项均在安全线内：

| 风险指标 | 影响因素 | 超标后果 |
|---------|---------|---------|
| 汇率敞口 | 美元资产净敞口占比 | 汇率突然波动导致巨额损失 |
| 库存风险 | 滞销库存占比/库龄 | 仓储成本侵蚀利润/被迫清仓 |
| 政策风险 | 目标市场集中度 | 单一市场政策突变打击全部业务 |
| 竞争压力 | 品类竞争烈度/对手行动 | 被迫降价/市场份额萎缩 |

## 九、商业模式

| 付费模式 | 说明 |
|---------|------|
| 买断制 | 游戏本体付费（40-60 元） |
| DLC 扩展包 | 新增品类包、地图扩展、历史剧本（如"2008 金融危机"剧本） |

**关键原则：** 不出抽卡，不设体力限制，不卖数值。所有游戏内容通过买断和 DLC 获取。

## 十、落地路径

### 10.1 MVP（V1.0）

第一阶段完整可玩（供应链阶段）+ 1 个目标市场（美国）+ 3 个品类（电子/服饰/配件）+ 基础物流系统。

核心循环打通：玩家前 30 分钟内完成选品→采购→发货→上架→出单→再投资闭环。

### 10.2 后续迭代

| 版本 | 新增内容 |
|------|---------|
| V1.1 | 第二阶段（品牌系统）+ 更多品类 + 独立站渠道 |
| V1.2 | 第三阶段（地缘博弈）+ 更多目标市场（欧洲/东南亚/非洲） |
| V1.3 | 跨国并购 + 金融工具 + 完整数值平衡 |
| V1.4 | 随机事件 + 周期事件 + 成就系统 |
| V2.0 | 历史剧本 + DLC 系统 |

### 10.3 第一步验证

**最关键假设：** 玩家愿意为"中国企业出海"这个现代商业题材买单。

**验证方法：** 做一个可玩原型（第 1-2 年供应链阶段，3 个品类，1 个目标市场），邀请模拟经营玩家试玩。关键指标：是否愿意玩第二遍 + 是否理解核心循环。

---

## 十一、风险与预期反馈

| 预期槽点 | 应对方案 |
|---------|---------|
| "和 Business Tour / 大富翁差不多" | 三阶段引擎 + 真实商业决策深度是核心差异 |
| "不如直接做跨境电商" | 游戏简化和抽象了真实业务，保留核心策略快感 |
| "第三阶段太复杂" | 分阶段解锁，玩家逐步上手，不一次性给全部信息 |
| "缺乏画面表现力" | 2D 地图 + 数据面板的信息可视化本身就是策略游戏的视觉语言 |
| "后期无聊" | 三阶段转换 + 随机事件 + 地缘博弈保持新鲜感 |

---

## 十二、边界声明

| 不做 | 原因 |
|------|------|
| 3D 写实画面 | 2D 地图+数据面板更清晰，降低开发成本 |
| 实时多人对战 | 单人策略经营体验，不对标 MMO |
| 真实企业/品牌名称 | 使用虚构品牌和供应商，避免侵权 |
| 模拟"灰色清关"等违规操作 | 游戏合规，不做规避法律的玩法 |
| 金融投资/股票投机 | 聚焦实业经营而非金融投机 |
| 移动端首发 | 信息密度高，优先 PC/桌面 Web |
| 内购抽卡/体力限制 | 买断制+DLC，不以强迫付费为设计导向 |
