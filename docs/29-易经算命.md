# 易经算命 — 产品功能说明书

## 一句话定义

基于《易经》六十四卦的手动起卦工具——用户逐爻选择阴阳，系统自动识别卦象并给出卦辞爻辞解读，让古老智慧以可交互的方式触达现代人。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：对传统文化感兴趣、做决策前寻求参考的年轻人（20-40 岁）**

| 维度 | 描述 |
|------|------|
| 传统文化态度 | 对易经感兴趣但觉得门槛高、读不懂古文 |
| 当前做法 | 上网搜"今日运势"（太浅）、找人算命（不信任）、买书自学（半途而废）|
| 使用场景 | 做重要决定前、心情迷茫时、对易经好奇学习时 |
| 底层需求 | 一个低门槛、不忽悠的易经体验入口 |

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 易经有文化价值但入门门槛极高（古文+阴阳+八卦） |
| **刚需** | 市场上的"算命"产品要么太玄要么太娱乐，缺少尊重经典的 |
| **改善型** | 年轻人对传统文化有好奇心但缺少可交互的体验入口 |
| **改善型** | 面临选择时想要一个"帮自己想清楚"的参考工具 |

---

## 二、解决方案与核心功能

### 2.1 解决方案概述

用户手动逐爻选择阴阳（从初爻到上爻），可标记动爻（0-6 个），系统自动匹配六十四卦，展示本卦/变卦/动爻的卦辞爻辞原文与白话释义。输入选填的"所问之事"可获得语境提示。

### 2.2 核心功能清单

1. **手动起卦** — 逐爻选择阴阳，共 6 次选择
2. **动爻标记** — 标记 0-6 个动爻，生成变卦
3. **卦象识别** — 6 爻组合自动匹配六十四卦
4. **本卦解读** — 卦名、卦符、卦辞原文+白话
5. **变卦解读** — 有动爻时额外显示变卦信息
6. **爻辞解读** — 动爻对应的爻辞原文+白话
7. **问题关联提示** — 结合用户填写的问题给出语境提示
8. **历史记录** — 保存每次起卦完整信息
9. **卦象浏览** — 自由浏览六十四卦全表
10. **时间起卦/数字起卦** — 辅助起卦方式

## 三、竞品与差异化分析

| 对比项 | 易经算命 | 传统算命 App | 周易书籍 | 在线随机卦象 |
|--------|---------|------------|---------|------------|
| 手动选爻 | **是，全过程透明** | 自动生成不透明 | 手动操作 | 一键随机 |
| 解读深度 | **卦辞爻辞原文+白话** | 商业化解读 | 原文需自学 | 浅层 |
| 动爻变卦 | **完整支持** | 部分支持 | 需自行推演 | 不支持 |
| 权威性 | **引用《周易》原文** | 二次加工 | 权威 | 无 |

**差异化优势：** 手动逐爻选择（有参与感）+ 严格引用原文（不忽悠）。

## 四、架构总览

```
用户层
 ├── 起卦界面 —— 逐爻选择阴阳（初爻→上爻）
 ├── 卦象展示 —— 卦名/卦符/卦辞/爻辞可视化
 └── 历史记录 —— 过往记录浏览

核心层
 ├── 起卦引擎 —— 接收 6 爻输入，组装本卦
 ├── 变卦引擎 —— 动爻翻转生成变卦
 ├── 卦象匹配器 —— 映射到六十四卦
 ├── 解读生成器 —— 输出对应卦辞爻辞
 └── 卦辞库 —— 64 卦完整数据

数据层
 ├── 六十四卦数据（卦名/卦符/卦辞/爻辞/白话）
 ├── 用户起卦记录（问题/爻选/动爻/解读）
 └── 用户偏好（起卦方式/显示偏好）
```

## 五、核心模块详解

### 5.1 起卦模块

手动选爻：初爻→二爻→...→上爻（从下到上），进度条显示。可选时间起卦（日期时间自动算爻）和数字起卦（3 组数字转 6 爻）。

### 5.2 动爻与变卦

动爻数量决定解读重点：

| 动爻数 | 解读规则 |
|--------|---------|
| 0 | 静卦，只看本卦卦辞 |
| 1 | 本卦变爻爻辞为主，参考变卦 |
| 2 | 以两变爻爻辞为主，以上爻为主 |
| 3 | 本卦+变卦卦辞并重 |
| 4 | 变卦中不变爻的爻辞为主，以下爻为主 |
| 5 | 变卦中唯一不变爻的爻辞为主 |
| 6 | 引用用九/用六，否则以变卦卦辞为主 |

### 5.3 解读层级

卦名+卦符 → 卦辞原文 → 卦辞白话 → 大象辞 → 变卦信息（有动爻）→ 爻辞原文+白话（有动爻）→ 问题关联提示（填了问题）。

## 八、落地路径

### 8.1 MVP

手动逐爻起卦 + 64 卦完整数据 + 本卦解读（卦名/卦符/卦辞原文+白话）+ 动爻标记 + 变卦生成。

### 8.2 第一步验证

**最关键假设：** 有人愿意用"手动选 6 次爻"这种稍麻烦的方式来起卦。

**验证方法：** 做 MVP 页面，不推广，跟踪日活和完成率。如果完成率 > 40%（即开始起卦的人中超 40% 完成全部 6 爻选择），说明用户对流程的接受度成立。

## 九、风险与预期反馈

| 预期槽点 | 应对方案 |
|---------|---------|
| "为什么不自动生成" | 手动选爻是仪式的核心——你的参与很重要 |
| "这不算真正的算命" | 定位是传统文化体验手册，不是天命预测 |
| "看不懂古文" | 默认显示白话释义，一键切换原文 |
| "凶卦怎么办" | 释义强调转化之道，不制造焦虑 |

## 十、边界声明

| 不做 | 原因 |
|------|------|
| 八字/紫微斗数/风水 | 定位仅在易经卦象 |
| AI 实时生成卦辞解读 | 使用《周易》原文，保证权威性 |
| 严肃命理预测 | 传统文化体验+决策辅助 |
| 付费墙 | 所有数据完全开放 |
| 用户数据云端分析 | 数据仅存本地 |
| 社交功能 | 算命是个人体验 |
| 推送通知 | 不主动推送，用户需要才来 |
