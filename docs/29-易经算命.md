# 易经算命 — 产品功能说明书

## 一句话定义

基于《易经》六十四卦的手动起卦算命工具——用户逐爻选择阴阳，系统自动识别卦象并给出卦辞爻辞解读，让古老智慧以可交互的方式触达现代人。

---

## 适龄建议

16岁以上

---

## 一、系统架构总览

```
用户层
 ├── 起卦界面 —— 逐爻选择阴阳，从初爻到上爻构建卦象
 ├── 卦象展示 —— 卦名、卦符、卦辞、爻辞的可视化呈现
 └── 历史记录 —— 过往起卦记录的浏览与回顾

核心层
 ├── 起卦引擎 —— 接收用户 6 爻输入，组装为本卦卦象
 ├── 变卦引擎 —— 根据用户标记的动爻，翻转阴阳生成变卦
 ├── 卦象匹配器 —— 将 6 爻组合映射到六十四卦数据库
 ├── 解读生成器 —— 根据本卦/变卦/动爻组合，输出对应卦辞爻辞
 └── 卦辞库 —— 六十四卦的卦名、卦符、卦辞、爻辞完整数据

数据层
 ├── 六十四卦数据 —— 每卦的卦名、卦象符号、卦辞原文、白话释义、六条爻辞
 ├── 用户起卦记录 —— 时间、问题、六爻选择、动爻标记、解读结果
 └── 用户偏好 —— 常用起卦方式、显示偏好（原文/白话）
```

---

## 二、核心功能清单

1. **手动起卦** — 用户逐爻选择阴阳（共 6 爻），从下往上（初爻→上爻）构建完整卦象
2. **动爻标记** — 用户可标记 0~6 个爻为"动爻"，动爻阴阳翻转后生成变卦
3. **卦象识别** — 根据 6 爻组合自动匹配六十四卦中的对应卦
4. **本卦解读** — 显示卦名、卦象符号（☰☷☵☲☳☴☶☱）、卦辞原文、白话释义
5. **变卦解读** — 有动爻时，额外显示变卦的卦名、卦符、卦辞
6. **爻辞解读** — 有动爻时，逐条显示动爻对应的爻辞原文及白话释义
7. **起卦问题输入** — 用户可选填心中所问之事，解读时会结合问题给出语境化提示
8. **历史记录** — 保存每次起卦的完整信息，支持回溯浏览
9. **卦象浏览** — 不占卜时，可自由浏览六十四卦全表，当作易经知识库使用

## 三、模块详解

### 3.1 起卦模块

#### 3.1.1 起卦方式

本产品采用**手动逐爻选择**方式，模拟古代铜钱起卦的数字化版本。

| 起卦方式 | 说明 |
|---------|------|
| 手动选爻（默认） | 用户逐爻点击选择阴阳，共 6 次选择，从初爻到上爻 |
| 时间起卦 | 根据当前日期时间自动计算 6 爻（可选辅助方式） |
| 数字起卦 | 用户输入 3 组数字，系统转换为 6 爻（可选辅助方式） |

**手动选爻流程：**

```
第 1 步：选择初爻（最下方）
  [阳爻 ⚊] 或 [阴爻 ⚋]
  ↓
第 2 步：选择二爻
  [阳爻 ⚊] 或 [阴爻 ⚋]
  ↓
第 3 步：选择三爻（下卦完成）
  [阳爻 ⚊] 或 [阴爻 ⚋]
  ↓
第 4 步：选择四爻
  [阳爻 ⚊] 或 [阴爻 ⚋]
  ↓
第 5 步：选择五爻
  [阳爻 ⚊] 或 [阴爻 ⚋]
  ↓
第 6 步：选择上爻（最上方，上卦完成）
  [阳爻 ⚊] 或 [阴爻 ⚋]
  ↓
卦象生成 → 进入动爻标记阶段
```

#### 3.1.2 动爻标记

卦象生成后，用户可选择哪些爻为"动爻"（老阳变阴、老阴变阳）：

| 动爻数量 | 含义 |
|---------|------|
| 0 个动爻 | 静卦，只看本卦卦辞 |
| 1 个动爻 | 以本卦变爻爻辞为主，参考变卦卦辞 |
| 2 个动爻 | 以本卦两个变爻爻辞为主，以上爻为主 |
| 3 个动爻 | 参考本卦卦辞和变卦卦辞 |
| 4 个动爻 | 以变卦中两个不变爻的爻辞为主，以下爻为主 |
| 5 个动爻 | 以变卦中唯一不变爻的爻辞为主 |
| 6 个动爻 | 乾坤二卦用"用九""用六"，其余以变卦卦辞为主 |

#### 3.2.3 解读层级

| 层级 | 内容 | 触发条件 |
|------|------|---------|
| 卦名 + 卦符 | 卦的序号、名称、六爻符号 | 所有起卦 |
| 卦辞原文 | 《周易》卦辞文言原文 | 所有起卦 |
| 卦辞白话 | 卦辞的现代汉语释义 | 所有起卦 |
| 大象辞 | 《象传》中对该卦的整体评述 | 所有起卦 |
| 变卦信息 | 变卦的卦名、卦符、卦辞 | 有动爻时 |
| 爻辞原文 | 动爻对应的爻辞文言原文 | 有动爻时 |
| 爻辞白话 | 爻辞的现代汉语释义 | 有动爻时 |

## 六、产品边界与原则

### 6.1 产品边界

| 不做 | 原因 |
|------|------|
| 八字排盘 / 紫微斗数 / 风水堪舆 | 产品定位为易经卦象工具，不扩展至其他术数体系 |
| AI 实时生成卦辞解读 | 使用《周易》原文卦辞爻辞，保证内容权威性和一致性 |
| 严肃命理预测 | 定位为"传统文化体验 + 趣味决策辅助"，不做确定性预言 |
| 收费解锁高级解读 | 所有卦辞爻辞数据完全开放，不做付费墙 |
| 用户数据云端分析 | 起卦记录仅存储在本地，不上传服务器 |
| 社交功能（评论/点赞/排行） | 算命是个人体验，不做社交化 |
| 推送通知（"今日运势"等） | 不做主动推送，用户需要时才来 |

### 6.2 设计原则

1. **尊重经典** — 卦辞爻辞严格引用《周易》原文，白话释义标注"仅供参考"
2. **降低门槛** — 不需要用户懂易经，界面引导清晰，每一步都有说明
3. **不制造焦虑** — 即使是凶卦（如否卦、剥卦），释义也强调"转化之道"而非恐吓
4. **透明机制** — 用户始终能看到自己的 6 爻选择和动爻标记，理解卦象是如何得出的
5. **本地优先** — 所有数据本地存储，无需注册登录即可使用

## 七、卦辞数据说明

### 7.1 数据来源

卦辞、爻辞原文来自《周易》（亦称《易经》），成书于西周至春秋时期，属公共领域的中华传统文化经典。白话释义由编者参考多家注本（王弼、孔颖达、朱熹、南怀瑾等）综合编写。

### 7.2 数据结构

每卦存储以下字段：

```
{
  "id": 1,
  "name": "乾为天",
  "upperTrigram": "乾",
  "lowerTrigram": "乾",
  "symbol": ["⚊", "⚊", "⚊", "⚊", "⚊", "⚊"],
  "guaCi": "元亨利贞。",
  "guaCiPlain": "创始通达，适宜坚守正道。",
  "daXiang": "天行健，君子以自强不息。",
  "yaoCi": [
    { "position": 1, "text": "潜龙勿用。", "plain": "龙潜藏于深渊，不宜施展。" },
    { "position": 2, "text": "见龙在田，利见大人。", "plain": "龙出现在田野，利于拜见大人物。" },
    ...
  ]
}
```
