# 聚变时代 — 产品功能说明书

## 一句话定义

把每度电的燃料成本压到近乎为零的紧凑型核聚变装置——氘从海水取、锂从地壳取，输出覆盖电力、工业高温热、合成燃料原料和淡水，使之前被能源成本压制的产业在一代人之内全部解锁。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：政府电力规划部门、大型工矿企业、缺水地区的城市运营商、远洋/极地工程运营商**

| 维度 | 现状 |
|------|------|
| 当前工业电价 | 0.05-0.25 美元/度（地区差异极大） |
| 工业高温热成本 | 燃煤/气锅炉产 800-1500°C 热，占产品成本的 15-40% |
| 海水淡化能耗 | 反渗透 3-4 kWh/吨，北非/中东城市淡水成本中 60-75% 来自能源 |
| 绿氢成本 | 当前电解制氢 4-8 美元/kg，制约氢能经济的关键瓶颈 |
| 典型用户需求 | 不是要"更省电"，是要"电可以随便用"来打开新业务 |

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 碳排放约束下化石能源逐步退出，可再生能源受天气和土地制约不满足全天候/高密度需求 |
| **刚需** | 制铝/制钢/制水泥等高温工业无法靠间歇式绿电脱碳 |
| **刚需** | 海水淡化和大规模碳捕集因能耗成本过高而无法规模化 |
| **改善型** | 算力中心电费占比从 30% 降到 3% 以下后，算力部署不再考虑电价 |
| **改善型** | 绿色合成燃料（e-fuel）成本 > 5 美元/升，比石化燃料贵 10 倍以上 |
| **超前型** | 沙漠/极地/深海基地的能源自给依赖核裂变，但核裂变存在核扩散和废料风险 |

## 二、解决方案与核心功能

### 2.1 解决方案概述

聚变核心：把氘和氚加热到 1.5 亿°C 以上，等离子体在超导磁体的强磁场（> 6T）约束下发生聚变反应。14.1 MeV 中子穿透第一壁，被锂铅包层吸收，热量经换热系统发电（热电转换效率 45-50%）。燃料氚由锂 6 捕获中子在线增殖，实现自持闭环。终端的废热梯级利用驱动淡化和区域供热。单台机组净出力 50MW-2GW，可并列部署。

### 2.2 核心功能清单

1. **稳态聚变燃烧** — 等离子体维持运行 > 1 年/次，每年计划性停机维护 2-4 周
2. **功率连续可调** — 出力 10%-150% 范围内分钟级响应，追踪电网负荷
3. **多形态能量输出** — 同时输出电力、500-1000°C 工业高温热、中温蒸汽（< 300°C）
4. **燃料自持闭环** — 锂包层增殖氚，增殖比 > 1.15，外供仅需氘和锂
5. **废热梯级利用** — 热交换后排出的 70-120°C 余热驱动淡化/供热/吸收式制冷
6. **模块化快速部署** — 单台机组拼装周期 ≤ 30 天，支持多机并列和孤立电网独立运行
7. **全自动控制** — 从点火启动到稳态调节全流程AI辅助，值班人员负责监督而非操作

## 五、核心模块详解

### 5.1 等离子体约束腔

聚变反应发生在环向真空室内，等离子体温度约 1.5 亿°C（是太阳核心温度的 10 倍），由超导磁体系统悬浮约束不与器壁接触。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 真空保持 | 主真空室维持 10⁻⁵ Pa，排除杂质气体防止等离子体冷却 | 真空泵组+低温泵，每年钡铝吸气剂再生 1 次 |
| 等离子体点火 | 中性束注入（NBI，100keV-1MeV）+ 离子回旋加热（ICRH，20-80MHz）+ 电子回旋加热（ECRH，140-170GHz）三段接力加热至点火温度 | 启动需 50-200MW 外部供电，持续 10-30 分钟 |
| 磁约束维持 | 环向场 6T + 极向场 3T，托卡马克位形 / 仿星器位形 | 超导磁体（Nb₃Sn/REBCO）冷却至 4.5K，电流 40-80kA |
| 等离子体控制 | 实时反馈控制等离子体位形、密度（n_e = 10²⁰ m⁻³）、温度、电流（I_p = 15-20MA） | 破裂预测窗口 10-50ms，触发自动缓降保护 |
| ELM 抑制 | 边缘局域模（ELM）失控会周期性冲击偏滤器靶板，靠共振磁扰动线圈主动抑制 | 偏滤器峰值热通量 ≤ 10 MW/m² |
| 偏滤器 | 等离子体排气通道，导向靶板排出氦灰和杂质 | 钨铜组件，可更换设计，维护周期 3-5 年 |

**启动过程：**

```
抽真空（24h）→ 线圈励磁（2h）→ 注氘→ 欧姆加热预电离 → NBI+RF 加热（10-30min）
  ↓
等离子体达到 1.5 亿°C → 氘氚聚变开始 → 中子通量上升
  ↓
包层温度升至 350°C → 一回路启动 → 二回路预热 → 汽轮机升速
  ↓
达到并网条件 → 断路器合闸 → 出力爬升到目标值（全过程约 2-5 天）
```

### 5.2 燃料循环与氚自持

聚变炉消耗氘（D）和氚（T），反应 D + T → He⁴（3.5MeV）+ n（14.1MeV）。氚在自然界几乎不存在（半衰期 12.3 年），必须由锂 6 在反应中捕获中子在线增殖再生。

**氘的来源：**

海水含氘浓度约 33g/m³。每台 1GW 聚变炉年消耗氘约 100-150kg，对应需处理海水约 400-500 万吨/年。

| 步骤 | 工艺 | 说明 |
|------|------|------|
| 提氘 | Girdler 硫化物法 / 电解法 | 利用 HDO 与 H₂O 的化学势差逐级富集，能耗约 20-50 GJ/kg 氘 |
| 纯化 | 气相色谱 / 低温蒸馏 | 去除杂质气体，氘纯度 > 99.9% |
| 制丸 | 氘低温凝结为 1-3mm 冰丸 | 高速气动注入等离子体，注入速度 > 1 km/s |

聚变炉自备海水提氘单元，或由集中部署的氘工厂供料。

**氚增殖：**

| 功能点 | 说明 | 约束 |
|--------|------|------|
| 包层材料 | 液态锂铅（Li₁₇Pb₈₃）+ 中子倍增剂（铅） | 工作温度 350-600°C，磁流体动力学阻力需绝缘涂层 |
| 增殖反应 | Li⁶ + n → T + He⁴ + 4.8MeV | 天然锂中 Li⁶ 丰度 7.5%，增殖包层可浓缩至 30-90% |
| 增殖比 | TBR 设计值 1.15-1.25 | 必须 > 1.0 才能自持，考虑泄漏和衰变损失需 1.15 以上 |
| 氚提取 | He 吹扫气通过包层 → 膜分离（Pd/Ag 合金）→ 同位素分离（低温蒸馏）→ 注入储存 | 提取循环周期约 2-4 小时 |
| 初始加载 | 首次启动需外部供氚约 5-10kg | 可由 CANDU 重水堆或专用嬗变堆提供 |

**氚安全：**

氚是 β 放射源（半衰期 12.3 年），易渗透金属壁。设计中采用三层包容：包层结构壁 → 一回路边界 → 安全壳建筑。环境排放限值 ≤ 1 Ci/年。渗透至一回路的氚由氚清洗系统主动捕获。

### 5.3 能量转换系统

聚变功率的约 80% 以 14.1MeV 中子动能形式释放，穿透第一壁后在包层中减速转化为热；约 20% 以 3.5MeV α 粒子动能形式留在等离子体中，维持等离子体温度。

**一回路（锂铅包层侧）：**

| 参数 | 数值 |
|------|------|
| 包层入口温度 | 350°C |
| 包层出口温度 | 600°C |
| 工作介质 | 液态锂铅共晶合金 |
| 总热功率 | 1.1-2.2GW（热）（对应 500MW-1GW 电） |

**二回路（超临界 CO₂ 布雷顿循环）：**

| 参数 | 数值 |
|------|------|
| 循环类型 | 闭式布雷顿循环 |
| 压缩机入口 | 35°C / 7.5MPa |
| 涡轮入口 | 550°C / 20MPa |
| 热电转换效率 | 45-50%（对 600°C 热源） |
| 工质 | 超临界 CO₂（sCO₂，密度接近液体，流动性接近气体） |

sCO₂ 布雷顿循环的紧凑性（透平体积仅为蒸汽轮机 1/10）+ 无相变（避免湿蒸汽侵蚀）+ 低 GWP 工质，使它与聚变堆的高温输出天然适配。

**三回路（废热利用）：**

热交换后排出的低温热（70-120°C）约占总功率的 40-50%。这部分"废热"不再排入环境，而是进入梯级利用管网：

| 温度段 | 用途 |
|--------|------|
| 100-120°C | 多效蒸馏海水淡化（吨淡水耗热约 40-60kWhₜₕ） |
| 80-100°C | 区域供热管网 |
| 70-80°C | 吸收式制冷（溴化锂机组，COP 0.7-1.4） |
| < 70°C | 农业大棚 / 水产养殖 |

**废热全部利用时，综合能源利用率可达 90% 以上。**

### 5.4 终端适配

| 输出形态 | 规格 | 适配对象 |
|---------|------|---------|
| 高压电 | 110-500kV 三相，50/60Hz | 国家电网 / 微电网 / 独立工业区 |
| 中温蒸汽 | 250°C / 4MPa | 石化精馏 / 造纸 / 食品加工 |
| 高温热风/热气 | 500-1000°C 洁净空气或氦气 | 钢铁电弧炉 / 水泥回转窑 / 玻璃熔炉 |
| 淡水 | 反渗透+多效蒸馏混合，TDS < 200ppm | 城市供水 / 农业灌溉 |
| 绿氢 | 高温电解（SOEC，850°C，效率 > 85%） | 合成氨 / e-fuel / 氢冶金 |
| 合成燃料 | 氢 + 空气捕集 CO₂ → Fischer-Tropsch | 航空煤油 / 航运燃料 |

## 七、应用场景

### 场景一：沙漠钢铁城

**地点：** 沙特 NEOM 工业区  
**部署：** 2 台 1GW 聚变炉  
**配置：**

| 输出形态 | 分配比例 | 用途 |
|---------|---------|------|
| 电力 | 40% | 电弧炉炼钢（电炉 + 直接还原铁）、工厂照明、制氧 |
| 高温热（900°C） | 35% | 铁矿石直接还原（Midrex 工艺）、石灰石分解 |
| 余热制淡水 | 15% | 日产淡水 50 万吨，供应生活+绿氢制取 |
| 余电制绿氢 | 10% | 氢基直接还原铁取代焦炭，吨钢碳排放从 1.8 吨→0.1 吨 |

**结果：** 吨钢综合能耗成本下降 60%，钢铁生产成本低于当前全球最低（中国沿海钢厂）约 35%，且接近零碳排放。同时为城市提供全部淡水和部分电力。

### 场景二：碳循环工厂

**地点：** 冰岛（地热资源叠加聚变+空碳捕集）  
**部署：** 1 台 500MW 聚变炉  
**配置：**

运行流程：

```
聚变炉电力 + 高温热
  → 直接空碳捕集（Climeworks 式 DAC，吸附再生能耗 70% 由废热覆盖）
  → 高温电解制氢（SOEC 850°C，效率 85%+）
  → 氢 + CO₂ 经 Fischer-Tropsch 合成  →  航空煤油 (e-kerosene)
  → 年产合成航空燃油约 20 万吨（足够支撑一家中型航司全年需求）
  → 单位成本约 0.8-1.2 美元/升，与传统航油平价（传统航油含碳税后）
```

同时，高温电解联产氧气（用于工业）和工业级中温水（用于区域供热）。

### 场景三：远洋自持节点

**地点：** 太平洋公海，深海采矿作业平台  
**部署：** 1 台 150MW 紧凑型聚变包（船载 + 海水淡化 + 合成燃料）  
**配置：**

```
聚变包（150MW）
  ├── 推进/平台运行电力（50MW）
  ├── 海水淡化（30MW）→ 日产淡水 1 万吨（饮用水+工业用）
  ├── 空气 CO₂ 捕获 + 氢化制合成燃料（50MW）→ 备载燃料/补给船
  └── 余热区域供热 + 深海养殖（20MW，调节海水温度）
```

平台可连续运行 3-5 年不需外部补给（除锂锭每半年运一次）。独立于全球供应链的能源自给节点，为公海产业（深矿/远洋渔业/海基数据中心）提供基础设施底座。

## 八、经济模型

### 8.1 成本结构（以 1GW 聚变炉计）

| 成本项 | 占比 | 说明 |
|--------|------|------|
| 建造投资 | 70-80% | 超导磁体 + 真空室 + 包层+换热系统，初始投资约 30-50 亿美元 |
| 运维费用 | 10-15% | 每年度停机维护、偏滤器更换、包层轮换、人工 |
| 燃料成本 | < 1% | 海水提氘（规模效应后 < 0.1 分/度）+ 锂采购 |
| 退役基金 | 5-10% | 活化材料处置 + 场地复垦 |
| 综合度电成本 | **2-4 美分/度** | 含全部成本摊销，若 30 年折旧 + 5% 资金成本 |

**对比：** 中国煤电约 4-6 美分/度（含环保成本约 7-9 美分/度），光伏约 3-5 美分/度（但需 2-4 倍容量配储能）。

### 8.2 经济效应传导链

```
聚变度电成本 2-4 美分
  ├── 工业电价降至 3-5 美分 → 制铝/制钢成本降 30-50%
  ├── 工业热几乎免费 → 水泥/玻璃/化工成本降 20-40%
  ├── 淡水成本从 0.5-2 美元/吨 → < 0.1 美元/吨
  ├── 绿氢从 4-8 美元/kg → < 1 美元/kg
  ├── e-fuel 从 > 5 美元/升 → < 1 美元/升
  └── 余热免费 → 北温带城市供热成本降为现有 10-20%
```

这些传导效应的经济价值大约是聚变堆自身发电收入的 **10-50 倍**——用户的收益主要来自"用聚变电做的事"而非"卖电本身"。

## 九、风险与预期反馈

| 预期质疑 | 应对 |
|---------|------|
| "聚变永远在 30 年后" | 全球已有 5 台聚变装置达成 > 100MW 峰值功率（如 JET, TFTR），ITER 预计 2030s 实现 Q > 10。从实验到商用仍需突破材料与工程瓶颈，非实验室科学问题 |
| "第一壁材料撑不住" | 钨 + 碳纤维复合材料 + 液态壁方案的逐步验证中，首壁更换周期 3-5 年已进入工程可行区间 |
| "氚自持做不到" | TBR > 1.15 尚未在真实包层中验证，但这属于工程优化问题而非原理障碍——锂铅包层设计已有充分模拟和部分堆内测试 |
| "成本比裂变还贵" | 裂变堆建设成本同样高昂（Vogtle 3/4 两台 AP1000 造价 > 300 亿美元）。聚变优势在于燃料无限且无高放废料。造价随着批量制造可望下降（参照核电从 1970s 至今的建筑成本曲线，反方向主要原因是每次堆型不同；聚变若标准化则有望学习曲线下降 10-15%/翻倍） |
| "会不会爆炸" | 聚变堆不存在核裂变式的堆芯熔毁反应。等离子体密度极低（仅空气的百万分之一），一旦失控等离子体自动膨胀冷却，反应停止。没有爆炸风险，也没有裂变堆级别的灾难性放射性释放。安全壳设计应对的仅是氚泄漏防护 |
| "和可再生能源抢市场" | 互补而非替代——太阳能和风能仍有分布式和低边际成本的优势。聚变填补的是**稳定基荷+高温工业热**这个可再生能源无法覆盖的空白 |

## 十、边界声明

| 不做 | 原因 |
|------|------|
| 替代分布式屋顶光伏 | 屋顶光伏的低成本（1-3 美分/度，无输配电损耗）在终端用电场景仍有竞争力 |
| 单体功率 < 10MW 的微型化 | 聚变堆物理尺寸下限由等离子体约束决定，最小经济规模约 50MW |
| 瞬发启动/频繁启停 | 冷态到满功率 2-5 天，热待机重启 < 8h，不适合作为调峰资源 |
| 完全无辐射 | 中子活化产生放射性第一壁材料，需按中放废物处置（寿命约 50-100 年） |
| 人造太阳 | 不会模拟恒星内部引力约束机制。聚变炉是用磁约束在地球上实现受控热核反应 |
| 无限能源承诺 | 聚变能无限但设备、材料、物流、土地皆有限——能源不再稀缺，但资源稀缺性不会消失 |
