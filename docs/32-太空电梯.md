# 太空电梯 — 产品功能说明书

## 一句话定义

把每公斤物资的入轨成本从数万美元压到数百元，让人类像坐电梯一样日常往返天地之间。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：航天机构、商业航天公司、太空产业运营方**

| 维度 | 描述 |
|------|------|
| 当前成本 | 火箭入轨成本约 3000-50000 美元/kg |
| 核心瓶颈 | 一次性火箭占发射成本 > 70% |
| 现有运力 | 同步轨道任务单程数周/月 |
| 痛点 | 太空规模化开发受运力成本严重制约 |

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 当前入轨成本过高，太空经济难以规模化 |
| **刚需** | 卫星/空间站补给等待周期长，错过发射窗口需等数月 |
| **改善型** | 航天任务对火箭依赖过重，发射失败即任务失败 |
| **改善型** | 太空旅游业迫切需求低成本重复性天地往返 |

---

## 二、解决方案与核心功能

### 2.1 解决方案概述

太空电梯是一条从赤道海面锚站直通同步轨道配重的超强缆索，攀爬舱沿缆索往返运输。核心是用材料强度替代火箭推进——入轨成本从数万美元/kg 降至数百元/kg。

### 2.2 核心功能清单

1. **系绳锚定** — 赤道公海锚定主缆，延伸至同步轨道配重
2. **攀爬运输** — 攀爬舱沿缆索运输货物与人员，能耗远低于火箭
3. **能源中继** — 地面基站激光/微波输电，攀爬舱捕获驱动
4. **天地调度** — 中央中枢编排所有舱体，避免缆索共振与碰撞
5. **应急避险** — 强风/雷暴/空间天气时自动降速/停靠/脱困
6. **轨道中转** — 同步轨道中转站，换乘传统航天器前往深空
7. **成本结算** — 按载重与目标高度计费

## 三、竞品与差异化分析

| 对比 | 太空电梯 | 可回收火箭 | 传统一次性火箭 |
|------|---------|-----------|-------------|
| 入轨成本 | **数百元/kg** | 数千元/kg | 数万元/kg |
| 重复使用 | **极高（缆索寿命>20年）** | 高（10-100次）| 无 |
| 运输连续性 | **7×24 班次** | 窗口期限制 | 窗口期限制 |
| 技术成熟度 | TRL 3-4（材料瓶颈）| TRL 7-9（已商用）| TRL 9 |
| 能源来源 | **地面供电** | 自带燃料 | 自带燃料 |

**差异化优势：** 极致低成本 + 连续运输 + 地面供电（不携带燃料）。

## 四、架构总览

```
地面锚站（港口/海关/装载平台）
  ↓
主缆+备份缆（碳纳米管/金刚石纳米线）
  ↓
攀爬舱（货运舱 / 客运舱）
  ↓
在轨空间站（轨道中转/对接平台）
  ↓
配重（同步轨道外端，提供持续张力）

能源系统（地面激光/微波阵 → 舱载接收板）
调度中枢（路径规划/避碰/天气窗口管控）
```

## 五、核心模块详解

### 5.1 系绳与缆索材料

当前核心瓶颈。碳纳米管束目标比强度 30-60 GPa·cm³/g，金刚石纳米线更优但更远期。凯夫拉强度不足。均未连续万公里量产。

### 5.2 攀爬舱

货运舱载重数吨-数十吨，巡航 200km/h；客运舱载数十人，巡航 150km/h。均靠地面激光/微波输电驱动，不带燃料。可停靠任意轨道高度。

### 5.3 锚站与配重

赤道无台风公海海域锚站（可移动平台）。配重在同步轨道外端，质量 ≥ 缆索总质量。备份缆与主缆并行，独立锚定。

### 5.4 调度中枢

按高度分层航道（间隔 ≥ 50km），上下行错峰。最小安全距离 10km。风速超阈值或太阳风暴时暂停上行。

## 六、用户流程

```
预约班次 → 锚站装载 → 安检 → 攀爬舱上行
  ↓
途经各轨道高度（可停靠）→ 同步轨道中转
  ↓
下行返回 → 锚站卸载 → 按高度与载重结算
```

## 八、落地路径

### 8.1 技术里程碑（TRL）

- TRL 1-3：碳纳米管连续纺丝、激光输电效率、缆索动力学建模
- TRL 4-6：公里级缆索测试、低空攀爬舱原型
- TRL 7-8：近地小尺度电梯在轨演示
- TRL 9：同步轨道级主缆铺设，常态化运营

### 8.2 关键瓶颈

材料科学——当前碳纳米管连续长度和量产能力距万公里级主缆要求仍有代差。属远期工程，不承诺近期商用。

## 九、风险与预期反馈

| 预期质疑 | 应对 |
|---------|------|
| "材料做不到" | 当前确实做不到——框架设计以材料突破为前提 |
| "台风/雷暴怎么办" | 锚站选在赤道无台风公海，极端天气暂停运行 |
| "缆索断裂怎么办" | 备份缆独立锚定，单点断裂可降级运行 |
| "太空垃圾" | 中高轨道垃圾密度远低于低轨，持续监测+机动避让 |
| "不如用可回收火箭" | 互补关系——大推力深空发射仍依赖火箭 |

## 十、边界声明

| 不做 | 原因 |
|------|------|
| 替代所有火箭发射 | 大推力深空发射仍依赖火箭 |
| 载客深空直达 | 仅到同步轨道，深空需换乘 |
| 高纬/台风带锚定 | 安全风险不可控 |
| 近期商用承诺 | 材料与能源瓶颈属远期工程 |
