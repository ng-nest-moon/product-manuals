# Agent Stable 驯马师物语 — 产品功能说明书

## 一句话定义

> 像素风驯马管理游戏，通过养马→做装备→建马场→打联赛的四段式体验，向开发者与非技术人员科普 AI agent 从 vibe coding 到 harness engineering 再到 agent infra 的进化路径。

---

## 一、架构总览

```
游戏层
 ├── 第一章：荒野（vibe coding 阶段）
 │    ├── 指令输入系统
 │    ├── 马匹行为概率引擎
 │    └── 荒野任务线（3 个任务）
 ├── 第二章：铁匠铺（harness engineering 阶段）
 │    ├── 装备制作系统（4 类装备，3 品质等级）
 │    ├── 装备升级系统（错误经验驱动）
 │    ├── 现实对照卡片
 │    └── 进阶任务线（5 个任务）
 ├── 第三章：马场（agent infrastructure 阶段）
 │    ├── 建筑建造系统（6 种建筑，6×4 网格）
 │    ├── 资源管理系统（木/石，马匹产出）
 │    ├── 多马调度系统（最多 5 匹，3 属性）
 │    └── 自动化任务线
 ├── 第四章：联赛（ecosystem 阶段）
 │    ├── 赛马注册系统
 │    ├── 联赛竞技系统（3 轮，3 子项）
 │    ├── 联盟互联系统
 │    └── 交易市场
 └── 全局系统
      ├── 驯马师手册（概念图鉴）
      ├── 悬浮现实对照卡
      └── 跨章数据继承
```

---

## 二、核心功能清单

1. **指令式驯马** — 玩家通过自然语言输入指令控制马匹行动，体验无工具约束下 AI 行为的不确定性
2. **装备制作与升级** — 在铁匠铺中打造缰绳、鞍具、马镫、眼罩四类装备，逐步提升马的可靠性和能力边界
3. **经营建造** — 在空地中规划并建造马厩、赛道、草料库、观赛台等设施，建设多马协作的基础设施
4. **联赛竞技** — 注册赛马参加多轮赛事，体验标准化竞争和生态互联
5. **概念图鉴** — 随游戏进度解锁"驯马师手册"，收录所有已解锁概念的解说

## 三、核心模块详解

### 3.1 第一章：荒野（vibe coding 阶段）

**职责：** 让玩家在无工具条件下体验自然语言控制的不确定性，建立对"需要更好工具"的认知缺口。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 指令输入 | 玩家在输入框中写自然语言指令，马匹执行 | 支持简体中文和英文输入；单条指令不超过 100 字 |
| 马匹行为概率 | 马匹对指令的响应包含三种结果 | 正确执行 60%、跑偏 20%、原地不动 20%；每个指令独立判定 |
| 荒野任务线 | 3 个固定任务：走到标记点、衔取物品、绕桩 | 任务按顺序解锁；每个任务完成后马匹"记忆"重置 |
| 挫败感阈值 | 同一指令连续失败 3 次后触发系统提示 | 提示语暗示"缺工具"而非"你没说清楚" |
| 章节通关 | 3 个任务全部完成 | 通关后触发老驯马师过场动画，解锁第二章 |

### 3.2 第二章：铁匠铺（harness engineering 阶段）

**职责：** 让玩家通过制作和升级装备，理解 harness 的四个核心维度：上下文、工具、反馈回路、防护栏。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 装备制作 | 在工作台消耗材料制作 4 类装备 | 每类装备有铁/钢/符文 3 个品质等级 |
| 缰绳（Reins） | 提升指令准确率 | 铁 +20%、钢 +35%、符文 +50% |
| 鞍具（Saddle） | 提升马匹同时承载的任务数 | 铁 1→2、钢 2→3、符文 3→4 |
| 马镫（Stirrups） | 马出错后自动触发修正 | 铁 1 次/任务、钢 2 次、符文无限次（冷却 2 回合） |
| 眼罩（Blinders） | 降低环境干扰对马的影响 | 铁 -20%、钢 -40%、符文 -60% |
| 装备升级条件 | 对应类型的错误经验累计达标后解锁 | 每类装备独立经验条 |
| 进阶任务线 | 5 个任务，复杂度递增 | 跨栏→送信→载货→救援→巡回 |
| 现实对照卡片 | 装备悬停显示概念说明 | 中英文名 + 一句话解释 + 现实示例 |
| 章节通关 | 4 件装备全部铁质 + 进阶任务线完成 | 通关后触发过场动画解锁第三章 |

### 3.3 第三章：马场（agent infrastructure 阶段）

**职责：** 让玩家从养一匹马升级到管理多匹马+基础设施，理解 infra 各组件的作用。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 空地场景 | 6×4 网格空地，玩家在上面放置建筑 | 每个建筑占 1×1 或 1×2 格 |
| 建筑列表 | 6 种功能建筑 | 消耗木料/石料；资源通过马匹执行任务产出 |
| 马厩（Stable） | 每座马厩容纳 +1 匹马同时工作 | 造 5 木；初始 1 座，最多 5 座 |
| 赛道（Track） | 允许马匹并行执行任务 | 造 8 石；每座 +1 并行槽位 |
| 草料库（Hayloft） | 马完成任务后保留部分记忆 | 造 6 木；每级 +1 记忆槽 |
| 观赛台（Obs Deck） | 查看马匹执行轨迹和耗时日志 | 造 10 石；解锁后出现详情面板 |
| 水槽（Water Trough） | 每回合自动回复马匹精力 | 造 3 木；+5 精力/回合 |
| 围栏（Fence） | 防止马匹随机跑出边界 | 造 4 木 |
| 马匹调度 | 为多匹马分配不同任务 | 每匹马有精力/熟练度/专精三个属性 |
| 自动化任务 | 任务可持续产出资源 | 任务类型决定产出（木料/石料等） |
| 章节通关 | 5 匹马同时稳定运作 + 资源自给自足 | 通关后触发联赛邀请过场 |

### 3.4 第四章：联赛（ecosystem 阶段）

**职责：** 展示 infra 成熟后生态层的机会——标准化、互通、竞争、交易。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 赛马注册 | 选择一匹马注册获得唯一编号 | 格式 ST-XXXX；注册后马名不可更改 |
| 联赛竞技 | 多轮比赛与预设 AI 对手角逐 | 3 轮制（初赛→复赛→决赛）；每轮含障碍/速度/负重三子项 |
| 联盟互联 | 与其他马场建立连接解锁外部任务 | 每个连接解锁 +1 外部任务槽；奖励高于场内任务 |
| 交易市场 | 买卖装备图纸和马匹 | 图纸用金币；马匹交易需双方有空闲马位 |
| 排行榜 | 记录联赛历史成绩 | 本地保存，不清除 |

### 3.5 全局系统

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 悬浮现实对照卡 | 悬停在装备/建筑上显示的科普卡片 | 中英文名 + 一句话定义 + 现实示例；不遮挡操作区域 |
| 驯马师手册 | 随时打开的图鉴界面，收录已解锁概念 | 按章节分类；图标灰色=未解锁；支持双语切换 |
| 跨章数据继承 | 装备/材料/马匹属性带入下一章 | 第二章装备在第三章继承给马；第一章不继承 |
| 中英双语切换 | 界面和手册内容在中文和英文之间切换 | 标题画面和暂停菜单中切换；即时生效 |

## 四、用户流程

```
开始游戏
  │
  ├─ 标题画面 → 选择语言 → 点击"开始"
  │
  ├─ 第一章：荒野
  │    输入指令 → 马匹响应 → 调整指令 → 3 个任务完成 → 解锁第二章

  ├─ 第三章：马场

  │    注册赛马 → 三轮竞技 → 联盟互联 → 体验交易

```

## 五、应用场景

### 场景一：开发者理解 harness

> 后端开发者刷到"harness engineering"看不懂。打完游戏，在铁匠铺里把缰绳从铁升级到钢、发现马准确率从 60% 涨到 80%——他懂了："原来 AGENTS.md 就是这个缰绳。"

### 场景二：非技术人员补 AI 认知

> 产品经理想搞懂 team 说的"agent infra"是什么。在游戏中建好马厩和赛道后发现，三匹马同时跑不建观赛台就看不到哪匹在摸鱼——她发朋友圈："理解了，agent infra 就是草料库和水槽，不建就转不起来。"

### 场景三：团队 onboarding

> AI 创业团队新人入职，老员工不用花一小时解释。新人打一遍游戏，半小时后全员有了 shared mental model。之后讨论时说"这里缺一副符文缰绳"而不是"我们需要优化 AGENTS.md 和 context window 的渐进式披露"。

## 六、边界声明

| 不做 | 原因 |
|------|------|
| 自由移动/角色行走 | 固定场景点击交互；30 分钟小品级体验不需要开放世界 |
| 马匹繁殖/遗传系统 | 超出科普范围，非教学机制的引入会稀释核心叙事线 |
| 在线多人/实时对战 | AI 脚本对手；聚焦单人体验 |
| 深度模拟经营 | 资源系统只做支撑科普的最小化设计 |
| 代码编辑器/真实编码 | 面向非开发者；所有操作通过点选和自然语言完成 |
| 持续运营/后续章节 | 一次性完整体验，不做免费增值或内购 |

### 8.2 第一章：荒野——关卡脚本

**场景视觉：** 暖黄色调的荒野，一条土路蜿蜒，远处有山丘轮廓。马站在画面中央偏左位置。右侧有 A、B、C 三个标记点（插着小旗的木桩）。

**固定布局（320×180 内部像素）：**

```
┌──────────────────────────────────────────────┐
│  [山丘]  [山丘]         [云]                  │
│                                              │
│    🐴                    ▲A 旗               │
│                          TARGET              │
│             🚩B                              │
│      🚩C                                     │
│                                              │
│ ┌────────────────────────────────────┐       │
│ │ > 去左边那根木桩旁边              │ [发送] │
│ └────────────────────────────────────┘       │
│ [任务进度：■■□□□ 走到A点]                    │
└──────────────────────────────────────────────┘
```

#### 任务一：走到标记点

| 字段 | 值 |
|------|-----|
| 目标 | 让马走到插旗的 A 点（屏幕右侧） |
| 初始状态 | 马在左侧，A 点在右侧 |
| 马行为 | 60% 正确走过去；20% 跑相反方向；20% 原地转圈 |
| 玩家挫败触发器 | 同一指令连续失败 3 次后弹出系统提示 |
| 系统提示文本 | "这匹马好像不太听使唤……光靠喊是不够的，但你先完成当前任务吧。" |
| 提示彩蛋 | 英文模式下提示: "This horse needs more than just voice. Hang in there." |

**成功判定：** 马的坐标到达 A 点周围 16px 范围内视为完成。

**NPC 对话（通关后弹出）：**

> **老驯马师（像素头像弹出）：**
> "马是好马，但你缺的不是嗓门——是家伙。"
> "往前走，谷里有间铁匠铺。"
>
> [画面渐黑 → 解锁第二章]

#### 任务二：衔取物品

| 字段 | 值 |
|------|-----|
| 目标 | 让马走到物品（一个包裹）处并衔起 |
| 物品位置 | B 点（屏幕左下） |
| 马行为 | 60% 正确走到并衔起；20% 走到但不衔；20% 走错方向 |
| 衔起判定 | 马在物品周围 16px 范围内停留 1 秒视为衔起 |

#### 任务三：绕桩

| 字段 | 值 |
|------|-----|
| 目标 | 让马按顺序经过 A→B→C 三个点 |
| 三点位置 | A(右)、B(左下)、C(右下) 呈三角 |
| 马行为 | 60% 正确走全程；20% 漏掉一个点后继续；20% 中途停下 |
| 记忆重置 | 完成一个任务后进入下一个，马的"上下文"清空，必须重新下达完整指令 |

**核心体验目标：** 玩家此刻应该开始感到"如果能记住我之前说过的就好了"。这个感受就是下一章的入口。

### 8.3 第二章：铁匠铺——关卡脚本

**场景视觉：** 铁匠铺内景，左侧是工作台（带铁砧），右侧是门通向外面（可以看到拴在外的马）。色调由暖黄转为铁锈橙。

**固定布局：**

```
┌──────────────────────────────────────────────┐
│  ┌───────┐                    [门→]          │
│  │ 工作台 │                                  │
│  │ ⚒铁砧 │   ┌──装备槽──┐  ┌──装备槽──┐    │
│  │ 材料：│   │ 缰绳：空 │  │ 鞍具：空 │    │
│  │ 木×12 │   └──────────┘  └──────────┘    │
│  │ 石×8  │   ┌──装备槽──┐  ┌──装备槽──┐    │
│  └───────┘   │ 马镫：空 │  │ 眼罩：空 │    │
│              └──────────┘  └──────────┘    │
│                                              │
│ [任务面板] 当前：跨栏  完成度：0/3           │
│ 马的状态：准确率60% 精力100%                 │
└──────────────────────────────────────────────┘
```

#### 装备制作流程

玩家进入铁匠铺后，老驯马师先给一段引导：

> **老驯马师：**
> "打造一副好缰绳，马就听你的了。"
> "材料在那边——去外面找找，有木头和石头。"

**四类装备制作参数：**

| 装备 | 铁质材料 | 铁质效果 | 钢质材料 | 钢质效果 | 符文材料 | 符文效果 |
|------|---------|---------|---------|---------|---------|---------|
| 缰绳 | 木×5 石×3 | +20% 准确 | 木×10 石×6 | +35% 准确 | 木×20 石×12 | +50% 准确 |
| 鞍具 | 木×4 石×4 | 2 任务并行 | 木×8 石×8 | 3 任务并行 | 木×16 石×16 | 4 任务并行 |
| 马镫 | 木×3 石×5 | 1 次修正/任务 | 木×6 石×10 | 2 次修正/任务 | 木×12 石×20 | 无限次(冷却2回合) |
| 眼罩 | 木×6 石×2 | 干扰-20% | 木×12 石×4 | 干扰-40% | 木×24 石×8 | 干扰-60% |

#### 装备升级经验表

| 当前等级 | 升下级所需"对应错误"次数 |
|---------|----------------------|
| 无→铁 | 制作即可，无需经验 |
| 铁→钢 | 该装备对应类型的累计错误 ≥ 5 次 |
| 钢→符文 | 该装备对应类型的累计错误 ≥ 12 次 |

**错误类型映射：**

| 装备 | 对应错误 | 现实映射 |
|------|---------|---------|
| 缰绳 | 马走错方向 | context 不够清晰——AGENTS.md 写清楚，agent 就不跑偏 |
| 鞍具 | 马无法同时处理多个指令 | tools 不够用——给 agent 更多工具才能并行 |
| 马镫 | 马犯错后不修正 | 缺少 feedback loop——错误要能自动捕获和修复 |
| 眼罩 | 马被环境干扰影响 | 缺少 guardrails——linter/type check 挡住干扰 |

#### 进阶任务线（5 个任务）

| 任务 | 描述 | 考核装备 | 环境干扰 |
|------|------|---------|---------|
| **跨栏** | 让马跳过 3 个栏杆 | 缰绳 | 无 |
| **送信** | 到 A 取信 → 送到 B | 缰绳 + 鞍具 | 风吹（干扰 +10%） |
| **载货** | 驮着货物走完路线 | 鞍具 + 马镫 | 重物压身，指令延迟 |
| **救援** | 穿越复杂地形找到目标并带回 | 缰绳 + 眼罩 | 飞鸟/野兔乱窜（干扰 +30%） |
| **巡回** | 按序访问 5 个点后返回 | 全部 4 件 | 全干扰模式 |

| 属性 | 范围 | 说明 |
|------|------|------|

| 金币 | 马执行"运输"任务产出 1-2/回合 | 第四章交易使用 |

#### 多马调度规则

1. 玩家可以在"结束回合"前为每匹空闲马分配任务
2. 任务并行数受赛道数量限制：1 座赛道 = +1 并行槽
3. 马匹总数受马厩数量限制：初始 1 座马厩 = 1 匹马
4. 马匹精力 ≤ 10 时强制休息，无法分配任务
5. 未建围栏时，马有 10% 概率在回合中随机跑出边界（丢失该回合产出）

#### 回合制流程

```
开始回合
  │
  ├─ 资源增长（建筑效果生效）
  │
  ├─ 玩家操作（不限顺序）：
  │    ├─ 建造/升级建筑
  │    ├─ 为马匹分配任务
  │    └─ 查看马匹详情（观赛台已建时）
  │
  ├─ 点击"结束回合"
  │
  ├─ 系统执行：
  │    ├─ 马匹执行任务（产资源 → 减精力）
  │    ├─ 围栏检查（未围栏时概率越界）
  │    ├─ 记忆衰减检查
  │    └─ 自动产出汇总
  │
  └─ 检查通关条件
```
