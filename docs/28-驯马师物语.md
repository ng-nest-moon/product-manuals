# Agent Stable 驯马师物语 — 产品功能说明书

## 一句话定义

像素风驯马管理游戏，通过养马→做装备→建马场→打联赛的四段式体验，向开发者与非技术人员科普 AI agent 从 vibe coding 到 harness engineering 再到 agent infra 的进化路径。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户两类：AI 开发者 + 与非技术人员合作的 AI 团队**

| 维度 | 描述 |
|------|------|
| 开发者 | 工作涉及 agent/writing code，但缺少对 harness/infra 层级的系统性认知 |
| 非技术人员 | PM/设计师/创始人，需要理解"agent infra"是什么但不关心代码细节 |
| 共同场景 | 团队 onboarding、跨职能对齐、自我认知补全 |
| 预期时长 | 约 30 分钟一次性体验 |

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | AI agent 开发的层级概念（vibe coding / harness / infra / ecosystem）缺少直觉化的表达方式 |
| **刚需** | 团队 onboarding 时每次都要花几小时讲这些概念 |
| **改善型** | 非技术人员对"agent infra"感到抽象和恐惧 |
| **改善型** | 科普内容要么太浅（短视频）要么太深（论文/文档） |

---

## 二、解决方案与核心功能

### 2.1 解决方案概述

像素风四章游戏，每章对应一个 AI agent 开发阶段。玩家驯马 = vibe coding，做装备 = harness engineering，建马场 = agent infrastructure，打联赛 = ecosystem 标准化。游戏机制本身就是比喻。

### 2.2 核心功能清单

1. **四章叙事** — 荒野(vibe coding)→铁匠铺(harness)→马场(infra)→联赛(ecosystem)
2. **指令式驯马** — 自然语言输入，马 60%/20%/20% 概率正确/跑偏/不动
3. **装备制作** — 4 类装备（缰绳/鞍具/马镫/眼罩），3 品质等级，对应上下文/工具/反馈/护栏
4. **马场经营** — 6 种建筑（马厩/赛道/草料库/观赛台/水槽/围栏），多马调度
5. **联赛竞技** — 3 轮赛制，每轮障碍/速度/负重三项目
6. **驯马师手册** — 游戏内概念图鉴，逐章解锁
7. **悬浮现实对照卡** — 悬停显示装备/建筑的现实 AI 概念映射
8. **中英双语** — 全程可切换

## 五、核心模块详解

### 5.1 第一章：荒野（vibe coding 阶段）

玩家输入自然语言指令，马匹 60% 正确/20% 跑偏/20% 不动。3 个任务：走到标记点、衔取物品、绕桩。同一指令连续失败 3 次触发提示"缺工具"。通关后解锁第二章。

### 5.2 第二章：铁匠铺（harness engineering 阶段）

4 类装备各自的现实映射：

| 装备 | 游戏效果 | 现实映射 |
|------|---------|---------|
| 缰绳 | 提升指令准确率（铁+20% 钢+35% 符文+50%）| AGENTS.md / context |
| 鞍具 | 提升并行任务数（1→2→3→4）| Tools / MCP |
| 马镫 | 出错自动修正次数 | Feedback Loop |
| 眼罩 | 降低环境干扰 | Guardrails / Linter |

升级条件：对应类型累计错误达到阈值（铁→钢需 5 次，钢→符文需 12 次）。

### 5.3 第三章：马场（agent infrastructure 阶段）

6×4 网格 + 回合制。6 种建筑各对应 infra 组件：

| 建筑 | 消耗 | 效果 | 现实映射 |
|------|------|------|---------|
| 马厩 | 木×5 | +1 马匹槽位 | Sandbox / Runtime |
| 赛道 | 石×8 | +1 并行槽位 | Orchestration |
| 草料库 | 木×6 | +1 记忆槽 | Memory / RAG |
| 观赛台 | 石×10 | 解锁详情面板 | Observability |
| 水槽 | 木×3 | +5 精力/回合 | Caching |
| 围栏 | 木×4 | 防马匹越界 | Permissions |

### 5.4 第四章：联赛（ecosystem 阶段）

赛马注册获取编号（ST-XXXX）。3 轮制初赛→复赛→决赛，每轮障碍/速度/负重三子项。联盟互联解锁外部任务（奖励 1.5-2.5×）。交易市场买卖装备图纸和马匹。

## 八、落地路径

### 8.1 MVP

像素风 + 四章骨架 + 每章最低可用关卡（荒野 3 任务/铁匠铺 1 件装备/马场 2 种建筑/联赛 1 轮）+ 手册基础条目。

### 8.2 第一步验证

**最关键假设：** 玩家玩完后能自发说出"原来 harness 就是给 agent 缰绳"这种类比。

**验证方法：** 做一版可玩的铁匠铺 demo（制作缰绳+1 个任务），找 10 个开发者和 10 个非技术 PM 分别测试。如果 > 70% 能在事后描述"缰绳≈AGENTS.md"，假设成立。
