# 庙算 — 产品功能说明书

## 一句话定义

用十三篇算出这仗该不该打，再用三十六计选出怎么脱身——算完它敢告诉你：这仗别打。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：25-40 岁，正卡在一个具体困境里、已经纠结了三个月以上的人**

| 维度 | 描述 |
|------|------|
| 处境 | 有一个明确的决定迟迟做不了：辞不辞、摊不摊牌、投不投、走不走 |
| 已做的事 | 搜过大量"要不要辞职""如何停止内耗"，问过朋友、看过书 |
| 得到的回应 | 情绪安慰、通用建议、"要看你自己想要什么" |
| 真实期待 | 一个能走完的判断流程，以及一个敢下结论的人 |
| 心理状态 | 不怕听到坏消息，怕的是绕圈的安慰 |
| 付费意愿 | 一个错误决定损失几万到几十万，愿意为"算清楚"付几百 |

典型用户不是"迷茫的年轻人"，而是**已经想了很多、但思路始终纠成一团的人**。他不缺信息，缺的是把信息组织成判断的结构。

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 面对重大选择时，手上没有一套能从头走到尾的判断流程 |
| **刚需** | 所有外部建议都停在"看你自己想要什么"，等于没有回答 |
| **刚需** | 没有人敢对用户说"这件事你别干了"，所以用户永远得不到否定信号 |
| **改善型** | 纠结太久产生决策疲劳，需要一个外部结构把思路钉住 |
| **改善型** | 想把一次推演留下来，三个月后回看当初算错在哪 |
| **猎奇伪需求** | 想找人替自己做决定——本产品明确不做 |
| **猎奇伪需求** | 想要一个预测吉凶的工具——本产品明确不做 |

关键区分：这款产品解决的是**决策流程缺失**，不是情绪问题，也不是信息不足。用户在别处能拿到安慰，在别处也能查到资料，唯独拿不到"算完之后的结论"。

## 二、解决方案与核心功能

### 2.1 解决方案概述

用户用自然语言描述困境，系统按十三篇的决策顺序把它拆成五个阶段、十三个追问。每个追问都要求用户给出**可比较的量**——不是感受，是数字或事实。

走完之后输出三项结论：**这仗该不该打、如果打在哪打、打到什么时候必须撤。**

设计原则只有一条：**只给流程，不给裁决；但流程走到"不若则能避之"这一步时，必须明确说出"别打"。**

### 2.2 核心功能清单

1. **困境立案** — 把"我很烦"逼成一句可推演的话：谁和谁在争什么、争到什么算赢、输的代价是什么
2. **五事七计打分** — 道天地将法五项各打 0-5 分，缺分的项直接标红，不看总分看短板
3. **力量对比测定** — 按十则围之、五则攻之、倍则分之、敌则能战、少则能逃、不若则能避六档定性，档位直接决定战法
4. **久战成本测算** — 算"日费千金"：这场仗每月烧掉多少时间、钱、心力，乘以已投入月数
5. **止损线设定** — 用户自己填"最多打多久"，系统到点强制复盘，不允许无限期拖着
6. **场域选择** — 按地形六种（通、挂、支、隘、险、远）判断该在哪个战场打，从哪里绕
7. **拒绝清单** — 四个"有所不"：哪条路不走、哪个机会不接、哪座城不攻、哪块地不争
8. **情绪合规检查** — 火攻篇自检：这个决定，等情绪过去还成立吗
9. **情报盘点** — 用间篇盘点：你的判断里多少是猜的，多少是问过当事人、查过数据的
10. **庙算报告** — 一页纸：得算几分、该不该打、用什么打法、撤退线在哪、下一步唯一动作
11. **不服备案** — 系统说"别打"而用户坚持要打时，改出"如果你一定要打"的次优方案，并记录这次不服
12. **回看校准** — 三个月后回看，逐条标记当初哪一步算错了，沉淀成个人判据偏差记录
13. **计层匹配** — 报告定性为"打"或"换场域再打"时，从三十六计里匹配可用招法，每招标注副作用
14. **用计红线** — 六条以第三方为代价的计永久排除，触碰即拦截并说明原因

## 三、竞品与差异化分析

### 3.1 同类替代品对比

| 竞品 | 优点 | 缺点 | 与本产品定位差异 |
|------|------|------|----------------|
| 通用 AI 对话 | 随时可用，共情好，能听懂复杂处境 | 没有固定流程，容易被情绪带跑，倾向输出"你可以的" | 本产品流程锁死，且允许输出否定结论 |
| 心理咨询 | 专业，能处理深层模式 | 周期长、单价高，不处理"这个具体决定该不该做" | 本产品不处理情绪，只处理判断 |
| 决策类书籍 | 框架成熟（《原则》《思考，快与慢》） | 需要自己往框架里套，套不动就放弃 | 本产品把框架变成填空，一步步推着走 |
| 朋友与长辈建议 | 快，且带立场关心 | 立场偏（怕你受伤、怕你后悔），系统性倾向劝稳 | 本产品无立场，只算力量与代价 |
| 塔罗 / 命理 App | 给确定性，体验顺滑 | 无因果，无法解释为什么 | 本产品每一条结论都可回溯到具体判据 |

### 3.2 差异化优势与护城河

**核心差异：唯一一个把"该不该打"当成可计算问题处理、并且允许输出"别打"的工具。**

第二个差异是**庙堂与战场分层**。市面上讲兵法谋略的内容大多把十三篇和三十六计混在一起讲，结果"该不该打"和"怎么打"纠缠不清——用户学完一堆计，反而更想打了。本产品把两本书严格分开：前面只判断，后面只给招法，顺序不可颠倒。

诚实评估护城河：**浅。**

十三篇是公版内容，判据设计也不难被抄，大模型一天就能复刻一个粗糙版本。真正的壁垒只有两处：

1. **性格壁垒** — "敢说别打"一旦立住品牌认知，中立型产品抢不走。用户来找它，恰恰是因为别处都在哄他。
2. **校准壁垒** — 回看数据会持续暴露用户自己的判据偏差（比如总是高估对手、总是低估成本）。这份个人偏差记录越积越厚，迁移成本越高，产品也越准。

这条护城河需要时间才能挖出来，短期只能靠内容立性格。

## 五、核心模块详解

### 5.1 困境立案

**职责**：把用户含糊的抱怨，压缩成一句可以被推演的话。

**核心流程**：用户自由描述 → 系统追问四件事 → 反复三轮直到能落成一句话。

立案句式固定为：**「我在 [场域] 里，和 [对手/阻力] 争 [具体的东西]，争到 [什么] 算赢，输了会失去 [什么]。」**

填不满这一句，说明困境本身还没成形，此时不进入推演。

| 追问 | 要逼出的东西 | 不合格的回答 |
|------|------------|-------------|
| 你在跟谁争 | 具体的人、组织、或某种结构性阻力 | "跟命运""跟自己" |
| 争的是什么 | 一个可指认的东西：岗位、额度、时间、决策权 | "争口气""争一个说法" |
| 什么算赢 | 可验证的终局状态 | "过得更好""被认可" |
| 输了丢什么 | 可计价的损失 | "丢面子" |

### 5.2 始计算筹 · 五事七计

**职责**：动手之前先算胜算，短板决定成败，不看总分。

| 五事 | 现代对应 | 打分依据 |
|------|---------|---------|
| 道 | 意义与人心 | 这件事你还信吗？身边有人真心支持吗？ |
| 天 | 时机与周期 | 现在是最佳时点吗？行业在涨还是在落？ |
| 地 | 场域与位置 | 你在这场竞争里的位置有利吗？ |
| 将 | 能力与品格 | 你的核心能力够吗？情绪稳定吗？ |
| 法 | 制度与流程 | 有章法吗？还是每次靠临场发挥？ |

**判定规则**：五项各 0-5 分。**任何一项 ≤1 分，直接判定"此处必败"**，不管总分多少。孙子的原话是"不知彼不知己，每战必殆"，短板不补，长板无意义。

### 5.3 谋攻定性 · 六档战法

**职责**：把力量对比换算成战法选择。这是全系统最硬的一步。

| 力量对比 | 战法 | 现代动作 | 系统语气 |
|---------|------|---------|---------|
| 十倍于敌 | 围之 | 全面碾压，一次解决 | 可以打，速决 |
| 五倍于敌 | 攻之 | 正面推进 | 可以打 |
| 两倍于敌 | 分之 | 分割对手注意力，各个击破 | 可打，但要设计 |
| 势均力敌 | 战之 | 只能硬碰，代价高 | 谨慎，先算成本 |
| 少于对手 | 逃之 | 换场域、换赛道、换时间 | **建议撤** |
| 远不如对手 | 避之 | 不接触，彻底绕开 | **明确劝退** |

**关键设计**：后两档必须正面输出"别打"。这是产品性格所在，也是它与所有"鼓励型"产品的分界线。孙子把"逃"和"避"写成与"围""攻"并列的正规战法，现代文化却把它污名化成失败——这一步要替用户把这个污名摘掉。

### 5.4 作战成本 · 久战阈值

**职责**：算清这场仗烧掉了多少，以及还能烧多久。

| 参数 | 计算方式 | 说明 |
|------|---------|------|
| 月耗 | 时间（小时/月）+ 金钱（元/月）+ 心力（1-5 级） | 三项分开记，不折算 |
| 已投入 | 月耗 × 已持续月数 | 这是沉没成本，只用于算清，不用于决定 |
| 剩余存量 | 你能承受的总量 − 已投入 | 诚实填，别乐观 |
| 久战阈值 | 剩余存量 ÷ 月耗 | 还能打几个月，系统直接算出来 |

**规则**：阈值一旦算出，写入止损线，到点强制复盘。**沉没成本不参与"要不要继续"的计算**，只参与"已经亏了多少"的记账——这一点必须在界面上用大字写明，因为用户最常犯的错就是"都投了三年了不能停"。

### 5.5 地形定场 · 该在哪打

| 地形 | 特征 | 现代对应 | 战法 |
|------|------|---------|------|
| 通 | 双方都能来去 | 开放竞争市场 | 先占高地，抢关键位置 |
| 挂 | 进去容易出来难 | 高投入低退出壁垒的领域 | 算清退路再进 |
| 支 | 对我不利，对他有利 | 对方的主场（他的公司、他的家族） | 不在此决战，引出来打 |
| 隘 | 狭窄，先占者得利 | 关键资源位、核心岗位 | 抢先 |
| 险 | 险要，易守难攻 | 技术壁垒、牌照、资历 | 有壁垒就守 |
| 远 | 距离远，补给难 | 跨行、跨城、跨语言 | 别打持久战 |

### 5.6 九变 · 拒绝清单

**职责**：逼用户写下不做什么。困境往往不是选择太少，而是全都想要。

四个必填项，每项都要落到具体：

| 问句 | 原文 | 填法示例 |
|------|------|---------|
| 哪条路我不走 | 途有所不由 | 我不走继续考公这条路 |
| 哪个机会我不接 | 军有所不击 | 我不接这个涨薪但要常驻外地的 offer |
| 哪个位置我不抢 | 城有所不攻 | 我不去争那个名义上的负责人 |
| 哪块好处我不要 | 地有所不争 | 我不要这次分红的优先权，换时间自由 |

### 5.7 火攻与用间 · 两道自检

**情绪合规检查（火攻）**

> 主不可以怒而兴师，将不可以愠而致战。怒可以复喜，愠可以复悦，亡国不可以复存，死者不可以复生。

一道题：**这个决定，等我情绪过去还成立吗？**

选"不成立"的，系统挂起 72 小时，不允许当天出报告。

**情报盘点（用间）**

> 先知者，不可取于鬼神，不可象于事，不可验于度，必取于人。

把用户的每条判断打上来源标记：亲眼看到 / 当事人说过 / 第三方转述 / 我自己推测。**推测占比超过一半时，报告结论全部标为"未经证实"，并提示先去问人。**

### 5.8 庙算报告

**职责**：把所有推演压成一页纸，一屏看完。

| 区块 | 内容 |
|------|------|
| 得算 | 五事得分 + 短板项，一句话结论 |
| 定性 | 力量对比档位 + 对应战法 |
| 成本 | 当前月耗、已投入、还能打几个月 |
| 判断 | **打 / 不打 / 换场域再打**，三选一，必须明确 |
| 下一步 | 只给一个动作，不给清单 |
| 撤退线 | 时间点 + 触发条件 |

报告不给"加油""相信自己"这类句子。结尾固定一行：**"以上是算出来的，不是感觉出来的。你可以不同意，但你得先算出另一个数。"**

## 六、三十六计 · 战场脱困招法

### 6.1 为什么单开一层

十三篇与三十六计不是同一本书。前者是春秋兵书，讲战略，追求"全胜"——不战而屈人之兵；后者成于明清坊间，作者不详，讲战术，追求"脱身"——三十六计走为上。

两者分工因此非常干净：

- 十三篇回答**该不该打**
- 三十六计回答**既然已经在打了、或者正在被压着打，怎么办**

产品若只有十三篇，能算出"这仗不该打"，但用户第二天还得走进那个办公室、还得面对那个人。他需要具体动作。这一层补的就是这一段。

### 6.2 收计标准

三十六计共六套：胜战计、敌战计、攻战计、混战计、并战计、败战计。原书混杂了大量权谋术，其中相当一部分以损人为前提。全收会把这个产品变成教人使坏的手册。

因此设三层筛选：

| 类别 | 处理 | 标准 | 举例 |
|------|------|------|------|
| **收** | 直接入库 | 靠自己脱身，不动第三方 | 走为上、金蝉脱壳、李代桃僵、假痴不癫、以逸待劳、釜底抽薪 |
| **限** | 改写后入库 | 需要对手配合，或有明显副作用，必须标代价 | 空城计→信息管理、反客为主→夺回议程、声东击西→分散注意力 |
| **不收** | 永久排除 | 以第三方为代价 | 借刀杀人、趁火打劫、上层抽梯、无中生有、笑里藏刀、隔岸观火 |

判定原则一句话：**这一计如果登在报纸上，用户会不会羞于承认？会，就不收。**

### 6.3 脱困八计

| 计 | 原文 | 现代招法 | 适用处境 | 副作用（必标） |
|---|------|---------|---------|--------------|
| 走为上 | 全师避敌，左次无咎 | 主动撤退，保住本金 | 力量悬殊、久战必亏 | 承担"半途而废"的舆论 |
| 金蝉脱壳 | 存其形，完其势 | 保持表面完整地退出 | 交接期、离职过渡 | 长期伪装消耗心力 |
| 李代桃僵 | 损阴以益阳 | 用小损失换大保全 | 必须二选一时 | 被牺牲的那部分会有怨 |
| 假痴不癫 | 宁伪作不知不为 | 该示弱时示弱，藏锋 | 新环境、被针对 | 长期示弱会被真的低估 |
| 以逸待劳 | 困敌之势，不以战 | 不主动消耗，等对方犯错 | 对方急躁、自己在恢复期 | 等待有窗口，错过即失效 |
| 釜底抽薪 | 不敌其力，而消其势 | 解决根本原因而非表面 | 反复出现的老问题 | 见效慢，中途看不出进展 |
| 反客为主 | 乘隙插足，扼其主机 | 夺回议程与节奏 | 长期被安排、被支配 | 会被视为越界 |
| 空城计 | 虚者虚之，疑中生疑 | 资源不足时的信息管理 | 硬实力不够但对方不确定 | 一旦被看穿，信用归零 |

**每一计都必须带副作用。** 只讲计不讲代价，就是把人从一个困境推进下一个困境。

### 6.4 用计红线

| 不收 | 原义 | 为什么排除 |
|------|------|-----------|
| 借刀杀人 | 借他人之手除去对手 | 把第三方当工具，且不可控 |
| 趁火打劫 | 趁对方危难取利 | 以他人灾难为机会，越界 |
| 上层抽梯 | 诱人深入再断其退路 | 主动制造他人绝境 |
| 无中生有 | 凭空捏造 | 建立在谎言上，无法收场 |
| 笑里藏刀 | 表面友善暗中下手 | 破坏信任基础，反噬最强 |
| 隔岸观火 | 坐视他人受损 | 不作为也是加害 |

产品性格在这里再延伸一步：**敢说"别打"，也敢说"这招不能用"。**

### 6.5 境界差：为什么三十六计必须排在后面

- 十三篇的最高标准是"不战而屈人之兵"——赢，但不打。
- 三十六计的最高标准是"走为上"——打不赢，就撤。

两者都指向少流血，但前者讲的是**如何不必进入战场**，后者讲的是**已经陷进去怎么出来**。

顺序不能颠倒。先判断该不该打，再决定怎么打。颠倒过来就会变成"手上拿着锤子，看什么都像钉子"——**学了一堆计的人，最容易把每件事都当仗打。**

## 七、用户流程

```
首次使用
  │
  ├─ ① 选一个卡住的事（可先看三个脱敏案例）
  │
  ├─ ② 困境立案 → 反复追问 → 落成一句话
  │        └─ 填不满 → 提示"这件事还没成形，先别算"
  │
  ├─ ③ 五事七计打分（每项 0-5，附打分依据）
  │        └─ 出现 ≤1 分 → 标红"此处必败"
  │
  ├─ ④ 力量对比定性（六档，选一档）
  │        └─ 落入后两档 → 弹窗"按兵法，此时该逃或该避"
  │
  ├─ ⑤ 久战成本与阈值（月耗 × 已投入 → 还能打几个月）
  │
  ├─ ⑥ 场域选择（六种地形，选当前战场）
  │
  ├─ ⑦ 拒绝清单（四个"有所不"必填）
  │
  ├─ ⑧ 两道自检（情绪合规 / 情报来源）
  │        └─ 情绪不过 → 挂起 72 小时
  │
  └─ ⑨ 出庙算报告 → 用户选"认"或"不服"
           ├─ 认 → 写入推演档案，设止损提醒
           └─ 不服 → 生成"如果你一定要打"的次优方案 + 记录不服
                    │
                    ▼
     ⑩ 计层匹配（结论为"打"或"换场域再打"时触发）
           ├─ 按处境匹配脱困八计（劣势脱身 / 僵持破局 / 资源不足 / 关系失衡）
           ├─ 每计必标副作用，逐条确认能否接受
           └─ 命中红线计 → 拦截并说明原因，不给替代方案

日常使用
  │
  ├─ 到止损线 → 强制复盘 → 重新推演一次
  ├─ 招法失效 → 回计层换一招，但结论不改
  ├─ 新困境 → 直接进 ②
  └─ 三个月后 → 回看校准 → 标记当初哪步算错
```

## 八、商业模式

### 7.1 定价区间

**订阅 39 元/月，或 199 元/年。单次深度报告 69 元。**

判断依据不是成本，是损失参照：用户面对的是辞职、分手、投钱这类决定，一次算错的代价通常以万计。199 元买一次"算清楚"，心理上属于保险支出，不是消费支出。

不做免费永久版——免费用户不会认真填"月耗"和"剩余存量"这类需要诚实面对的数字，填得敷衍，结论就没价值，反而砸口碑。首次推演可免费一次，够体验，不够依赖。

### 7.2 销售渠道

- **内容引流**：十三篇逐篇做现代解读，发在公众号与知乎。不写鸡汤，只写判据，比如"为什么'少则能逃之'是最被低估的一条"
- **案例传播**：脱敏的真实推演记录，展示"系统劝人别打"的完整过程，这是最有说服力的素材
- **不做投放**：这类低频高决策重量的产品，投放转化极差，且会拉来大量猎奇用户

### 7.3 盈利模式

| 收入 | 说明 |
|------|------|
| 订阅 | 主收入，解锁无限推演 + 回看校准 |
| 单次报告 | 一次性用户，69 元导出完整 PDF |
| 实体推演本 | 纸质的十三问填空册，定价 59，作为周边与礼品 |
| 不做 | 不做广告、不做数据售卖、不做付费"改命" |

## 九、落地路径

### 8.1 五大落地难点

| 难点 | 具体表现 | 应对 |
|------|---------|------|
| 用户不愿填量 | 想把感受当输入，一问"月耗多少"就烦 | 每个数字都给换算示例；允许"不知道"，但标为盲区 |
| 判据硬套 | 古文到现代量的映射容易失真，变成穿古装的问卷 | 每条判据必须有反例校验，宁可少一条，不硬凑 |
| "别打"激怒用户 | 一部分人会觉得被否定，直接卸载 | 不服备案承接情绪，同时记录不服，后续回看 |
| 低频留存差 | 一年只用三五次，订阅续费难 | 靠回看校准与拒绝清单沉淀制造日常价值 |
| 容易被复刻 | 大模型可直接生成粗糙版本 | 靠性格与校准数据，不靠功能 |

### 8.2 MVP 最小可行产品

**只做一件事：判断"要不要打"。**

砍掉：地形选择、九地定位、拒绝清单、回看校准、报告导出，全部不做。

保留：困境立案 + 五事七计 + 六档定性 + 久战阈值 + 一页结论。

形态甚至可以不是 App——一个网页表单 + 一段生成文本即可。验证周期两周，成本一个人力。

### 8.3 第一步验证

**最关键假设**：人愿意为"一个敢说别打的结论"付费，且填得下那些冷酷的数字。

**验证方法**：找 20 个正在纠结具体决定的人（不是泛泛迷茫的人），陪他们走完一遍，然后问一个问题——

> **"这个结论，你敢不敢照着做？"**

不问"有没有用"，不问"喜不喜欢"。只问敢不敢照做。

**通过标准**：20 人里 ≥8 人回答"敢"，且其中 ≥3 人愿意当场付 69 元。低于 8 人，说明判据还不够硬；没人敢照做，说明推演只是走了个形式。

## 十、风险与预期反馈

### 9.1 预期负面吐槽

| 吐槽 | 背后的真实问题 | 应对 |
|------|--------------|------|
| "这不就是让我自己想吗" | 期待被给答案，落差感 | 承认：它不给答案，它给算法。答案得你自己算 |
| "古文绕，看不懂" | 门槛高 | 每条配白话与填法示例，原典折叠 |
| "它说我别打，可我不甘心" | 最重要的一类反馈 | 出次优方案，并明说"这是次优，代价更大" |
| "三个月后我早忘了" | 无回访机制 | 止损线到点主动推送 |
| "填了半天结果模棱两可" | 判据输出不够硬 | 报告必须三选一，禁止"视情况而定" |

## 十一、边界与原则

| 不做 | 原因 |
|------|------|
| 不做情绪安抚与心理咨询 | 混进来会稀释判断的锐度，那是另一门专业 |
| 不做命理与吉凶预测 | 孙子明说"不可取于鬼神，不可象于事" |
| 不替用户做最终决定 | 只给流程和判据，最后一步必须用户自己迈 |
| 不评价道德对错 | 兵法只管胜负与代价，不管谁更正义 |
| 不做"如何变强" | 十三篇假设力量已给定，教的是在给定力量下怎么打 |
| 不收构陷型计谋 | 借刀杀人、趁火打劫一类以第三方为代价，会把被困者变成加害者 |
| 不做计谋大全 | 三十六计只收脱困型，不追求收全，收全就等于教人使坏 |
| 不服务团队与组织决策 | 第一版只做个人困境，组织决策另立产品 |
| 不提供无限期陪伴 | 它是一个回合，不是一段关系 |

## 十二、配置示例

### 三个典型困境的推演参数

| 参数 | 要不要辞职 | 要不要和上级摊牌 | 要不要继续副业 |
|------|-----------|----------------|--------------|
| 道（意义） | 4 — 已不信这份工作 | 2 — 只为出口气 | 5 — 真的想做 |
| 天（时机） | 2 — 行业在裁 | 1 — 他刚被上面压 | 3 — 还能撑半年 |
| 地（位置） | 3 — 有两年资历 | 1 — 他是评价你的人 | 4 — 有独门手艺 |
| 将（能力） | 4 — 技能可迁移 | 2 — 情绪不稳 | 4 — 手艺过关 |
| 法（章法） | 2 — 没存够六个月 | 1 — 没有筹码 | 3 — 没固定节奏 |
| 力量对比 | 五倍于敌 — 攻之 | 远不如 — 避之 | 倍于敌 — 分之 |
| 月耗 | 2 万 + 心力 4 级 | 心力 5 级 | 8000 + 每周 15 小时 |
| 结论 | **可打，但要先补"法"** | **别打，换场域** | **可打，先分割** |
| 计层招法 | 走为上 + 釜底抽薪 | 反客为主 | 李代桃僵 + 以逸待劳 |
| 副作用 | 承担"半途而废"的舆论 | 会被视为越界 | 被牺牲的那部分会有怨 |
| 下一步 | 存够六个月再递辞呈 | 不摊牌，先建立不可替代性 | 副业拆成最小可交付单元 |
