# 重新认识自己 — 产品功能说明书

## 一句话定义

让你用**别人的嘴**把自己说一遍，再让 AI 用**你自己的素材**把你演一遍——两个版本在台上当面对质，差出来的那部分，就是你从没见过的那部分自己。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：28-40 岁，正处于一段"说不清哪里不对"的关系里的人**

| 维度 | 描述 |
|------|------|
| 典型处境 | 伴侣说"你根本不在乎我"、下属说"你太强势了"、父母说"你变了"、朋友突然不再主动找你——但你自己真的没有那个意思 |
| 高频口头禅 | "我不是这个意思"、"我明明已经……"、"为什么每次都变成我的错" |
| 心理状态 | 有改变的意愿，但**归因总是落在对方身上**，绕不出来；隐约怀疑问题在自己，又不敢深想 |
| 已有尝试 | 做过 MBTI / 大五 / DISC，测完截图发朋友圈，三天后忘了；买过沟通类书籍，看完知道"要倾听"，回到现场照样吵 |
| 消费能力 | 愿意为一次心理咨询付费（¥400-1500），但嫌贵、嫌慢、更怕把最难堪的事说给一个活人听 |
| 决策触发点 | 一次具体的关系崩塌——吵架、离职、被拉黑、父母一句"算了" |

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 关系反复出问题、复盘时永远自洽。人对自己的解释天然是"善意版"的，靠自己永远看不到别人实际接收到了什么——这个盲区**无法自证，只能借外力** |
| **改善型** | 各类人格测评给的是类型标签（"你是 INFP"），和生活里具体那一句话、那一个表情对不上；用户要的不是"我是什么型"，是"我上次那句话她到底听成了什么" |
| **猎奇伪需求** | ① 想让 AI 夸自己一顿（那叫心理按摩，不叫认识自己）；② 想拿报告去证明自己是对的（这是把产品当武器，必须拦）；③ 想知道"对方到底怎么想我"（**不可能，也不需要**——你演的是你理解的对方，不是对方本人） |

**核心洞察：** 认识自己最大的障碍不是信息不足，是**你既当运动员又当裁判**。日记、复盘、自我觉察全都逃不开这个结构——而"别人的眼睛"这个变量，你自己生产不出来。

## 二、解决方案与核心功能

### 2.1 解决方案概述

不测你，**让你演**。

舞台上只有三方：

- **你** —— 不演自己，扮演"某个具体的人眼中的你"（你爱人、你下属、你三年没联系的大学室友）。你必须用他的记忆、他的语气、他对你的固定判断来说话
- **AI** —— 扮演**你**。它拿的是你自己给它的素材：你的自述、你的口癖、你承认过的反应模式
- **记录员** —— AI 的第二人格，全程不发言，只做一件事：标记哪两句"对不上"

机制的关键在**换嘴**。心理学上有个稳定的现象：一个人一旦被要求扮演他人，就会不自觉地把对方的误解、怨气和期待**完整地复述出来**——这份"别人对你的理解"，你在真实生活里永远听不到，因为没人敢说，也没人说得清。

当"你演的他人眼中的你"和"AI 演的你以为的你"开始对话，两边的细节会迅速分岔。而**每一处分岔，你都有话说**——"我不是这样的"。问题在于：AI 演你用的素材，是你自己十分钟前交给它的。

### 2.2 核心功能清单

1. **他者档案** — 把"谁眼中的你"做成一个可扮演的具体对象：关系类型、共同经历、口头禅、他对你的三个固定判断
2. **自我素材库** — AI 用 20 分钟访谈问出你的关键场景记忆；可选导入聊天记录 / 日程 / 决策日志（本地解析）
3. **AI 演你** — 用你的口癖、反应速度、回避点、防御机制建一个行为模型，替你和"他人眼中的你"对话
4. **剧本生成器** — 从真实冲突史里挑一个双方说法对不上的场景，写成三轮对质脚本：陈述 → 追问 → 反证
5. **盲区开关** — 单盲（你不知道 AI 拿了哪些素材）/ 双盲（AI 也不知道你在演谁）/ 复盘局（逐句重放）
6. **记录员** — 不参与对话，只标记分歧点，事后交分歧清单
7. **认知差六维分析** — 情绪基线差、意图—效果差、边界感差、自我评价差、关系一致性差、盲区强度
8. **分歧原声回放** — 逐句回放并标注：这句是你演的 / 这句是 AI 演的 / 这句是真实发生过的
9. **《他人使用说明书》** — 交付物一：告诉别人该怎么用你、别对你做什么
10. **《我自己反对的地方》** — 交付物二：你说"我不是这样"、但素材是你自己给的那些点
11. **真实关系小实验** — 报告结尾只给**一个**可执行动作，让你去真实关系里验一次，并回填结果

## 三、竞品与差异化分析

### 3.1 同类替代品对比

| 竞品 / 替代方案 | 优点 | 缺点 | 与本产品定位差异 |
|----------------|------|------|----------------|
| MBTI / 大五 / 16PF | 几分钟出结果、有社交货币、可分享 | 全部是**自评量表**——测的是"你希望自己是什么样"，不是别人接收到的你 | 本产品不用量表，用**行为素材 + 他人视角**做输入 |
| DISC / 盖洛普优势 | 有职场包装、企业采购成熟 | 输出的是类型标签，落不到"那一句话"上 | 本产品不给标签，只给**场景级分岔** |
| 心理咨询 | 深度最高、有专业兜底 | 贵（¥400-1500/次）、周期长、要向活人自我暴露 | 本产品是**低门槛预演**，不替代咨询，且对咨询师是可用的前置素材 |
| 日记 / 复盘 | 免费、私密、无门槛 | 没有反馈回路，**自己看自己永远自洽** | 本产品引入"他者"这个用户无法自我生成的变量 |
| 让朋友直说 | 最真实 | 没人敢说、代价高、说的人也不一定准 | 把"不敢说"变成"让 AI 替他说" |
| 通用大模型对话 | 便宜、随手可用 | 结构上只会顺着你——你越说"我不是这样"，它越同意你 | 三角色 + 双盲 + 记录员，**结构上不允许它顺着你** |

### 3.2 差异化优势与护城河

**差异化：** 竞品都在问"你是谁"，本产品在问"两个版本的你差在哪"。前者需要你如实回答（做不到），后者只需要你上台（做得到）。

**护城河深浅评估：**

- ❌ **单次剧场体验** —— 极易被复制。任何一家做 AI 伴侣的产品加两个角色就能模仿，这只是先发优势
- ✅ **他者档案的纵向积累** —— 同一段关系、不同剧本的历次报告会形成一条"认知差曲线"。曲线越长，用户看到的越不是一份报告而是一个人的变化史，**迁移成本随时间单调上升**
- ✅ **可信度资产** —— 用户愿不愿意交出真素材，取决于产品是否被证明"不会出卖我"。这是隐私口碑，无法用钱买
- ✅ **他者侧的网络效应** —— 当一个人被 3 个不同关系的人各录过一次"我眼中的你"后，他会开始邀请别人也来做；邀请链才是真正的增长引擎

## 四、架构总览

```
重新认识自己
 ├── 关系素材层（输入：谁眼中的你）
 │    ├── 自述访谈（AI 20 分钟问出关键场景记忆）
 │    ├── 行为切片（聊天记录 / 日程 / 决策日志，本地解析）
 │    ├── 他者录音（邀请 2-5 位不同关系者录「我眼中的你」）
 │    └── 关系图谱（该演谁：亲密 / 工作 / 家庭 / 泛交）
 │
 ├── 角色引擎层（把素材变成两个「人」）
 │    ├── 你-扮演器（把「他人视角」打包成扮演提示）
 │    ├── AI-扮演器（用你的素材还原「你」的行为模型）
 │    ├── 人格锚点（口癖 / 反应速度 / 回避点 / 防御机制）
 │    └── 记忆边界（AI 只能用你给的，不许凭空编）
 │
 ├── 剧场调度层（让对话撞出裂缝）
 │    ├── 剧本生成器（从真实冲突史里挑一个「对不上」的场景）
 │    ├── 三轮对质（陈述 → 追问 → 反证）
 │    ├── 盲区开关（单盲 / 双盲 / 复盘局）
 │    └── 记录员（不参与对话，只标记分歧）
 │
 ├── 差异检测层（找出「两个你」在哪分岔）
 │    ├── 情绪基线差（自认冷静 vs 实际冷感）
 │    ├── 意图—效果差（想表达 X vs 被接收成 Y）
 │    ├── 边界感差（你认为的玩笑 vs 对方记了三年）
 │    ├── 自我评价差（自评负责 vs 他人评价控制）
 │    └── 关系一致性差（在 A 关系里的你 ≠ 在 B 关系里的你）
 │
 └── 报告输出层
      ├── 他人使用说明书（别人该怎么用你）
      ├── 我自己反对的地方（你说不是、素材是你给的）
      ├── 分歧原声回放（逐句标注谁在说）
      └── 真实关系小实验（下一步只做一个动作）
```

## 五、核心模块详解

### 5.1 关系素材层

三通道输入，**从易到难**，允许用户只做第一条就开演。

| 通道 | 内容 | 难度 | 权重 |
|------|------|------|------|
| 自述访谈 | AI 用 5 个问题引导：最近一次争吵、你最不想承认的一次反应、别人夸你的话（你信吗）、你最常回避的话题、你希望别人怎么想你 | ★ | 40% |
| 行为切片 | 导入聊天记录 / 日程 / 消费记录，本地解析用户的话密度、回复速度、道歉频率、话题切换模式 | ★★★ | 35% |
| 他者录音 | 邀请 2-5 位不同关系者，各答 3 题："他最好的地方"、"他最让你累的地方"、"你有没有话憋着没说" | ★★★★★ | 25% |

**关系图谱**决定"该演谁"，这是产品使用顺序的核心算法：

| 关系类型 | 优先级 | 理由 |
|---------|-------|------|
| 长期伴侣 / 家人 | 最高 | 冲突最密、素材最多、用户最想解决 |
| 直接下属 / 上级 | 高 | 反馈最结构化、认知差最容易被量化 |
| 老友（1 年以上未联系） | 中 | 时间尺度最能暴露"你变了" |
| 泛交 / 陌生人 | 低 | 双方都没素材，不演 |

### 5.2 角色引擎层

**AI 演你**的质量判定只有一条标准：**像不像**。但这里有个反直觉的设计——**"不像"比"像"更有价值**。

| 机制 | 说明 |
|------|------|
| 人格锚点 | 从素材里抽取 4 类特征：口癖与用词习惯、反应速度（秒回 / 隔天回）、回避点（一提就转话题）、防御机制（辩解 / 沉默 / 反攻） |
| 记忆边界 | AI 只能使用素材中出现过的事实。**素材里没有的事，AI 必须说"我不知道"** ——这是防"AI 瞎编你的人生"的硬约束 |
| 校准反馈 | 前 3 轮对话中，用户可以随时标注"这不是我"。每次标注都立刻回写行为模型，并**记录在案**——因为这些标注本身就是盲区线索 |
| 反向盲测 | 生成 3 段"你的反应"（2 段来自你的真实素材、1 段由 AI 虚构），让你盲选哪段不是你。选错的那次，就是你对自己最不确定的地方 |

**你-扮演器**则给用户发一份"扮演卡"：这个人的身份、他和你共有的 3 段记忆、他对你的固定判断、他的口头禅。用户必须顺着这张卡说——**不能跳出来为自己辩解**，一辩解，剧场就散了。

### 5.3 剧场调度层

一场标准剧场 15-25 分钟，固定三轮。

| 轮次 | 形式 | 目的 | 记录员动作 |
|------|------|------|-----------|
| 第一轮：陈述 | 你（演对方）先开口说"你这个人最大的问题是……" | 逼你和盘托出对方对你的判断 | 标记 AI 认同 / 反驳 / 沉默的位置 |
| 第二轮：追问 | AI（演你）反问"那你当时为什么不直说？" | 让"对方视角"和"你的反应"正面相撞 | 标记双方情绪强度峰值 |
| 第三轮：反证 | 你举一个"我没那样"的具体反例，AI 用你的素材反驳 | 检验你举的反例站不站得住 | 标记反例被推翻的次数 |

**盲区开关：**

| 模式 | 你事先知道 | AI 事先知道 | 适用 |
|------|-----------|-----------|------|
| **单盲** | 知道你演谁，不知道 AI 拿了哪些素材 | 知道你给了什么 | 首次使用、求温柔（推荐默认） |
| **双盲** | 不知道 AI 的素材版本 | 不知道你在演谁 | 二次以上、求真实；认知差最大 |
| **复盘局** | 全知 | 全知 | 结束后单独一轮，逐句重放标注 |

**记录员**是产品的结构核心：它不参与对话，因此**不可能被说服**。它输出的是纯分歧清单——"第 6 句你说'我从来不催'，第 14 句 AI 引用你的原话'你怎么又没回我'，冲突。"

### 5.4 差异检测层

六个维度，每一项都由"分歧点"聚合而成，不做任何量表打分。

| 维度 | 定义 | 典型结论形态 |
|------|------|-------------|
| 情绪基线差 | 你自认的情绪基调 vs 别人接收到的基调 | "你觉得自己是冷静，别人收到的是冷" |
| 意图—效果差 | 你想表达的 vs 对方接收到的 | "你在解释原因，对方听到的是推卸" |
| 边界感差 | 你认为无所谓的 vs 对方记住的 | "你开过 3 次同样的玩笑，对方记了 3 年" |
| 自我评价差 | 你自评的词 vs 他人视角里出现的词 | "你自评负责，别人用的词是控制" |
| 关系一致性差 | 你在不同关系中的行为差异 | "你在下属面前和父母面前几乎是两个人" |
| 盲区强度 | 你标注"这不是我"的次数与位置 | "你 80% 的否认，都集中在'情绪'这一类" |

**盲区强度是全局指标**：一个人否认得越密集的地方，越不是他被冤枉的地方，而是他最没准备好面对的地方。

### 5.5 报告输出层

报告不是"你的性格分析"，是**两份说明文档 + 一次实验**。

| 交付物 | 内容 | 语气 |
|--------|------|------|
| 他人使用说明书 | 从他人视角写的操作手册：触发你的雷区、让你进入状态的方式、你需要的反馈形式、你容易误会的表达 | 中性、工具化，**像给人写的产品文档** |
| 我自己反对的地方 | 列出所有你标注过"这不是我"的点，附上**来自你自己素材的原话**作为对照 | 不下结论，只并置 |
| 分歧原声回放 | 逐句回放，标注三类颜色：你演的 / AI 演的 / 真实发生过的 | 纯记录 |
| 真实关系小实验 | 只给一个动作，例如"这周找那个人说一句'上次那件事，我想再听你说一遍'" | 行动导向 |

**情绪保护缓冲层（强制）：** 报告必须先说 3 条你已经知道的事实（建立信任），再说 1 条新的（有效冲击），**不允许连续输出 2 条以上新信息**。这是产品伦理的硬性约束，不可配置。

### 5.6 隐私与素材安全

| 机制 | 说明 |
|------|------|
| 本地解析 | 聊天记录 / 日程等行为切片在设备本地完成特征提取，只上传特征不传原文 |
| 可撤回 | 用户可随时删除任意一条素材，并立刻重算所有基于它的历史结论 |
| 不对外 | 报告仅本人可见。任何社交分享动作默认**关闭**，开启需二次确认（防"拿报告去对质") |
| 他者授权 | 他者录音必须由本人确认用途、可随时撤回，撤回后不再参与演算 |

## 六、用户流程

```
   首次使用（约 45 分钟）
       │
       ▼
   选一个关系对象（系统按关系图谱推荐优先级最高的那个）
       │
       ▼
   录他者档案（他是谁 · 你们共有的 3 段记忆 · 他对你的固定判断）
       │
       ▼
   AI 访谈我 20 分钟（素材通道一，必做）
       │
       ▼
   生成剧本（从你的真实冲突史里挑一个双方说法对不上的场景）
       │
       ▼
   开场对质 15-25 分钟（单盲模式：你演他，AI 演你）
       │
       ▼
   复盘局（逐句回放，看哪些句子对不上）
       │
       ▼
   拿报告（他人使用说明书 + 我自己反对的地方 + 一个真实关系小实验）

   日常使用（每月 1 次，10-30 分钟）
       │
       ▼
   换一个关系对象 / 同一个对象换一个剧本
       │
       ▼
   认知差曲线更新（同一维度跨月对比，看变化而不是看结论）
       │
       ▼
   回填小实验结果（做了 / 没做 / 什么反应）
       │
       ▼
   更新行为模型 → 下次剧场更准
```

**步骤说明：**

| 步骤 | 用户动作 | 产品机制 |
|------|---------|---------|
| 选对象 | 从关系图谱里挑 | 优先推荐"最近 3 个月有过冲突"的关系 |
| 录档案 | 填扮演卡 | 信息不足时降低 AI 反证强度，避免误伤 |
| 做访谈 | 回答 5 个问题 | 边聊边抽人格锚点，实时显示抽取进度 |
| 生成剧本 | 从 3 个候选里选 1 个 | 剧本必须来自真实事件，禁止虚构情境 |
| 对质 | 演出三轮 | 记录员全程标记，用户不可见（防表演） |
| 复盘 | 看回放标注 | 允许这一阶段标注"这句不是我会说的"→ 回写模型 |
| 拿报告 | 阅读 + 完成一个实验 | 强制情绪缓冲层；实验未回填则下次报告延后解锁 |

## 七、商业模式

### 7.1 定价区间

| 产品 | 价格 | 说明 |
|------|------|------|
| 首次体验（1 个关系对象 · 单盲 · 含报告） | ¥39 押金 | 完成后可退，或换第二份报告（防"顺手一玩"） |
| 单次剧场（含行为切片 / 多关系对象） | ¥49 - ¥99 | 对标一次心理咨询的 1/15，用户心理无痛 |
| 年费会员 | ¥199 / 年 | 含认知差曲线、他者档案维护、每月 1 场剧场 |
| 他人视角扩展包 | ¥29 / 人 | 邀请他者参与时的解锁费用（由邀请方支付） |

**定价逻辑：** 用户愿付的价格由"痛的程度"决定，不由成本决定。一次真实的关系崩塌，用户的心理价位区间是 ¥200-2000。把首单价压到 ¥39 是为了让它成为一个**可以随手做的动作**，而不是一个重大决定。

### 7.2 销售渠道

| 渠道 | 打法 |
|------|------|
| 小红书 / 抖音 | 主战场。内容即产品：发布"AI 演的我 vs 我演的我"对话片段，天然带戏剧冲突和评论区争吵 |
| 播客 / 情感类 KOL | 长内容深度种草，适合讲机制（"为什么你永远看不到别人眼中的你"） |
| 职场沟通垂类 | 切入"我到底给同事什么印象"这个更轻量、更少情绪风险的话题 |
| 企业 EAP 采购 | 团队版：一个小组互演，输出团队认知差图谱。客单价高、决策链短 |
| 心理咨询机构 | 作为咨询前的素材采集工具卖给咨询师，B 端渠道平摊 C 端获客成本 |

### 7.3 盈利模式

- **主收入**：单次剧场 + 年费订阅
- **增值**：他人视角扩展包、认知差曲线历史回看、团队版
- **摇摆收入**：与心理咨询机构的转介佣金（用户报告显示高情绪风险时的合规转介）
- **明确不做**：广告、把匿名化数据卖给第三方、社交攀比榜（会把产品变成"谁更懂自己"的秀场）

## 八、落地路径

### 8.1 落地难点

| 难点 | 具体表现 | 应对方向 |
|------|---------|---------|
| ① 他者视角冷启动 | 没人愿意录"我眼中的你"，尤其录缺点 | MVP 阶段**主动砍掉**他者录音，仅靠自述访谈也能跑通，他者侧作为 v2 增长引擎 |
| ② "像不像"没有判定标准 | 用户说"AI 演的不是我"，无法证伪 | 不做真实性判定，改做**共识度**：AI 的反应与你素材原话的一致率，可量化、可展示 |
| ③ 心理安全 | 演出来的"你"被否定，用户可能当场崩 | 强制情绪缓冲层、全程可暂停、报告延迟 24 小时解锁（给情绪降温期） |
| ④ 隐私 | 聊天记录是最敏感的数据，一次泄露即品牌死亡 | 本地解析 + 只传特征 + 可撤回重算，并把"不留原文"做成核心宣传点 |
| ⑤ 用户把报告当武器 | 拿去和伴侣对质，关系二次受损 | 报告带自用水印、分享默认关闭、页脚固定条款；把"别拿去对质"写进产品第一课 |

### 8.2 MVP

**唯一目标：验证"两个版本的自己对质，能不能让人说出一个他原本不知道的事实"。**

| 保留 | 砍掉 |
|------|------|
| 自述访谈（5 问） | 行为切片导入 |
| AI 演你 + 单盲对质 | 他者录音 |
| 记录员标记分歧 | 双盲 / 复盘局 |
| 一页纸报告（只做 3 个维度） | 认知差曲线、年费体系 |
| 文本交互 | 语音 / 视频 / 多人剧场 |

**成本估算：** 1 名全栈 + AI 编排逻辑，6-8 周；纯文本交互，无实时音视频，服务器成本可忽略。首轮内测 30 人，改造现有大模型 API 即可跑。

### 8.3 第一步验证

**最关键假设：** 人在扮演他人时，会说出自己平时不敢承认的东西，并且这个"说出来"是有价值的。

**验证方法：** 招 20 个"最近一次吵架说不清为什么"的人，每人收 ¥39 押金，免费跑一次单盲剧场。完成后当场只问 3 个问题：

1. 你有没有听到一句你从没意识到的事？（是 / 否）
2. 那句话是"你演的对方"说的，还是"AI 演的你"说的？
3. 你愿意为第二次（换一个关系对象）付 ¥49 吗？

**判断标准：**

| 指标 | 通过线 | 含义 |
|------|-------|------|
| 说出"从没意识到的事实" | ≥ 60% | 核心价值成立 |
| 愿意付第二单 | ≥ 35% | 有商业价值 |
| 要求删除记录 / 中途退出 | ≤ 15% | 心理安全可控 |
| 反馈"AI 演得完全不像" | ≤ 30% | 模型可用 |

三项以上不达标，说明问题不在交互而在机制——**"扮演他人"这个动作本身是否成立**，需要在做产品之前先被人肉验证一次（第一阶段甚至可以用真人主持剧场，不写代码）。

## 九、风险与预期反馈

| 预期吐槽 | 应对 |
|---------|------|
| "AI 演的我一点都不像我" | 这道反馈是**产品价值的一部分**：你否认得最激烈的那几处，恰恰是素材里原话最密的地方。报告会把这些否认点单独列出，并附你自己的原话——不辩解，只并置 |
| "这不就是让我自己骂自己吗" | 是，但是有结构的：素材是你给的，视角是你要的，AI 只负责让它们对上。不是你骂你，是**你演的别人**在说，AI 演的你在答 |
| "我会被这份报告伤害" | 三层保护：情绪缓冲层（先 3 条已知，再 1 条新）、24 小时延迟解锁、随时可删。产品宁可不给结论，也不让人崩 |
| "我拿报告去和 TA 对质总行吧" | 明确禁止。报告带自用条款水印，分享入口默认关闭。**用报告去证明自己是对的，正好是产品想治的病** |
| "只是个 GPT 套壳" | 结构完全不同：三角色、盲区开关、记录员不可被说服、分歧逐句标注。通用对话你越说"我不是这样"它越同意你，这是角色的结构性缺陷，不是提示词问题 |
| "演的是我理解的对方，不是我真正的对象" | 对，产品从不说"这是对方眼中的你"，只说"这是**你以为**对方眼中的你"。第一步就写明，避免误解 |
| "我演不下去 / 尴尬" | 允许随时暂停；提供"扮演卡"降低表演难度；也支持只写不说的文本模式 |

## 十、边界声明

| 不做 | 原因 |
|------|------|
| 心理诊断与治疗 | 不是医疗 / 咨询产品。不做任何诊断、不下量表结论、不输出病理化表述 |
| 评判关系里的对错 | 只描述认知差，不判定责任归属。谁对谁错不是这个产品能回答的问题 |
| 代表"对方"发言 | 剧场里的"对方"是你扮演的，是你理解的他们。产品永远不会声称自己知道别人怎么想 |
| 输出人格类型标签 | 不给"你是 INFP / 讨好型人格"这类标签。只给场景级分岔——标签不可证伪，分岔可以 |
| 代做真实沟通 | 报告必须落到一个真实关系里的小实验。不替用户发消息、不生成"和解话术" |
| 作为证据或社交素材 | 报告仅限自用，禁作争议证据，分享默认关闭。防止产品变为关系武器 |
| 使用未经同意的他人数据 | 涉及第三方的素材（他者录音 / 聊天记录）须对方确认，可随时撤回 |
| 追求"彻底认识自己" | 这个目标本身不成立。产品只承诺一件事：让你看到**两个版本的你之间的缝**，并且这个缝可以逐年变窄 |

---

*重新认识自己 — 不是把一个更真实的你挖出来，而是让你第一次听见，你演的你和别人收到的你，原来不是同一个人。*
