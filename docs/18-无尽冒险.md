# 无尽冒险 — 产品功能说明书

## 一句话定义

20 分钟的 RPG 讽刺短品，游戏和你一起把行业套路从头吐槽到尾，笑着关掉。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：玩过很多 RPG、对行业套路有共鸣的玩家**

| 维度 | 描述 |
|------|------|
| 身份 | 玩过 5+ 款 RPG 的老玩家 |
| 笑点 | 知道 RPG 的套路（新手村/垃圾装备/剧情注水/内购礼包）|
| 单次游戏时长 | 15-20 分钟，一次通关 |
| 底层心理 | 想找一个能"懂我"的游戏，陪我一起吐槽 |

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 玩家对 RPG 套路审美疲劳但找不到替代表达 |
| **刚需** | 缺少短平快的"吐槽向"游戏体验 |
| **改善型** | 玩家需要被"懂"的感觉——游戏比你还清楚你在想什么 |
| **改善型** | meta 元素在独立游戏中有稳定的受众 |

---

## 二、解决方案与核心功能

### 2.1 解决方案概述

无尽冒险是一个 meta 讽刺短品游戏。它完整模拟一个 RPG 的每个经典环节（标题营销→角色创建→新手引导→战斗→装备→内购→Boss→结局），但每个环节都以当面拆穿的方式消解套路。

核心设计：
- **无存档** — 20 分钟一次通关的设计逼你一次走完
- **每步拆穿** — 角色创建后告诉你"选什么都一样"，战斗第 4 回合出现"跳过"按钮
- **内购讽刺** — 商店卖"空气礼包"，弹窗轰炸你
- **结局 Meta** — Boss 直接问你"你想做什么？"，答案是关掉游戏

### 2.2 核心功能清单

1. **标题营销模块** — 营销文案逐条滚动 → 删除线划掉
2. **角色创建** — 12 种族 × 8 职业 × 20 背景 → 揭示选择无意义
3. **新手引导** — NPC 指路自己、任务再对话一次就完成
4. **战斗系统** — 自动推进回合制，第 4 回合出现跳过
5. **装备展示** — 传说武器攻击力 +1，史诗故事纯属虚构
6. **技能树** — 50 节点无用技能树，唯一有用的是"卸载本游戏"
7. **内购商城** — 限时礼包、弹窗轰炸、空气礼包（虚拟货币）
8. **最终 Boss** — 魔王直接提问引导玩家主动结束游戏
9. **制作人员名单** — 吐槽字幕 + 结尾彩蛋

## 三、竞品与差异化分析

| 竞品 | 优点 | 缺点 | 差异 |
|------|------|------|------|
| The Stanley Parable | meta 叙事巅峰 | 较长 | 无尽冒险 20 分钟一次通关 |
| Undertale | RPG 反套路 | 较长，需要多周目 | 无尽冒险短平快，单次体验完整 |
| 传统 RPG | 内容丰富 | 套路化，注水 | 无尽冒险拆解套路不注水 |

**差异化优势：** 20 分钟短平快 + 纯讽刺（不做正经内容）+ 当面拆穿。

## 四、架构总览

```
用户层
 ├─ 标题与营销模块（文案滚动 → 自毁）
 ├─ 角色创建模块（多组合选择 → 揭底反馈）
 ├─ 新手引导模块（NPC 对话 → 反套路任务）
 ├─ 战斗模块（回合制 → 跳过按钮）
 ├─ 成长展示模块（装备展示 → 技能树）
 ├─ 商业化展示模块（商店 → 礼包弹窗）
 ├─ 结局模块（最终 Boss → 制作人员名单）
 └─ 全局控制（场景推进 / 元文本注入 / 状态追踪）
```

---

## 五、核心模块详解

### 5.1 标题营销模块

标题画面逐条显示 6 条经典营销文案（"海量装备！无限重玩性！史诗剧情！"），每条显示后出现删除线特效划掉。背景 8-bit 交响乐播放至第 3 条时卡碟中断。

### 5.2 角色创建模块

12 种族 × 8 职业 × 20 背景故事（可无限刷新组合）。选择完成后弹出："六个种族、八个职业、二十个背景——一共 1,920 种组合。其实选哪个都一样，我们替你省了 3 秒。"

### 5.3 战斗模块

野怪史莱姆出现 → 玩家只能点「攻击」→ 第 4 回合右下角浮现小字"不想看了？" → 点击跳过："你早该按这个的。" → 不跳过打到胜利后提示："你升到了 2 级。但怪物也会升级。所以你其实没有变强。永远没有。"

### 5.4 技能树模块

50 节点技能树，名称为"脚趾灵活度 Lv.1""头发韧性 Lv.3"。唯一有用的节点在最远端——"卸载本游戏"。

### 5.5 结局模块

魔王登场，对话框："你打到这了。你杀了无数的怪。你穿了无数的装备。然后呢？你想做什么？" 选项 A"继续冒险"→ 空世界游荡 30 秒后自动结局；选项 B"关掉游戏"→ 制作人员名单 + 结尾彩蛋"续作开发中……逗你的。"

## 六、用户流程

```
标题画面（文案划掉）→ 角色创建（揭底）→ 新手村（反套路任务）
  ↓
战斗（第 4 回合跳过）→ 装备展示（攻 +1）→ 技能树（卸载按钮）
  ↓
商城（空气礼包）→ 最终 Boss → 选择关掉游戏 → 名单 → 退出
```

## 八、落地路径

全内容 ≈ 1-2 周开发周期。重点在文案打磨和节奏控制，技术实现极轻。不需要存档、联网、多语言。

## 九、风险与预期反馈

| 预期槽点 | 应对方案 |
|---------|---------|
| "太短了" | 20 分钟就是设计目标——短到没尿点 |
| "这不就是个玩笑" | 是的，这就是个玩笑——你笑了就对了 |
| "我花了 15 块钱就这？" | 定价 6-18 元，够低 |
| "没有可玩性" | 可玩性不是目标，"有趣"才是 |

## 十、边界声明

| 不做 | 原因 |
|------|------|
| 真实的程序生成 | 短品不需要 |
| 多结局分支 | 保证一致性体验 |
| 存档或进度保存 | 20 分钟不需要 |
| 联网或多人 | 纯单机 |
| 游戏内帮助 | 游戏本身在吐槽教程 |
| 真实支付渠道 | 空气礼包用虚拟货币 |
| 可玩性验证 | 目的不是好玩，是有趣 |
