# 无尽冒险 — 产品功能说明书

## 一句话定义

> 20 分钟的 RPG 讽刺短品，游戏和你一起把行业套路从头吐槽到尾，笑着关掉。

---

## 一、架构总览

```
用户层
 ├── 标题与营销模块
 │    ├── 宣传文案滚动
 │    └── 文案自毁机制
 ├── 角色创建模块
 │    ├── 多组合选择器
 │    └── 揭底反馈
 ├── 新手引导模块
 │    ├── NPC 对话
 │    ├── 任务系统
 │    └── 引导完成反馈
 ├── 战斗模块
 │    ├── 回合制战斗
 │    ├── 跳过机制
 │    └── 战斗反馈
 ├── 成长展示模块
 │    ├── 装备展示
 │    ├── 技能树展示
 │    └── 成长反馈
 ├── 商业化展示模块
 │    ├── 商店页面
 │    ├── 礼包弹窗
 │    └── 购买反馈
 ├── 结局模块
 │    ├── 最终 Boss 对话
 │    ├── 制作人员名单
 │    └── 真结局
 └── 全局控制模块
      ├── 场景推进控制
      ├── 元文本注入
      └── 状态追踪
```

---

## 二、核心功能清单

1. **标题营销** — 在标题画面滚动展示经典营销文案，随后逐条否定
2. **角色创建** — 提供多组合选择器，选择后揭示选择无意义
3. **新手任务** — 模拟经典 RPG 任务流程，以反套路方式完成
4. **战斗系统** — 自动推进的回合制战斗，第 4 回合开放跳过
5. **装备与技能树** — 展示一把高名低实的武器和一棵庞大的无用技能树
6. **内购商城** — 展示游戏内商店与限时礼包，允许购买虚拟空气
7. **最终 Boss** — Boss 直接向玩家提问，引导玩家主动结束游戏
8. **制作人员名单** — 吐槽向滚动字幕，包含彩蛋和隐藏信息

---

## 三、核心模块详解

### 3.1 标题与营销模块

**职责：** 展示游戏包装层面的"卖点"，然后当面拆穿

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 宣传文案滚动 | 标题画面逐条显示营销用语 | 文案池 6 条（"程序生成！海量装备！无限重玩性！史诗剧情！动态世界！玩家选择影响结局！"），每条显示间隔 1.5 秒，淡入淡出 |
| 文案自毁机制 | 每条文案显示后出现删除线特效 | 延迟 0.5 秒后从文案正中划一道红线，配"咻"音效；全部划完后屏幕碎裂特效过渡到下一场景 |
| 背景音乐 | 宏大的交响乐开场 | 音源为 8-bit 低质模拟；播放至文案第 3 条时卡碟直至中断，之后全游戏无声或仅用极简音效 |

### 3.2 角色创建模块

**职责：** 提供丰富的角色定制假象，然后揭露真相

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 种族选择 | 从 12 个种族中选择 | 包含常见种族及恶搞选项（"人类但戴了帽子"、"精灵但很困"）；滚动列表视觉效果完整，选中无反馈 |
| 职业选择 | 从 8 个职业中选择 | 每个职业附带一段夸张描述（"法师——可以搓出毁天灭地的火球，前提是你找到法力药水"） |
| 背景故事生成 | 从 20 个片段中随机拼接 | 点击"生成"可无限刷新，所有组合句式不同但语义相同 |
| 揭底反馈 | 选择完成后弹出总结对话框 | 文本固定："好的。六个种族、八个职业、二十个背景故事——一共 1,920 种组合。下面是你的最终角色：[随机名称]，[随机种族] [随机职业]。其实选哪个都一样，我们替你省了 3 秒。"此后自动推进 |

### 3.3 新手引导模块

**职责：** 模拟 RPG 经典新手流程，以反套路方式消解

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| NPC 对话 | 新手村 NPC 头顶感叹号，与之对话 | NPC 立绘为极简陋像素头；对话框打字机效果逐字输出；对话内容："勇者！请帮我消灭洞窟里的哥布林！……啊不对，你看这游戏哪有洞窟。你的第一个任务是——再和我说一次话。" |
| 任务标记 | 屏幕显示任务指引箭头 | 箭头在第一次对话时指向 NPC 自身；第二次对话后标记自动消失 |
| 任务交付 | 第二次对话后触发"任务完成" | 出现庆祝特效，音效为派对喇叭；NPC："恭喜！你现在已经是一个真正的冒险者了。让我们看看你还有什么其他本事。" |
| 引导完成反馈 | 场景过渡特效 | 画面闪烁后切换至战斗场景 |

### 3.4 战斗模块

**职责：** 呈现回合制战斗，然后鼓励玩家跳过它

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 战斗开始 | 野怪出现，屏幕震动 | 史莱姆占屏比 60%，像素抖动；上方面板显示双方 HP 和攻击力数值 |
| 回合制战斗 | 玩家回合选择动作，怪物回合自动行动 | 可用操作仅「攻击」按钮，技能按钮显示但置灰，标题"技能（升级后解锁）" |
| 敌我数值 | 玩家 HP:100，攻:10；史莱姆 HP:50，攻:8 | 每回合玩家输出 9~11，史莱姆输出 7~9；固定第 4 回合玩家 HP 降至 60 以下 |
| 跳过按钮 | 第 4 回合时右下角浮现小字"不想看了？" | 字体大小 10px，透明度 30%，鼠标悬停变为 100%；点击后游戏文本："你早该按这个的。"直接切至下一场景 |
| 不跳过路径 | 继续战斗直至胜利（第 6~7 回合） | 胜利后经验值条暴涨至溢出的动画，然后文本："你升到了 2 级。但怪物也会升级。所以你其实没有变强。永远没有。" |

### 3.5 成长展示模块

**职责：** 展示 RPG 成长系统的空洞本质

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 装备展示 | 获得一把"传说级武器" | 武器名称为"[形容词]之[名词]"模式（如"永恒烈焰之剑"、"虚空暗影之刃"）；展示页面包含剑的旋转动画、属性面板、一段史诗级背景描述 |
| 属性揭露 | 装备属性显示 | 攻击力 +1；背景描述结尾小字："（以上故事纯属虚构。）" |
| 技能树展示 | 展开一棵 50 节点的技能树 | 节点名称为无意义组合（如"脚趾灵活度 Lv.1"、"头发韧性 Lv.3"、"站立姿态优化 Lv.2"）；逐级解锁动画，每条加 0.5% 暴击率 |
| 技能树终末 | 唯一有用的节点在最远端 | 需要连续点击 30 次才可解锁；节点名称为"卸载本游戏"，点击后弹出确认对话框："你想好了？" |
| 确认卸载 | 确认后展示结局画面 | 是—跳转结局；否—返回技能树顶部，需重新拖动寻找该节点 |

### 3.6 商业化展示模块

**职责：** 展示游戏内购生态的荒诞性

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 商店页面 | 展示可购买商品列表 | 商品：经验加成包、幸运护符、传说装备箱、限时礼包（原价 ¥128，限时 ¥6）；每个商品配有 3D 旋转展示和打折倒计时 |
| 购买流程 | 选择商品 → 确认购买 → 支付 | 支付流程走通，显示支付成功动画和扣款（虚拟货币） |
| 空气礼包 | 一个特殊的免费商品 | 名称为"空气礼包"，描述："里面什么都没有。但我们花了 10 分钟做这个页面。" |
| 购买反馈 | 购买后效果展示 | 经验加成包 → "+1 经验值"浮动文字；幸运护符 → "幸运值 +0"；空气礼包 → "你已经拥有了一切。真的。"并扣除玩家虚拟货币余额至负数 |
| 弹窗轰炸 | 页面停留超 3 秒触发 | 弹窗内容："限时优惠！错过今天再等明天！"；关闭后 2 秒再次弹出："你真的忍心错过吗？"；之后不再弹出 |

### 3.7 结局模块

**职责：** 以 meta 方式结束游戏，让玩家带着微笑离开

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 最终 Boss 登场 | 屏幕剧烈震动，魔王降临 | 魔王外观为文字构成的巨大黑影；背景变为纯黑，仅魔王轮廓可见 |
| Boss 对话 | 魔王开口说话 | 文字逐字浮现；内容："你打到这了。你杀了无数的怪。你穿了无数的装备。然后呢？……你想做什么？" |
| 玩家回应 | 显示两个选项 | 选项 A："继续冒险"→ Boss："继续去哪？这里已经没有别的东西了。"; 选项 B："……关掉游戏"→ Boss："好主意。终于有人说到点子上了。" |
| 选项 B 后 | 屏幕渐暗，文字浮现 | "你通关了《无尽冒险》。外面天气不错。" |
| 选项 A 后 | 循环回到新手村 | 但所有 NPC 消失，背景音乐静默，仅一个路牌："你已经把这里的一切都看完了。"；30 秒无操作后自动触发结局 |

### 3.8 制作人员名单

**职责：** 以吐槽字幕结束全片

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 滚动名单 | 黑底白字向上滚动 | 包含制作人、策划、美术、程序、测试、特别鸣谢等条目，所有人员均为虚构名称（如"王建国（策划，同时也是美术、程序、测试）"） |
| 文案彩蛋 | 字幕中夹杂吐槽 | 如"感谢你玩到了这里。如果你真的玩到了最后，请发朋友圈证明自己是天选之人。" |
| 结尾彩蛋 | 名单结束后显示 | 大字："续作开发中。"停顿 2 秒后缩小变为小字："逗你的。" |
| 退出 | 点击任意处退出到桌面 | 或显示链接导向一个"请给本作写评价"的页面（实为一张猫的图片） |

## 四、用户流程

```
开始
  │
  ├─ 操作 1：启动游戏
  │    看到标题画面 → 营销文案逐条滚动 → 逐一被划掉 → 自动进入下一步
  │
  ├─ 操作 2：角色创建
  │    选种族 → 选职业 → 生成背景（可刷新）→ 系统替你决定 → 自动进入下一步
  │
  ├─ 操作 3：新手村
  │    和 NPC 对话 → 接任务 → 再对话一次 → 任务完成 → 自动进入下一步
  │
  ├─ 操作 4：第一场战斗
  │    史莱姆出现 → 自动进入战斗 → 每回合点「攻击」→ 第 4 回合出现跳过选项
  │    ├─ 点击跳过 → 自动进入下一步
  │    └─ 继续砍到结束 → 获得暗示"你没有变强"→ 自动进入下一步
  │
  ├─ 操作 5：成长展示
  │    获得神器 → 看到属性 +1 → 展开技能树 → （可选）找到"卸载本游戏"节点
  │    ├─ 点击卸载确定 → 跳转结局
  │    └─ 取消 → 自动进入下一步
  │
  ├─ 操作 6：商城
  │    浏览商品 → （可选）购买空气礼包 → 弹窗轰炸 → 自动进入下一步
  │
  ├─ 操作 7：最终 Boss
  │    魔王提问 → 选择"关掉游戏"或"继续冒险"
  │    ├─ 关掉游戏 → 制作人员名单 → 结尾彩蛋 → 退出
  │    └─ 继续冒险 → 空世界游荡 30 秒 → 自动结局 → 名单 → 退出
  │
  └─ 结束：玩家退出游戏
```

## 五、应用场景

### 场景一：社交媒体传播

> 玩家在朋友圈看到朋友分享的截图，出于好奇下载

打开即玩，全程 15-20 分钟。玩家在角色创建和技能树环节会自发截图分享（"这游戏在吐槽我"）。通关后因共谋感和荒诞结局，容易形成二次传播。开发方可在结局页预埋分享引导链接。

### 场景二：游戏展会试玩

> 用户在展会摊位前被像素风吸引，驻足体验

无需教程，点几下就能 get 到笑点。5 分钟内可以走完一半流程（到战斗跳过），足够形成记忆点。适合在独立游戏展会作为引流品，结尾导向开发者其他正经作品的 wishlist。

### 场景三：直播效果

> 主播开玩，观众弹幕互动

短平快的节奏适合直播节奏。每个场景都有"出戏点"适合制造节目效果（角色创建揭底、战斗跳过按钮的一本正经吐槽、技能树的"卸载本游戏"节点）。全场可以在一集直播内播完，完整的起承转合保证内容完整性。

## 六、边界声明

| 不做 | 原因 |
|------|------|
| 真实的程序生成 | 短品不需要，所有场景手写以控制节奏和笑点密度 |
| 多结局分支 | 玩家选择不影响最终走向，以保证所有玩家获得一致性体验 |
| 存档或进度保存 | 游戏总时长 20 分钟，无中断续玩需求 |
| 联网或多人 | 纯单机体验，无社交或联机必要 |
| 游戏内帮助或教程 | 游戏本身就是对教程的吐槽，无需额外引导 |
| 多语言本地化 | 讽刺和 meta 文本高度依赖语言文化，优先单语言市场 |
| 成就系统 | 游戏本身就在讽刺成就系统，不会给它 |
| 更新或运营 | 一次交付，不追加内容；留白本身是设计的一部分 |
| 真实支付渠道 | 空气礼包的"购买"使用虚拟货币，不接入真实支付 |
| 可玩性验证 | 本作目的不是"好玩"，而是"有趣"—笑点与共鸣取代可玩性 |

## 七、配置示例（可选）

### 配置：极速体验流

```yaml
跳过按钮出现回合: 2
战斗自动推进: 开启
技能树拖动速度: 2x
商城弹窗: 关闭
Boss 默认选项: 关掉游戏
特征: 用于展会 demo 或直播快速向，压缩至 10 分钟
```

### 配置：完整体验流

```yaml
跳过按钮出现回合: 4
战斗自动推进: 关闭
技能树拖动速度: 1x
商城弹窗: 开启（每个弹窗延迟 3 秒）
Boss 默认选项: 无，等待玩家选择
特征: 用于个人体验，保留完整节奏和笑点密度
```
