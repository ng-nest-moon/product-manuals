# 言随宅 — 产品功能说明书

## 一句话定义

一套面向空巢与独居老人的家庭智能化适老改造系统：老人只需用日常说话（哪怕带口音、说半句），家里的灯、窗帘、空调、药盒、报警器就听话照做——**言出法随，让家成为会照顾人的"超级大脑"，儿女退居为远程守护者**。

---

## 一、架构总览

```
用户层
 ├── 老人（核心使用者，语音优先）
 ├── 子女 / 亲属（远程协同与授权）
 └── 社区 / 医护（守护闭环外联）

家庭超级大脑（中枢本体）
 ├── 语言理解 — 方言 / 模糊语 / 多轮对话的意图识别
 ├── 意图规划 — 把一句话拆成可执行动作序列
 ├── 记忆库 — 生活习惯 / 用药 / 偏好 / 风险画像
 └── 风险分级与授权环 — 高危动作先确认或上报

神经末梢（设备与传感层）
 ├── 环境控制 — 灯 / 窗帘 / 空调 / 地暖 / 门锁
 ├── 安全守护 — 毫米波跌倒检测 / 燃气 / 水浸 / 门磁 / 长时间静止
 ├── 健康陪伴 — 用药提醒 / 血压体温 / 紧急呼叫
 └── 生活助理 — 代拨电话 / 买菜订餐 / 日程提醒

守护闭环（外联通道）
 ├── 子女推送 — 异常实时通知 + 远程代操作
 ├── 社区网格 — 上门核实 / 定期巡访
 └── 紧急医疗 — 一键直连 120 / 家庭医生

适老交互层
 ├── 语音优先 — 全功能免唤醒或轻唤醒对话
 ├── 大字屏 — 极简状态面板，字大对比强
 └── 物理一键 — 床头/腰间实体呼救按钮
```

---

## 二、核心功能清单

1. **言出法随** — 老人说一句自然语言，系统调度全屋设备完成动作，无需APP、无需学习。
2. **方言与模糊理解** — 识别各地方言、口语化与不完整表达（"有点热""把亮着的关了"），不必字正腔圆。
3. **主动适老** — 依据记忆库中的习惯与时段，自动调节环境，多数时候老人根本不用开口。
4. **安全守护** — 毫米波无感检测跌倒、燃气泄漏、水浸、长时间无活动，异常自动告警。
5. **用药与健康管理** — 到点提醒吃药、记录血压体温、异常趋势提示子女与医生。
6. **子女远程协同** — 子女在手机端查看家中状态、接收告警、代为下发指令。
7. **一键呼救** — 语音"救命"或按实体键，立即触发就近守护闭环。
8. **可审计记忆日志** — 每次听话动作、每次告警都有"为何做、做了什么、结果如何"的留痕，可回放复盘。

## 三、核心模块详解

### 3.1 语言理解

把老人的自然语言转成系统可执行的意图，不要求标准普通话。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 方言识别 | 支持主要方言与带口音普通话 | 首次适配时录制少量样本做声纹+口音校准 |
| 模糊补全 | "太亮了""我冷"自动推断目标是灯/空调 | 歧义时反问一次，不擅自大动作 |
| 多轮对话 | "把卧室灯关了——不对，客厅的"可纠正 | 上下文保留 3 轮，超时清空 |
| 免唤醒 | 在房内自然语言即触发，无需"小X小X" | 仅在家居私密场景启用，公共区域关闭 |

### 3.2 意图规划

将一句目标拆成有序的设备动作，老人只说结果，系统决定步骤。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 目标拆解 | "我想睡了"→关灯+拉帘+调温+落锁 | 拆出的动作须全部可回滚 |
| 冲突检测 | "开窗"与"开空调"冲突时提示取舍 | 不静默忽略用户显性指令 |
| 习惯融合 | 结合记忆库选择老人偏好的温度/亮度 | 偏好可被一句话临时覆盖 |

### 3.3 记忆库

系统的"海马体"，让家越用越懂老人。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 习惯记忆 | 作息、常去房间、舒适温区 | 仅本地存储，脱敏 |
| 用药记忆 | 药名、频次、剂量、剩余量 | 与子女端共享，老人可隐藏 |
| 风险画像 | 跌倒史、慢病、夜间起夜频率 | 用于主动守护策略加权 |
| 偏好记忆 | 称呼、语气、想听的新闻/戏曲 | 语音播报个性化 |

### 3.4 风险分级与授权环

所有听话动作先过风险分级，保障老人安全与自主权。

| 风险级别 | 示例 | 处理方式 |
|---------|------|---------|
| 低（自主） | 开灯、播新闻、关窗帘 | 直接执行并语音回执 |
| 中（自主+通知） | 调低水温、锁门、关燃气阀 | 执行后推送子女一条简报 |
| 高（需确认） | 呼叫 120、远程开门、转账类 | 先语音确认，再上报子女并发指令 |
| 禁止 | 私自改用药剂量、关摄像头弃守 | 系统硬性禁止，仅人工可解 |

### 3.5 安全守护

无感传感替代"人盯着"，异常自动进入守护闭环。

| 异常类型 | 自愈 / 处置动作 |
|---------|---------------|
| 跌倒（毫米波） | 先语音询问，无应答→告警子女+社区，必要时 120 |
| 燃气泄漏 | 关阀+开窗+播报警+推子女 |
| 水浸 | 关水阀+通知，防老人滑倒 |
| 长时间静止 | 超过基线阈值触发"你还好吗"询问，无应答升级告警 |

### 3.6 健康陪伴

把"记得吃药""量个血压"变成系统本职，而非靠子女唠叨。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 用药提醒 | 到点语音播报+药盒亮灯，漏服追问 | 不替代医生处方，仅提醒 |
| 体征记录 | 血压计/体温计数据自动入库 | 趋势异常才打扰子女 |
| 紧急呼叫 | 语音或按钮触发 | 直连守护闭环，不绕路 |

### 3.7 子女远程协同

让儿女"不在身边也在场"，但不剥夺老人主控。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 状态看板 | 今日活动、用药、告警概览 | 默认汇总，不实时直播隐私 |
| 远程代操作 | 帮父母开空调、确认告警 | 每次代操作留痕并语音告知老人 |
| 授权管理 | 设定哪些动作需子女二次确认 | 由子女与老人共同约定 |

### 3.8 适老交互层

决定老人"用不用得起来"，比功能更关键。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 语音优先 | 90% 操作靠说 | 不强制触屏 |
| 大字屏 | 进门一块极简面板 | 字号≥28pt，高对比 |
| 物理一键 | 床头/腰间实体呼救键 | 无需联网也能本地触发声光 |

## 四、用户流程

### 首次改造适配

```
上门评估 → 安装传感与中枢，录入老人口音与习惯
  │
  ▼
老人试说几句（"开灯""我热"），系统现场校准理解
  │
  ▼
子女端绑定，共同设定风险授权边界
  │
  ▼
系统进入"学习+值守"状态，前两周动作附带语音解释
```

### 日常使用

```
老人开口："把客厅灯关了，有点困"
  │
  ▼
大脑识别意图 → 拆成"关客厅灯 + 调暗环境 + 记'准备午睡'"
  │
  ▼
高危？──否──▶ 直接执行，语音回执"好嘞，灯关了"
  │
  ▼是
语音确认 ──批准──▶ 执行并推子女
  │
  ▼拒绝
维持原状，改为更保守动作
```

### 异常守护

```
毫米波检测到跌倒且语音无应答
  │
  ▼
系统按风险画像升级：推子女 + 通知社区 + 征询是否 120
  │
  ▼
子女确认 / 超时无应答 → 直连 120 并同步门牌与病史
```

## 五、应用场景

### 场景一：半夜起夜怕黑
老人迷糊说一句"开个灯"，系统联动地脚灯与卫生间灯柔和亮起、水温锁定防烫、回床后延时熄灭。全程不用摸开关，降低跌倒风险。

### 场景二：记性差漏吃药
下午三点药盒亮灯+语音"该吃降压片了"，老人应一声"吃了"即记录；若二十分钟无应答，转提醒子女并标注"未确认"。

### 场景三：子女不在家的安心
老人独居滑倒，系统先问无应答，自动推告警给子女与社区网格，同步门牌、慢病与是否独居，子女一键授权呼叫 120。家替儿女"在场"。

## 六、边界声明

| 不做 | 原因 |
|------|------|
| 替代医生诊断与处方 | 仅提醒与记录，医疗判断归专业人 |
| 静默关掉摄像头/麦克风做"全面监控" | 隐私是信任底线，感知须可解释可关闭 |
| 擅自改用药剂量或自行购药 | 健康高风险，必须人确认 |
| 把老人当"被看护对象"剥夺主动权 | 言出法随的前提是老人仍是发令者 |
| 跨家庭无授权数据共享 | 隐私与数据安全合规要求 |
| 承诺"永不误报/永不漏报" | 只承诺可解释、可回滚、可追责 |

## 七、配置示例

### 配置 A：低龄健康老人（轻改造）
- 中枢 + 语音 + 基础环境控制 + 用药提醒
- 授权环：仅 120/远程开门需确认
- 目标：省心、延后依赖

### 配置 B：高龄独居（标准守护）
- 中枢 + 语音 + 环境 + 毫米波跌倒 + 燃气水浸 + 药盒 + 子女协同
- 授权环：关燃气阀、锁门自主执行并简报；120 先问后报
- 目标：安全兜底、延缓入住机构

### 配置 C：失能/半失能（重度协同）
- 标准守护 + 体征监测 + 社区网格直连 + 护工排班
- 授权环：多数高危动作由子女/护工确认
- 目标：居家照护替代部分机构成本
