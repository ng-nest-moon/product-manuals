# 自动打工仔 — 产品功能说明书

## 一句话定义

录制桌面窗口的操作视频，AI 通过视觉分析自动生成可执行的自动化流程，并在指定窗口精准回放。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：有重复性桌面操作的职场人**

| 维度 | 描述 |
|------|------|
| 角色 | 需要每天重复相同桌面操作的业务人员 |
| 典型场景 | 每日填报、批量报表导出、ERP 数据录入 |
| 技术背景 | 非程序员，不会写脚本 |
| 现有解法 | 忍着做 / 找人写脚本（贵且不可维护） |

**次要用户：游戏玩家**

| 维度 | 描述 |
|------|------|
| 场景 | 游戏日常任务挂机、连招宏 |
| 需求 | 不需要懂编程就能自动化游戏操作 |

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 每天重复相同桌面操作，耗时且无价值 |
| **刚需** | 不会编程的人无法享受自动化 |
| **改善型** | 传统脚本工具对界面变化不鲁棒 |
| **改善型** | 录制后的流程编辑需要可视化支持 |

---

## 二、解决方案与核心功能

### 2.1 解决方案概述

自动打工仔通过"录一遍 → AI 理解 → 自动执行"的流程，让任何桌面操作都能一键自动化。

核心设计：
- **视觉驱动执行** — 通过截图比对 + OCR 定位元素，不再依赖固定坐标
- **AI 意图抽象** — 把"点击 (320,480)" 转化为"点击「提交」按钮"
- **窗口绑定** — 锁定操作窗口，不干扰其他应用
- **变量系统** — 支持执行时动态输入

### 2.2 核心功能清单

1. **窗口录制** — 指定任意桌面窗口，录制鼠标/键盘/滚轮/拖拽完整操作
2. **AI 视觉识别** — OCR 识别界面文字 + 目标检测定位 UI 元素
3. **智能意图理解** — 操作序列自动抽象为有语义的逻辑步骤
4. **SOP 生成与编辑** — 自动生成可读流程，支持 YAML/JSON/流程图编辑
5. **视觉驱动执行** — 通过截图比对 + OCR 判断状态，不再依赖固定延时
6. **窗口绑定** — 锁定执行窗口，避免误操作到其他应用
7. **异常检测** — 识别弹窗、卡死、加载失败等，自动暂停
8. **速度调节** — 回放速度可调（0.5x ~ 10x）
9. **循环执行** — 支持重复执行指定次数或无限循环
10. **游戏场景优化** — 图像匹配、连招宏、循环挂机、多分辨率

## 三、竞品与差异化分析

| 竞品 | 优点 | 缺点 | 差异 |
|------|------|------|------|
| Power Automate / UiPath | 企业级 RPA，功能强大 | 学习成本高，不开箱即用 | 自动打工仔录一遍就能用 |
| 按键精灵 | 轻量，老牌 | 固定坐标，不鲁棒 | 视觉驱动，自适应界面变化 |
| Playwright/Selenium | 浏览器自动化标准 | 需要编程 | 自动打工仔不需要代码 |
| AHK (AutoHotkey) | 灵活可编程 | 需要脚本知识 | 录一遍即可，AI 自动生成 |

**差异化优势：** 零代码 + 视觉驱动（非固定坐标）+ 窗口绑定安全执行。

## 五、核心模块详解

### 5.1 录制层

用户指定目标窗口后开始录制。录制内容：鼠标（点击/右键/滚轮/拖拽）、键盘（按键/组合键/文本输入）、窗口状态（大小/滚动/焦点）、关键节点截图、操作时间戳。

### 5.2 AI 分析层

原始操作轨迹经过三步处理：截图分析（OCR + 目标检测识别界面元素）→ 意图抽象（坐标转语义）→ 去冗余（去除手抖/无效移动）→ 流程结构化（含条件判断和循环）。

### 5.3 执行引擎

视觉驱动定位优先顺序：OCR 文本定位（按钮有文字）> 图标模板匹配（固定图标）> 语义布局定位（表单相对位置）> 坐标回退。

异常处理：元素找不到时重试 → 超时暂停；弹窗干扰自动关闭；窗口关闭尝试恢复。

### 5.4 存储与配置

流程文件为 YAML 格式，支持：文本变量（执行前填写）、时间变量（{{today}}）、剪贴板变量（{{clipboard}}）。

## 六、用户流程

```
打开自动打工仔 → 指定目标窗口 → 开始录制
    ↓
执行要自动化的操作 → 停止录制
    ↓
AI 分析 → 生成 SOP 流程（可编辑）
    ↓
配置变量（可选）→ 选择目标窗口 → 执行
    ↓
系统视觉驱动执行 → 完成或异常暂停
```

## 八、落地路径

### 8.1 MVP（V1.0）

窗口录制（鼠标/键盘）+ 基础回放（固定坐标）+ 速度调节 + 窗口绑定。

### 8.2 第一步验证

**最关键假设：** 非编程用户愿意"录一遍"来替代每日重复操作。

**验证方法：** 邀请 10 个有重复性桌面操作需求的人试用，录一个真实操作流程。关键指标：录制 + 分析 + 一次执行成功的完整流程用时，目标 < 10 分钟。

## 九、风险与预期反馈

| 预期槽点 | 应对方案 |
|---------|---------|
| "录完了执行出错" | 视觉驱动替代坐标，异常时暂停可手动干预 |
| "和按键精灵有什么区别" | 视觉识别 + AI 意图理解是本质差异 |
| "游戏挂机会被封号" | 免责声明，不做对抗检测 |
| "窗口一变化就不能用了" | 视觉驱动就是为了解决这个 |

## 十、边界声明

| 不做 | 原因 |
|------|------|
| 桌面环境无关的云执行 | 必须在用户指定窗口运行 |
| 跨平台录制 | MVP 仅支持 Windows |
| 后台静默执行 | 执行过程对用户可见 |
| 浏览器内自动化 | 不替代 Playwright/Selenium |
| 模拟账号登录 | 用户自行登录后录制 |
| 自动更新界面元素 | 界面变了重新录制或调整模板 |
