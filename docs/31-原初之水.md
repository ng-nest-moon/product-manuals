# 原初之水 — 产品功能说明书

## 一句话定义

一种有自我意识的古老之水从远古封印中苏醒，以接触即同化的方式吞噬全球水源。极少数能与之精神共鸣的人，在驾驭它毁灭力量的同时，也在对抗被其吞噬的命运。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：喜欢黑暗奇幻/末世设定/能力代价类故事的读者（18-35 岁）**

| 维度 | 描述 |
|------|------|
| 阅读偏好 | 读过三体、进击的巨人、Rick and Morty、scp 基金会等 |
| 兴趣点 | 喜欢"强大的能力有无法承受的代价"设定 |
| 情感触点 | 对人类困境、能力与责任、成瘾与沉沦等主题敏感 |
| 消费形式 | 小说 / 漫画 / 设定集 / TRPG 模组 |

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 黑暗奇幻题材缺少"水"作为核心设定——水太日常了，不容易被当作威胁 |
| **刚需** | "能力代价"类故事需要系统化的代价体系而非"用完就虚脱" |
| **改善型** | 末世设定中"源自大陆自身"的威胁比外星人入侵更有宿命感 |
| **改善型** | 读者想要一个能自己推演的世界规则系统 |

## 二、解决方案与核心功能

### 2.1 解决方案概述

原初之水世界设定：远古之水觉醒 → 接触即同化全球水源 → 世界进入四阶段危机。少数人（约十万分之一）能与原初之水精神共鸣，获得操控水的力量——但每次使用都在付出不可逆的代价。共鸣深度分三层，代价从可恢复到不可逆逐层加重。

### 2.2 核心功能清单

1. **水之觉醒** — 遗迹封印解除，原初之水重新流入世界
2. **指数级同化** — 接触即感染，全球水体逐一沦陷
3. **危机四阶段** — 警戒期→失控期→适应期→终局期
4. **精神共鸣** — 约十万分之一的人具备潜在能力
5. **三层共鸣能力** — 基础层（安全）/深度层（代价）/融合层（不可逆）
6. **14 种水之能力** — 水形操控/相态爆破/完全水化等
7. **3 类使用者** — 驾驭型/沉溺型/共生理
8. **3 层代价体系** — 生理代价/精神代价/存在代价
9. **衍生威胁** — 水灵/水疫/人类极端派系
10. **世界观规则** — 自洽的设定和约束

## 五、核心模块详解

### 5.1 精神共鸣

约每 10 万人中有 1 人具备。三要素：精神韧性高 + 精神创伤裂痕 + 不被恐惧支配。共鸣越深力量越大、反噬风险越高。骑手与烈马的关系——不是主仆，是博弈。

### 5.2 能力体系

**基础层：** 水形操控（水刀/水鞭/水弹/水盾）、水幕防御、水中感知（静水 50m/动水 200m）、水线追踪。反噬风险极低或低。

**深度层：** 相态爆破（目标体内水气化或结晶）、水化身躯（免疫物理攻击）、同化领域（10m 半径）、水之记忆（读取水中存储画面）。代价从体温剧烈波动到逐渐丧失恐惧。

**融合层（不可逆）：** 完全水化（身体分解为水团）、同化传播（成为移动同化节点）、意识洪流（精神接入集体意识）。代价从身体边界模糊到最终忘记自己是谁。

### 5.3 危机四阶段

警戒期（局部异变，封锁消息）→ 失控期（城市水源沦陷，瓶装水成硬通货）→ 适应期（地下水源被保护，水墙城市兴起）→ 终局期（几乎所有水体被覆盖，缩居堡垒城市）。

### 5.4 衍生威胁

水灵（原初之水自然凝聚的人形流体）、水疫（摄入后持续口渴、皮肤渗出粘液）、融水教（认为同化是进化）、清道夫（猎杀共鸣者）、水源掠夺者（控制净水武装割据）。

## 六、用户流程

**普通人视角：** 日常生活 → 新闻"水质污染"→ 自来水异味恐慌 → 搬迁水墙城市 → 配给制净水 → 缩居堡垒。

**共鸣者视角：** 偶然触发共鸣 → 被登记 → 训练基础能力 → 执行任务 → 每次使用累积代价 → 最终选择收敛/退隐/彻底融合。

完整设定文档（已完成本说明书）+ 1-2 篇短篇故事或设定展示页。

### 8.2 第一步验证

**最关键假设：** 读者愿意花时间了解一个原创世界观设定。

**验证方法：** 发布设定摘要和 1 篇短篇故事到社交媒体。如果自然流量阅读完成率 > 30% 或点赞/收藏比 > 5%，设定成立。

## 九、风险与预期反馈

| 预期槽点 | 应对方案 |
|---------|---------|

| "为什么共鸣者这么少" | 设定如此——稀少才珍贵 |
| "感觉没有结局" | 设定本身是开放的——三体式的章节结构 |

## 十、边界声明

| 不做 | 原因 |
|------|------|
| 原初之水可以被"驯服" | 它只是暂时配合，吞噬本能永远存在 |
| 保证使用者安全 | 每一次共鸣都是意志对抗 |
| 承诺每个人都有共鸣潜力 | 精神共鸣不可强求 |
| 区分原初之水的"善恶" | 它没有道德概念，只是在做本能 |
| 提供治愈水疫的常规手段 | 水疫没有疫苗 |
