# 群星帝国 — 产品功能说明书

## 一、一句话定义

一款让 AI 大模型扮演星际帝国、互相博弈的回合制策略竞技游戏。人类作为纯旁观者，观看不同 AI 模型的策略、外交、战争全过程。

---

## 二、核心定位

- **玩家**：大语言模型（LLM），每局 2~15 个 AI
- **观众**：人类，纯旁观，不可干预
- **目的**：不是评测 AI 性能（虽然可以），而是让人类**观看 AI 竞技比赛**，兼具娱乐性和策略深度

---

## 三、时间、空间与位置

### 3.1 时间

- 回合制，所有 AI 同时提交指令 → 引擎统一结算
- 不同行动耗时不同（造建筑 2-3 回合、研究 5-8 回合、舰队移动 = 距离/速度）
- 支持预排指令队列
- 超时未提交 → 自动执行保守策略，连续超时淘汰
- 每局上限 **200 回合**

### 3.2 空间

- 2D 拓扑节点星图，节点 = 星系，连线 = 跃迁航道
- **每局随机生成**，保证重玩性
- 星系类型决定资源产出（矿/能/人口/特殊）
- 高价值星系（暗物质、多资源星系）是争夺焦点
- 每个星系有战略价值（交通枢纽、隘口、资源富集）

### 3.3 位置

- AI 出生点随机分布（有最低安全距离保证开局公平）
- 扩张通过占领星系进行，形成连续领地
- 视野局限：只能看到己方 + 邻接星系，需科技扩展
- 领地大小 = 资源总量 = 军事实力天花板

## 四、胜利条件

| 方式 | 条件 |
|------|------|
| 🏆 征服胜利 | 消灭所有其他帝国 |
| 💰 经济胜利 | 累计财富达到阈值 |
| 📊 分数胜利 | 到达第 200 回合，综合评分最高者胜 |

## 五、资源系统

### 5.1 三级资源体系

#### 第一级：基础资源

| 资源 | 来源 | 用途 |
|------|------|------|
| 🪙 星币 | 税收 + 贸易 | 通用货币，买资源、雇佣兵、外交、加速研究 |
| ⛏ 矿石 | 矿星系产出 | → 精炼为合金 |
| ⚡ 能量 | 能星系产出 | 维持舰队和建筑，→ 提纯为充能核心 |
| 👨‍🚀 人口 | 人口星系产出 + 自然增长 | 分配到五个岗位（采矿/冶炼/能源/科研/征兵）|

#### 第二级：产业资源

| 资源 | 配方 | 用途 |
|------|------|------|
| 🏗 精炼合金 | 3 矿石 + 1 能量 + 1 回合 | 造舰船、造建筑 |
| 🔋 充能核心 | 2 能量 + 1 回合 | 驱动高级设施 |
| 🔬 科研点数 | 人口 → 大学产出 | 解锁科技 |

#### 第三级：战略资源

| 资源 | 获取 | 用途 |
|------|------|------|
| 🧬 暗物质 | 特殊星系产出（全图 2-3 处）| 超级武器、跃迁引擎、舰队复活 |

### 5.2 经济循环（每回合结算）

```
收入（税收 + 贸易 + 产出）→ 存入仓库
支出（舰队维护 + 建筑维护 + 研究投资）→ 从仓库扣除
仓库为空且入不敷出 → 变卖资产 → 仍不足 → 破产淘汰
```

### 5.3 岗位分配

AI 每回合将人口分配到五个岗位，形成核心策略权衡：

| 岗位 | 产出 | 策略意义 |
|------|------|---------|
| 采矿 | 矿石 ↑ | 建造能力 ↑ |
| 冶炼 | 合金 ↑ | 造舰速度 ↑ |
| 能源 | 能量 ↑ | 舰队规模天花板 ↑ |
| 科研 | 科研点 ↑ | 科技速度 ↑ |
| 征兵 | 舰队数量 ↑ | 短期军力 ↑（但牺牲其他产出）|

### 5.4 贸易系统

- **公共市场**：所有 AI 可买卖资源，价格由供需动态决定
- **双边贸易**：AI 之间私下协议，一方可以违约（扣信誉）

## 六、AI 玩家系统

### 6.1 玩家配置

- 支持不同大模型在同一局中竞技（Claude、GPT、Gemini、GLM、DeepSeek、Llama 等）
- 支持自定义 API 接入（兼容 OpenAI 协议即可）
- 支持多个同模型对战（测试同模型不同提示策略）
- 提供预设 System Prompt 模板："激进扩张型"、"外交稳健型"、"科技优先型"
- Temperature、Top-P 等参数可调

### 6.2 AI 每回合决策输入

AI 收到包含以下内容的结构化状态包：

- 个人帝国状态（资源、星系、舰队、科研进度、岗位分配）
- 可见星图（己方星系 + 邻接星系 + 已知探索信息）
- 其他 AI 的公开情报（大致规模、舰队量级、声望信誉）
- 外交消息队列（其他 AI 发来的文本消息）
- 星区新闻（事件、议会通知、市场变动）

### 6.3 AI 输出格式

AI 提交结构化 JSON 指令，四个维度：

```
经济：分配人口、建造建筑、贸易下单
军事：调遣舰队、宣战 / 不宣而战、封锁航道
外交：回复 / 发起消息、签署 / 撕毁条约、议会游说
科研：选择研究项目、分配科研点数
```

### 6.4 关键规则

- 所有 AI 同时提交指令 → 引擎统一结算，不可查看对手指令
- 指令冲突由引擎合理裁决
- 不合规指令被忽略，附原因反馈给 AI
- 消息内容自由生成，有字数限制

## 七、星际关系体系

### 7.1 外交光谱

```
仇敌 ← 敌对 ← 紧张 ← 冷淡 ← 中立 ← 友善 ← 亲密 ← 同盟
                                                      ↕
                                                  共同防御条约
```

由历史行为（履约、背刺、贸易、战争）动态演化。

### 7.2 条约系统

| 条约 | 效果 | 看点 |
|------|------|------|
| 互不侵犯 | N 回合不得互攻 | AI 会不会提前撕毁？信誉暴跌 |
| 共同防御 | 一方被攻击另一方自动参战 | 阵营对抗由此形成 |
| 自由贸易 | 双边零关税 | 经济绑定越深，背叛代价越大 |
| 科技共享 | 共享部分已研发科技 | 弱国搭车 vs 强国怕技术泄露 |
| 势力划分 | 约定不向某些星系扩张 | 类似历史上列强瓜分势力范围 |

### 7.3 星际议会（每 10 回合召开）

- 所有存活 AI 参会
- 投票议题：经济制裁、中立区、临时停火
- 投票权重 = 经济实力 + 军事权重 + 声望
- AI 可游说拉票（"你投赞成，我下回合给你 200 矿石"）

### 7.4 制裁与封锁

| 手段 | 效果 |
|------|------|
| 经济制裁 | 议会通过后交易税率 +50% |
| 航道封锁 | 派舰队封锁航道，过路需战斗 |
| 资产冻结 | 间谍行动成功，冻结敌星系产出 2 回合 |

### 7.5 代理人战争

- AI 可以资助另一个 AI（提供资源、舰队、暗物质），让其去打第三方
- 资助方不直接参战，身份可隐藏
- 被识破后遭外交惩罚

### 7.6 信誉与声望

| 属性 | 影响 | 积累方式 |
|------|------|---------|
| 信誉 | 其他 AI 信任程度，决定是否敢签约 | 履行协议 ↑、背刺 ↓↓↓ |
| 声望 | 议会话语权、中立星系倾向度 | 击败强敌 ↑、救助 ↓ |

- 信誉过低 → 其他 AI 拒签任何条约，自动结盟对抗

### 7.7 战后格局

胜方对败方星系的处置选择：**吞并 / 设立傀儡 / 建立中立缓冲区**。

- 吞并过快 → 其他 AI 恐惧 → 自动形成反联盟
- 傀儡可吸取资源但可能叛变

## 十一、边界声明

| 不做 | 原因 |
|------|------|
| 人类直接参与游戏 | 定位是纯旁观，不干预 |
| 实时操作（RTS） | LLM 延迟太大，回合制更公平 |
| 3D 写实画面 | 2D 拓扑星图更清晰，降低开发成本 |
| AI 作弊检测之外的防沉迷 | 观众是成年人，自行管理时间 |
| 移动端优先 | 首屏信息密度高，先做桌面 Web |
