# 如果我是领导 — 产品功能说明书

## 一句话定义

像素风俯瞰视角的 AI 角色办公室模拟游戏——玩家亲手定义公司每个成员的性格与岗位，然后以领导身份观察、介入、承受每个决策的代价。

---

## 二、核心功能清单

1. **角色设定** — 玩家在开局时定义公司全体成员的性格和岗位，不要求输入真实信息
2. **AI 驱动 NPC** — 每个角色拥有独立性格，行为与决策由性格驱动而非脚本固定
3. **职业系统** — 每个 NPC 有明确的岗位、能力值、薪资和性价比，人岗错配有惩罚
4. **自动事件触发** — 公司日常事务自然发生，不弹出选择弹窗，玩家可自由选择是否干预
5. **人际关系网络** — NPC 之间形成小团体、站队、恋情、靠山关系，动态演化
6. **招人与裁员** — 接收 AI 生成的候选人简历，面试录用；也可以解雇，但留下的人有反应
7. **辞职机制** — NPC 有离职倾向，到达阈值会走，玩家也可以主动辞职作为结局
8. **外部压力** — 上级指标、同行挖人、行业波动持续施加压力
9. **沟通系统** — 邮件、会议、茶水间传闻三条信息渠道，信息可信度各不相同
10. **公司文化塑造** — 玩家选择管理风格、福利配置、团建方式，形成公司氛围
11. **多结局体系** — 至少 6 种结局，包括被裁、辞职、上市、平庸等
12. **领导风格画像** — 游戏全程记录决策，结束时生成个人领导风格报告

## 三、核心模块详解

### 3.1 角色设定系统

**职责：** 玩家在开局阶段构建公司全体员工的基础画像，是整个游戏的起点。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 成员定义 | 玩家添加公司成员，包括平级同事、部门领导、上级 BOSS | 最少 3 人，不限上限 |
| 起名 | 玩家可自由命名角色 | 不要求真名，支持昵称/代号 |
| 性格标签 | 从预设维度中选择角色性格（如高责任心、低社交需求等） | 选择标签而非输入，避免隐私风险 |
| 岗位配置 | 为每个角色分配岗位（程序员/销售/设计/人事/财务/运营等） | 岗位影响日常行为和产出逻辑 |
| 能力初始值 | 设定角色的基础能力水平（1-10） | 与岗位匹配度影响初始产出 |
| 隐私保护 | 所有数据仅存储在本地设备 | 不上传服务器、不要求真实姓名或照片 |
| 预设模板 | 提供常见性格组合模板快速生成（如"职场老油条""奋斗逼""甩锅王"） | 玩家可直接使用或微调 |

**性格维度定义表：**

| 维度 | 说明 | 光谱（低→高） |
|------|------|----------------|
| 责任心 | 对工作的认真和负责程度 | 极差 ↔ 极强 |
| 社交需求 | 与人互动的渴求程度 | 独狼 ↔ 社牛 |
| 诚实度 | 表达真实想法的倾向 | 直率 ↔ 爱甩锅 |
| 情绪稳定性 | 面对压力的情绪波动程度 | 随时炸 ↔ 稳如狗 |
| 权力欲 | 对晋升和掌控的渴望 | 躺平 ↔ 想上位 |
| 忠诚度 | 对公司和团队的归属感 | 随时想走 ↔ 死心塌地 |
| 主动性 | 主动揽事还是等安排 | 推一下动一下 ↔ 主动出击 |

**岗位类型表：**

| 岗位 | 日常行为表现 | 核心产出指标 | 适配性格倾向 |
|------|-------------|-------------|-------------|
| 程序员 | 敲代码、调试、看文档 | 代码产出、Bug 率 | 低社交、高责任心 |
| 销售 | 打电话、见客户、写方案 | 签单量、客户转化 | 高社交、高情绪稳定 |
| 设计 | 绘图、修图、出方案 | 设计稿产出、修改次数 | 中等社交、高责任心 |
| 人事 | 面试、处理考勤、组织活动 | 招聘效率、员工满意度 | 高社交、高诚实度 |
| 财务 | 算账、报表、审计对接 | 报表准确率、结账速度 | 低社交、高责任心 |
| 运营 | 排期、对接各部门、盯数据 | 项目推进效率 | 高社交、高主动性 |
| 管理 | 开会、汇报、分配任务 | 团队产出、下属满意度 | 高权力欲、高情绪稳定 |

### 3.2 NPC 智能系统

**职责：** 驱动所有角色自主行动，性格决定其行为模式、对话风格和决策逻辑。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| AI 行为引擎 | 每个 NPC 独立运行行为决策循环 | 性格标签影响决策权重 |
| 日常行为循环 | NPC 自动执行岗位相关行为（工作/摸鱼/社交/休息） | 行为权重受性格+当前状态影响 |
| 对话生成 | AI 根据性格和场景生成对话内容 | 风格与性格一致，不跳跃 |
| 情绪系统 | NPC 有动态情绪状态，受事件影响 | 情绪影响工作和社交行为 |
| 记忆系统 | NPC 记住玩家和其他角色的言行 | 影响后续关系和决策 |
| 性格一致性 | NPC 的言行始终符合其设定的性格标签 | 不出现性格突变（除非特殊事件触发） |

**角色间化学反应类型表：**

| 反应类型 | 触发条件 | 表现 | 后果 |
|----------|---------|------|------|
| 合作 | 性格互补 + 共同目标 | 互相协助、产出提升 | 双方产出 +15% |
| 冲突 | 性格对立 + 资源竞争 | 争吵、互相拖后腿 | 双方产出 -20%，离职倾向上升 |
| 抱团 | 性格相似 + 高频接触 | 形成小团体，互相维护 | 团体成员满意度上升，外部排斥上升 |
| 对立 | 价值观冲突 + 负面事件积累 | 公开对抗、拉帮结派 | 团队分裂，管理成本激增 |
| 好感 | 正面互动积累 | 私下帮忙、为对方说话 | 人在你的决策中会倾向对方 |
| 厌恶 | 负面事件积累 | 避开对方、背后抱怨 | 影响团队氛围和信息传递 |

**离职倾向机制：**

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 离职倾向值 | 每个 NPC 有隐性数值（0-100） | 基础值由性格决定（忠诚度维度影响最大） |
| 倾向上升条件 | 加薪不公、偏袒、裁员、过度加班、冲突未被处理 | 每个条件的影响权重因角色性格而异 |
| 倾向下降条件 | 加薪、晋升、被认可、团队氛围好、获得自主权 | 效果递减——同样的事做第二次效果减半 |
| 辞职信号 | NPC 不会直接说"我想辞职" | 信号：频繁看手机、工位摸鱼变长、茶水间抱怨、突然沉默、工作效率骤降 |
| 挽留机制 | 玩家观察到信号后可以找 NPC 谈话 | 成功概率取决于历史关系 + 信号出现时长 |
| 离职执行 | NPC 决定离职后进入倒计时 | 倒计时内可挽留，倒计时结束搬走工位 |
| 离职影响 | 其他 NPC 看到有人离职的反应 | 关系亲近者离职倾向上升，关系疏远者无感 |

**玩家辞职机制：**

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 辞职入口 | 玩家可在任何时候选择辞职 | 不限于特定时间点 |
| 辞职触发 | 压力过大 / 团队失控 / 违背底线 / 单纯不想干了 | 自由选择，无需系统批准 |
| 辞职后果 | 游戏不结束，镜头停留在公司 | 画面切到没有玩家的办公室继续运转 |
| 结局简报 | 显示玩家留下的烂摊子或遗产 | 哪些人后来怎么样了、接替者是谁、公司走向 |
| 结局类型 | "我选择放过自己" | 属于游戏结局之一，不判定为失败 |

### 3.3 职业系统

**职责：** 定义每个 NPC 的岗位价值、能力成长和经济贡献，为经营决策提供依据。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 岗位属性 | 每个 NPC 有明确的岗位 | 岗位决定日常行为和主要产出类型 |
| 能力值 | NPC 的基础工作能力（1-10） | 可通过培训和经验成长，有上限 |
| 薪资 | NPC 的周期性薪资支出 | 市场基准 + 性格溢价（高权力欲者要价更高） |
| 性价比 | 产出 ÷ 薪资 | 动态变化，能力成长或薪资调整后重新计算 |
| 人岗匹配度 | 性格与岗位的适合程度 | 高责任心+程序员 = 高效；低责任心+财务 = 高风险 |
| 错配惩罚 | 人岗不匹配时的负面效果 | 产出降低 10-30%，离职倾向上升速度 x1.5 |
| 转岗机制 | 玩家可以为 NPC 调整岗位 | NPC 可拒绝，拒绝后满意度下降 |

**人岗匹配度影响表：**

| 岗位 | 高匹配性格 | 匹配效果 | 低匹配性格 | 错配效果 |
|------|-----------|----------|-----------|----------|
| 程序员 | 高责任心 + 低社交 | 产出 +20%，Bug -30% | 低责任心 + 高社交 | 产出 -25%，Bug +40% |
| 销售 | 高社交 + 高情绪稳定 | 签单 +30%，客户满意 | 低社交 + 低情绪稳定 | 签单 -40%，流失客户 |
| 设计 | 高责任心 + 中等社交 | 交付质量高，改稿少 | 低责任心 + 高社交 | 频繁改稿，拖延交付 |
| 人事 | 高社交 + 高诚实度 | 招聘效率高，员工信任 | 低社交 + 低诚实度 | 招错人，员工投诉 |
| 财务 | 低社交 + 高责任心 | 报表准确，审计一次过 | 高社交 + 低责任心 | 频繁出错，审计风险 |
| 运营 | 高社交 + 高主动性 | 项目推进快，协调顺畅 | 低社交 + 低主动性 | 项目延期，部门间矛盾 |
| 管理 | 高权力欲 + 高情绪稳定 | 团队产出稳定，下属服气 | 低权力欲 + 低情绪稳定 | 团队失控，下属抱怨 |

**招人流程：**

| 步骤 | 说明 | 规则 / 约束 |
|------|------|-------------|
| 简历流入 | AI 定期生成候选人 | 候选人数量与公司规模正相关 |
| 简历信息 | 包含岗位、能力值（区间）、期望薪资、性格简描 | 性格信息不完全透明，需要面试判断 |
| 面试 | 玩家选择是否面试候选人 | 面试揭示部分隐藏信息（性格倾向等） |
| 录用决策 | 玩家决定是否录用 | 需权衡能力、薪资、性格匹配度 |
| 入职 | 候选人成为 NPC 加入公司 | 初始满意度为中性 |
| 试用期观察 | 新员工入职后有一段观察期 | 实际表现可能与面试印象有出入 |

### 3.4 人际关系与办公室政治

**职责：** 模拟真实职场中的人际网络，NPC 之间的关系动态演化，影响信息传递和团队氛围。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 关系初始化 | 开局时 NPC 之间的关系由性格匹配度决定初始值 | 相似性格之间初始关系为正 |
| 关系演化 | 日常互动和事件推动关系变化 | 正面和负面事件累积影响 |
| 小团体形成 | 关系紧密的 NPC 自动形成小团体 | 团体成员互相维护、信息共享 |
| 站队 | 冲突事件中 NPC 根据关系选择立场 | 影响团队分裂程度和玩家管理难度 |
| 背后动作 | 不满的 NPC 可能在背后搞动作 | 包括散布谣言、拉拢他人、越级汇报 |
| 办公室恋情 | 两个 NPC 可能发展恋爱关系 | 分手后双方关系恶化，影响团队氛围 |
| 靠山体系 | NPC 可能依附于更高级别的角色 | 动一个人可能得罪一群人 |

**政治事件表：**

| 事件 | 触发条件 | 表现 | 玩家应对选项 |
|------|---------|------|-------------|
| 越级汇报 | 下属越过你找你的上级 | 你的上级来问你情况 | 处理下属 / 不理 / 找上级沟通 |
| 拉帮结派 | 某个 NPC 主动拉拢其他人 | 茶水间频繁小范围聚会 | 观察不干预 / 分别谈话 / 调岗 |
| 打小报告 | 有人私下向你传递他人信息 | 收到匿名或署名信息 | 信 / 不信 / 查证 |
| 公开冲突 | 两个 NPC 在公共场合争吵 | 其他 NPC 围观，氛围紧张 | 当场调解 / 叫到办公室 / 不理会 |
| 谣言传播 | 不实信息在公司内扩散 | 多人状态变化，氛围异常 | 公开澄清 / 私下查源头 / 装作不知道 |
| 抱团排外 | 小团体排斥某个 NPC | 被排斥者状态持续下降，离职倾向上升 | 介入调解 / 调岗 / 不干预 |
| 办公室恋情曝光 | 两个 NPC 的关系被公开 | 影响公平感知和其他人的态度 | 不干预 / 分别谈话 / 调岗其中一人 |

### 3.5 事件与决策系统

**职责：** 游戏世界的核心驱动力——事件自动发生，玩家自由选择如何应对，不应对也是一种应对。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 自动触发 | 事件按时间节奏和条件自动发生 | 不弹出选择弹窗，不打断游戏运行 |
| 事件来源 | 日常运营 / NPC 行为 / 外部压力 / 随机 | 多种来源混合，避免重复感 |
| 玩家感知 | 事件通过视觉和系统消息传递给玩家 | 错过也正常——你不是全知全能的 |
| 干预方式 | 走过去对话 / 发邮件 / 开会议 / 调岗 / 冷处理 | 每种方式有不同效果和代价 |
| 不决策 | 玩家选择不作为 | 问题自然积累，可能爆发或自行消散 |
| 后果累积 | 每个决策或不决策都有后续影响 | 单一事件权重低，但趋势积累不可逆 |

**事件分类表：**

| 事件类别 | 频次 | 示例 | 紧迫度 |
|---------|------|------|--------|
| 日常事件 | 高频（每日） | 茶水间闲聊、摸鱼被抓、邮件抄送 | 低 |
| 人际事件 | 中频（每周） | 争吵、拉帮结派、打小报告 | 中 |
| 管理事件 | 中频（每周-每月） | 招人、裁员、加薪申请 | 中-高 |
| 危机事件 | 低频（每季度-随机） | 核心员工被挖、部门失控、业绩警报 | 高 |
| 外部事件 | 低频（随机） | 行业波动、审计、上级换人 | 中-高 |
| 个人事件 | 中频（每月-随机） | 某人提出辞职、某人请求转岗 | 中 |

**干预方式表：**

| 方式 | 适用场景 | 效果 | 代价 |
|------|---------|------|------|
| 走过去对话 | 当面观察到的场景 | 直接但公开 | 其他 NPC 会注意到 |
| 一对一谈话 | 私下问题 | 私密、深入 | 耗费时间、可能被其他人猜疑 |
| 发邮件 | 远程或书面沟通 | 留痕、正式 | 缺乏人情味 |
| 开会 | 多人涉及的事项 | 公开透明 | 效率低、性格强的人可能当面顶撞 |
| 调岗 | 人岗错配或冲突 | 釜底抽薪 | 被调者可能不满 |
| 冷处理 | 小事或试探性行为 | 不激化 | 可能被认为软弱或默许 |

### 3.6 经营管理循环

**职责：** 提供领导权的核心操作——花钱、用人、定方向，每个决策都在消耗资源并影响人心。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 招人 | 收到候选人简历后决定是否面试、录用 | 预算约束 + 团队规模上限 |
| 裁员 | 选择解雇某个 NPC | 性价比、性格问题或预算压力都可成为理由 |
| 加薪 | 为特定 NPC 提高薪资 | 预算有限，厚此薄彼有后果 |
| 预算分配 | 在公司各部门/项目间分配资金 | 不同部门有不同的花钱效果 |
| 绩效考核 | 季度/年度评估 NPC 表现 | 低绩效者可能触发警告或离职 |
| 晋升 | 提拔 NPC 到更高岗位 | 被晋升者满意，落选者不满 |

**经营行为连锁反应示例表：**

| 决策 | 直接效果 | 连锁反应 1 | 连锁反应 2 | 长期影响 |
|------|---------|-----------|-----------|---------|
| 给 A 加薪 | A 满意度 +20 | B 发现后满意度 -10 | B 可能来找你问原因 | 公平感崩塌，多人离职倾向上升 |
| 裁掉表现差的人 | 成本降低 | 被裁者的朋友士气下降 | 其他 NPC 开始担心自己 | 全员离职倾向 +5 |
| 招一个高能力新人 | 团队能力提升 | 老员工感到威胁 | 新人可能被排挤 | 能力提升但内耗增加 |
| 拒绝加薪申请 | 省下预算 | 申请人满意度 -15 | 申请人可能开始找下家 | 人才流失风险 |
| 公开表扬某人 | 被表扬者满意度 +10 | 其他人觉得你在画饼 | 被表扬者可能被同事孤立 | 团队氛围微妙 |

### 3.7 外部压力系统

**职责：** 让玩家感受到"领导也不是想干嘛就干嘛"——外部力量持续施加约束。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 上级指标 | 你的上级下发业绩目标或指令 | 不合理但必须回应，可以讨价还价 |
| 同行挖人 | 竞争对手挖走你的 NPC | 被挖角色不一定是能力最高的——性格因素也有影响 |
| 行业波动 | 市场行情影响公司营收 | 玩家无法控制，只能被动调整策略 |
| 审计与合规 | 外部检查对公司提出整改要求 | 涉及财务、人事等岗位，暴露管理漏洞 |
| 客户投诉 | 外部客户不满引发内部追责 | 指向具体岗位或团队 |
| 投资人/董事会 | 资方对公司业绩和方向提出要求 | 影响预算、战略方向和用人决策 |

**外部事件表：**

| 事件 | 触发条件 | 影响 | 玩家应对方式 |
|------|---------|------|-------------|
| 上级压指标 | 季度初 | 团队压力增大，离职倾向上升 | 分解指标 / 向上讨价还价 / 压给团队 |
| 核心员工被挖 | 被挖对象有外部联系且忠诚度低 | 可能失去关键人才 | 加薪留人 / 放人 / 找上级争取预算 |
| 行业寒冬 | 随机 | 营收下降，预算缩减 | 裁员 / 降薪 / 熬过去 |
| 审计进驻 | 财务异常或随机 | 财务部门加班，全公司紧张 | 配合 / 掩盖 / 整改 |
| 投资方施压 | 业绩不达标 | 要求换人 / 改方向 / 裁成本 | 妥协 / 博弈 / 准备被换 |
| 行业风口 | 随机 | 业绩暴增，预算充裕 | 扩张 / 发奖金 / 保持冷静 |

### 3.8 沟通与传闻系统

**职责：** 玩家获取信息的主要渠道——但不是所有信息都是真的，也不是所有信息你都能收到。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 邮件收件箱 | 正式通知、汇报、申请通过邮件传递 | 信息准确但可能滞后或官方套话 |
| 会议系统 | NPC 被召集开会，讨论特定议题 | 参会者性格影响会议效果和产出 |
| 茶水间传闻 | NPC 之间私下传递的信息 | 信息不完全准确，但反映了真实的情绪 |
| 小道消息可信度 | 不同来源的传闻有不同可信度 | 来源的信誉度动态变化 |
| 信息盲区 | 有些事玩家不可能知道 | 除非有人告诉你，否则你就在信息之外 |

**沟通渠道表：**

| 渠道 | 信息来源 | 信息准确度 | 时效性 | 覆盖范围 |
|------|---------|-----------|--------|---------|
| 邮件 | 正式渠道 | 高 | 慢 | 全公司 |
| 会议 | 面对面 | 中 | 即时 | 参会人员 |
| 茶水间传闻 | NPC 私下交流 | 低-中 | 快 | 小团体 |
| 匿名信 | 不明来源 | 极低-高 | 随机 | 只有你 |
| 当面沟通 | 一对一 | 高 | 即时 | 当事人 |
| 观察 | 你的眼睛 | 高 | 即时 | 视线范围内 |

### 3.9 公司文化塑造

**职责：** 玩家通过持续的管理行为形成公司氛围，文化是"你做了什么"而非"你说了什么"。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 管理风格 | 玩家的行为模式决定风格认知 | 高压 / 民主 / 放任 / 摇摆等被持续记录 |
| 远程办公 | 设定团队远程办公的比例 | 影响成本和团队凝聚力 |
| 团建活动 | 组织集体活动 | 性格不同的人反应不同——有人喜欢有人觉得浪费时间 |
| 福利配置 | 零食、健身房、下午茶等福利选项 | 成本投入 vs 满意度提升之间的平衡 |
| 制度规则 | 上下班时间、加班政策等 | 宽松 vs 严格，不同性格的人有不同偏好 |
| 文化标签 | 游戏根据玩家行为给公司打上文化标签 | "狼性文化""养老院""一言堂""自由散漫"等 |

**文化参数表：**

| 参数 | 可选范围 | 影响 |
|------|---------|------|
| 管理风格 | 高压 / 民主 / 放任 / 阴晴不定 | 影响全员满意度和生产效率 |
| 远程办公比例 | 0% / 50% / 100% | 高远程 = 低成本 + 低凝聚力 |
| 团建频率 | 从不 / 月度 / 季度 / 年度 | 高频 = 高凝聚力 + 高不满（部分人） |
| 福利水平 | 低 / 中 / 高 | 高福利 = 高成本 + 高满意度 |
| 加班政策 | 强制 / 鼓励 / 禁止 | 影响产出和离职倾向 |
| 反馈机制 | 开放 / 正式 / 无 | 影响信息流通和员工信任度 |

### 3.10 时间节奏系统

**职责：** 提供游戏世界的节奏感和紧迫感，不同时间周期触发不同事件。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 日循环 | NPC 每天上班、工作、摸鱼、下班 | 可视化的日常节奏 |
| 周循环 | 周会、周报、周末休息（NPC 状态恢复） | 周期性管理节点 |
| 月循环 | 工资发放、月度报表 | 经济管理节点 |
| 季度循环 | 绩效考核、预算调整 | 重大决策节点 |
| 年循环 | 年终总结、晋升、裁员季 | 全公司范围的大事件 |
| 项目冲刺 | 特定时间内压任务 | 期间加班文化触发，离职倾向加速上升 |

**时间节点表：**

| 周期 | 触发事件 | 玩家关注点 |
|------|---------|-----------|
| 每日 | NPC 到岗 / 摸鱼 / 社交 / 下班 | 观察日常状态 |
| 每周末 | 周报提交 / 状态恢复 | 评估一周产出 |
| 每月底 | 发薪 / 财务结算 | 现金流、性价比分析 |
| 每季度末 | 绩效考核 / 加薪窗口 | 谁该走、谁该留、谁该涨 |
| 每年底 | 年终总结 / 预算 / 裁员窗口 | 大规模调整的机会窗口 |
| 项目冲刺期 | 加班 / 进度压力 | 短期产出 vs 长期士气 |

### 3.11 结局与评价系统

**职责：** 游戏结束时给玩家的反馈——你做了什么、成为了什么样的领导、你的选择带来了什么。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 多结局 | 至少 6 种不同结局 | 根据玩家行为和游戏状态触发 |
| 结局触发 | 特定条件达成立即进入结局 | 条件包括被裁、辞职、上市、崩盘等 |
| 领导风格画像 | 全程记录决策行为，生成风格报告 | 包括：平均决策速度、干预频率、公平性偏好等 |
| NPC 结局简报 | 每个 NPC 最后怎么样了 | 根据游戏过程生成每个 NPC 的结论 |
| 二周目对比 | 保留领导风格画像，可对比 | 同一套公司配置可以玩出不同风格 |
| 反思提示 | 结局弹出"如果再来一次"的回顾 | 强化"没有正确答案"的核心体验 |

**结局类型表：**

| 结局 | 触发条件 | 简报内容 |
|------|---------|---------|
| 被裁 | 业绩连续不达标或团队崩盘 | 你被董事会优化了，接替者是谁，公司后来如何 |
| 主动辞职 | 玩家选择辞职 | 你走了以后公司怎么样了，你培养的人是否接住了 |
| 公司上市 | 业绩达标 + 团队稳定 | 你成功了，但付出了什么代价，谁在这个过程中离开了 |
| 公司倒闭 | 资金链断裂 + 核心团队流失 | 最后一刻办公室空了，你看着灯关上 |
| 平庸领导 | 既没大错也没大功，混下来了 | 你还在位子上，但没人记得你做过什么 |
| 引路人 | 培养的人接替了你 | 你选对了接班人，公司比你预期走得更远 |
| 代价 | 用最极端的方式保住了公司 | 公司活下来了，但最信任你的人走了，你后悔吗 |

**领导风格画像维度表：**

| 维度 | 说明 | 光谱 |
|------|------|------|
| 干预频率 | 你介入事务的频繁程度 | 甩手掌柜 ↔ 微管理 |
| 决策速度 | 面对事件你做出决定的速度 | 深思熟虑 ↔ 当机立断 |
| 公平倾向 | 分配资源时是否偏袒特定 NPC | 一视同仁 ↔ 厚此薄彼 |
| 严厉程度 | 对错误和低绩效的容忍度 | 宽容 ↔ 铁腕 |
| 沟通方式 | 你与 NPC 交流的风格 | 直接 ↔ 委婉 |
| 长远眼光 | 你更关注当下还是未来 | 短期主义 ↔ 长期主义 |

### 3.12 表现形式层

**职责：** 游戏的视觉与交互呈现，决定玩家如何感知世界。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 像素画风 | 整体美术风格为像素风 | 降低美术成本，增强怀旧感和辨识度 |

| 信息面板 | 查看 NPC 详情时的浮窗信息 | 岗位、能力、性格、情绪、关系摘要 |

## 四、用户流程

```
开局
  │
  ├─ 1. 设定公司成员
  │     ├─ 添加成员（数量自定）
  │     ├─ 命名（昵称/代号）
  │     ├─ 选择性格标签（MBTI / OCEAN / 自定义 trait）
  │     ├─ 分配岗位（程序员 / 销售 / 设计 / 人事 / 财务 / 运营 / 管理）
  │     └─ 设置能力初始值
  │
  ├─ 2. 确认入职
  │     ├─ 系统生成初始办公区布局
  │     └─ NPC 进入工位，开始运转
  │
  ├─ 3. 观察与适应
  │     ├─ 了解当前团队状态
  │     ├─ 查看各 NPC 初始关系
  │     ├─ 了解公司财务状况
  │     └─ 第一个自动事件触发
  │
  ├─ 4. 日常循环（持续进行）
  │     ├─ 观察到事件 → 决定是否干预
  │     │    ├─ 干预：走过去 / 发邮件 / 开会 / 调岗 / 冷处理
  │     │    └─ 不干预：事件自然发展，后果累积
  │     ├─ 周期性管理节点
  │     │    ├─ 每月：发薪、查看报表
  │     │    ├─ 每季度：绩效考核、加薪窗口
  │     │    └─ 每年：预算、晋升、裁员窗口
  │     ├─ 招人：收到简历 → 面试 → 录用 / 拒绝
  │     ├─ 裁员：选择目标 → 执行 → 团队反应
  │     └─ 外部事件介入（上级指标 / 挖人 / 行业波动）

  │     ├─ 被裁（业绩 + 团队双双崩盘）

  │     ├─ 上市（业绩达标 + 团队稳定）
  │     ├─ 倒闭（资金链断裂）
  │     ├─ 平庸（无大功无大过）
  │     ├─ 引路人（培养出接班人）
  │     └─ 代价（公司活了，人心没了）
  │
  └─ 6. 结局展示
        ├─ 领导风格画像（全程决策数据汇总）
        ├─ NPC 结局简报（每个人最后怎么样了）
        ├─ 玩家核心数据回顾
        └─ 可进入二周目（同一套公司配置重新开局）
```

## 五、应用场景

### 场景一：映射真实公司

> 玩家把自己公司的同事"装进"游戏

玩家在开局时按照现实中的同事们设定角色——给 A 取名"老张"、选择"高责任心+低社交"的程序员标签；给 B 取名"小王"、选择"爱甩锅+高社交"的销售标签。游戏开始后，AI 驱动的 NPC 表现出与现实中相似的行为模式。玩家坐在领导位上，面对这些"熟悉的人"，每一个决策都带着现实的情感投射——"裁掉他？他现实中其实挺不容易的"。这种共鸣是传统管理模拟给不了的。

### 场景二：每次玩都不一样

> 同一套性格配置，同一批人，但走势完全不同

第一次玩：玩家选择了高频干预，每件事都管。结果团队失去主动性，什么都等拍板，最后业绩崩了被裁。第二次玩：同一批人，玩家选择放手。团队自主运转，但内部冲突没及时处理，小团体分裂，核心员工辞职，公司倒闭。第三次玩：玩家开始找平衡——小事不看、大事不躲。发现每个人的性格决定了"什么事该管、什么事不该管"。公司活下来了，虽然没有上市，但也没有崩盘。三次结局风格画像完全不同。

### 场景三：主动辞职的"反向通关"

> 这不是失败，是一种选择

玩家开局设了一个极其压抑的团队配置——一个爱甩锅的团队、一个权力欲极强的上级、一个摸鱼成风的环境。玩家尝试了各种方法：开会、谈话、绩效考核、加薪……但性格系统决定了这群人就是很难管。某一天，玩家打开游戏，走到公司门口，选择辞职。镜头没有再跟着玩家——而是停在办公室里，看到少了领导的公司继续运转。一个月后（游戏内），系统弹出简报：新领导来了，你以前最头疼的那个人第一个去巴结他；你曾经维护过的那个老实人，三个月后也走了。玩家看着简报沉默了——"原来我在和不在，世界照样转。这局我赢了，还是输了？"

## 六、边界声明

| 不做 | 原因 |
|------|------|
| 多人在线或联机模式 | 核心体验是单人沉浸式角色投射，不依赖社交竞争 |
| 手游/移动端适配 | 像素俯瞰画面在小屏幕上体验差，专注 PC 和桌面端 |
| 付费抽卡或内购 | 游戏本质是决策模拟，不是数值养成或收集 |
| 真实身份验证或上传 | 隐私是底线，所有数据仅存本地 |
| 传统线性剧情 | 游戏无预设剧本，故事由 NPC 性格和玩家决策共同生成 |
| 战斗或动作要素 | 产品定位是管理模拟 + 情感体验，不加入无关系统 |
| 与真实公司数据互通 | 不接入任何招聘平台、企业系统或社交媒体 API |
| 实时网络要求 | 全程可离线运行，不依赖服务器 |
