# 如果我是领导 — 产品功能说明书

## 一句话定义

像素风俯瞰视角的 AI 角色办公室模拟游戏——玩家亲手定义公司每个成员的性格与岗位，然后以领导身份观察、介入、承受每个决策的代价。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：职场人（25-40 岁）**

| 维度 | 描述 |
|------|------|
| 年龄 | 25-40 岁，有 3 年以上工作经验的职场人 |
| 岗位 | 基层员工到中层管理者，尤其是"对上汇报、对下背锅"的中间层 |
| 收入 | 月入 1-3 万，愿意为独立游戏付费 50-100 元 |
| 日常体验 | 白天在公司被上级压指标、被同事甩锅、带不动团队、做不了主 |
| 底层心理 | "如果我是领导，我一定做得比 TA 好"——对上级的不满和对管理的想象 |
| 游戏习惯 | Steam 玩家，喜欢模拟/策略/叙事的慢节奏游戏 |

**次要用户：管理学习者和心理咨询爱好者**

| 维度 | 描述 |
|------|------|
| 场景 | 想"安全地"体验管理决策的后果，自我反思 |
| 需求 | 游戏提供的是现实映射，不是教学 |

### 1.2 真实痛点分级

| 需求类型 | 痛点 | 用户行为证据 |
|---------|------|-------------|
| **刚需** | 职场人有强烈的"如果我是领导"的心理投射需求 | 社交媒体上"如果我是老板我就XX"是高频表达 |
| **刚需** | 现实中无法安全地试错管理决策 | 一犯错就是真代价，没有安全环境 |
| **改善型** | 现有的管理模拟游戏缺乏情感深度 | 大多数管理游戏是数值游戏，不关心"人"的层面 |
| **改善型** | 玩家想看到"同样的人在不同管理风格下会怎样" | 对管理变量和因果关系的探索欲 |
| **猎奇伪需求** | "我要当领导爽一把"的纯权力幻想 | 如果游戏只给爽感没有代价，用户不会持续 |

## 二、解决方案与核心功能

### 2.1 解决方案概述

如果我是领导不教你"怎么做个好领导"。它让你**亲手体验当领导的全部代价**。

核心设计：
- **角色投射：** 玩家把自己认识的同事"装进"游戏，AI 驱动的 NPC 表现出与性格一致的行为——你给一个人设了"爱甩锅"，他真会甩锅
- **决策有代价：** 每个选择都有连锁反应——给一个人加薪，其他人会不满意；裁一个人，他朋友士气下降
- **不决策也是决策：** 你选择不干预，问题会自然积累，可能爆发也可能消散
- **没有正确答案：** 同一批人，三种管理风格走三种结局——上市、被裁、主动辞职，没有哪个是"通关"

不是爽游戏，是让你在安全环境里承受管理决策的全部后果。

### 2.2 核心功能清单

1. **角色设定** — 玩家在开局时定义公司全体成员的性格和岗位，不要求输入真实信息
2. **AI 驱动 NPC** — 每个角色拥有独立性格，行为与决策由性格驱动而非脚本固定
3. **职业系统** — 每个 NPC 有明确的岗位、能力值、薪资和性价比，人岗错配有惩罚
4. **自动事件触发** — 公司日常事务自然发生，不弹出选择弹窗，玩家可自由选择是否干预
5. **人际关系网络** — NPC 之间形成小团体、站队、恋情、靠山关系，动态演化
6. **招人与裁员** — 接收 AI 生成的候选人简历，面试录用；也可以解雇，但留下的人有反应
7. **辞职机制** — NPC 有离职倾向，到达阈值会走，玩家也可以主动辞职作为结局
8. **外部压力** — 上级指标、同行挖人、行业波动持续施加压力
9. **沟通系统** — 邮件、会议、茶水间传闻三条信息渠道，信息可信度各不相同
10. **公司文化塑造** — 玩家选择管理风格、福利配置、团建方式，形成公司氛围
11. **多结局体系** — 至少 6 种结局，包括被裁、辞职、上市、平庸等
12. **领导风格画像** — 游戏全程记录决策，结束时生成个人领导风格报告

## 三、竞品与差异化分析

### 3.1 同类替代品对比

| 竞品 | 类型 | 优点 | 缺点 | 与本产品定位差异 |
|------|------|------|------|----------------|
| 模拟人生 | 生活模拟 | 自由度极高，内容丰富 | 不聚焦职场，不涉及管理 | 如果我是领导只聚焦办公室管理 |
| 星露谷物语 | 农场经营 | 像素风治愈，沉浸感强 | 没有复杂的人际模拟 | 如果是领导核心是"人"的博弈 |
| 环世界 | 殖民地管理 | NPC 独立行为，叙事强 | 科幻背景，与职场无关 | 如果我是领导映射真实职场 |
| 双点医院 | 经营模拟 | 幽默有趣，管理轻松 | 深度不够，决策无代价 | 如果我是领导每个决策都有连锁反应 |
| 公司模拟器 | 企业经营 | 尝试模拟办公室 | 角色浅，AI 行为简单 | 如果我是领导 AI 性格驱动，深度不同 |

### 3.2 差异化优势与护城河

| 优势 | 说明 | 可模仿性评估 |
|------|------|-------------|
| AI 性格驱动 NPC | 不是固定脚本，性格决定行为 | 中等——需要好的 AI 行为模型 |
| 角色投射 | 玩家自定义同事，情感共鸣强 | 低——理念易复制，但情感深度难 |
| 不决策也是决策 | 事件不弹窗，错过就错过了 | 中等——系统设计复杂 |
| 无正确答案 | 没有"通关"，只有不同的结局 | 低——商业上需要勇气不做数值引导 |
| 领导风格画像 | 全程记录生成风格报告 | 低——数据记录和呈现方式可复制 |

**核心护城河：** 情感共鸣 + AI 行为深度。当玩家把自己的同事"装进"游戏、看到 AI 驱动的 NPC 表现出相似行为时，那种情感绑定是竞品无法快速复制的。

## 五、核心模块详解

### 5.1 角色设定系统

**职责：** 玩家在开局阶段构建公司全体员工的基础画像，是整个游戏的起点。

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 成员定义 | 玩家添加公司成员，包括平级同事、部门领导、上级 BOSS | 最少 3 人，不限上限 |
| 起名 | 玩家可自由命名角色 | 不要求真名，支持昵称/代号 |
| 性格标签 | 从预设维度中选择角色性格 | 选择标签而非输入，避免隐私风险 |
| 岗位配置 | 为每个角色分配岗位 | 岗位影响日常行为和产出逻辑 |
| 能力初始值 | 设定角色的基础能力水平（1-10） | 与岗位匹配度影响初始产出 |
| 隐私保护 | 所有数据仅存储在本地设备 | 不上传服务器、不要求真实信息 |

**7 大性格维度：** 责任心、社交需求、诚实度、情绪稳定性、权力欲、忠诚度、主动性。

### 5.2 NPC 智能系统

**职责：** 驱动所有角色自主行动，性格决定其行为模式、对话风格和决策逻辑。

- AI 行为引擎：每个 NPC 独立运行行为决策循环
- 日常行为循环：自动执行岗位相关行为（工作/摸鱼/社交/休息）
- 角色间化学反应：合作（产出+15%）、冲突（产出-20%）、抱团、对立、好感、厌恶
- 离职倾向机制：隐性数值 0-100，受加薪不公/偏袒/裁员/过度加班等影响
- 辞职信号不直接显示：玩家需要通过观察（频繁看手机、茶水间抱怨、效率下降）来判断
- 玩家也可以主动辞职作为结局之一

### 5.3 职业系统

**职责：** 定义每个 NPC 的岗位价值、能力成长和经济贡献。

7 个岗位类型：程序员、销售、设计、人事、财务、运营、管理。每个岗位有适配的性格倾向，人岗错配导致产出下降 10-30% 和离职倾向加速。

**招人流程：** AI 生成候选人简历 → 玩家决定是否面试 → 面试揭示部分隐藏信息 → 录用决策 → 试用期观察。

### 5.4 人际关系与办公室政治

NPC 之间关系由性格匹配度决定初始值，日常互动推动变化。小团体形成、站队、背后动作、办公室恋情、靠山体系——完整模拟真实职场政治生态。

### 5.5 事件与决策系统

**自动触发：** 事件按时间节奏和条件自动发生，不弹出选择弹窗。玩家通过视觉和系统消息感知事件。

**干预方式：** 走过去对话 / 一对一谈话 / 发邮件 / 开会 / 调岗 / 冷处理。不干预也是一种应对，问题自然积累可能爆发或自行消散。

### 5.6 结局与评价系统

**6 种结局：** 被裁 / 主动辞职 / 公司上市 / 公司倒闭 / 平庸领导 / 引路人 / 代价。

**领导风格画像：** 全程记录决策，从干预频率、决策速度、公平倾向、严厉程度、沟通方式、长远眼光 6 个维度生成风格报告，同一个公司配置可以玩出完全不同的风格画像。

## 六、用户流程

```
开局
  ├─ 1. 设定公司成员（命名/性格/岗位/能力）
  ├─ 2. 确认入职 → 办公区生成
  ├─ 3. 观察与适应 → 第一个事件触发
  ├─ 4. 日常循环
  │    ├─ 观察到事件 → 干预/不干预
  │    ├─ 周期性节点（月/季/年）
  │    └─ 招人/裁员/应对外部事件
  ├─ 5. 结局触发
  └─ 6. 结局展示（风格画像 + NPC 结局）
```

## 七、商业模式

### 7.1 定价区间

| 付费模式 | 定价区间 | 依据 |
|---------|---------|------|
| PC 买断制 | 58-88 元 | 独立模拟游戏标准价格带 |
| 首发折扣 | 39-58 元 | 首周/预售折扣 |

**用户心理价位：** 独立游戏玩家对 50-80 元的像素风策略模拟类定价接受度高。

### 7.2 销售渠道

| 渠道 | 优先级 |
|------|--------|
| Steam | ★★★★★ 首发渠道 |
| B 站 UP 主实况 | ★★★★★ 核心传播（适合像素风叙事游戏） |
| 职场类公众号/知乎 | ★★★★ 精准触达职场人群 |

### 7.3 盈利模式

| 收入来源 | 预期占比 |
|---------|---------|
| 游戏本体买断 | 85% |
| DLC（新岗位/新场景/新事件包） | 15% |

## 八、落地路径

### 8.1 五大落地难点

| 难点 | 缓解策略 |
|------|---------|
| AI 行为质量不足时 NPC 显得"蠢" | 初期用脚本+规则引擎兜底，AI 作为增强层 |
| 内容量不足以支撑多周目 | 随机事件池+性格组合多样性自然产生变化 |
| 像素风可能被误认为"小孩游戏" | 宣传强调"成人向职场模拟" |
| 管理模拟类受众相对窄 | 靠口碑和内容传播，不追求大 DAU |
| 结局缺乏"爽感"影响评价 | 不追求通关，追求情感共鸣 |

### 8.2 MVP 最小可行产品

| 功能 | MVP | 后续 |
|------|-----|------|
| 角色设定 | 预设模板快速生成 | 完整自定义 |
| NPC 行为 | 规则引擎驱动 | AI 增强 |
| 事件 | 10 个核心事件 | 完整事件池 |
| 结局 | 3 种核心结局 | 6+ 种结局 |
| UI | 基础像素风 | 完整像素美术 |

**最低试错成本：** 1-2 人 × 3-4 个月 ≈ 10-15 万。

### 8.3 第一步验证

**最关键假设：** 职场人愿意在游戏中"当领导"并承受决策代价。

**验证方法：** 做 1 个可玩的场景（3 个 NPC + 基本事件循环），让 30 个职场人试玩。判断标准：完成一局后，超过 50% 的人表示"想再玩一局试试不同做法"。

## 九、风险与预期反馈

| 预期槽点 | 应对方案 |
|---------|---------|
| "像素风太简陋了" | 像素是有意选择的美术风格，降低美术成本聚焦玩法 |
| "NPC 行为好傻" | MVP 阶段用规则引擎，后续 AI 增强 |
| "玩完有点压抑" | 游戏本就不是爽游戏，是情感体验 |
| "内容太少" | 随机事件 + 性格组合保证重玩性 |
| "不就是个管理模拟吗" | 强调角色投射和情感共鸣的差异化 |

## 十、边界与原则

| 不做 | 原因 |
|------|------|
| 多人在线或联机 | 核心体验是单人沉浸式角色投射 |
| 手游/移动端 | 像素画面在小屏幕上体验差 |
| 付费抽卡或内购 | 不是数值养成游戏 |
| 真实身份验证 | 所有数据仅存本地 |
| 传统线性剧情 | 故事由性格和决策共同生成 |
| 战斗或动作要素 | 定位管理模拟 + 情感体验 |
