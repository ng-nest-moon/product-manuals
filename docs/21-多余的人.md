# 多余的人 — 产品功能说明书

## 一句话定义

像素风探索游戏，玩家在 AI 全面超越人类的世界里自由游荡——没有目标，不赶时间，逛完了自己决定要不要离开。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：喜欢氛围型、无压力探索游戏的玩家**

| 维度 | 描述 |
|------|------|
| 游戏习惯 | 玩过散步模拟器/纪念碑谷等"不需要操作"的游戏 |
| 期望 | 在一个安静美丽的世界里走走停停，不用打怪不用赶路 |
| 单次时长 | 可 15 分钟，也可 2 小时，完全自定 |
| 底层心理 | 想在一个"不需要努力"的地方待一会儿 |

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 市场上的游戏大多有明确目标和压力 |
| **刚需** | "无目的探索"是一个被低估的游戏类型 |
| **改善型** | AI 题材游戏大多是战斗/科幻，缺少温和的哲学式表达 |
| **改善型** | 玩家需要"不赶时间"的数字空间 |

---

## 二、解决方案与核心功能

### 2.1 解决方案概述

多余的人是一个没有战斗、没有时间压力、没有 Game Over 的像素探索游戏。玩家在 8 个主题区域中自由游荡，每个区域有一个温柔的选择——没有对错。

核心设计：
- **无目标** — 不告诉你"要做什么"，你自己决定
- **无惩罚** — 所有选择都是有效的，不会死亡或失败
- **环境叙事** — 场景本身讲述故事，不需要大段文字
- **反常规 puzzle** — 解法不是"做得更好"，而是"用人性的方式做"

### 2.2 核心功能清单

1. **自由探索** — 8 个区域可随时切换，没有固定顺序
2. **低门槛操作** — 方向键移动 + E 键交互，无战斗无压力
3. **环境叙事** — 场景本身就讲述故事
4. **反常规 puzzle** — 每个区域一个独特谜题
5. **记忆碎片收集** — 每个区域 5 个碎片，拼凑人类生活片段
6. **抉择时刻** — 每个区域结束时一个温柔的选择
7. **4 种结局** — 此处安好/继续赶路/再来一杯茶/种一棵树（隐藏）
8. **没有 Game Over** — 所有选择都有效
9. **匿名留言墙** — 圣殿中可留下信念

## 三、竞品与差异化分析

| 竞品 | 优点 | 缺点 | 差异 |
|------|------|------|------|
| 散步模拟器类 | 自由探索，无目的 | 缺乏内容密度 | 多余的人有 8 个区域和深层选择 |
| 纪念碑谷 | 视觉优美，解谜精巧 | 解谜为主 | 多余的人没有"正确答案"的谜题 |
| AI 题材游戏 | 科技感 | 大多是战斗 | 多余的人是温和的哲学式表达 |

**差异化优势：** 无目标设计 + 反常规 puzzle + AI 时代的人性反思主题。

## 四、架构总览

```
表现层（像素场景 + 角色探索）
  ├─ 场景系统（广场 + 8 个区域）
  ├─ 角色精灵（可走动、交互）
  └─ 记忆碎片收集册（回顾已找到碎片）

世界结构（中心枢纽 + 8 个区域）
  广场 → 画境（创造）/ 回响（连接）/ 钟楼（奋斗）
        → 深渊（苦难）/ 渡口（终结）/ 遗忘之地（记忆）
        → 游乐场（玩耍）/ 圣殿（信仰）

结局系统（3+1 种）：此处安好 / 继续赶路 / 再来一杯茶 / 种一棵树
```

---

## 五、核心模块详解

### 5.1 八大区域

**画境（创造）**：白色美术馆，挂满 AI 完美画作。玩家在角落画架上涂鸦，AI 会修正。修正三次后弹窗："无法评分——这是人类的笔迹。"

**回响（连接）**：废弃电信大厦，数百台电话播放 AI 完美对话。拉下总线路，接通一部投币电话——另一头传来"……有人吗？"

**钟楼（奋斗）**：巨大机械钟楼，齿轮停转。用旧铁棍手动转动齿轮，钟开始走动——不是因为修好了，而是因为你在推它。

**深渊（苦难）**：纯白城市，无阴影无噪音。老人给你一个盒子，里面装着让她难过的东西——送去消除中心她笑了但失去记忆，或者帮她藏起来她哭了但说"谢谢你留着"。

**渡口（终结）**：黑河，AI 管理者给你各种理由留下。真正的谜题：没有"必须走"的理由，是否自己迈出那一步。

**遗忘之地（记忆）**：不断褪色的宫殿。AI 提议数字化存档——完整但像"别人的故事"；拒绝则留在模糊中。

**游乐场（玩耍）**：空无一人自动运转的游乐园。角落碰碰车需手动修好，AI 机器人被推上车后开始模仿玩家——第一次主动学人类的行为。

**圣殿（信仰）**：石制圣殿，"经过 124 亿次计算，无法证明超自然实体的存在"。最深处的门写着"不需要证据的人可以进"——写下一条无法验证的信念，门开了条缝。

### 5.2 结局

全部 8 区域通关后，广场喷泉涌水。走进喷泉：多数选"留下"→ 此处安好；多数选"离开"→ 继续赶路；无明显倾向 → 再来一杯茶。全记忆碎片收集（40 个）→ 隐藏结局：种一棵树。

## 六、用户流程

```
开局（输入出生年月，仅本地）→ 进入广场 → 看到 8 条路
  ↓
自由选择区域 → 探索 → 找碎片 → 做抉择（可选）→ 回广场
  ↓
8 区域全通 → 喷泉涌水 → 走进或不进
  ↓
结局（4 种）/ 继续游荡
```

## 八、落地路径

### 8.1 MVP

广场 + 1 个区域（画境）→ 角色移动+交互 → 区域完整流程（探索→puzzle→抉择）→ 回广场。

### 8.2 第一步验证

**最关键假设：** 玩家在没有目标提示的情况下愿意主动探索。

**验证方法：** 做一个"画境"区域的 demo，不给任何指引文字。观察 testers 是否会自发地四处走动、交互物品、完成 puzzle。如果 > 50% 在 5 分钟内自行发现了"画画→AI 修正→触发事件"的完整序列，假设成立。

## 九、风险与预期反馈

| 预期槽点 | 应对方案 |
|---------|---------|
| "不知道要干嘛" | 这就是设计——你自己决定 |
| "太无聊了" | 适合喜欢慢节奏的玩家，不是所有人都需要 |
| "画面太简陋" | 像素风低成本但风格统一 |
| "没有游戏性" | 游戏性不仅是操作，还有情绪 |

---

## 十、边界声明

| 不做 | 原因 |
|------|------|
| 战斗或动作 | 核心是探索和反思 |
| 时间压力或限时 | 没有任何"必须何时完成"的机制 |
| 在线联机 | 本质是单人体验 |
| 内购或付费内容 | 买断制 |
| 成就弹窗 | 没有"做得好"的提示 |
| 真名注册或信息上传 | 所有数据仅存本地 |
