# 鬼话连篇 — 产品功能说明书

## 一句话定义

一群人围坐讲鬼故事，但讲着讲着，故事里的鬼开始出现在现实中。你必须分辨哪些是编的、哪些是真的——因为相信错误的故事，会害死你。

---

## 一、产品形态

| 维度 | 决策 |
|------|------|
| 类型 | 单人恐怖推理游戏（实时叙事污染） |
| 视角 | 第一人称，固定场景（老宅客厅） |
| 一局时长 | 45-75 分钟 |
| 首发平台 | PC（Steam） |
| 定价 | 买断制 |

---

## 二、世界观设定

### 2.1 核心前提

一座与世隔绝的老宅，7 个人被困其中，大雨封路，信号中断，任何人无法离开。

有人提议"讲鬼故事打发时间"——但这座老宅本身有问题。

每讲一个鬼故事，老宅里的"东西"就活跃一分。不讲会冷场尴尬，讲了可能招来不该来的。唯一的目标：**活到天亮**。

### 2.2 老宅背景

| 层 | 信息 | 玩家可见度 |
|----|------|-----------|
| 表层 | 一栋民国时期的旧宅，废弃多年，最近被改建成民宿 | 开局即知 |
| 中层 | 近百年来，老宅范围内失踪过 12 人，从未找到尸体 | 游戏进程中逐步发现 |
| 深层 | 老宅建在一处"地脉裂隙"上——此地是不同"叙事层"的交汇点。强烈的叙事（鬼故事）会撕裂现实与非现实的边界 | 仅最终结局揭示 |

### 2.3 叙事污染规则

| 规则 | 说明 |
|------|------|
| 污染源 | 每个讲出的鬼故事都是污染源 |
| 污染积累 | 故事讲得越精彩、细节越丰富、讲述者情绪越投入，污染值越高 |
| 污染体现 | 听觉（异响）→ 视觉（影子/光影异常）→ 触觉（温度下降/物体移动）→ 具象化（故事中的鬼物部分显现） |
| 污染不可逆 | 污染只能被抑制（停止讲故事、转移话题），不能被消除 |
| 临界点 | 污染值到达阈值时触发"显现事件"——某个故事中的鬼物真正出现在老宅中 |

## 三、架构总览

```
表现层（第一人称老宅客厅 + 状态面板）
 ├── 客厅场景 —— 固定视角，7 人围坐，环境随污染程度变化
 ├── 叙事记录 —— 每个 NPC 的讲述被自动转录为文本，可回溯
 ├── 推理面板 —— 证据链 / 矛盾对比 / 可信度评分
 ├── 状态 HUD —— 污染指示器 / 各 NPC 状态 / 恐惧值 / 距天亮时间
 └── 结局演出 —— 根据玩家推理结果触发的多分支结尾

叙事污染引擎（核心）
 ├── 污染值计算 —— 根据故事内容、细节密度、情绪强度实时累加
 ├── 环境反馈系统 —— 灯光 / 音效 / 温度 / 物体位移的逐级变化
 ├── 显现事件调度 —— 污染达阈值时从当前故事池抽取显现
 ├── 污染篡改 —— 高污染下玩家的记录文本可能被修改
 └── 抑制机制 —— 转移话题 / 质疑故事 / 中断讲述 可减缓污染

NPC 系统（6 个独立角色）
 ├── 角色属性 —— 身份 / 动机 / 秘密 / 讲述风格
 ├── 叙事生成 —— 每个 NPC 的鬼故事根据其角色设定动态生成
 ├── 情绪状态 —— 恐惧 / 兴奋 / 怀疑 / 沉默 影响讲述行为
 ├── 信任网络 —— 对其他 NPC 和玩家的信任度动态变化
 └── 私下交互 —— 特定条件触发一对一密谈

推理系统
 ├── 叙事记录 —— 自动记录所有讲述，标注时间戳和讲述者
 ├── 矛盾检测 —— 不同 NPC 对同一细节的表述自动对比标红
 ├── 可信度评估 —— 基于讲述者状态、情绪、历史一致性评分
 ├── 证据污染警告 —— 高污染下记录可能被篡改，标注"存疑"
 └── 推理结论 —— 玩家拼合线索得出最终判断

恐惧值系统
 ├── 恐惧来源 —— 污染事件 / 他人讲述 / 独自调查 / 时间推移
 ├── 恐惧影响 —— 高恐惧下判断力下降，可能看错听错
 ├── 恐惧抑制 —— 有人陪伴 / 理性分析 / 发现真相 可以降低恐惧
 └── 恐惧峰值 —— 达到上限触发"恐慌"——强制失能一段时间

结局系统
 ├── 清醒者 —— 找出真相，全员存活
 ├── 幸存者 —— 活到天亮，但有人死亡或疯狂
 ├── 沉沦者 —— 相信了假故事并按它的规则行动
 ├── 揭穿者 —— 发现真正的"鬼"不在老宅而在人之间
 └── 迷失者 —— 被老宅同化，成为第十三个失踪者
```

---

## 四、核心功能清单

1. **实时叙事污染** — 每个讲出的鬼故事实时改变环境，污染累积触发显现事件
2. **6 个独立 NPC** — 各有身份、动机、秘密和独特的讲述风格，故事内容动态生成
3. **自动叙事记录** — NPC 的每句话被自动转录，支持回溯对比
4. **矛盾检测推理** — 系统自动标注不同版本间的矛盾点，辅助推理
5. **证据污染机制** — 高污染下记录可能被篡改，玩家不能完全信任自己的笔记
6. **恐惧值系统** — 恐惧影响判断力，制造"越怕越看不清"的恶性循环
7. **信任网络** — NPC 对玩家的信任度影响其私下透露的信息量
8. **叙事抑制** — 玩家可主动质疑、打断、转移话题来控制污染节奏
9. **4+1 种结局** — 基于玩家推理结论和行为的多种结局
10. **环境渐进变化** — 老宅从正常到扭曲的视觉/听觉演变，不依赖跳吓

## 五、角色池

### 5.1 角色总览

| 角色 | 身份 | 讲述风格 | 隐藏秘密 |
|------|------|---------|---------|
| 你 | 偶然入住的游客 | 自选（可撒谎可讲真事） | 全员中唯一不知情的人 |
| 林述 | 民宿老板，30 岁 | 喜欢渲染气氛，真假混讲，追求故事效果 | 他知道老宅死过人，但隐瞒了人数 |
| 苏晚 | 中学教师，28 岁 | 只讲"听来的真事"，但来源不可靠 | 她包里有一本前任住客遗留的日记 |
| 陈小满 | 大学生，20 岁 | 胆子最小，被逼着讲，越讲越怕 | 她刚才在窗外的雨里看到了一张脸 |
| 方竞 | 自由摄影师，35 岁 | 编造离奇经历吸引注意，细节经不起推敲 | 他什么都没见过，但需要别人关注他 |
| 老赵 | 退休工人，62 岁 | 讲几十年前的旧事，记忆模糊，细节矛盾 | 年轻时在这片区域修过路，见过不该见的东西 |
| 白鸦 | 身份不明，约 25 岁 | 沉默寡言，被迫开口时细节异常真实 | 她不记得自己是怎么来到这座老宅的 |

### 5.2 角色关系网

| 关系 | 涉及 | 说明 |
|------|------|------|
| 旧识 | 林述 ↔ 老赵 | 林述小时候老赵帮他家修过房子，但两人都不确定是否认对了 |
| 怀疑 | 白鸦 ↔ 所有人 | 白鸦的出现最晚，没人记得她什么时候进来的，但都默认她在 |
| 保护欲 | 陈小满 → 林述 | 林述一直在照顾最害怕的陈小满，但原因不明 |
| 对立 | 方竞 ↔ 苏晚 | 方竞编故事时苏晚会拆穿，两人关系紧张 |

### 5.3 叙事生成约束

每个 NPC 讲鬼故事时遵循以下规则：

| 约束 | 说明 |
|------|------|
| 风格一致 | 讲述风格始终符合角色设定，不出现性格跳跃 |
| 细节来自自身 | 故事中的场景、物品、地名来自该角色的真实经历碎片 |
| 秘密稀释 | 角色的真实秘密不会直接出现在故事中，但会以变形的方式流露 |
| 污染同步 | 故事越接近自己的恐惧点，污染值越高 |

## 六、叙事污染引擎

### 6.1 污染值计算

| 维度 | 权重 | 说明 |
|------|------|------|
| 时长 | 基础系数 | 每讲 1 分钟 +10 基础污染 |
| 细节密度 | ×1.0-3.0 | 每多一个具体细节（名字、地点、时间、感官描述）乘数递增 |
| 情绪强度 | ×1.0-2.5 | 讲述者越投入（颤抖/激动/压低声音），乘数越高 |
| 听众反应 | ×0.5-1.5 | 听众越安静越专注，乘数越高（被打断会降低） |
| 故事真实性 | ×0.5-2.0 | 真实事件改编比纯编造污染更高 |

### 6.2 污染等级与表现

| 等级 | 污染值范围 | 环境表现 | 游戏影响 |
|------|-----------|---------|---------|
| 安宁（Lv.0） | 0-20 | 正常老宅，雨声，灯光稳定 | 无影响 |
| 低语（Lv.1） | 20-50 | 偶尔听到有人小声说话（无人开口时），灯光轻微闪烁 | 部分 NPC 开始紧张 |
| 寒意（Lv.2） | 50-100 | 温度明显下降，呼气可见白雾，角落有影子滞留 | NPC 讲述意愿下降，部分人想停 |
| 骚动（Lv.3） | 100-200 | 物体轻微位移，墙壁有刮擦声，窗外可见模糊人影 | 记录系统开始出现乱码 |
| 显现（Lv.4） | 200-400 | 某个故事中的鬼物局部显现，攻击 NPC | 强制进入生存模式 |
| 侵蚀（Lv.5） | 400+ | 老宅空间扭曲，现实与非现实边界消失 | 最终结局前置 |

### 6.3 显现事件

当污染值达到指定阈值时，从"当前活跃故事池"中抽取一个显现事件：

| 事件 | 触发条件 | 效果 | 应对方式 |
|------|---------|------|---------|
| 重复低语 | 污染 ≥50 | 无人在说话时听到有人反复念一个名字 | 找到那个名字的来源，否则全体恐惧 +10 |
| 物体消失 | 污染 ≥100 | 场景中某件物品消失（如茶杯、照片） | 没人承认动了它，恐慌蔓延 |
| 门无故开关 | 污染 ≥150 | 老宅的门自行打开或关闭 | 需要有人去关上（单独行动有风险） |
| 影子分离 | 污染 ≥200 | 某个 NPC 的影子做出与他不同的动作 | 立即暴露在视野中，否则影子会消失 |
| 故事具象化 | 污染 ≥300 | 当前污染值最高的故事中的鬼物开始成形 | 根据该故事的"规则"对抗（打破规则即可消失） |
| 时间断裂 | 污染 ≥400 | 钟表开始倒走，有人记忆出现大面积空白 | 进入终局阶段 |

### 6.4 抑制机制

玩家可采取以下行动减缓污染：

| 行动 | 效果 | 代价 |
|------|------|------|
| 质疑故事细节 | 打断讲述节奏，污染增速 -30% | 讲述者不满，信任下降 |
| 转移话题 | 切换注意力，污染 -20 固定值 | 被转移者可能反感 |
| 提议休息 | 暂停讲故事，污染随时间自然衰减（每 1 分钟 -5） | 可能有人反对（想离开的人着急） |
| 拆穿谎言 | 如果故事是编造的，拆穿后可大幅降低污染 | 揭穿者可能被报复 |
| 讲一个"安全"的故事 | 用低污染的故事覆盖高污染的氛围 | 需要提前准备/编造一个无害的故事 |

## 七、推理系统

### 7.1 叙事记录

| 功能 | 说明 |
|------|------|
| 自动转录 | 所有 NPC 的讲述自动转为文本，标注讲述者、时间戳 |
| 标签分类 | 每条记录自动标注：事实陈述 / 个人观点 / 情绪表达 / 明显编造 |
| 搜索回溯 | 玩家可搜索关键词，快速定位不同版本中对同一事物的描述 |
| 污染标记 | 若记录在高污染下产生，标记为"存疑——可能已被污染" |

### 7.2 矛盾检测

| 矛盾类型 | 示例 | 系统表现 |
|---------|------|---------|
| 时间矛盾 | A 说"三年前"，B 说"五年前" | 标红并排展示 |
| 人物矛盾 | A 说"一个人"，B 说"两个人" | 生成矛盾卡片 |
| 因果矛盾 | A 说"先有声音后有影子"，B 说"先有影子后有声音" | 标注为关键矛盾 |
| 记忆矛盾 | 同一人两次讲述细节不一致 | 标注"自相矛盾" |

### 7.3 推理结论

玩家在游戏结束时需要回答一组问题以触发对应结局：

| 问题 | 回答方式 | 影响结局 |
|------|---------|---------|
| 这座老宅到底有什么？ | 从证据中选择 | 核心判断 |
| 谁讲的鬼故事是真的？ | 选择一个 NPC | 影响信任路线 |
| 那个"东西"怕什么？ | 从故事中找到规则 | 决定能否存活 |
| 你相信谁？ | 选择信任对象 | 决定是否有人陪你到最后 |

## 八、恐惧值系统

### 8.1 恐惧来源与数值

| 来源 | 增加量 | 说明 |
|------|--------|------|
| 听到恐怖故事 | +5-15/个 | 取决于故事本身的恐怖程度 |
| 观察到异常 | +10-30/次 | 看到影子、听到异响等 |
| 独自一人 | +5/分钟 | 离开客厅单独行动时 |
| 污染等级提升 | +20/级 | 每次污染等级突破 |
| 显现事件 | +30-60/次 | 鬼物实际出现时 |
| 时间接近天亮 | +2/分钟（最后 10 分钟） | 黎明前最黑暗的焦虑 |

### 8.2 恐惧影响

| 恐惧值 | 等级 | 对玩家的影响 |
|--------|------|-------------|
| 0-30 | 冷静 | 无影响，判断力正常 |
| 30-60 | 紧张 | 偶尔出现听觉错觉（把风声听成脚步声） |
| 60-100 | 恐惧 | 推理面板出现随机干扰信息，需要二次确认 |
| 100-150 | 恐慌 | 叙事记录出现乱码，部分条目不可读 |
| 150-200 | 濒临崩溃 | 屏幕边缘出现幻觉，真实环境与幻觉混杂 |
| 200+ | 崩溃 | 角色失能，强制跳过一段时间（期间 NPC 可能出事） |

### 8.3 恐惧抑制手段

| 手段 | 效果 | 条件 |
|------|------|------|
| 与他人同处一室 | 恐惧增速 -50% | 不单独行动 |
| 理性分析故事破绽 | 恐惧 -15/次 | 发现逻辑漏洞 |
| 确认某个 NPC 安全 | 恐惧 -20 | 证实某人的故事是假的 |
| 发现关键真相碎片 | 恐惧大幅下降 | 每解锁一个关键信息 |
| 有人握住你的手 | 恐惧停止增长 | 信任度达到一定水平的 NPC |

## 九、结局系统

### 9.1 结局一览

| 结局 | 触发条件 | 简述 |
|------|---------|------|
| 清醒者 | 正确回答全部四个问题，找出真相，污染未达 Lv.5 | 全员平安，天亮后老宅恢复平静。你带走了那本日记，从此再没对人提起那晚的事 |
| 幸存者 | 活到天亮（时间耗尽），但至少一人死亡或疯狂 | 你活着走出了老宅，但总在深夜听到雨声和当时那些故事的片段 |
| 沉沦者 | 相信了假故事，并按故事中的规则行动 | 你为了保护自己做了故事里教的事，但那正是真正的鬼希望你做的。天亮时你不在人群中 |
| 揭穿者 | 发现所有鬼故事都是假的，真正的威胁来自在场的某个人 | 没有鬼。有人利用大家的恐惧在掩盖更现实的目的。你揭穿了他——但其他人相信你吗？ |
| 迷失者 | 污染值达到 Lv.5 且未能恢复 | 老宅的墙壁上又多了一个模糊的影子。第 13 个失踪者，就是你 |

### 9.2 结局评价维度

| 维度 | 说明 |
|------|------|
| 幸存者数 | 除了你之外还活着离开的人数（0-6） |
| 理智状态 | 游戏结束时你的恐惧水平（0-200） |
| 真相完成度 | 正确推理出的核心信息比例（0-100%） |
| 污染等级 | 游戏结束时老宅的污染等级（0-5） |
| 信任得分 | 最终有多少 NPC 信任你（0-6） |

## 十、用户流程

```
开局
  │
  ├─ 序幕（约 5 分钟）
  │     ├─ 开场动画：大雨中你到达老宅，其余 6 人已在客厅
  │     ├─ 基础教学：移动、观察、与 NPC 对话
  │     ├─ 环境介绍：认识老宅客厅及可探索的相邻房间
  │     └─ 触发事件：有人说"要不，讲个鬼故事打发一下？"
  │
  ├─ 第一阶段：暖场（污染值 0-30）
  │     ├─ 第一个讲故事的人被推出（通常是林述或方竞）
  │     ├─ 故事期间玩家了解系统：叙事记录、污染指示器
  │     ├─ 故事结束后出现第一次轻微异常（灯光闪烁）
  │     └─ NPC 开始各怀心思地回应
  │
  ├─ 第二阶段：蔓延（污染值 30-150）
  │     ├─ 更多 NPC 开始自发讲故事
  │     ├─ 污染进入 Lv.2-3，环境明显异常
  │     ├─ 出现第一个显现事件（物体消失或门开关）
  │     ├─ 玩家开始收集矛盾信息，进入推理模式
  │     └─ 有些人想停，有些人想继续，分歧出现
  │
  ├─ 第三阶段：失控（污染值 150-300）
  │     ├─ 某个故事中的鬼物真正显现（显现事件）
  │     ├─ 玩家必须采取抑制行动，否则污染继续攀升
  │     ├─ 恐惧值进入高危区，判断力开始受影响
  │     ├─ 信任网络变得关键——谁可以依靠，谁在说谎
  │     └─ 部分 NPC 可能受伤或失能
  │
  ├─ 第四阶段：终局（污染值 300+ 或时间进入最后 15 分钟）
  │     ├─ 玩家必须回答四个核心问题
  │     ├─ 根据回答触发对应的结局路线
  │     ├─ 最终场景演出
  │     └─ 结算画面：结局评价 + 数据回顾
  │
  └─ 通关后
        ├─ 解锁新游戏+（角色秘密随机化重排）
        ├─ 成就系统
        └─ 全结局解锁奖励：老宅背景全貌文档
```

## 十一、应用场景

### 场景一：深夜单人沉浸

> 玩家在晚上关灯戴上耳机，一局通关

45-75 分钟的紧凑体验，适合一个晚上的完整沉浸。叙事污染的音效设计（环绕声低语、远处敲击声、温度感的视觉暗示）配合耳机效果最佳。游戏不依赖跳吓，靠持续的心理压迫感制造恐怖。

### 场景二：多周目解谜

> 玩家反复游玩，试图解锁全部结局

每个结局要求不同的推理结论——"清醒者"需要找出真相，"揭穿者"需要识破所有人的谎言，"沉沦者"需要相信一个特定的假故事。不同选择导向完全不同的叙事体验。同时 NPC 的秘密在二周目中会变化排列，保证重玩价值。

### 场景三：直播与实况

> 主播与观众一起推理

推理过程适合与观众互动——"你们觉得谁在说谎？""这个矛盾点你们看到了吗？""该信 A 还是 B？"观众可以参与投票式推理。每个结局都有强烈的叙事反转，适合剪辑传播。"揭穿者"结局的"根本没有鬼"反转最有讨论度。

## 十二、边界声明

| 不做 | 原因 |
|------|------|
| 多人联机 | 核心体验是孤独感和信息不对称——知道别人是人而不是 AI 会破坏恐怖感 |
| 战斗系统 | 无法对抗鬼——只能理解规则、规避危险、保护他人。战斗会削弱无力感 |
| 开放式地图 | 场景限制在老宅内，强化封闭空间压迫感 |
| 跳吓式恐怖 | 不依赖突然出现的鬼脸音效，靠氛围和叙事积累的心理压力 |
| 随机生成故事 | NPC 的故事是预设计但参数化生成的，保证每条故事都有推理价值 |
| 跨局存档互通 | 每局独立，不继承能力或道具 |
| 移动端首发 | 叙事记录面板和推理操作在 PC 大屏上体验最佳 |
| 多语言首发 | MVP 仅中文，叙事文本量大，本地化成本高 |
| 内购/抽卡 | 买断制，无额外付费内容 |
