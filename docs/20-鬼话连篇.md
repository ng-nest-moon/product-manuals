# 鬼话连篇 — 产品功能说明书

## 一句话定义

一群人围坐讲鬼故事，但讲着讲着，故事里的鬼开始出现在现实中。你必须分辨哪些是编的、哪些是真的——因为相信错误的故事，会害死你。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：喜欢推理和恐怖叙事游戏的老玩家（22-35 岁）**

| 维度 | 描述 |
|------|------|
| 游戏习惯 | 玩过返校/烟火/纸嫁衣/极乐迪斯科 |
| 期望 | 心理恐怖（非跳吓）+ 推理叙事 |
| 单局时长 | 45-75 分钟 |
| 底层心理 | 享受"信息不可靠"带来的推理挑战 |

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 恐怖游戏缺少原创的"信息污染"机制 |
| **刚需** | 玩家对纯跳吓式恐怖疲劳 |
| **改善型** | 推理游戏的信源总是可靠的——"信息不可靠"是未被充分挖掘的玩法 |

---

## 二、解决方案与核心功能

### 2.1 解决方案概述

鬼话连篇是一个恐怖推理游戏。7 人被困老宅，轮流讲鬼故事。每讲一个故事，污染值上升，环境恶化——故事中的"东西"开始出现在现实中。玩家必须在恐惧和可信度之间分辨谁在说谎，谁的真正危险。

核心设计：
- **叙事污染引擎** — 鬼故事的内容实时改变环境，污染积累触发显现事件
- **证据污染** — 高污染下你的记录可能被篡改，不能完全信任笔记
- **6 个不可靠叙事者** — 每人有不同动机和秘密，故事真伪参半
- **恐惧影响判断力** — 越怕越看不清，越看不清楚越怕

### 2.2 核心功能清单

1. **实时叙事污染** — 每个鬼故事实时改变环境，污染累积触发显现
2. **6 个独立 NPC** — 各有身份、动机、秘密和独特讲述风格
3. **自动叙事记录** — NPC 的每句话自动转录，可回溯对比
4. **矛盾检测** — 不同版本间的矛盾自动标注
5. **证据污染** — 高污染下记录可能被篡改
6. **恐惧值系统** — 恐惧影响判断力
7. **信任网络** — NPC 信任度影响私下信息
8. **抑制机制** — 质疑/打断/转移话题控制污染节奏
9. **5 种结局** — 清醒者/幸存者/沉沦者/揭穿者/迷失者
10. **环境渐进变化** — 从正常到扭曲的视听演变

## 三、竞品与差异化分析

| 竞品 | 优点 | 缺点 | 差异 |
|------|------|------|------|
| 烟火/返校 | 中国风恐怖叙事 | 线性剧情 | 鬼话连篇每局不同，推理驱动 |
| 纸嫁衣 | 氛围好，解谜设计 | 偏重谜题 | 鬼话连篇核心是"信谁"而非解谜 |
| 极乐迪斯科 | 技能驱动的叙事 | 西式背景 | 鬼话连篇聚焦信息可靠性的推理 |

**差异化优势：** "讲故事污染现实"机制 + 证据污染（不可靠笔记）+ 5 种推理结局。

## 四、架构总览

```
表现层（第一人称老宅客厅 + 状态面板）
  ├─ 客厅场景（固定视角，7 人围坐，环境随污染变化）
  ├─ 叙事记录（自动转录 + 矛盾检测 + 可信度评分）
  └─ 状态 HUD（污染指示器 / NPC 状态 / 恐惧值 / 距天亮时间）

叙事污染引擎（核心）
  ├─ 污染值计算（细节密度×情绪强度×听众反应×故事真实性）
  ├─ 环境反馈（灯光/音效/温度/位移的逐级变化）
  ├─ 显现事件调度（污染达阈值时抽取）
  └─ 污染篡改（高污染下记录被修改）

NPC 系统（6 个独立角色 + 信任网络）

推理系统（叙事记录 / 矛盾检测 / 可信度评估 / 证据污染）

恐惧值系统（恐惧来源 / 影响 / 抑制手段）

结局系统（清醒者 / 幸存者 / 沉沦者 / 揭穿者 / 迷失者）
```

## 五、核心模块详解

### 5.1 世界观设定

7 人被困老宅，大雨封路，有人提议讲鬼故事——但老宅建在地脉裂隙上，强烈的叙事会撕裂现实与非现实的边界。

**叙事污染规则：** 故事越精彩、细节越丰富、讲述者越投入，污染值越高。污染从听觉→视觉→触觉→具象化逐级加重。污染不可逆，只能抑制（停止讲故事/转移话题）。到达阈值触发"显现事件"——故事中的鬼物真正出现。

### 5.2 NPC 角色池（6 人）

| 角色 | 身份 | 讲述风格 | 隐藏秘密 |
|------|------|---------|---------|
| 林述 | 民宿老板，30 岁 | 真假混讲，追求效果 | 知道老宅死过人但隐瞒人数 |
| 苏晚 | 中学教师，28 岁 | 只讲"听来的真事" | 包里有前任住客日记 |
| 陈小满 | 大学生，20 岁 | 胆子最小，越讲越怕 | 窗外看到了一张脸 |
| 方竞 | 自由摄影师，35 岁 | 编造离奇经历 | 什么都没见过，需要关注 |
| 老赵 | 退休工人，62 岁 | 讲几十年前旧事，细节矛盾 | 在这片区域见过不该见的东西 |
| 白鸦 | 身份不明，约 25 岁 | 沉默，细节异常真实 | 不记得自己怎么来的 |

### 5.3 污染等级

Lv.0 安宁（0-20）→ Lv.1 低语（20-50，灯光闪烁）→ Lv.2 寒意（50-100，温度下降，角落有影子）→ Lv.3 骚动（100-200，物体位移，记录出乱码）→ Lv.4 显现（200-400，鬼物具象化）→ Lv.5 侵蚀（400+，空间扭曲）。

### 5.4 推理系统

叙事记录：自动转录 + 标签分类（事实/观点/情绪/编造）+ 污染标记。矛盾检测：时间矛盾/人物矛盾/因果矛盾/自相矛盾。最终结束时回答 4 个问题触发对应结局。

### 5.5 恐惧系统

来源：讲故事（+5-15）、异常观察（+10-30）、独自一人（+5/分钟）、污染升级（+20/级）、显现事件（+30-60）。恐惧 > 60 产生推理干扰，> 100 乱码，> 150 幻觉与真实混杂，> 200 失能。

## 六、用户流程

```
序幕（5 分钟）：到达老宅 → 认识 6 人 → 有人提议讲鬼故事
  ↓
第一阶段 暖场（污染 0-30）：第一个故事 → 轻微异常
  ↓
第二阶段 蔓延（污染 30-150）：更多故事 → 环境异常 → 矛盾信息出现
  ↓
第三阶段 失控（污染 150-300）：鬼物显现 → 抑制行动 → 恐惧高企
  ↓
第四阶段 终局（污染 300+ 或最后 15min）：回答 4 个问题 → 结局
  ↓
通关后：新游戏+（秘密随机化）→ 全结局解锁
```

## 八、落地路径

### 8.1 MVP

核心叙事污染引擎 + 6 NPC 角色设定 + 自动叙事记录 + 3 种结局（清醒者/幸存者/迷失者）+ 基础恐惧系统 + 禁止跳吓。

### 8.2 第一步验证

**最关键假设：** 玩家享受"信息不可靠"带来的推理焦虑。

**验证方法：** 做一段纯文字交互 demo（无画面，纯故事文本+选项），测试玩家对"谁在说谎"的推理兴趣。如果 > 60% 玩家愿意读完并做出推理结论，需求成立。

## 九、风险与预期反馈

| 预期槽点 | 应对方案 |
|---------|---------|
| "太恐怖了不敢玩" | 恐怖是心理压迫而非跳吓，有轻度模式 |
| "分不清谁说的真的" | 矛盾检测系统辅助推理 |
| "一局太长了" | 45-75 分钟是完整叙事所需 |
| "记录被篡改太坑了" | 就是设计——"信息不可靠"是核心机制 |
| "没有战斗太无聊" | 定位是推理叙事，不是动作冒险 |

## 十、边界声明

| 不做 | 原因 |
|------|------|
| 多人联机 | 知道别人不是 AI 会破坏恐怖感 |
| 战斗系统 | 无力感是恐怖感的来源 |
| 开放式地图 | 封闭空间强化压迫感 |
| 跳吓式恐怖 | 不依赖突然出现的鬼脸 |
| 跨局存档互通 | 每局独立 |
| 移动端首发 | 叙事记录面板在大屏上更好 |
| 内购/抽卡 | 买断制 |
