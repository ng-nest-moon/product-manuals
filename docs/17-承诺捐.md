# 承诺捐 — 产品功能说明书

## 一句话定义

设定每日挑战并绑定免密代扣，完成则无事发生，失败则自动捐出承诺金——用损失厌恶驱动行为改变，让每一份"违约"都变成善意。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：想培养习惯但缺乏自我约束力的人**

| 维度 | 描述 |
|------|------|
| 身份 | 上班族、学生、自我提升爱好者 |
| 典型行为 | 立过很多 Flag（锻炼/阅读/早起），但坚持不下来 |
| 底层心理 | 知道应该做什么，但缺乏"不做就要付出代价"的外部约束 |
| 现有解法 | 打卡 App（没惩罚，弃了也没事）/ 押金群（钱去了别人口袋，不合规） |

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 习惯养成缺乏"不做就有代价"的约束机制 |
| **刚需** | 押金模式在中国不合规且有资金池风险 |
| **改善型** | 现有打卡工具没有实质惩罚，放弃成本为零 |
| **改善型** | 用户希望"即使失败了也有意义"（捐给公益） |

---

## 二、解决方案与核心功能

### 2.1 解决方案概述

承诺捐用"免密代扣 + 公益捐赠"替代传统押金模式。用户签约时绑定代扣（不预扣款），每日验证达标则无事发生，断签则自动扣款直达基金会账户。

核心设计：
- **零资金池** — 平台不经手资金，代扣直达基金会
- **损失厌恶驱动** — 比奖励更有效的行为改变机制
- **失败也有意义** — 扣款变成公益捐赠，负面情绪减半
- **合规安全** — 微信支付服务委托代扣官方接口

### 2.2 核心功能清单

1. **创建挑战** — 选择类型/目标/周期（7/21/30 天）/ 承诺金（5/20/50/100 元）
2. **签约代扣** — 微信支付委托代扣授权，不预扣款
3. **每日验证** — 5 种验证方式（步数/早起/专注/阅读/冥想）
4. **断签扣款** — 超时未完成 → 自动发起代扣 → 直达基金会
5. **公益项目池** — 3-5 个合作项目（山区净水/免费午餐/植树/乡村书柜）
6. **免死金牌** — 每月 2 次豁免
7. **履约日历** — 每日标记完成/跳过/断签
8. **成就徽章** — 连续完成 7/21/30/100 天
9. **组队挑战** — 2-5 人组队，一人违约全队受罚
10. **PK 模式** — 两人同类型目标比履约率

## 三、竞品与差异化分析

| 竞品 | 优点 | 缺点 | 差异 |
|------|------|------|------|
| 押金打卡群 | 社交压力 | 资金池不合规，群主跑路风险 | 承诺捐代扣直达基金，平台不碰钱 |
| 习惯打卡 App | 轻量免费 | 无惩罚，放弃零成本 | 承诺捐有实际财务惩罚 |
| Forest | 专注种树 | 虚拟惩罚，无实质损失 | 承诺捐是真金白银捐赠 |

**差异化优势：** 零资金池合规 + 公益捐赠驱动 + 免密代扣零启动成本。

## 五、核心模块详解

### 5.1 挑战系统

**挑战类型（5 种）：** 日行万步（微信运动自动同步）→ 早起打卡（时段内签到）→ 专注阅读（截图 AI 校验）→ 每日冥想（手动/穿戴设备）→ 自定义（高级用户，需审核）。

**参数：** 周期仅 7/21/30 天三档；承诺金 5/20/50/100 元四档；每月 2 次免死金牌。

**挑战终止规则：** 连续断签 3 天终止，剩余天数按比例扣款。

### 5.2 信用承诺机制（与押金模式对比）

| 维度 | 传统押金 | 信用代扣 |
|------|---------|---------|
| 资金流向 | 用户→平台→再处理 | 用户→代扣→基金会（平台不经手） |
| 资金池 | 有 | 无 |
| 合规风险 | 涉嫌非法集资+赌博 | 合规清晰 |
| 用户启动成本 | 先付钱 | 不预扣，零成本 |

**核心链路：** 签约代扣（仅授权不扣款）→ 每日验证 → 达标无事发生 / 断签发起代扣 → 资金直达基金会。

### 5.3 公益项目池

合作机构要求：持有公开募捐资格、可开具捐赠票据、有资金公示机制。

| 项目 | 产出 |
|------|------|
| 山区净水（壹基金） | 20 元 = 1 儿童 1 月安全饮水 |
| 免费午餐（中国社会福利基金会） | 20 元 = 1 儿童 1 周午餐 |
| 荒漠植树（中国绿化基金会） | 10 元 = 1 棵梭梭树 |
| 乡村小书柜（担当者行动） | 50 元 = 1 本书 |

### 5.4 合规说明

规避赌博定性：零资金池（代扣直达基金会）、用户不获利（钱全部捐赠）、平台不抽成、结果由用户行为决定（无随机概率）。敏感词替换："承诺金"替代"押金"，"捐赠"替代"罚款"。

## 六、用户流程

```
创建挑战 → 设定目标/周期/金额 → 选择公益项目
  ↓
微信签约代扣（不预扣款）→ 挑战开始
  ↓
每日自动/手动验证 → 达标继续 / 断签扣款
  ↓
宽限期：当日 24:00 前可补签
  ↓
超时 → 次日 08:00 自动扣款 → 微信通知捐赠完成
  ↓
挑战结束 → 全部完成得徽章 / 部分违约总结看板
```

## 七、商业模式

| 付费模式 | 定价 | 依据 |
|---------|------|------|
| 基础免费 | 0 元 | 所有核心功能免费 |
| Pro 订阅 | 10-20 元/月 | 自定义挑战 + 组队 PK + 详细数据报告 |

**盈利逻辑：** 公益属性降低定价空间，靠 Pro 订阅覆盖运营成本。平台不抽成捐赠资金，只收订阅费。

## 八、落地路径

### 8.1 MVP

步数/早起/阅读 3 种挑战 + 基础代扣流程 + 1 个公益项目 + 免死金牌 + 履约日历。

### 8.2 第一步验证

**最关键假设：** 用户愿意绑定代扣来驱动自己完成目标。

**验证方法：** 招募 50 人内测 7 天"日行万步"挑战，承诺金 20 元。关键指标：签约率 > 40%（愿意绑代扣的比例）、完成率 > 60%（7 天全部达标）。

## 九、风险与预期反馈

| 预期槽点 | 应对方案 |
|---------|---------|
| "绑代扣不安全" | 微信官方接口，可随时解约 |
| "这不就是赌博吗" | 用户不获利、钱全捐、无随机因素 |
| "扣款了我不服" | 免死金牌 + 宽限期，规则透明 |

---

## 十、边界声明

| 不做 | 原因 |
|------|------|
| 押金池 | 资金池模式法律风险不可控 |
| 平台截留 | 代扣直达基金会 |
| 用户间转账 | 避免赌博定性 |
| 退款 | 扣款即完成捐赠，不可撤回 |
| 动态排行榜奖励 | 避免过度竞争 |
| 自由金额 | 固定 4 档，防止变相赌博 |
