# 酒话连篇 — 产品功能说明书

## 一句话定义

一场酒局，每个人都有自己的记忆版本。社交推理游戏——通过敬酒降低 NPC 记忆，在真话和错构之间提取关键信息。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：喜欢社交推理和叙事游戏的玩家**

| 维度 | 描述 |
|------|------|
| 游戏习惯 | 玩过鹅鸭杀/Among Us/极乐迪斯科 |
| 喜好 | 喜欢看角色吐露真话、信息不对称的游戏 |
| 单局时长 | 15-25 分钟，适配碎片时间 |
| 底层心理 | 想知道别人"喝醉了会说什么"|

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 社交推理游戏缺乏"记忆不可靠"这个核心玩法 |
| **刚需** | 玩家喜欢通过社交线索而非直接质问获取信息 |
| **改善型** | AI 对话叙事类的游戏数量稀缺 |
| **改善型** | 中国本土酒桌文化题材在游戏中几乎没有 |

---

## 二、解决方案与核心功能

### 2.1 解决方案概述

酒话连篇是一个以"酒局社交推理"为核心的叙事游戏。玩家坐在酒桌上，通过敬酒降低 NPC 的记忆质量，在"清醒说假话、醉了说漏嘴、断片说胡话"的渐变中挖掘关键信息。

核心设计：
- **老糊涂记忆引擎** — NPC 随清醒值下降，记忆从精准到错构渐变
- **每次都不一样** — 清醒衰减曲线、错构位置每局随机
- **扮演谁就是谁** — 可选角色决定目标、信息权限、对话切入点
- **LLM 对话生成** — 负责"怎么说"，老糊涂负责"怎么错"

### 2.2 核心功能清单

1. **老糊涂记忆引擎** — NPC 独立清醒值、记忆置信度、错构触发器、情绪染色
2. **酒局流程系统** — 5 阶段回合制流程（入座→主陪→副陪→自由→收尾）
3. **NPC 角色池** — 6 个固定 NPC（主陪/副陪/主宾/随行/秘书/司机）
4. **地区特色规则** — 座位、敬酒顺序、杯沿礼仪、鱼头酒（渐进解锁）
5. **随机事件系统** — 30+ 事件：入场事件、流程事件、老糊涂联动、收尾事件
6. **玩家角色系统** — 谈判代表/助理/老同学（首发），后续解锁卧底/记者/纪委/司机
7. **记忆状态可视化** — NPC 脑力值条 + 对话可信度三色标记（白/黄/红）
8. **三级 LLM 接入** — 内置离线 / 云端 API / 自定义端点
9. **新手关** — 5 回合教学，3 NPC 简化局
10. **地区 DLC 扩展** — 东北烧烤、川渝火锅、广东早茶、西北全羊宴、江浙私房菜

## 三、竞品与差异化分析

| 竞品 | 优点 | 缺点 | 差异 |
|------|------|------|------|
| 极乐迪斯科 | 叙事深度，技能驱动对话 | 西方背景，冗长 | 酒话连篇聚焦中国酒桌，15 分钟一局 |
| 鹅鸭杀/Among Us | 多人社交博弈 | 需要多人，无 AI NPC | 酒话连篇单人 vs AI，联机为后续扩展 |
| 逆转裁判 | 法庭推理，证据导向 | 线性剧情 | 酒话连篇每局不同，AI 动态生成对话 |

**差异化优势：** 酒桌文化题材 + 记忆不可靠机制 + 单人社交推理。

## 五、核心模块详解

### 5.1 老糊涂记忆引擎

**清醒值与记忆表现：** 80-100 清醒（说话官腔，准确不说真话）→ 40-80 微醺（话变多，细节流失但核心准确）→ 10-40 醉了（错构高发，张冠李戴）→ 0-10 断片（胡话，目标可能直接失败）。

**记忆衰减：** 刚写入 100% → 3 回合后 85% → 6 回合后 65% → 10 回合后 45% → 15 回合后 30% → 20 回合后 15%。重要性越高、回忆次数越多、情绪越强、关联越多，衰减越慢。

**错构类型：** 张冠李戴、时间混淆、情绪染色、虚假记忆、遗忘重叠、身份错认。

### 5.2 酒局流程（首发山东商务局）

**5 阶段：** ① 入座寒暄 → ② 主陪开场三杯 → ③ 副陪接力两杯 → ④ 自由交战（核心阶段）→ ⑤ 收尾定局。

**NPC（6 人固定）：** 主陪（张总，50 岁，酒量极高，滴水不漏）、副陪（李主任，45 岁，高酒量，容易说漏嘴）、主宾（王局，55 岁，中酒量，主要目标）、随行（小刘，30 岁，低酒量，知道得多）、秘书（陈姐，35 岁，不喝酒，耳朵最灵）、司机（老赵，40 岁，中酒量，表面憨厚实际精明）。

### 5.3 随机事件系统

每局抽取 3-4 个事件。入场事件（迟到罚酒、全员氛围诡异、有人认识你等 13 种）→ 流程事件（敬酒冲突、话题触发、突发状况等 24 种）→ 老糊涂联动（错构/情绪/信息三类共 25 种）→ 收尾事件（装醉、账被买了、散场单聊等 10 种）。

### 5.4 新手关

5 回合教学流程：引导敬主陪→自由敬副陪→再敬主陪到微醺→自由操作→结算。学到的核心：敬酒降记忆→记忆越低信息越多→不同 NPC 信息矛盾→不是所有信息都可信。

## 六、用户流程

```
选择角色（谈判代表/助理/老同学）→ 进入酒局
  ↓
5 阶段回合制（每回合选：敬酒/聊话题/观察/执行目标/特殊）
  ↓
NPC 清醒值随敬酒下降 → 记忆从精确→模糊→错构渐变
  ↓
对话气泡标记可信度（白/黄/红）
  ↓
各角色推进自己的隐藏目标（签约/收集情报/叙旧办事）
  ↓
收尾阶段 → 结算 —— 目标达成/失败 → 解锁新角色/地区
```

## 八、落地路径

### 8.1 MVP

山东商务局 + 3 个 NPC（新手关）/ 6 个 NPC（完整局）+ 3 个玩家角色 + 老糊涂引擎 + 事件池 + 内置离线 LLM + 5 回合新手关。

### 8.2 第一步验证

**最关键假设：** 玩家享受"看 NPC 醉酒说漏嘴"这种不对称信息游戏。

**验证方法：** 用一个纯文字版 demo（1 个 NPC，3 回合酒局）做 AB 测试——A 组：NPC 有清醒衰减，喝多了说真话；B 组：NPC 无记忆变化。观察喜欢 A 组的比例。

## 九、风险与预期反馈

| 预期槽点 | 应对方案 |
|---------|---------|
| "酒桌文化让人不适" | 设计为策略推理游戏，不灌酒、不劝酒、不提倡过量饮酒 |
| "LLM 对话太生硬" | 三级 LLM 方案+离线模型兜底 |
| "事件太多看不完" | 每局只触发 3-4 个 |
| "重玩性不够" | 6 个角色+5 个地区 DLC+随机事件保证差异 |

---

## 十、边界声明

| 不做 | 原因 |
|------|------|
| 精确记忆模式 | 所有记忆都有缺陷是核心机制 |
| 病理状态模拟 | 不模拟阿尔茨海默等病理 |
| 跨实例记忆同步 | 每局独立 |
| 纯文字版 | 必须有视觉表现 |
| 开放世界 | 聚焦"一场酒局"的封闭场景 |
