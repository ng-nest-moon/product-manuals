# 酒话连篇 — 产品功能说明书

## 一句话定义

一场酒局，每个人都有自己的记忆版本。

---

## 一、产品形态

| 维度 | 决策 |
|------|------|
| 类型 | 单人社交推理游戏（联机潜力预留） |
| 视角 | 俯视圆桌 + 第一人称对话 |
| 一局时长 | 15-25 分钟 |
| 首发平台 | PC（Steam） |
| 定价 | 买断制，地区 DLC 扩展 |

---

## 二、核心体验三支柱

| # | 支柱 | 玩家体验到的 |
|---|------|-------------|
| 1 | 每次都不一样 | 同一个人同一目标，但每局 NPC 的清醒衰减曲线、错构位置都不同。不能背板，每局重新"读人" |
| 2 | 扮演谁就是谁 | 可选角色决定你的目标、信息权限、对话切入点。谈判代表、秘书、卧底、记者……各有各的酒局 |
| 3 | NPC 像人一样记错 | 清醒 → 微醺 → 醉了 → 断片，每个阶段记忆质量不同，可信度不同 |

---

## 三、系统架构

```
┌──────────────────────────────┐
│       玩家选择角色            │
│   (身份 → 目标 → 信息权限)    │
└──────────┬───────────────────┘
           ↓
┌──────────────────────────────┐
│       酒局规则层              │
│  回合制流程 + 地区特色规则     │
│  地区礼仪渐进解锁             │
└──────────┬───────────────────┘
           ↓
┌──────────────────────────────┐
│    老糊涂记忆引擎（核心）      │
│  每 NPC 独立:                  │
│   清醒值 · 记忆置信度          │
│   错构触发器 · 情绪染色        │
└──────────┬───────────────────┘
           ↓
┌──────────────────────────────┐
│     LLM 对话生成层            │
│   三级可选:                   │

│   只负责"怎么说"，不负责"怎么错"│
└──────────────────────────────┘
```

## 四、首发地区：山东商务局

### 4.1 酒局流程（永久框架）

每局固定 5 个阶段，每阶段 3-5 回合，整局约 20-25 回合：

```
① 入座寒暄 — 开局信息，座位分配
② 主陪开场 — 主陪三杯（系统引导）
③ 副陪接力 — 副陪两杯（节奏加快）
④ 自由交战 — 玩家自由操作（核心阶段）
⑤ 收尾定局 — 最后一轮 + 结算
```

### 4.2 NPC 角色池（固定 6 人）

| 角色 | 年龄 | 酒量 | 记忆特征 | 在桌上的位置 |
|------|------|------|---------|-------------|
| 主陪（张总） | 50 | 极高 | 滴水不漏，难套话 | 掌控节奏 |
| 副陪（李主任） | 45 | 高 | 话多，最容易说漏嘴 | 执行暖场 |
| 主宾（王局） | 55 | 中 | 沉默寡言，记忆精准 | 你的主要目标 |
| 随行（小刘） | 30 | 低 | 职位低但知道得多 | 挡酒/跑腿 |
| 秘书（陈姐） | 35 | 不喝 | 全程旁观，耳朵最灵 | 不参与敬酒 |
| 司机（老赵） | 40 | 中 | 表面憨厚，实际精明 | 边缘位置 |

### 4.3 地区特色规则（渐进解锁）

```
新手关:
  无规则，只敬酒聊天

完整局逐步解锁:
  ① 座位系统 — 坐对位置影响操作范围
  ② 敬酒顺序 — 顺时针不可跳位
  ③ 杯沿礼仪 — 低于对方，单手/双手
  ④ 鱼头酒 — 鱼头对准谁谁三杯
```

### 4.4 所有 NPC 共享基础设定

| 参数 | 值 |
|------|-----|
| 清醒范围 | 100%（绝对清醒）→ 0%（断片） |
| 衰减速度 | 山东商务局默认"酒量大"，比普通局慢一半 |
| 记忆分档 | 80-100 清醒 / 40-80 微醺 / 10-40 醉了 / 0-10 断片 |
| 错构概率 | 清醒=0% → 断片=60%+ |

## 五、老糊涂记忆引擎

### 5.1 清醒值与记忆表现

| 清醒值 | 阶段 | 说话风格 | 记忆可靠性 | 游戏价值 |
|--------|------|---------|-----------|---------|
| 80-100 | 清醒 | 场面话、官腔 | 准确但不说真话 | 试探 |
| 40-80 | 微醺 | 话变多、开始交心 | 细节流失、核心准确 | 套话窗口 |
| 10-40 | 醉了 | 说漏嘴、吹牛、上头 | 错构高发、张冠李戴 | 关键信息可能在此暴露 |
| 0-10 | 断片 | 胡话、睡倒、失态 | 不可靠 | 目标可能直接失败 |

### 5.2 记忆写入属性

每条记忆写入时携带以下属性：

| 字段 | 说明 | 示例 |
|------|------|------|
| 内容 | 记忆的核心信息 | "王局说预算上限是 300 万" |
| 时间戳 | 写入时间（游戏内回合数） | R3 |
| 情绪标签 | 当时的情绪状态 | 开心 / 难过 / 愤怒 / 中性 |
| 重要性 | 初始权重（1-10） | 7 |
| 关联记忆 | 关联的其他记忆 ID | [mem_001, mem_003] |
| 上下文 | 环境信息 | "在敬第三杯酒时说的" |

### 5.3 记忆衰减曲线

| 时间（回合后） | 细节保留度 | 表现 |
|---------------|-----------|------|
| 刚写入 | 100% | 完整精确 |
| 3 回合后 | 85% | 细节开始模糊 |
| 6 回合后 | 65% | 大致记得，部分细节丢失 |
| 10 回合后 | 45% | 核心内容保留，细节模糊 |
| 15 回合后 | 30% | 记得发生过，但不记得具体 |
| 20 回合后 | 15% | 只有重要的节点留存 |

**调节因子：**

- 重要性越高 → 衰减越慢
- 回忆次数越多（被玩家/其他 NPC 提及）→ 衰减越慢
- 情绪强度越高 → 衰减越慢
- 关联记忆越多 → 衰减越慢

### 5.4 记忆检索与置信度

检索记忆时的输出表现：

| 置信度 | 输出表现 |
|--------|---------|
| > 80% | "我记得是……（精确描述）" |
| 50%-80% | "好像是在……应该是……" |
| 20%-50% | "有点印象，但不太确定了……" |
| < 20% | "我不记得了" 或 触发错构 |

### 5.5 错构类型

| 类型 | 表现 | 示例 |
|------|------|------|
| 张冠李戴 | 把 A 做过的事安到 B 身上 | "你不是去年签过这个合同吗？"（实际签的是另一个人） |
| 时间混淆 | 把不同时间的事拼在一起 | "上次你说预算 300 万"（实际是上上次说的） |
| 情绪染色 | 情绪扭曲记忆细节 | "那天谈得很愉快"（实际氛围很僵） |
| 虚假记忆 | 脑补出从未发生的事 | "你当年不是欠我一顿饭吗"（实际没有这回事） |
| 遗忘重叠 | 忘了自己说过的话，重复讲 | "我刚才说过了吗？那我再说一遍……" |
| 身份错认 | 把玩家认成另一个人 | "哎老李，好久不见！"（实际不是老李） |

## 六、随机事件系统

每局开局从事件池抽取 3-4 个事件叠加在基础流程上：1 个入场事件 + 2 个流程事件 + 1 个老糊涂联动事件。新手关只触发轻量级事件。

### 6.1 入场事件（开局触发）

| 事件 | 效果 |
|------|------|
| 某 NPC 迟到罚酒 | 该 NPC 初始清醒-25%，话匣子提前打开 |
| 主宾迟到 | 罚酒三杯，清醒-30%，但面子挂不住，戒心更高 |
| 关键 NPC 缺席 | 换成不熟的副手，话术废了半套 |
| 全员氛围诡异 | 有人刚在停车场吵过架，桌上暗流涌动 |
| 时间紧迫 | 回合数-3 |
| 被安排到次陪位 | 身份被低估，需证明自己 |
| 边上坐了个自来熟 | 解锁"邻座私语"选项 |
| 核心人物中间隔了人 | 对话效率打折 |
| 有人认识你 | 先入为主的印象（好感±） |
| 有人误会你身份 | 可顺势装成另一个人 |
| 穿错衣服来错局 | 礼仪初始分-10 |
| 带了不该带的礼物 | 某 NPC 警戒拉满 |
| 和你撞衫了 | 全场尴尬，反复被比较 |

### 6.2 流程事件（进行中触发）

| 类别 | 事件 | 效果 |
|------|------|------|
| 敬酒 | 敬酒顺序被插队 | 打乱计划 |
| 敬酒 | 有人替你挡酒 | 不一定是帮你 |
| 敬酒 | 杯沿压不下去 | 对方试探你懂不懂 |
| 敬酒 | 热菜迟迟不上 | 空腹喝，清醒衰减×1.5 |
| 敬酒 | 有人提议换大杯 | 全员清醒-15% |
| 敬酒 | 鱼头对准了你 | 鱼头酒三杯，成焦点 |
| 敬酒 | 服务员倒错酒 | 某人状态意外下滑 |
| 敬酒 | 有人"打一圈" | 全场轮流敬一轮，全员清醒-10% |
| 话题 | 提了不该提的名字 | 全场沉默，一回合不能动作 |
| 话题 | 新闻触发关联记忆 | 某 NPC 触景生情 |
| 话题 | 吹牛大赛 | 某 NPC 所有记忆临时-20% 可信度 |
| 话题 | 低俗笑话 | 有人尴尬有人笑 |
| 话题 | 回忆往昔 | 50 岁以上 NPC 临时清晰+10% |
| 话题 | 吐槽行业形势 | 某 NPC 话多/话少切换 |
| 话题 | 谈起共同熟人 | 激活你以为忘了的信息 |
| 话题 | 有人讲鬼故事 | 全场注意力分散 |
| 突发 | 有人接电话离席 | 窗口期缩短 |
| 突发 | 上洗手间结伴 | 消失 2 回合，可能在交换信息 |
| 突发 | 喝吐了 | 直接断片，提前退出 |
| 突发 | 有人拍桌子 | 冲突爆发，好感清零 |
| 突发 | 隔壁局的人串场 | 多出一个临时 NPC |
| 突发 | 停电跳闸 | 回来时所有人表情都变了 |
| 突发 | 菜里有异物 | 全场注意力转移 |
| 突发 | 外面有人闹事 | 敏感话题容错率+20% |
| 突发 | 服务员认错人 | 给另一个"张总"倒了酒 |
| 突发 | 手机响了不该响的 | 来电显示暴露了关系 |
| 突发 | 有人把酒打翻 | 污渍溅到合同上，对方有理由拖延 |

### 6.3 老糊涂联动事件（记忆专场）

| 类别 | 事件 | 效果 |
|------|------|------|
| 错构 | NPC 把玩家认成旧识 | 可以"认亲"套近乎 |
| 错构 | NPC 记混 A/B 公司 | 说错合作细节，可用可纠 |
| 错构 | NPC 记错自己年龄 | 暗示此 NPC 整体不可靠 |
| 错构 | 重复讲同一件事 | 遗忘症状——不记得刚讲过 |
| 错构 | 把去年的事安到前年 | 时间线错乱 |
| 错构 | 把"听说的"记成"亲眼见" | 二道消息变铁证 |
| 错构 | 忘了自己喝过酒 | 继续灌，加速断片 |
| 错构 | 觉醒"错误的共识" | 听了半句话，脑补出完整故事 |
| 错构 | 把"别人欠他"记成"他欠别人" | 债务关系翻转 |
| 错构 | 把两个人合成一个人 | A 的脸+B 的事=一个不存在的人 |
| 情绪 | 中性记忆染上愤怒 | "上次你们态度很差"——其实没有 |
| 情绪 | 美化糟糕回忆 | "上次合作很愉快"——差点打起来 |
| 情绪 | 代入不相干的情绪 | 刚跟老婆吵完架，对谁都有敌意 |
| 情绪 | 过度乐观 | 合同条件变得过分宽松 |
| 情绪 | 自我怀疑 | "可能你说得对"，容易被说服 |
| 情绪 | 小误会大反应 | 需要第三方调停 |
| 信息 | A 的话被 B 听岔传给 C | 三人成虎，信息开始走样 |
| 信息 | 隔桌有耳 | 服务员/司机在听 |
| 信息 | 手机没锁屏被看到 | 你的屏幕被对面瞥见 |
| 信息 | 有人在录视频 | 某 NPC 极度谨慎 |
| 信息 | 假装接电话实则在监听 | 收集桌上每个人的话 |
| 信息 | 有人掺水被发现 | 信任崩盘，此人所有话×0.5 |
| 信息 | 有人发错微信消息 | 发给你的消息发到了群里 |
| 信息 | 酒后说外语 | 某 NPC 开始说不该说的方言/外语 |
| 信息 | 看穿你的伪装 | 某 NPC 识破你的身份但不揭穿——变成把柄 |

### 6.4 收尾事件（最后 3 回合）

| 事件 | 效果 |
|------|------|
| 再来一轮 | 节奏延长，继续衰减 |
| 有人装醉逃脱 | 看似断片实际清醒——你是唯一发现的 |
| 笔没墨了 | 最后一刻意外 |
| 主陪突然不谈正事 | 目标直接报废，需调整策略 |
| 账被买了 | 不是你买的，欠了人情 |
| 散场被拉住单聊 | 最后的情报窗口 |
| 有人要送你回家 | 独处时间，真话或试探 |
| 走之前留了张名片 | 上面有额外信息 |
| 有人落了东西 | 可能是线索 |
| 外面下雨 | 所有人被困在屋里，延长一回合 |

## 七、新手关设计

**设计目标：** 15 分钟上手，第一局玩得明白。

### 7.1 新手关配置

| 参数 | 值 |
|------|-----|
| NPC | 3 个（主陪+副陪+主宾，去掉随行/秘书/司机） |
| 操作 | 每回合 4 个按钮：[敬主陪] [敬副陪] [敬主宾] [聊聊] |
| 规则 | 零礼仪规则，只有"喝酒掉记忆→记忆低了说真话" |
| 事件 | 仅触发轻量级（迟到、邻座自来熟、热菜慢） |
| 角色 | 仅开放"谈判代表" |
| 目标 | 唯一目标——签下合同 |

### 7.2 5 回合教学流程

```
R1: 系统指引"敬主陪一杯"
     → 主陪记忆掉一截，话从客套变放松
     → 玩家学到：敬酒会让 NPC 记忆下降

R2: 玩家自由选"敬副陪"
     → 副陪记忆掉了，说了一句和主陪矛盾的话
     → 玩家学到：不同 NPC 的信息可能矛盾

R3: 系统提示"再敬主陪"
     → 主陪记忆到黄色区域（微醺），开始漏细节
     → 玩家学到：记忆越低，信息量越大

R4: 玩家自由操作
     → 可以选择补敬/聊话题/观察

R5: 目标达成/失败 → 结算
```

### 7.3 玩家通过新手关学到的

1. 喝酒会让 NPC 记忆下降
2. 记忆下降后 NPC 会说之前不会说的话
3. 不同 NPC 的信息可能互相矛盾
4. 不是所有信息都可信——有些是记忆模糊，有些是记错了

## 八、玩家可选角色

### 8.1 首发角色池（3 个）

| 角色 | 目标 | 信息权限 | 入场切入点 |
|------|------|---------|-------------|
| 谈判代表 | 完成签约 | 商务信息 | "王局，我们上次谈的方案……" |
| 助理 | 带回可靠情报 | 细节信息 | 坐角落记笔记，没人防你 |
| 老同学 | 叙旧办事 | 私人关系 | "老张，咱毕业多少年了？" |

### 8.2 后续解锁角色

| 角色 | 解锁条件 | 目标 |
|------|---------|------|
| 中间人 | 通关任意完整局 | 撮合双方不翻船 |
| 卧底 | 完成 3 局助理 | 破坏签约或套底价 |
| 记者 | 完成 5 局 | 挖独家新闻 |
| 纪委 | 全部角色通关一次 | 查违规线索 |
| 司机 | 隐藏成就解锁 | 不喝酒，全程清醒旁观，护送目标安全回家 |

不同角色看同一场酒局——**信息不对称本身就是可玩性**。

## 九、UI/UX 设计原则

### 9.1 记忆状态可视化

```
NPC 状态条（永远可见）:

  [张总]  🧠 ████████░░ 75%  😊 友好
  [李主任] 🧠 ████░░░░░░ 45%  😵 微醺
  [王局]   🧠 ██░░░░░░░░ 20%  😴 快倒了
```

### 9.2 对话可信度标记

```
[事实] "下季度的预算是 300 万"              ← 白色气泡，可信
[模糊] "好像是……跟老王有关系？"             ← 黄色气泡，可能记错
[错构] "你去年不是自己说过不做了吗"         ← 红色气泡，记忆已变形
```

### 9.3 操作选择永不超 5 个

```
每回合：
  [敬酒] → 选一个人 → 看动画 → 对方记忆下降
  [聊话题] → 选一个话题 → 对方根据记忆状态回应
  [观察] → 看一圈状态，不消耗回合
  [执行目标] → 推进你的隐藏目标
  [特殊] → 当前事件/角色相关的特殊动作
```

### 9.4 设计原则

```
① 记忆状态永远可见 —— 不让玩家猜"他喝到哪了"
② 规则不教学，只反馈 —— 做对了 NPC 表情变好，错了有预警
③ 所有信息有标记 —— 白色/黄色/红色 三级可信度
④ 操作不超过 5 个 —— 每回合都清爽
```

## 十、LLM 对话生成层

### 10.1 核心原则

> **老糊涂管"怎么错"，LLM 管"怎么说"。**

### 10.2 LLM 输入输出

LLM 输入（从老糊涂引擎获取）：

```
角色: 张总
```

## 十一、多人联机模式（远景规划）

### 11.1 模式定位

```
单人版: 玩家 vs AI NPC
联机版: 玩家 vs 玩家

联机版的核心变化:
  老糊涂从 NPC 专用 → 作用于每个玩家的"醉酒值"系统
  你的清醒值 = 你的信息质量
  你看不到别人的清醒值 = 你分不清他是真醉还是装醉
```

## 十四、边界声明

| 不做 | 原因 |
|------|------|
| 精确记忆模式 | 老糊涂的 DNA 是"所有记忆都有缺陷"，不提供"永不遗忘"模式 |
| 病理状态模拟 | 不模拟阿尔茨海默等病理状态，只模拟正常人的记忆缺陷 |
| 跨实例记忆同步 | 每局记忆库独立，不能串局 |
| 纯文字版 | 必须有视觉表现（记忆条、状态、气泡标记），否则看不清 |
| 开放世界 | 聚焦"一场酒局"的封闭场景，不扩展地图 |
