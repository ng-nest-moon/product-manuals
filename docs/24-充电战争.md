# 充电战争 — 产品功能说明书

## 一句话定义

多人物理派对游戏，玩家扮演手机角色，在电量持续衰减的焦虑中争夺充电资源——既是搞笑乱斗，也是现代电量焦虑的社会讽刺。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：喜欢派对乱斗游戏的玩家（16-35 岁）**

| 维度 | 描述 |
|------|------|
| 游戏习惯 | 玩过糖豆人/人类一败涂地/动物派对 |
| 场景 | 朋友聚会、线上开黑 |
| 单局时长 | 2-3 分钟快节奏 |
| 底层心理 | 喜欢物理搞笑 + 轻度社会讽刺 |

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 派对游戏缺少"充电焦虑"这种现代生活题材 |
| **刚需** | 玩家喜欢不公平起点的竞技（阶级系统） |
| **改善型** | 物理派对游戏受众持续增长 |
| **改善型** | "电量焦虑"是全民共鸣点 |

---

## 二、解决方案与核心功能

### 2.1 解决方案概述

充电战争 = 手机角色在电量持续下降中抢夺充电资源。S/A/B/C/D 五级阶级随机分配，效率从 3x 到 0.3x。快充座、普通插座、损坏插座、共享充电宝随机分布。被淘汰变幽灵可继续干扰。

### 2.2 核心功能清单

1. **充电阶级系统** — S(3x)/A(2x)/B(1x)/C(0.5x)/D(0.3x 移动 2x 静止)
2. **电量持续衰减** — 1.67%/秒，归零淘汰变幽灵
3. **插座争夺** — 普通/快充(3x)/损坏(-1x)，近身吸附可被打断
4. **共享充电宝** — 30 秒刷新，移动充电，被击掉落
5. **物理碰撞交互** — 推搡/抓投/绊倒/弹飞
6. **10 种道具** — 数据线陷阱/降频弹/弹窗广告/充电头飞弹等
7. **幽灵模式** — 淘汰后可丢石子干扰活人
8. **4 张地图** — 候机厅/阶梯教室/办公室/大排档，各有专属事件
9. **双冠军结算** — 电量冠军 + 杀戮冠军
10. **多种对战模式** — 大乱斗/2v2/夺宝战/饥饿模式

## 三、竞品与差异化分析

| 维度 | 充电战争 | 糖豆人 | 动物派对 |
|------|---------|-------|---------|
| 核心 | 充电争夺 | 闯关淘汰 | 物理对战 |
| 阶级系统 | 有（随机不公） | 无 | 无 |
| 社会讽刺 | 强 | 弱 | 无 |
| 每局时间 | 2-3 分钟 | 5-10 分钟 | 3-5 分钟 |

**差异化优势：** 阶级随机分配的不公平性 + 电量焦虑题材 + 幽灵模式。

## 五、核心模块详解

### 5.1 阶级系统

S 快充旗舰（3x，移动慢，闪充技能）→ A 标准快充（2x，中速，无线协同分电）→ B 普通充电（1x，省电模式）→ C 慢充（0.5x，移动快，抢跑技能）→ D 无线充电（0.3x 移动/2x 静止，极快，碰瓷技能）。外观也对应：S 金属质感 → D 贴膜起泡。

### 5.2 地图与事件

候机厅（长条形，登机广播干扰信号）→ 阶梯教室（多层台阶，下课铃打断充电）→ 共享办公室（工位隔板，保洁阿姨弹飞玩家）→ 深夜大排档（插座仅一个摊位，城管来了消失 8 秒）。

### 5.3 道具（10 种）

干扰类：数据线陷阱（绊倒 1.5s）、降频弹（卡顿 3s）、弹窗广告（遮视野 2s）、低电量警告（假动画恐吓）。
强化类：快充线（速度翻倍 10s）、移动电源（恢复 15%）、超级省电（0 掉电 8s）。
攻击类：充电头飞弹（远程 5%+击退）、拖线板（近战击飞）、拔线器（强制打断充电）。

## 六、用户流程

```
匹配 → 分配阶级和地图 → 出生
  ↓
电量开始衰减（1.67%/秒）
  ↓
抢插座/充电宝，使用道具攻击
  ↓
电量归零变幽灵（丢石子干扰）
  ↓
时间到 → 双冠军结算（电量+杀戮）
```

## 八、落地路径

### 8.1 MVP

本地 4 人分屏 + 1 张地图（阶梯教室）+ 3 个阶级（S/C/B）+ 基础插座 + 1 个道具 + 电量衰减 + 淘汰 + 单冠军结算。

### 8.2 第一步验证

用简化原型（2 人分屏，一个插座，30 秒倒计时）测试核心假设：玩家是否会为了抢插座互相推搡。如果 10 组测试中 8 组出现主动抢资源行为，假设成立。

---

## 九、风险与预期反馈

| 预期槽点 | 应对方案 |
|---------|---------|
| "阶级不公平" | 就是设计——体验不公平，表达阶级主题 |
| "太像动物派对" | 核心机制不同（电量/阶级），不是纯物理对战 |
| "单机没意思" | 派对游戏需要多人，先做本地分屏 |

---

## 十、边界声明

| 不做 | 原因 |
|------|------|
| 长线养成/抽卡 | 买断制或通行证 |
| 单人剧情 | MVP 仅多人 |
| 手机端首发 | 优先 Steam/主机 |
| 反作弊硬核竞技 | 定位是派对快乐游戏 |
