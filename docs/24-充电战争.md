# 充电战争 — 产品功能说明书

## 一句话定义

多人物理派对游戏，玩家扮演手机角色，在电量持续衰减的焦虑中争夺充电资源——既是搞笑乱斗，也是现代电量焦虑的社会讽刺。

---

## 适龄建议

12岁以上（包含讽刺性社会隐喻，低龄玩家仅作派对游戏体验）

---

## 一、系统架构总览

```
表现层（3D 卡通物理场景）
 ├── 角色系统 —— 手机外形角色，外观随阶级和状态变化
 ├── 物理引擎 —— 推搡、绊倒、弹飞，基于刚体碰撞
 ├── 地图系统 —— 候机厅 / 阶梯教室 / 办公室 / 大排档
 └── UI 层 —— 手机状态栏风格电量条 + HUD

资源层
 ├── 电量系统 —— 100% 上限，每秒自然衰减 1.67%
 ├── 插座系统 —— 普通插座 / 快充座 / 损坏插座
 └── 共享充电宝 —— 地图随机刷新，边移动边充

对战层
 ├── 阶级系统 —— S/A/B/C/D 五级随机出生，充电效率与速度关联
 ├── 道具系统 —— 干扰类 / 强化类 / 主动攻击类
 ├── 幽灵系统 —— 淘汰后变为幽灵，可干扰活人
 └── 随机事件 —— 登机广播 / 下课铃 / 保洁 / 城管

结算层
 ├── 双冠军 —— 电量冠军 + 杀戮冠军
 ├── 结局动画 —— 手机系统通知风格结算画面
 └── 多周目标 —— 成就徽章 / 段位积分 / 角色皮肤解锁
```

---

## 二、核心功能清单

1. **充电阶级系统** — 每局随机分配 S/A/B/C/D 阶级，效率从 3x 到 0.3x，决定打法策略
2. **电量持续衰减** — 电量以固定速率下降，归零即淘汰变幽灵
3. **插座争夺** — 普通插座 / 快充座 / 损坏插座，靠近即吸附，被攻击打断
4. **共享充电宝** — 地图定时刷新，拾取后边移动边充电，被击倒掉落
5. **物理碰撞交互** — 推搡、抓投、绊倒、弹飞，所有交互基于刚体物理
6. **道具系统** — 10 种道具覆盖干扰 / 强化 / 攻击三类
7. **幽灵模式** — 淘汰后变成幽灵继续参与，可丢石子干扰活人
8. **多地图** — 4 张初始地图，各带专属随机事件
9. **双冠军结算** — 电量最高者和击倒最多者各获冠军
10. **多种对战模式** — 大乱斗 / 2v2 团队 / 夺宝战 / 饥饿模式
11. **本地与在线联机** — 支持本地 4 人分屏 + 在线 8 人对战
12. **成就与排位** — 段位积分制 + 角色皮肤解锁 + 结局收藏

## 三、模块详解

### 3.1 充电阶级系统

每局开始时为每位玩家随机分配一个"充电阶级"，与该局绑定，不可更换：

| 阶级 | 字面名 | 充电效率 | 移动速度 | 天赋技能 | 社会隐喻 |
|------|--------|----------|---------|----------|---------|
| S | 快充旗舰 | 3x | 慢 | 闪充（5 秒无敌充电） | 先天资源好，但行动笨重，目标大 |
| A | 标准快充 | 2x | 中 | 无线协同（靠近插座可给队友分电） | 中产互助 |
| B | 普通充电 | 1x | 中 | 省电模式（静止时掉电减半） | 普通人被动生存 |
| C | 慢充 | 0.5x | 快 | 抢跑（开局 0.5 秒加速） | 出身差，必须更拼 |
| D | 无线充电 | 0.3x(移动) / 2x(静止) | 极快 | 碰瓷（被击时有概率让对手掉电） | 灵活就业者 |

**设计意图：** S 天然被集火，C/D 必须主动进攻才可能翻盘。玩家会自发感受到"这不公平"——这正是游戏要表达的核心主题。

**外观差异：** 不同阶级的角色在视觉上有明显区别：
- S：金属质感机身，摄像头环形闪光
- A：磨砂背板，简约设计
- B：塑料外壳，普通直板
- C：外壳有划痕，屏幕有裂纹
- D：贴膜起泡，充电口接触不良

---

### 3.2 电量与资源系统

#### 3.2.1 电量

- **上限**：100%，以手机顶部状态栏风格显示在角色头顶
- **自然衰减**：约 1.67%/秒（满电到淘汰约 60 秒）
- **淘汰**：电量归零 → 角色冒烟黑屏 → 以幽灵形态继续参与
- **结算**：按淘汰时的电量冻结值排名（活人 > 幽灵）

#### 3.2.2 插座系统

| 类型 | 单局数量 | 充电速度 | 识别方式 | 特点 |
|------|---------|----------|---------|------|
| 普通插座 | 4-6 | 1x | 白色 | 谁进吸附范围谁充，可被推开打断 |
| 快充座 | 1-2 | 3x | 金色发光 | 通常在地图中央，必争之地 |
| 损坏插座 | 2-3 | -1x（放电） | 冒火花 | 看起来像普通插座，插上反而掉电 |

**交互规则：**
- 角色靠近插座触发"吸附"状态，物理绑定后开始充电
- 外力击飞 / 别人弹开 / 道具干扰均可打断充电
- 同一插座最多同时充 2 人（快充座仅 1 人）

#### 3.2.3 共享充电宝

- **刷新**：每 30 秒在地图随机位置刷 1-2 个
- **拾取**：经过即拾取，绑定在角色身上
- **充电效果**：边移动边充电（0.5x 速率）
- **掉落条件**：被击中 / 被推搡 / 被其他角色碰撞
- **归还机制**：插到插座上可将充电宝转换为固定插座（策略选择：自己用 vs 团队贡献）
- **隐喻**：你永远无法真正拥有一块充电宝

---

### 3.3 道具系统

局内随机刷新在地图固定位置，玩家触碰拾取，单次使用。

#### 3.3.1 干扰类

| 道具 | 效果 | 冷却参考 | 设计意图 |
|------|------|---------|---------|
| 数据线陷阱 | 在地上铺线，绊倒第一个碰到的人（倒地 1.5s） | 10s | 控制型，区域封锁 |
| 降频弹 | 命中后对手屏幕持续卡顿 / 降帧 3 秒 | 15s | 视觉干扰，制造焦虑 |
| 弹窗广告 | 在对手屏幕中央弹出"恭喜您中奖"遮视野 2s | 12s | 讽刺性极强 |
| 低电量警告 | 伪造对手电量暴跌的假动画（实际不扣） | 20s | 心理战术，诱其慌张 |

#### 3.3.2 强化类

| 道具 | 效果 | 持续 |
|------|------|------|
| 快充线 | 充电速度翻倍 | 10s |
| 移动电源 | 立即恢复 15% 电量 | 瞬时 |
| 超级省电 | 掉电速度为 0 | 8s |
| 短路器 | 范围内所有插座失效 | 5s |

#### 3.3.3 主动攻击类

| 道具 | 效果 | 说明 |
|------|------|------|
| 充电头飞弹 | 弹道式投射，命中造成 5% 电量损失 + 击退 | 远程消耗 |
| 拖线板 | 近战挥击，范围大但慢，命中造成击飞 | 范围控制 |
| 拔线器 | 远程锁定一个充电中的对手，强制打断并拉出 | 针对充电目标 |

### 3.4 对战地图

#### 3.4.1 候机厅

| 项目 | 说明 |
|------|------|
| 格局 | 长条形，中央大屏显示实时电量排名，两侧墙排插座 |
| 插座分布 | 靠墙 4 普通 + 中央 1 快充 + 角落 1 损坏 |
| 随机事件 | 每 45 秒"登机广播"，所有手机信号受干扰，画面出现雪花 2s |
| 充电宝刷新 | 座椅下方（2 个位置） |
| 场景机关 | 传送带（缓慢移动，站上去被带到另一端） |

#### 3.4.2 大学阶梯教室

| 项目 | 说明 |
|------|------|
| 格局 | 多层台阶，每层墙边有插座，中央粉笔槽可跳跃穿越 |
| 插座分布 | 每层台阶各 1 普通 + 讲台 1 快充 |
| 随机事件 | 下课铃响，所有充电中的玩家被强制打断（"老师拔插头"） |
| 充电宝刷新 | 讲台后方 |
| 场景机关 | 台阶可跳跃，高处推人有地形击杀效果 |

#### 3.4.3 共享办公室

| 项目 | 说明 |
|------|------|
| 格局 | 开放式工位，隔板可翻越，插座集中在工位侧面 |
| 插座分布 | 工位侧边 4 普通 + 会议室 1 快充 |
| 随机事件 | 保洁阿姨推车经过，碾到玩家即弹飞 |
| 充电宝刷新 | 前台、咖啡机旁 |
| 场景机关 | 旋转门（进入后被甩到出口） |

#### 3.4.4 深夜大排档

| 项目 | 说明 |
|------|------|
| 格局 | 室外杂乱桌椅，插座仅在一家摊位上 |
| 插座分布 | 摊位 1 普通（独占） + 街边 2 普通 + 垃圾桶旁 1 损坏 |
| 随机事件 | 城管来了！所有插座消失 8 秒（全部替换为损坏插座） |
| 充电宝刷新 | 垃圾桶旁 |
| 场景机关 | 凳子可踢飞作为临时障碍物 |

### 3.5 双冠军与结算系统

#### 3.5.1 冠军判定

| 称号 | 判定条件 |
|------|---------|
| 🔋 电量冠军 | 结算时电量最高的活人（幽灵不计入） |
| ⚡ 杀戮冠军 | 累计击倒数最多（幽灵击杀活人计入） |
| 👑 绝对王者 | 双冠兼得 → 特殊动画 + 双倍奖励 |

#### 3.5.2 结算界面

以手机系统通知样式弹出全屏结算：

```
┌─────────────────────┐
│   🔋 电量冠军        │
│   "iPhone 15 Pro"   │
│   ☻ 剩余电量 73%    │
│                     │
│   ⚡ 杀戮冠军        │
│   "Redmi Note 12"   │
│   ☠ 击倒 5 人        │
│                     │
│   👑 绝对王者  —     │
│   无人在此局封神     │
│                     │
│   下局 → 按 A        │
└─────────────────────┘
```

**结算后展示：** 关键数据统计图（电量曲线、击倒时间线、道具使用效率）+ 本局 MVP 回放片段。

### 3.6 对战模式

| 模式 | 人数 | 规则 |
|------|------|------|
| 大乱斗 | 2-8 | 标准混战，默认模式 |
| 2v2 团队 | 4 | 共享团队电量池，团队电量归零全队输 |
| 夺宝战 | 2-6 | 地图只有一个超级充电宝，持有者每秒 +2% 电量，其他人抢 |
| 饥饿模式 | 2-8 | 每 30 秒电量上限降低 10%（100%→90%→80%→...），逼迫近距离交战 |
| 训练场 | 1-4 | 自定义规则：关闭淘汰、随意调整阶级和刷新率 |
| 自定义 | 2-8 | 可独立开关各项系统（禁道具 / 禁幽灵 / 固定阶级等） |

## 五、边界声明

| 不做 | 原因 |
|------|------|
| 长线养成 / 抽卡氪金 | 买断制或通行证式皮肤解锁，不卖数值 |
| 单人剧情模式 | MVP 仅做多人对战，剧情模式视后续资源 |
| 真实手机品牌联名 | 初版使用虚构手机名，避免授权和法律风险 |
| 复杂操作组合 | 仅摇杆 + 动作键 + 道具键，派对游戏门槛要低 |
| 反作弊 / 硬核竞技 | 定位是派对快乐游戏，非电竞方向 |
| UGC 地图编辑器 | MVP 不做工坊，后续可考虑 |
| 手机端首发 | 优先 Steam/主机，手机端触屏操作需重新设计 |
| 实时语音社交 | 仅保留基础语音或预设表情包，不做开放语音 |

## 六、开发优先级

### P0 — 核心循环原型（2 周）

- 本地 4 人分屏基础框架
- 1 张地图（阶梯教室）
- 角色基础模型 + 移动 + 物理碰撞
- S 和 C 两个阶级（验证阶级差异体验）
- 普通插座 + 损坏插座
- 电量衰减 + 淘汰 + 幽灵基础
- 1 个道具（数据线陷阱）
- 60 秒倒计时 + 单冠军结算
- 验证核心命题："电量焦虑 + 抢资源"是否成立

### P1 — 完整玩法内容（4 周）

- 全 5 阶级上线，天赋技能实现
- 4 张地图全部完成 + 各自随机事件
- 插座系统完整版（快充座 / 共享充电宝）
- 全 10 道具实现
- 双冠军结算系统 + 结算界面
- 幽灵模式完整版（可丢石子）
- 2v2 团队模式
- 基础 UI / HUD / 设置菜单

### P2 — 体验打磨（3 周）

- 多种对战模式（夺宝战 / 饥饿模式）
- 在线联机（8 人，Rollback netcode）
- 排位段位系统
- 角色皮肤解锁系统
- 成就徽章 + 一局数据回顾
- 物理手感调优（碰撞参数、抓投手感）
- 音效 / 背景音乐

### P3 — 发布准备（3 周）

- 训练场 + 自定义模式
- 性能优化（稳定 60fps，4 人分屏 + 8 人在线）
- 局内视频回放 / 高光时刻
- 全平台手柄适配
- 本地化（后续多语言预留架构）
- 全面调优测试 + 封测
