# 炒股能力评测 — 产品功能说明书

## 一句话定义

AI 模拟资深交易员对用户进行实时对抗式审讯，通过深度追问和极限情境推演，诊断用户是否具备炒股所需的决策心智——不考知识，只考在压力下怎么想、怎么判断。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：对炒股有兴趣或已入市但想客观认识自己的人**

| 维度 | 描述 |
|------|------|
| 炒股经验 | 从没买过股票到已炒股 2-3 年 |
| 心理状态 | 怀疑自己是否适合炒股、或亏损了不确定原因 |
| 当前做法 | 看书学习技术分析、进群听消息、自己复盘（但没用）|
| 最大盲区 | 不知道自己的思维缺陷在哪里——归因偏差、过度自信、逻辑断裂 |

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 炒股亏钱的人通常不知道亏在心智而不是知识 |
| **刚需** | 市场没有工具能客观评估一个人的"交易心智" |
| **改善型** | 亏损者容易把原因归结为"运气不好"或"市场不正常" |
| **改善型** | 入市前缺乏"心智体检"——绝大多数人是亏了才发现自己不适合 |

---

## 二、解决方案与核心功能

### 2.1 解决方案概述

AI 审讯官模拟资深交易员，分四阶段审讯（投资哲学→决策逻辑→极限情境→盲区照射），全程 15-30 分钟。不考技术面/基本面知识，只通过对抗式追问暴露用户的思维模式、归因方式和逻辑漏洞。审讯结束后生成多维度心智画像和盲区清单。

### 2.2 核心功能清单

1. **AI 审讯官** — 模拟资深交易员实时对抗式对话，风格可选（温和/标准/毒舌）
2. **投资哲学盘问** — 探查用户对市场的底层信念是否自洽
3. **决策逻辑深挖** — 苏格拉底式质疑暴露逻辑断层
4. **极限情境推演** — 把用户逻辑推到极端市场环境中测试
5. **盲区照射** — 专问用户从未思考过的问题
6. **动态追问链** — 一条线追到底直到暴露矛盾
7. **沉默战术** — 故意停顿 3-5 秒，观察用户补充/修改/转移
8. **语言模式分析** — 检测确定性偏差/防御心理/归因模式
9. **心智成熟度画像** — 四维画像+总分+S/A/B/C/D 等级
10. **矛盾回溯报告** — 审讯全程前后矛盾言论逐条展示

## 三、竞品与差异化分析

| 对比 | 炒股能力评测 | 在线测试问卷 | 投资课程 | 模拟交易 |
|------|-----------|------------|--------|---------|
| 交互形式 | **对抗式审讯** | 选择题 | 看视频 | 实操 |
| 评测维度 | **决策心智** | 知识水平 | 知识型 | 实操型 |
| 深度 | **追到逻辑漏洞为止** | 表面 | 单向 | 无反思 |
| 盲区揭示 | **核心功能** | 无 | 无 | 无 |

**差异化优势：** 对抗式审讯（不是选择题）+ 专注心智而非知识 + 盲区揭示。

## 四、架构总览

```
审讯层
 ├── AI 审讯官引擎（3 种人格 / 追问策略树 / 压力梯度 / 沉默战术）
 └── 四阶段审讯
      ├── 投资哲学盘问
      ├── 决策逻辑深挖
      ├── 极限情境推演
      └── 盲区照射

分析层
 ├── 语言模式分析（确定性/防御性/归因模式/逻辑跳跃）
 ├── 逻辑质量评估（因果链完整性/反例容忍度/思维灵活性）
 ├── 心智成熟度评估（元认知/情绪觉察/不确定性容忍/学习意愿）
 └── 盲区与偏误图谱（认知偏误/知识边界/行为模式预警）

报告层
 ├── 心智总分（S/A/B/C/D）
 ├── 交易心智画像卡片（清醒型/激情型/防御型/幻想型/固执型/成长型）
 ├── 决策逻辑漏洞清单（含审讯回放片段）
 ├── 盲区预警 + 适合交易风格建议 + 心智训练计划
```

## 五、核心模块详解

### 5.1 AI 审讯官引擎

三种人格可供选择：温和导师型（循循善诱，低压）、标准教练型（直接犀利，中压）、毒舌老手型（带讽刺挑衅，高压）。

追问策略：模糊回答→要求具体；确定回答→极限推演；情绪化回答→追问来源。

审讯全程 15-30 分钟。沉默战术中用户的反应（补充/修改/沉默/转移）本身就是诊断数据。

### 5.2 四阶段审讯

| 阶段 | 内容 | 时长 |
|------|------|------|
| 投资哲学盘问 | 市场底层信念是否自洽 | ~5min |
| 决策逻辑深挖 | 以用户真实交易经历为例拆解决策节点 | ~5min |
| 极限情境推演 | 暴涨/暴跌/黑天鹅/流动性枯竭 | ~5min |
| 盲区照射 | 测试元认知边界 | ~5min |

### 5.3 分析引擎

语言确定性分析（绝对化用词频率 vs 软化用词）→ 归因模式（成功归自己 vs 失败归外部）→ 逻辑跳跃检测 → 矛盾侦测 → 沉默反应分析。

### 5.4 交易心智画像

| 类型 | 特征 | 适合/风险 |
|------|------|----------|
| 清醒型 | 逻辑自洽、承认不确定 | 稳定盈利潜力高 |
| 激情型 | 热情高、归因偏自我 | 牛市表现好，熊市易大亏 |
| 防御型 | 话中有保留、怕犯错 | 适合保守策略，机会抓不住 |
| 幻想型 | 归因混乱、过于乐观 | 不适合炒股 |
| 固执型 | 自信满满、拒绝被挑战 | 风险最高 |
| 成长型 | 被质疑时思考而非防守 | 长期进步潜力大 |

## 八、落地路径

### 8.1 MVP

标准教练型审讯官 + 四阶段完整审讯 + 基本分析报告（心智总分+画像类型+3 条漏洞）。无语言模式分析，无毒舌人格。

### 8.2 第一步验证

**最关键假设：** 被测者在看完报告后有"原来我是这样的"的认知冲击。

**验证方法：** 招募 50 名有炒股经验者进行 MVP 测试。评测后 7 天随访。如果 > 60% 的人表示"评测结果让我反思了以前没注意到的思维习惯"，核心价值成立。

## 九、风险与预期反馈

| 预期槽点 | 应对方案 |
|---------|---------|
| "AI 凭什么评判我" | 审讯官是镜子——反映的是你自己的逻辑 |
| "我就是运气不好" | 审讯正是帮你区分运气和能力 |
| "选择题测不出来" | 所以不是选择题——是对抗式审讯 |
| "评测结果不准" | 心智评测是参考工具，不是临床心理诊断 |

## 十、边界声明

| 不做 | 原因 |
|------|------|
| 分析真实交易记录 | 定位是心智评测，不是业绩分析 |
| 推荐具体股票或买卖时机 | 不构成投资建议 |
| 预测炒股收益或成功率 | 不承诺收益结果 |
| 接入券商或交易系统 | 与交易行为完全隔离 |
| 实时行情或盯盘 | 静态诊断，不是日常交易工具 |
| 选择题或量表 | 只有对抗式审讯才能暴露真实思维模式 |
| 告知"标准答案" | 没有正确答案，目的是暴露你的真实模式 |
| 存储审讯录音或身份信息 | 隐私保护，评测后不保留 |
