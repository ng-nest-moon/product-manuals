# 老糊涂 — 产品功能说明书

## 一句话定义

让系统拥有一个可选年龄、会遗忘、会模糊、会记错的记忆系统。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：AI 应用开发者、角色扮演系统设计者、叙事游戏设计师**

| 维度 | 描述 |
|------|------|
| 角色 | 需要为 AI 系统设计"人性化记忆"的开发者 |
| 场景 | 构建长期陪伴型 AI、虚拟角色、叙事生成系统 |
| 典型需求 | 现有系统的记忆要么全有要么全无，没有"人之常情"的模糊地带 |
| 底层认知 | 精确的记忆系统让 AI 显得"不像人"、过于机械 |

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 传统记忆系统过于精确，导致 AI 角色显得"不真实" |
| **刚需** | 开发者需要可配置的"遗忘曲线"而非硬编码 |
| **改善型** | 现有方案缺乏情绪对记忆的影响机制 |
| **改善型** | 需要错构记忆生成叙事冲突的能力 |

---

## 二、解决方案与核心功能

### 2.1 解决方案概述

老糊涂是一个模拟人类记忆机制的系统组件。它不追求"永远记住你的一切"，而是模拟人的遗忘、模糊、变形、错构、情绪染色。

核心设计：
- **年龄可配置** — 从 5 岁到 80 岁，每一年龄段的记忆特征不同
- **遗忘是设计目标** — 不是 bug，是 feature
- **每次回忆都是一次重写** — 模拟人类记忆的"再巩固"机制
- **错构带来惊喜** — 把不同时间的事拼在一起，产生新的叙事可能性

### 2.2 核心功能清单

1. **记忆年龄设定** — 系统的心理年龄（5-80 岁），影响遗忘曲线和记忆特征
2. **记忆写入** — 每条记忆携带内容、时间戳、情绪标签、重要性、关联记忆
3. **记忆衰减** — 基于遗忘曲线自动衰减，受重要性/回忆次数/情绪强度调节
4. **记忆检索** — 关联激活 → 候选召回 → 置信度排序 → 输出
5. **梦境整合** — 空闲时巩固记忆、冲突检测、碎片拼接、冗余清理
6. **遗忘回收** — 容量上限时回收低重要/长期未访问/低关联记忆
7. **错构回忆** — 置信度低时自动拼接多段记忆生成"可能"的回忆
8. **情绪染色** — 情绪标签影响回忆的色彩和表达方式
9. **记忆可视化** — 记忆星图（节点大小=重要性，颜色=清晰度）+ 记忆年轮

## 三、竞品与差异化分析

| 竞品 | 优点 | 缺点 | 差异 |
|------|------|------|------|
| Mem0 / MemGPT | 精确持久化，适合实用场景 | 缺少模糊/错构/遗忘 | 老糊涂以"不精确"为核心设计 |
| 传统向量数据库 | 检索快速，可扩展 | 无遗忘机制，纯精确匹配 | 老糊涂用置信度排序和模糊输出 |
| 角色卡固定设定 | 可控性好 | 无动态记忆演化 | 老糊涂记忆动态变化 |

**差异化优势：** 遗忘和错构不是 bug 而是 feature，适合追求"人性化"而非"精确性"的 AI 角色场景。

## 四、架构总览

```
用户
 ├── 1. 配置层 —— 选定年龄、遗忘曲线、错构倾向、情绪敏感度
 ├── 2. 记忆层 —— 写入（内容/时间/情绪/重要性/关联）、衰减、检索
 ├── 3. 维护层 —— 梦境整合（巩固/冲突检测/碎片拼接）、遗忘回收
 └── 4. 输出层 —— 精确回忆 / 模糊回忆 / 错构回忆 / 情绪染色
```

## 五、核心模块详解

### 5.1 配置层

| 参数 | 取值 | 说明 |
|------|------|------|
| 记忆年龄 | 5-80 岁 | 5-12 岁情绪记忆鲜明但易混淆；13-25 岁细节最强；26-45 岁工作记忆下降理解增强；46-60 岁近期衰减明显；60+ 近期模糊远期稳固但可能变形 |
| 遗忘曲线类型 | 陡峭型/平缓型/标准型 | 记忆衰减速度 |
| 错构倾向 | 低/中/高 | 记忆变形概率 |
| 情绪敏感度 | 低/中/高 | 情绪对记忆的影响程度 |

### 5.2 记忆层

**写入字段：** 内容、时间戳、情绪标签（开心/难过/愤怒/中性）、重要性（1-10）、关联记忆 ID、上下文环境。

**衰减规则：** 刚写入 100% → 1 小时 90% → 1 天 70% → 1 周 50% → 1 月 35% → 半年 20% → 1 年 10%。重要性越高、回忆次数越多、情绪越强、关联越多的记忆衰减越慢。

**检索流程：** 关联激活 → 候选召回（允许部分匹配）→ 置信度排序（重要性×时效性×关联度）→ 输出。置信度 > 80% 精确描述，50-80% 模糊表达，20-50% "不太确定"，< 20% "不记得了"或错构。

### 5.3 维护层

**梦境整合：** 提取高频记忆 → 关联比对 → 冲突检测（根据置信度决定保留哪个）→ 碎片拼接 → 冗余清理。

**遗忘回收：** 容量超限时按 低重要性 > 长期未访问 > 低关联度 > 情感抑制（负面情绪且长期不访问）顺序回收。回收记忆转入"深层存储"，极特殊情况下可唤醒。

### 5.4 输出层

四种输出模式：精确回忆（"2023年9月你提过想去云南大理"）、模糊回忆（"好像你说过想去云南……"）、错构回忆（"云南大理的烤饵块很好吃"——实际用户去的是丽江）、情绪染色回忆（"窗外还有阳光洒进来"——实际是阴天）。

**遗忘表达：** "这个我还真不记得了"/"好像有这么回事"/"我不能确定"/"我好像记错了"。

### 5.5 记忆可视化

**记忆星图：** 节点大小 = 重要性，颜色深浅 = 清晰度，连线 = 关联关系，虚线节点 = 衰减中。

**记忆年轮：** 按时间维度展示记忆分布密度。

## 六、用户流程

```
引入老糊涂 SDK → 配置记忆年龄与参数
    ↓
系统运行时 → 写入记忆（内容/情绪/重要性/关联）
    ↓
记忆自动衰减（按遗忘曲线）
    ↓
空闲时梦境整合 → 巩固或清理
    ↓
用户提问 → 检索记忆 → 按置信度输出
    ↓
查看记忆星图/年轮 → 了解当前记忆状态
```

## 八、落地路径

### 8.1 落地难点

| 难点 | 缓解策略 |
|------|---------|
| 错构记忆可能导致严重错误 | 错构仅在低置信度下触发，高置信度场景精确输出 |
| 遗忘曲线参数需要大量调优 | 预设三组曲线（年轻人/中年人/老年人）开箱即用 |
| 开发者不习惯"会遗忘的系统" | 明确说明使用场景（角色扮演/叙事），非通用记忆方案 |

### 8.2 第一步验证

**最关键假设：** AI 角色开发者愿意用"会遗忘"的记忆系统替代精确记忆。

**验证方法：** 发布一个开源的 Python 版本，在开发者社区获取 Star 和 Issue 反馈。如果一周内获得 200+ Star，需求成立。

| 预期槽点 | 应对方案 |
|---------|---------|

## 十、边界声明

| 不做 | 原因 |
|------|------|
| 精确数据存储 | 密码、日程、账目建议用常规数据库 |
| 医疗级记忆诊断 | 不模拟阿尔茨海默等病理状态 |
| 用户心理分析 | 不基于记忆模式做心理诊断 |
| 记忆永久备份 | 遗忘是设计的一部分 |
| 跨实例记忆同步 | 每个实例的记忆库独立 |
