# 老糊涂 — 产品功能说明书

## 一句话定义

让系统拥有一个可选年龄、会遗忘、会模糊、会记错的记忆系统。

---

## 一、系统架构总览

```
用户
 ├── 1. 配置层 —— 选定年龄、初始化
 ├── 2. 记忆层 —— 写入、衰减、检索
 ├── 3. 维护层 —— 梦境整合、遗忘回收
 └── 4. 输出层 —— 回忆、模糊、错构
```

---

## 二、核心理念

传统系统的记忆是精确的、永久的、不变的。而人的记忆不是。

人的记忆会：
- **遗忘** — 时间越久，细节越模糊
- **变形** — 每次回忆都是一次重写
- **错构** — 把不同时间的事拼在一起
- **情绪染色** — 开心的回忆越来越美好，痛苦的回忆越来越尖锐
- **年龄差异** — 年轻人记细节，老年人记感觉

老糊涂 模拟的就是这套人性化记忆机制。

## 三、配置层

### 3.1 记忆年龄设定

| 参数 | 说明 | 取值范围 |
|------|------|---------|
| 记忆年龄 | 系统的"心理年龄" | 5岁 ~ 80岁 |
| 遗忘曲线类型 | 记忆衰减的速度模型 | 陡峭型 / 平缓型 / 标准型 |
| 错构倾向 | 记忆变形的概率 | 低 / 中 / 高 |
| 情绪敏感度 | 情绪对记忆的影响程度 | 低 / 中 / 高 |

**不同年龄的记忆特征：**

| 年龄段 | 特征 |
|--------|------|
| 5-12岁 | 记性很好，但容易混淆相似的事，情绪记忆鲜明 |
| 13-25岁 | 细节记忆最强，但容易过度自信于记忆的准确性 |
| 26-45岁 | 工作记忆开始下降，但理解性记忆增强 |
| 46-60岁 | 近期记忆衰减明显，远期记忆稳固 |
| 60岁以上 | 近期记忆模糊，远期记忆清晰但可能变形 |

### 3.2 初始化配置

```yaml
记忆体配置:
  年龄: 28
  遗忘曲线: 标准型
  错构倾向: 中
  情绪敏感度: 中
  初始记忆: []
  语言: 简体中文
```

## 四、记忆层

### 4.1 记忆写入

每条记忆写入时携带以下属性：

| 字段 | 说明 | 示例 |
|------|------|------|
| 内容 | 记忆的核心信息 | "2025年3月15日，用户说最喜欢秋天的枫叶" |
| 时间戳 | 写入时间 | 2025-03-15T14:30:00 |
| 情绪标签 | 当时的情绪状态 | 开心 / 难过 / 愤怒 / 中性 |
| 重要性 | 初始权重（1-10） | 7 |
| 关联记忆 | 关联的其他记忆 ID | [mem_001, mem_003] |
| 上下文 | 环境信息 | "在咖啡馆，窗外下着小雨" |

### 4.2 记忆衰减

记忆随着时间推移逐渐衰减，模拟遗忘曲线：

**衰减规则：**

| 时间 | 细节保留度 | 表现 |
|------|-----------|------|
| 刚写入 | 100% | 完整精确 |
| 1小时后 | 90% | 细节开始模糊 |
| 1天后 | 70% | 大致记得，部分细节丢失 |
| 1周后 | 50% | 核心内容保留，细节模糊 |
| 1月后 | 35% | 记得发生过，但不记得具体 |
| 半年后 | 20% | 只有重要节点留存 |
| 1年后 | 10% | 只有反复提及或重要性高的记忆留下 |

**调节因子：**
- **重要性越高** → 衰减越慢
- **被回忆次数越多** → 衰减越慢（每次回忆相当于一次"复习"）
- **情绪强度越高** → 衰减越慢
- **关联记忆越多** → 衰减越慢

### 4.3 记忆检索

检索记忆时，系统不是精确匹配，而是模拟人的回忆过程：

**检索流程：**

```
用户提问 → 关联激活 → 候选召回 → 置信度排序 → 输出
```

| 步骤 | 说明 |
|------|------|
| 关联激活 | 根据问题关键词激活关联网络中的相关记忆节点 |
| 候选召回 | 从衰减后的记忆库中召回候选，允许部分匹配 |
| 置信度排序 | 综合重要性、时效性、关联度计算置信度 |
| 输出 | 高置信度直接输出，中置信度模糊输出，低置信度不输出 |

**置信度对输出的影响：**

| 置信度 | 输出表现 |
|--------|---------|
| > 80% | "我记得是……（精确描述）" |
| 50% - 80% | "好像是在……应该是……" |
| 20% - 50% | "有点印象，但不太确定了……" |
| < 20% | "我不记得了" 或 错构 |

## 五、维护层

### 5.1 梦境整合

模拟人类的睡眠记忆巩固机制。在系统空闲时触发：

**梦境整合过程：**

```
1. 提取当天高频访问或新写入的记忆
2. 与历史关联记忆进行交叉比对
3. 冲突检测：如果新旧记忆矛盾，根据置信度决定保留哪个
4. 碎片拼接：将分散的相关片段合并为结构化记忆
5. 冗余清理：删除完全重复的记忆
```

### 5.2 遗忘回收

当记忆库达到容量上限时，触发遗忘回收：

| 回收策略 | 说明 |
|---------|------|
| 低重要性优先 | 重要性 < 3 的记忆优先回收 |
| 长期未访问 | 超过半年未被访问的记忆优先回收 |
| 低关联度 | 孤立记忆（无关联链接）优先回收 |
| 情感抑制 | 负面情绪强度过高且长期不被访问的记忆自动抑制 |

被回收的记忆不是彻底删除，而是转入"深层存储"——在极特殊情况下仍可被唤醒。

## 六、输出层

### 6.1 回忆模式

根据置信度，系统输出不同形式的"回忆"：

**精确回忆：**

> "2023年9月，你提过你想去云南大理，说想看苍山洱海，还问过我最推荐的季节。"

**模糊回忆：**

> "我记得你之前好像说过想去云南……是跟朋友一起吗？还是一个人去？"

**错构回忆：**

> "你之前不是去过云南大理吗？你说那边的烤饵块很好吃。"（实际用户去的是丽江，说的是烤乳扇）

**情绪染色回忆：**

> "那天我们聊起你的旅行，你说话的语气很开心，窗外还有阳光洒进来。"（实际是阴天，但用户当时心情好）

### 6.2 遗忘表达

当记忆不确定或已遗忘时，系统的回应方式：

| 场景 | 回应 |
|------|------|
| 完全遗忘 | "这个我还真不记得了，能再跟我说说吗？" |
| 模糊记得 | "好像有这么回事，但细节我记不清了……" |
| 不确定 | "我不能确定是不是这样，我可能记混了" |
| 意识到记错 | "我好像记错了，你纠正过我一次" |

## 七、记忆可视化

### 7.1 记忆星图

以可视化方式展示记忆库中的记忆：

```
                      [用户说喜欢猫]
                      /        \
        [用户养了一只橘猫]      [猫叫大黄]
             /                      \
    [大黄很贪吃]                 [大黄喜欢晒太阳]
         |                            |
    [大黄偷吃鱼干]               [窗台是专属位置]
```

- 节点大小代表记忆的重要性
- 颜色深浅代表记忆的清晰度
- 连线代表关联关系
- 虚线节点代表已进入衰减状态的记忆

### 7.2 记忆年轮

按时间维度展示记忆分布：

```
2023 ║▓▓▓▓▓░░░░░░░░░░░║ 3条重要
2024 ║▓▓▓▓▓▓▓▓▓░░░░░░░║ 15条重要
2025 ║▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓░║ 28条重要
```

## 八、应用场景

### 场景一：长期陪伴型对话系统

系统能记住几个月前的对话细节，但会随着时间模糊，像真人一样"久了不聊就会忘"。

> 用户：你还记得我上次说想去哪旅游吗？
> 系统：嗯……好像是云南方向？记得你说过想看山还是湖……苍山洱海？我没记错吧？

### 场景二：角色扮演

虚拟角色带有年龄设定，记忆表现符合其设定年龄：

> 18岁的角色：记得所有细节，但容易混淆日期顺序
> 70岁的角色：记得年轻时的事，但昨天说过什么可能不记得了

### 场景三：故事生成

利用错构记忆生成新的叙事内容：

> 系统把两次不同旅行中的记忆片段拼接，生成一个"虚拟故事"——不是事实，但符合用户的喜好和风格。

## 九、边界声明

| 不做 | 原因 |
|------|------|
| 精确数据存储 | 需要精确存储的场景（密码、日程、账目）建议用常规数据库 |
| 医疗级记忆诊断 | 不模拟阿尔茨海默等病理状态 |
| 用户心理分析 | 不基于记忆模式对用户做性格或心理诊断 |
| 记忆永久备份 | 遗忘是设计的一部分，不提供"永不遗忘"模式 |
| 跨实例记忆同步 | 每个实例的记忆库独立 |

## 十、配置示例

### 配置一：知心好友型（28岁）

```yaml
年龄: 28
遗忘曲线: 平缓型
错构倾向: 低
情绪敏感度: 高
特征: 记得住重要的事，偶尔记错小细节，像个靠得住的朋友
```

### 配置二：老顽童型（65岁）

```yaml
年龄: 65
遗忘曲线: 陡峭型
错构倾向: 高
情绪敏感度: 高
特征: 近期的事转头就忘，但年轻时的趣事记得一清二楚，经常把不同人不同时间的事串在一起讲
```

### 配置三：精明管家型（30岁）

```yaml
年龄: 30
遗忘曲线: 平缓型
错构倾向: 低
情绪敏感度: 低
特征: 记忆准确度高，不掺杂情绪，适合需要可靠记忆的服务场景
```
