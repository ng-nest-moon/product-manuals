# 功夫武馆 — 产品功能说明书

## 一句话定义

像素风武馆经营模拟——收徒教拳、开馆立派，你教的每套武功都会被弟子"活学活用"产生变异，十年后你的武馆拥有全江湖独一份的传承。

---

## 一、架构总览

```
武馆经营层
 ├── 选址与扩建 ── 场地/练功房/宿舍/药房/藏经阁
 ├── 财务管理 ── 学费/镖局任务/药材买卖/比武奖金
 ├── 声誉系统 ── 本地声望/江湖名望/官府关系
 └── 分馆扩张 ── 跨城开分馆/派驻弟子坐馆

弟子培养层
 ├── 招徒 ── 各地来投/天赋随机/背景各异
 ├── 教学 ── 基础教学/师徒对练/弟子互练/下山历练
 ├── 三维天赋 ── 根骨(体质)/悟性(速度)/心性(上限)
 └── 弟子状态 ── 忠诚/疲劳/伤病/心境

武学变异层 ◀── 核心
 ├── 武学库 ── 拳/掌/腿/兵刃/内功五大类
 ├── 变异引擎 ── 性格×天赋×经历→招式变异
 ├── 融合系统 ── 双人对练/多人切磋→招式融合
 └── 传承谱系 ── 每套武功的变异树/师承链路

江湖事件层
 ├── 踢馆 ── 其他武馆上门挑战
 ├── 武林大会 ── 年度比武/门派排名
 ├── 江湖恩怨 ── 弟子在外惹事/仇家寻仇/联姻
 └── 官府与绿林 ── 查访/招安/镖局合作
```

---

## 二、核心功能清单

1. **武学变异引擎** — 每套武功因弟子性格、天赋、对练记录产生招式变异，形成独门武功
2. **融合创造系统** — 两名弟子长期对练可融合出全新招式，且继承双方风格特征
3. **三维天赋体系** — 根骨/悟性/心性决定弟子成长方向与上限
4. **武馆经营模拟** — 选址、扩建、收学费、接任务、开分馆完整经营链
5. **教学与历练** — 基础教学→对练→下山历练→比武实战的养成闭环
6. **师承谱系图** — 可视化展示每套武功从传入到变异的完整谱系树
7. **江湖事件池** — 50+ 随机事件：踢馆、拜师、寻仇、联姻、官府查访
8. **武林大会** — 年度比武大会，各门派排名决定江湖地位
9. **弟子独立AI** — 每个弟子有性格、偏好、野心，可能叛门或自立门户
10. **存档独特性** — 每个存档的武学谱系独一无二，无重复传承

## 三、核心模块详解

### 3.1 武学变异引擎

这是产品的核心机制。每套武学进入武馆后不是固定模板，而是一个"活"的传承。

**变异触发条件：**

| 触发条件 | 效果 | 示例 |
|---------|------|------|
| 弟子性格偏激 | 招式威力上升但稳定性下降 | 「崩拳」→「烈风崩」(+40%伤害，-20%命中) |
| 弟子悟性高 | 招式产生巧变，附加特殊效果 | 「崩拳」→「寸劲崩」(范围缩小50%，暴击+60%) |
| 反复实战 | 招式向实战方向优化，去繁就简 | 「长拳三十六式」→「杀式三招」(只剩三招但每招致命) |
| 师徒默契高 | 招式继承师父风格但更精纯 | 师父阴柔路子 → 弟子版更加阴狠 |
| 多日对练 | 两人招式产生"共鸣"，融合出新 | 「铁桥硬马」+「柳絮身法」→「铁柳缠丝手」 |

**变异方向不可控但可引导：** 玩家不能指定变异结果，但可以通过选择对练对手、指派任务类型、决定教学方式来影响变异倾向。

### 3.2 弟子培养系统

**招徒：** 每年春秋两季招徒。来投弟子携带随机三维天赋（根骨/悟性/心性）和隐藏性格属性。天赋总值固定，但分布倾向不同——有人根骨奇佳但悟性愚钝，有人悟性过人但心性浮躁。

**教学流程：**

```
选择教授武功 → 指定教学方式（演练/讲解/对练）
  → 消耗课时 → 弟子悟道进度变化
    → 触发性格判定 → 可能触发变异
      → 记录练法笔记 → 玩家可查阅调整策略
```

**弟子状态管理：**

| 状态 | 影响 | 应对方式 |
|------|------|---------|
| 疲劳 | 悟道效率下降 | 安排休息/药浴 |
| 伤病 | 无法练武 | 药材治疗/养伤 |
| 心境低落 | 有叛门风险 | 谈话/安排外出散心 |
| 野心膨胀 | 可能自立门户 | 提升地位/传授核心武功 |

### 3.3 武馆经营系统

| 功能 | 说明 |
|------|------|
| 收学费 | 基础收入，受声誉和教学品质影响 |
| 镖局任务 | 派遣弟子押镖，赚取额外收入和弟子实战经验 |
| 药材买卖 | 种植/采购药材，用于弟子治疗和状态提升 |
| 比武奖金 | 参加武林大会或擂台赛赢得奖金 |
| 门派捐赠 | 高声誉后地方乡绅主动捐赠 |

**扩建路径：** 练功场 → 宿舍 → 药房 → 藏经阁 → 演武台 → 分馆

### 3.4 江湖事件系统

每季度触发 1-2 个事件，全年推进。事件类型：

| 类型 | 示例 | 选择影响 |
|------|------|---------|
| 踢馆 | 隔壁武馆上门叫阵 | 赢则声望↑/输则声望↓+弟子信心↓ |
| 拜师 | 江湖散人携艺来投 | 接受则获得新武学/拒绝则可能结仇 |
| 寻仇 | 弟子在外惹了仇家 | 交出弟子(忠诚↓)/庇护(可能全面开战) |
| 联姻 | 他派掌门提亲联姻 | 联姻则两派好感↑/拒绝则好感↓ |
| 官府查访 | 当地官府怀疑武馆有乱党 | 打点/配合/抗命，三选一 |
| 天灾 | 洪水地震损坏武馆 | 耗资重修/暂停招生 |

### 3.5 师承谱系图

可视化展示武馆的完整传承树：

```
张师父（开馆祖师）
 ├── 大弟子·赵虎 ── 习「崩拳」→ 变异为「烈风崩」
 │    ├── 再传·钱六 ── 习「烈风崩」→ 变异为「怒涛崩」
 │    └── 再传·孙七 ── 习「烈风崩」→ 未变异
 └── 二弟子·李娥 ── 习「柳絮身法」→ 变异为「飞絮步」
      └── 再传·周五 ── 习「飞絮步」→ 与「烈风崩」传人对练
           └── 融合产物：「风絮连环」◀── 新武功诞生
```

每个玩家存档的谱系图不可能重复——两套相同的初始武功，因为弟子不同、选择不同，十年后走向天壤之别。

## 四、用户流程

```
开馆（取名、选址、初始资金、选择本门核心武功）
  ↓
第一年春招徒（3-5 人来投，查看天赋，选择收徒）
  ↓
教学回合（每月：安排课程/指派对练/管理状态）
  ↓
季度事件（踢馆/拜师/江湖传闻——做选择）
  ↓
年终总结（弟子成长报告/武学变异记录/财务状况/江湖地位变化）
  ↓
循环 → 第二年春招 → 新弟子入馆
  ↓
达到条件 → 开分馆 / 参加武林大会 / 解锁新武学流派
  ↓
终局条件（任选其一）
  ├── 武学传承达到 100 种 → "百艺归宗"结局
  ├── 武林大会三连冠 → "天下第一"结局
  ├── 弟子出师自立 10 人 → "桃李满天下"结局
  └── 武馆传承三代 → "百年武馆"结局
```

## 五、应用场景

### 场景一：保守派 vs 革新派

玩家甲选择稳扎稳打，只教基础拳法，不给弟子自由发挥空间——武馆稳定但武学从未变异，几十年如一日。
玩家乙鼓励弟子个性发展，接受变异甚至主动创造条件——前期混乱（变异不一定都是正向的），但十年后门下独门武功百花齐放。
两套策略在武林大会上正面碰撞，各有优劣。

### 场景二：一个"叛徒"的价值

核心弟子孙七天赋极高，玩家倾囊相授。不料孙七野心膨胀，带着变异版「怒涛崩」叛门自立。五年后孙七的武馆在邻城做大，成为头号竞争对手。玩家有两个选择：上门清理门户（夺回武功传承）或 放任不管（江湖上多了一支从自己门派分出去的流派）。

### 场景三：无心插柳的融合

玩家安排大弟子赵虎（刚猛路子）和二弟子李娥（轻灵路子）长期对练，本意是让两人互补短板。没想到两年后两人在对练中无意融合出一招「风絮连环」——兼具刚猛和轻灵两种特性，成为本馆镇馆绝学。这一招在武林大会上从未出现过，对手无从应对。

## 六、边界声明

| 不做 | 原因 |
|------|------|
| 真实门派名称 | 少林武当等有版权和文化敏感性，使用虚构门派体系 |
| 暴力血腥表现 | 像素风+文字描述，不展示真实暴力 |
| 玄幻/超自然武功 | 坚持"武侠"而非"仙侠"，不离地 |
| PvP 联机竞技 | 聚焦单人经营叙事，不对标格斗游戏 |
| 自动挂机模式 | 教学选择和弟子管理是核心玩法，不自动化 |
| 武功数值完全可预测 | 变异引擎的不可预测性是核心乐趣 |
