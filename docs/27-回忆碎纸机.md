# 回忆碎纸机 — 产品功能说明书

## 一句话定义

一段你想放下的回忆，安放进来，亲手粉碎，看着它变成别的东西。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：有未处理情绪回忆的年轻人（16-35 岁）**

| 维度 | 描述 |
|------|------|
| 心理状态 | 对某段回忆有执念/遗憾/悔恨/愤怒，想要放下但不知道怎么做 |
| 当前做法 | 写日记（缺乏仪式感）、找朋友倾诉（怕被评判）、闷在心里（最普遍） |
| 使用场景 | 睡前独处、失恋后、人生转折点、周末下午 |
| 底层需求 | 一个安全、私密、有仪式感的方式跟过去告别 |

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 放不下回忆的人缺乏"仪式性"的告别方式 |
| **刚需** | 很多人需要"不被人看到"的情感处理空间 |
| **改善型** | 已有产品要么是正经心理咨询（门槛高），要么是日记（无变化感） |
| **改善型** | "放下"需要被感知为一个过程，而非某天突然消失 |

---

## 二、解决方案与核心功能

### 2.1 解决方案概述

回忆碎纸机 = 三种方式输入回忆（文字/照片/语音）→ 自动具象化为视觉物件 → 五种粉碎仪式（撕碎/焚烧/溶解/埋葬/飘散）→ 碎片蜕变为新形态 → 永远存在在回忆花园中。

所有数据仅存于浏览器 localStorage，无云端上传。仪式不可逆——一旦蜕变完成，无法查看原始内容。

### 2.2 核心功能清单

1. **回忆输入** — 文字（50-500 字）/ 照片 / 语音三种方式
2. **情绪标签** — 7 种情绪可选，影响物件视觉风格
3. **回忆具象化** — 输入内容自动映射为视觉物件（旧照片/手写信/千纸鹤/石头/木匣子/枯花）
4. **五种粉碎仪式** — 撕碎 / 焚烧 / 溶解 / 埋葬 / 飘散，全屏交互场景
5. **蜕变重组** — 碎片重组为新形态：折纸心 / 星辰 / 莲花 / 嫩芽 / 极光
6. **回忆花园** — 按仪式分区的可视化空间，所有蜕变记忆共存
7. **回望 prompt** — 仪式前后可选的自省引导问题
8. **告别日历** — 时间线 + 月度概览 + 情绪变迁
9. **轻量统计** — 仪式偏好、情绪分布、释放频率
10. **纯粹本地** — 全部数据仅存于浏览器，不上传

## 三、竞品与差异化分析

| 对比项 | 回忆碎纸机 | 日记 App | 冥想 App | 心理咨询 |
|--------|----------|---------|---------|---------|
| 仪式感 | **核心设计** | 无 | 有（呼吸练习）| 有（对话） |
| 私密性 | **完全本地，不上传** | 通常有云同步 | 需注册 | 有记录 |
| 视觉转化 | **有（物件→蜕变）** | 无 | 无 | 无 |
| 门槛 | 低（5 分钟）| 低 | 低 | 高（费用+勇气）|

**差异化优势：** 仪式感 + 视觉转化 + 不可逆蜕变 + 完全本地。

## 四、架构总览

```
表现层（宁静视觉空间）
 ├── 欢迎页 —— 极简界面
 ├── 回忆入口 —— 文字/照片/语音 + 情绪标签
 ├── 具象化场景 —— 物件展示（微动效 + 氛围光影）

 └── 回忆花园 —— 所有蜕变记忆共存空间

仪式引擎
 ├── 撕碎 —— 拖拽撕裂 + 纸片纷飞物理
 ├── 焚烧 —— 点燃蔓延 + 火焰粒子 + 灰烬升腾

 ├── 埋葬 —— 覆土掩埋 + 破土新芽

 ├── 回忆碎片库 —— localStorage 加密

 ├── 告别日历 —— 时间线 + 统计
 └── 回望笔记 —— 可选自省记录
```

## 五、核心模块详解

### 5.1 具象化引擎

情绪标签 + 输入语义自动匹配物件：

| 物件 | 适合氛围 | 动态表现 |
|------|---------|---------|
| 旧照片（褪色宝丽来） | 怀念、遗憾 | 边缘微卷，光线掠过 |
| 手写信（泛黄信纸） | 悔恨、释然 | 笔迹隐现，折痕纹理 |
| 千纸鹤 | 遗憾、怀念 | 翅膀微颤，柔和投影 |
| 石头（刻字） | 愤怒、沉重 | 刻痕纹理，静止稳重 |
| 木匣子（黄铜锁扣） | 秘密、封存 | 灰尘粒子，细微光泽 |
| 枯花（压花玻璃框） | 感恩、释然 | 花瓣裂痕，玻璃反光 |

### 5.2 五种粉碎仪式

| 仪式 | 操作 | 物理模拟 | 蜕变结果 |
|------|------|---------|---------|
| 撕碎 | 拖拽划过，沿轨迹撕开 | 纸张纹理实时分裂 | 折纸心 |
| 焚烧 | 长按或点击点燃 | 火焰蔓延，纸张卷曲变黑 | 星辰 |
| 溶解 | 自动落入水中，点击加速 | 墨色晕散，颜色剥离 | 莲花 |
| 埋葬 | 点击"捧土"掩埋 | 土粒逐层覆盖，土壤堆积 | 嫩芽 |
| 飘散 | 吹气/滑动引导风向 | 数百光点受风场影响 | 极光 |

蜕变动画 3-5 秒，ease-in-out 曲线，完成后物件表面铭刻日期+情绪+摘要。**不可逆**——一旦完成无法查看原始内容。

### 5.3 回忆花园

五个区域（折纸角落/星空穹顶/莲花池塘/萌芽园地/极光天际），4 分钟日夜交替。点击弹出铭刻卡片，长按播放 2 秒缩略回放。

## 六、用户流程

```
欢迎页 → 回忆入口（文字/照片/语音 + 情绪标签）
  ↓
具象化（自动生成物件，3s 展示）
  ↓
仪式前 prompt（可选）
  ↓
仪式选择 → 全屏交互 → 粉碎完成
  ↓
蜕变动画（3-5s）
  ↓
仪式后 prompt（可选）
  ↓
花园入口（新物件出现在对应区域）
```

## 八、落地路径

### 8.1 MVP

欢迎页 + 文字输入 + 情绪标签 + 3 种物件（旧照片/手写信/千纸鹤）+ 撕碎仪式 + 蜕变（折纸心）+ 回忆花园基础网格。

### 8.2 第一步验证

**最关键假设：** 用户愿意把真实的情绪回忆放进一个工具并亲手"销毁"。

**验证方法：** 做一个极简原型（文字输入 + 撕碎仪式 + 蜕变为折纸心）。找 20 人试用。如果 > 60% 的人在测试后表示"感觉真的放下了某种东西"，需求成立。

## 九、风险与预期反馈

| 预期槽点 | 应对方案 |
|---------|---------|
| "怎么还要写 50 字" | 低于 50 字不足以生成有细节的物件 |
| "不是心理治疗吗" | 明确声明不是心理咨询替代品 |
| "怎么不能恢复" | 不可逆是核心设计——蜕变就是告别 |
| "太伤感了" | 产品本身就是为处理伤感而存在的 |

---

## 十、边界声明

| 不做 | 原因 |
|------|------|
| 心理治疗替代 | 不提供诊断、治疗或危机干预 |
| 数据上传 / 云端同步 | 所有数据仅存于 localStorage |
| 社交 / 分享 / 排行榜 | 回忆是私密的 |
| AI 编造"更好的版本" | 不修改用户记忆内容 |
| 推送通知 / 签到 | 无主动推送 |
| 付费 / 内购 / 广告 | 完全免费 |
| 未满 12 岁使用 | 涉及情绪处理，建议 12 岁以上 |
