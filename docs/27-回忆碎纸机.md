# 回忆碎纸机 — 产品功能说明书

## 一句话定义

一段你想放下的回忆，安放进来，亲手粉碎，看着它变成别的东西。

---

## 适龄建议

12 岁以上

---

## 一、系统架构总览

```
表现层（宁静的视觉空间）
 ├── 欢迎页 —— 极简界面，一句话引导 + 开始按钮
 ├── 回忆入口 —— 文字/照片/语音三种输入 + 情绪标签
 ├── 具象化场景 —— 回忆物件展示（微动效 + 氛围光影）
 ├── 仪式选择 —— 5 种粉碎方式预览 + 对应蜕变展示
 ├── 仪式全屏 —— 沉浸式交互动画场景
 ├── 蜕变展示 —— 碎片重组为新形态的慢速动画
 └── 回忆花园 —— 所有蜕变记忆的共存空间

仪式引擎
 ├── 撕碎 —— 拖拽撕裂，纸片纷飞物理模拟
 ├── 焚烧 —— 点燃蔓延，火焰粒子 + 灰烬升腾
 ├── 溶解 —— 落入水中，墨色晕散 + 透明渐变
 ├── 埋葬 —— 覆土掩埋，破土新芽动画
 └── 飘散 —— 化作光点，风向粒子系统

蜕变系统
 ├── 碎片重组算法 —— 粒子/碎片沿贝塞尔曲线重组
 ├── 花园生态 —— 花/星/莲/芽/光 持续呈现
 └── 时间印记 —— 日期 + 情绪 + 用户摘要铭刻

数据层
 ├── 回忆碎片库 —— localStorage 加密存储
 ├── 花园存档 —— 所有蜕变记忆状态与位置
 ├── 告别日历 —— 时间线 + 统计数据
 └── 回望笔记 —— 可选的自省记录
```

---

## 二、核心功能清单

1. **回忆输入** — 文字（50-500 字）/ 照片 / 语音三种方式描述一段想要放下的回忆
2. **情绪标签** — 7 种情绪可选：遗憾、悔恨、愤怒、怀念、感恩、释然、其他
3. **回忆具象化** — 输入内容自动映射为一件视觉物件（旧照片、手写信、千纸鹤、石头、木匣子、枯花）
4. **五种粉碎仪式** — 撕碎 / 焚烧 / 溶解 / 埋葬 / 飘散，每种独立的全屏交互场景与物理逻辑
5. **蜕变重组** — 碎片不消失，重组为新的美好形态：折纸心 / 星辰 / 莲花 / 嫩芽 / 极光
6. **回忆花园** — 按仪式类型分区的可视化空间，所有蜕变记忆共存其中
7. **回望 prompt** — 仪式前后可选的自省引导问题，回答铭刻在物件上
8. **告别日历** — 时间线 + 月度概览 + 情绪变迁
9. **轻量统计** — 仪式偏好、情绪分布、释放频率
10. **纯粹本地** — 全部数据仅存于 localStorage，无云端上传

## 三、模块详解

### 3.1 回忆入口

#### 3.1.1 输入方式

三种输入方式，任选至少一种：

| 方式 | 格式限制 | 交互 | 具象化影响 |
|------|---------|------|-----------|
| 文字 | 50-500 字 | 多行文本框，实时字数统计 | 内容语义影响物件细节（关键词/语气） |
| 照片 | JPEG/PNG，< 5MB | 上传或调用摄像头拍照 | 主色调 + 构图影响物件配色 |
| 语音 | < 3 分钟 | 按下录制，松开停止 | 语速/语调影响物件动态节奏 |

#### 3.1.2 情绪标签

单选，可跳过：

| 标签 | 色调 | 仪式动效偏向 |
|------|------|-------------|
| 遗憾 | 蓝灰 | 轻柔、缓慢 |
| 悔恨 | 深棕 | 沉重、有力 |
| 愤怒 | 赤红 | 快速、激烈 |
| 怀念 | 暖黄 | 温暖、不舍 |
| 感恩 | 金色 | 明亮、升腾 |
| 释然 | 浅绿 | 轻盈、扩散 |
| 其他 | 白色 | 中性 |

#### 3.1.3 输入规则

| 规则 | 说明 |
|------|------|
| 文字最少 50 字 | 低于 50 字无法生成有细节的物件，提示"再多说一点" |
| 文字最多 500 字 | 超出部分截断，不影响流程 |
| 照片不上传云端 | 仅在本地浏览器内存中处理，不保存原始照片 |
| 语音不传云端 | 仅用于语调分析，处理完后丢弃音频 |
| 情绪标签不影响流程 | 纯视觉和动效偏好，不改变仪式可用性 |

### 3.2 具象化引擎

#### 3.2.1 物件池

根据情绪标签 + 输入内容语义，自动匹配一件物件：

| 物件 | 适合氛围 | 动态表现 |
|------|---------|---------|
| 旧照片（褪色宝丽来） | 怀念、遗憾 | 边缘微卷，光线掠过头，轻微浮动 |
| 手写信（泛黄信纸） | 悔恨、释然 | 纸面有笔迹隐现，折痕纹理明显 |
| 千纸鹤 | 遗憾、怀念 | 翅膀微颤，底部投影柔和 |
| 石头（刻字） | 愤怒、沉重 | 表面刻痕纹理，静止稳重 |
| 木匣子 | 秘密、封存 | 带黄铜锁扣，有细微灰尘粒子 |
| 枯花（压花玻璃框） | 感恩、释然 | 花瓣有裂痕，玻璃反光渐变 |

#### 3.2.2 生成规则

```
情绪 → 优先决定物件类型
  怀念/遗憾 → 旧照片、千纸鹤
  悔恨/愤怒 → 手写信、石头
  感恩/释然 → 枯花、木匣子
  其他 → 随机

文字关键词 → 影响细节
  如"车站" → 照片边缘有站台光影
  如"失败" → 石头刻字为"失败"
  如"毕业" → 信纸抬头有校徽轮廓

照片主色调 → 物件颜色偏移
  暖色调 → 物件泛黄/金
  冷色调 → 物件泛蓝/灰

语音语调 → 物件动态速度
  语速快、音调高 → 物件轻微抖动
  语速慢、音调低 → 物件静止缓和
```

### 3.3 粉碎仪式

每种仪式是一个独立的全屏交互场景，时长约 5-15 秒。

#### 3.3.1 撕碎（Tear）

| 属性 | 值 |
|------|-----|
| 情绪基调 | 果断、干脆 |
| 操作方式 | 用户在物件上拖拽划过，沿轨迹撕开 |
| 物理模拟 | 撕裂方向跟随鼠标路径，纸张纹理实时分裂 |
| 反馈 | 撕裂声、纸纤维拉开、碎片飘落触底反弹 |
| 完成条件 | 最后一块碎片落下触底 |
| 适合情绪 | 愤怒、悔恨——需要一把撕掉的力量感 |

#### 3.3.2 焚烧（Burn）

| 属性 | 值 |
|------|-----|
| 情绪基调 | 终极、不可逆 |
| 操作方式 | 长按物件或点击打火机图标点燃 |
| 物理模拟 | 火焰从接触点向外蔓延，燃烧路径随机分支 |
| 反馈 | 火苗跳动、纸张卷曲变黑、灰烬升腾、暖色光晕 |
| 完成条件 | 全部化为灰烬，灰烬开始发光 |
| 适合情绪 | 悔恨、愤怒——最彻底的告别方式 |

#### 3.3.3 溶解（Dissolve）

| 属性 | 值 |
|------|-----|
| 情绪基调 | 温柔、逐渐 |
| 操作方式 | 物件自动落入水中，用户点击水面可加速 |
| 物理模拟 | 墨色从边缘向中心晕散，颜色一层层剥离 |
| 反馈 | 水面涟漪扩散、颜色如烟雾般弥散、气泡上浮 |
| 完成条件 | 最后一抹颜色在水中消散 |
| 适合情绪 | 遗憾、怀念——让痛慢慢化开 |

#### 3.3.4 埋葬（Bury）

| 属性 | 值 |
|------|-----|
| 情绪基调 | 落地、生根 |
| 操作方式 | 物件落入土坑，用户点击"捧土"掩埋 |
| 物理模拟 | 土粒逐层覆盖物件，土壤堆积成小丘 |
| 反馈 | 土粒摩擦声、覆盖进度可视化、掩平轻拍 |
| 完成条件 | 土面平整后开始裂开 |
| 适合情绪 | 感恩、释然——把过去还给大地 |

#### 3.3.5 飘散（Scatter）

| 属性 | 值 |
|------|-----|
| 情绪基调 | 轻盈、自由 |
| 操作方式 | 物件碎裂为光点，用户吹气/滑动引导风向 |
| 物理模拟 | 数百光点受风场影响，带有拖尾粒子 |
| 反馈 | 光点飞舞、风声、景深感、远近模糊 |
| 完成条件 | 光点飘散到屏幕边缘后回拢 |
| 适合情绪 | 释然、怀念——放它走 |


### 3.4 蜕变引擎

碎片的最终去向不是消失，是蜕变。

| 仪式 | 蜕变结果 | 视觉表现 | 寓意 |
|------|---------|---------|------|
| 撕碎 → | **折纸心** | 碎纸片飞卷组合，折痕自然折叠成型 | 破碎过的心重新折叠好 |
| 焚烧 → | **星辰** | 灰烬凝聚为发光星体，背景转为星空 | 燃尽后化为永恒的光 |
| 溶解 → | **莲花** | 水下颜色聚拢为花瓣轮廓，浮出水面 | 沉淀后有新的绽放 |
| 埋葬 → | **嫩芽** | 土面裂开，绿芽破土，舒展两片叶子 | 埋下的成了养分 |
| 飘散 → | **极光** | 光点交织成彩色光带，在天幕流动 | 散落各处也能成风景 |

**蜕变动画规则：**

| 规则 | 参数 |
|------|------|
| 持续时间 | 3-5 秒 |
| 动画曲线 | ease-in-out，先慢后快再慢 |
| 粒子路径 | 贝塞尔曲线，终点聚拢为新形态轮廓 |
| 完成铭刻 | 物件表面浮现：日期 + 情绪 + 用户的一句话摘要 |
| 可逆性 | **不可逆**——一旦蜕变完成，无法查看原始内容 |

### 3.5 回忆花园

所有蜕变记忆的共存视觉空间。

#### 3.5.1 五个区域

| 仪式 | 区域 | 背景 | 物件呈现 |
|------|------|------|---------|
| 撕碎 | 折纸角落 | 暖色木架、柔和灯光 | 每颗折纸心挂在不同的位置 |
| 焚烧 | 星空穹顶 | 深蓝夜空、缓慢星轨 | 每颗星辰有自己的运行轨道 |
| 溶解 | 莲花池塘 | 水面倒影、浮萍 | 每朵莲花在不同位置开放 |
| 埋葬 | 萌芽园地 | 阳光草地、轻柔风动 | 每株植物在不同生长阶段 |
| 飘散 | 极光天际 | 暗色山脉、云层流动 | 每道极光色彩与形态各异 |

#### 3.5.2 交互

| 操作 | 效果 |
|------|------|
| 点击物件 | 弹出铭刻卡片：日期、情绪、你写的那句话 |
| 拖拽/滚轮 | 在花园中漫游，视差滚动 |
| 长按物件 | 播放该次仪式的 2 秒缩略回放（静默无声） |
| 双指缩放 | 拉近查看物件细节 / 拉远看全貌 |

**日夜循环：** 花园有缓慢的 4 分钟日夜交替，不同时间的色温和阴影不同。

**生长系统：** 花园随物件数量增长而自然扩展边界。空区域会逐渐有野花/萤火虫/流云填充。

### 3.6 回望与书写

可选环节，不强制。

**仪式前 prompt（三选一，随机展示）：**

| prompt | 意图 |
|--------|------|
| "这段回忆还在用什么方式影响你？" | 觉察当下影响 |
| "如果给这段回忆写一句标题，你会写什么？" | 提炼核心 |
| "你准备好了吗？" | 确认意愿 |

**仪式后 prompt（三选一，随机展示）：**

| prompt | 意图 |
|--------|------|
| "释放之后，现在感觉怎么样？" | 体察变化 |
| "有什么想对那时候的自己说？" | 和解 |
| "可以写一句告别的话。" | 收尾仪式 |

**内容去向：**

| prompt 类型 | 去向 |
|------------|------|
| 仪式前回答 | 微缩文字出现在物件表面（如信纸边缘的小字） |
| 仪式后回答 | 铭刻在花园物件的底座/标签上 |
| 不输入 | 物件仅有日期 + 情绪标签铭刻 |

### 3.7 告别日历

| 视图 | 内容 |
|------|------|
| **时间线** | 按日期降序排列，每项显示：日期 + 情绪 + 仪式 + 蜕变后缩略图 + 一句话摘要 |
| **月度概览** | 当月释放数量 + 情绪分布圆环 |
| **情绪变迁** | 折线图展示情绪标签随月份的变化趋势 |
| **仪式偏好** | 各仪式使用次数柱状图 |
| **周年提示** | 在花园内显示"一年前的今天，你放下了..."（不推送通知） |

**隐私保护：** 日历只展示用户写的那句话摘要（≤ 20 字），不展示原始详细内容。

## 四、用户流程

```
首次使用：

  [欢迎页] → 极简白底 + 一句文案 + [开始] 按钮
     ↓
  [回忆入口] → 输入文字 / 上传照片 / 录制语音 → 选情绪标签（可选）
     ↓
  [具象化] → 输入内容自动生成物件（全屏展示 3s）
     ↓
  [仪式前 prompt]（可选弹出）
     ↓
  [仪式选择] → 5 种仪式平铺预览 → 点击选择
     ↓
  [仪式全屏] → 沉浸式交互 → 完成粉碎
     ↓
  [蜕变动画] → 碎片重组为新形态（3-5s 慢速动画）
     ↓
  [仪式后 prompt]（可选弹出）
     ↓
  [花园入口] → 新物件出现在对应区域 + 引导提示
     ↓
  [继续释放] / [逛逛花园] / [离开]

日常使用：

  [开门直达花园] → 漫步 / 点击物件 / 查看日历 / 查看统计
     ↓
  点击 [+ 新的告别] → 进入回忆入口
```

## 五、边界声明

| 不做 | 原因 |
|------|------|
| 心理治疗替代 | 不是专业心理咨询工具，不提供诊断、治疗或危机干预 |
| 数据上传 / 云端同步 | 所有数据只存在于浏览器 localStorage |
| 社交 / 分享 / 排行榜 | 回忆是私密的，不分享、不排名、不公开 |
| AI 编造"更好的版本" | 不修改、不美化用户的记忆内容 |
| 主动推送 / 每日签到 | 无推送通知、无签到奖励、无连续天数要求 |
| 付费 / 订阅 / 内购 | 完全免费，无付费墙 |
| 广告插入 | 仪式过程中不出现任何广告 |
| 记忆分析推断 | 不做"你的性格分析"或"心理状态评估" |
| 自动删除 / 清理 | 数据只在用户手动操作时才被清除 |
| 未满 12 岁使用 | 涉及情绪处理，建议 12 岁以上 |

## 六、配置示例

### 配置一：失恋告别

| 项目 | 值 |
|------|-----|
| 回忆类型 | 一段关系的结束 |
| 典型输入 | "三年前我们在车站最后一次见面，那天的阳光很好，但我没回头。" |
| 情绪标签 | 怀念 → 释然 |
| 推荐仪式 | 第一次：焚烧（仪式感的终结）；过段时间：飘散（真正放手） |
| 使用时段 | 睡前，独处时 |
| 预期效果 | 承认它存在过，然后继续走 |

### 配置二：遗憾小石

| 项目 | 值 |
|------|-----|
| 回忆类型 | 没做成的事、说错的话 |
| 典型输入 | "那次面试我太紧张了。准备了好久，但临场大脑一片空白。" |
| 情绪标签 | 遗憾 |
| 推荐仪式 | 溶解（让遗憾慢慢化开）→ 埋葬（埋进土里长出新的） |
| 使用时段 | 周末下午 |
| 预期效果 | 从"如果当初"的循环里走出来 |

### 配置三：阶段翻篇

| 项目 | 值 |
|------|-----|
| 回忆类型 | 毕业 / 离职 / 搬家 |
| 典型输入 | "在 602 住了四年，钥匙还掉的那一刻，才真的觉得结束了。" |
| 情绪标签 | 怀念 |
| 推荐仪式 | 撕碎（干脆地结束这一页）→ 折纸心（把好的部分留下） |
| 使用时段 | 收拾东西时 / 最后一天 |
| 预期效果 | 有仪式感地翻篇，而不是默默消失 |

## 七、开发优先级

### 第一周 —— 核心循环

- 欢迎页 + 回忆入口（文字输入 + 情绪标签）
- 具象化引擎（3 种物件：旧照片 / 手写信 / 千纸鹤）
- 撕碎仪式（拖拽撕裂交互 + 碎片物理模拟）
- 蜕变动画（碎纸 → 折纸心，贝塞尔曲线粒子）
- 回忆花园基础框架（网格布局）

### 第二周 —— 仪式丰富

- 焚烧仪式（火焰粒子 + 燃烧路径 + 灰烬系统）
- 溶解仪式（水面涟漪 + 墨色晕散 + 透明渐变）
- 埋葬仪式（土壤覆盖 + 破土嫩芽动画）
- 对应蜕变：星辰 / 莲花 / 嫩芽
- 仪式选择预览界面

### 第三周 —— 体验打磨

- 飘散仪式（光点粒子 + 风场模拟 + 吹气交互）

## 八、落地原则

**三条核心原则：**

1. **用户主动，系统被动**
   - 系统永远不会主动问"你有什么放不下的？"
   - 用户走进来、开口说、动手做，每一步都是自愿的
   - 不做"猜你想忘掉什么"的推荐

2. **不摧毁，只蜕变**
   - 回忆不是被"消灭"，而是被转化
   - 原始内容不可逆，但用户能看到它变成了什么
   - 花园里的每一件东西都来自一段真实的过去

3. **仪式感大于功能**
   - 交互节奏要慢，不能"点一下完事"
   - 每个仪式有开头 → 过程 → 结尾的完整节奏
   - 视觉与声音共同营造"这是一件重要的事"的氛围
