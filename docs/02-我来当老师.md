# 我来当老师 — 产品功能说明书

> **教是最好的学。** 费曼学习法的最后一公里。用户当老师，虚拟学生当听众，通过教学来巩固知识、暴露盲区。

---

## 一、核心理念

费曼学习法的四个步骤：

1. 选择一个概念
2. 把它教给别人（**本产品核心**）
3. 发现解释不清的地方，回去复习
4. 简化比喻，再次输出

我来当老师 承载的是第 2-3 步：用户真正开口讲，虚拟学生用不同角度提问，逼用户把知识讲透。讲不清楚的地方就是盲区，课后精准复盘。

---

## 二、目标用户

| 用户类型 | 典型场景 |
|---------|---------|
| 学生/备考人群 | 学完一章后，讲课给自己听，检验是否真懂 |
| 职场人 | 技术分享、方案汇报前演练，用虚拟学生模拟真实提问 |
| 知识创作者 | 验证自己对某个领域的理解是否成体系、无漏洞 |

## 四、课堂教学模式

### 模式一：自由课堂（Free Mode）

- 用户点"开始上课"→ 录音开始 → 直接对着麦克风讲课
- 讲到自然段落时停顿超过阈值（~2s），系统触发一轮学生提问
- **从全班中随机抽取一名学生**发言
- 用户回答后继续讲，循环
- 适合：快速梳理思路、口头复述

### 模式二：分阶段提问（Staged Mode）

- 进入前设定知识点列表（如"TCP 三次握手、四次挥手、滑动窗口"）
- 用户逐个知识点讲课
- 讲完一个知识点后，触发一轮提问
- 全部知识点讲完 → 进入自由 Q&A 环节
- 适合：系统性过一遍知识体系

### 模式三：课件驱动（Outline Mode）

- 用户上传/输入大纲（Markdown 格式）
- 虚拟学生"预习"大纲，上课时按大纲结构推进
- 用户在每个章节下讲课，学生针对性提问
- 适合：已有笔记 / PPT 内容，按自己结构输出

## 五、学生系统

### 基础角色模板

| 学生 | 人设 | 提问风格 | 课堂作用 |
|------|------|---------|---------|
| 🧒 小白 | 零基础，好奇宝宝 | "这个是什么意思？""为什么重要？" | 逼用户用最简单的话解释 |
| 🤔 杠精 | 爱挑刺，要求严格 | "你确定吗？""这里有个漏洞？" | 逼用户严谨，不留模糊地带 |
| 🎓 学霸 | 知识渊博，喜欢深挖 | "背后的原理是什么？""那 X 和 Y 的关系是？" | 推用户到知识边界 |
| 💡 举一反三 | 联想力强 | "这个在场景 Y 也能用吗？" | 帮用户建立知识迁移 |

### 可调节项
- **开关** — 选择哪些学生参与课堂
- **数量** — 同类型可添加多人，学生总数不设上限
- **力度** — 如杠精从"温和质疑"到"猛烈抨击"可调
- **知识水平** — 小白的起点水平可调（纯零基础 / 略懂皮毛）
- **自定义角色** — 用户可创建全新学生（名字 + 头像 + 提问风格）

### 发言规则
- 轮到学生发言时，**从全班中随机抽取**（非固定轮询），增加课堂不确定性
- 被抽到的学生座位/头像高亮，并播放提示音
- 学生提问结束后，自动回到用户讲课状态

## 六、课后产出

### 1. 课堂回放
- 完整音频记录 + 同步文字转录
- 可回放、可跳转、可搜索

### 2. 知识盲区清单（三种视图）

| 视图 | 形式 |
|------|------|
| 列表式 | 逐条列出未讲清的知识点，附带原文引用 |
| 对比式 | "你的回答" vs "准确解释" 并列对比，直观看到差距 |
| 学习路径式 | 盲区按依赖关系组织成知识图谱，标注学习顺序 |

盲区的判断来源：
- 用户说"跳过"/"不知道"的知识点
- 学生追问后用户回答含糊、卡顿、回避
- 逻辑前后矛盾或跳跃的部分

## 七、用户流程总览

```
[启动应用]
    ↓
[选择教学模式] — 自由 / 分阶段 / 课件驱动
    ↓
[编排学生阵容] — 增减学生、调整个性、排座位
    ↓
[开始上课]
    ├─ 用户讲课（录音）
    ├─ 停顿 → 随机抽取学生提问
    └─ 循环直到下课
    ↓
[下课]
    ├─ 课堂回放（音频 + 文字）
    └─ 知识盲区清单（三种视图）
```

## 八、交互细节

- **被问住了怎么办？** 用户可以说"这个我不知道"或"跳过"——学生不会再追问，该知识点自动标记到盲区清单
- **课堂不尴尬**：跳过是产品设计的一环，不是失败
- **节奏控制**：课堂由用户主导，虚拟学生是被动响应方，不抢话、不跑题

---

## 九、产品边界与原则

- **不做**：题库、自动化评分、多人协作课堂
- **聚焦**：一个人讲课 → 虚拟学生提问 → 识别盲区的闭环
