# 验厂 — 产品功能说明书

## 一句话定义

offer 到手不算数，先像买方验厂那样把这公司翻一遍——验出七条硬红线、四张核查表、一份能签字的报告，然后去、谈、或者走。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：手里握着一个 offer，答复期限还剩 4 天的 25-38 岁职场人**

| 维度 | 描述 |
|------|------|
| 身份 | 3-10 年经验的工程师、产品、运营、销售，正在或准备跳槽 |
| 场景 | offer 已到手，HR 在催，猎头在催，家里人每天问一句"定了吗" |
| 决策窗口 | 名义上 3-7 天，真正用于核查的时间不到 4 小时 |
| 已试过的方案 | 脉脉搜公司名、看准网刷评价、知乎搜"XX 公司值得去吗"、拉前同事打听、让猎头"内部问问" |
| 试过的结果 | 越查越乱——有人说神仙公司有人说是坑，各有各的道理，最后靠感觉拍板 |
| 真实期待 | 不是要一个"好公司排行榜"，是"这家公司有哪些我扛不住的东西，我能不能扛" |
| 付费意愿 | 一次错误跳槽的代价是 6-12 个月，愿意为"少踩一次"付两百 |

典型用户不是求职小白。恰恰相反，他面试表现好、判断力也不差。他的困境是三件事同时发生：

1. **判断时间被压缩到几天**——面试准备了三个月，决策只给四天；
2. **手上的信息全是卖方提供的**——HR、面试官、猎头，三个信源全都有成交动机；
3. **没有人替他把"事实"和"感觉"分开**——他能记住的所有细节，都带着面试当天的情绪。

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 所有信息都来自卖方，没有一个中立信源，而人一旦手握 offer 就会本能地停止搜索 |
| **刚需** | 判断窗口只有 3-7 天，来不及做系统核查，只能凭零散印象拍板 |
| **刚需** | 匿名评价互相矛盾且不可验证，无法判断哪一条该信、哪一条是泄愤 |
| **刚需** | 不知道这个岗位是怎么空出来的——是新增编制，还是连续三个人都干不下去 |
| **改善型** | 不知道公司近三年的裁员史、降薪史、社保缴纳基数 |
| **改善型** | 不知道怎么把"半年后调薪"这类口头承诺变成可执行的东西 |
| **改善型** | 担心问太多显得不信任公司，反而把 offer 问没了 |
| **猎奇伪需求** | 想要一份"公司红黑榜"——榜单会被公关，且对个体没有意义 |
| **猎奇伪需求** | 想让 AI 直接替他决定去不去——重大决策不能外包，也不该外包 |

关键区分：**这款产品不回答"这家公司好不好"，只回答"这家公司有哪些你扛不住的东西"。**

同一家公司，对 A 是坑，对 B 是跳板。差别不在公司，在 A 和 B 各自能承受什么、各自要拿这份工作换什么。所以产品输出的从来不是评分榜，是一份**风险敞口清单**——把公司的事实摆出来，由用户自己认领哪几条不能接受。

## 二、解决方案与核心功能

### 2.1 解决方案概述

四步：**立案 → 验四表 → 扫红线 → 出结论。**

先把口头 offer 落成 8 个结构化字段，让"我到底拿到了什么"第一次变得可读；再按主体表、钱袋表、岗位表、人链表四路核查，把每条结论挂上信源等级；然后过七条一票否决的红线；最后输出一页纸，结论必须三选一：**去 / 谈条件再去 / 不去**。

两条不可妥协的规则，决定了整个产品的形状：

> **规则一：报告只陈述事实与风险敞口，不做"好公司/坏公司"的判决。**

判决会被告，也因为判决对个体没意义。产品给的是"如果你最在意的是稳定，那么这条事实意味着什么"，而不是"这家公司不行"。

> **规则二：答复期再短，48 小时冷静闸不能省。**

拿到 offer 的第一件事既不是签约也不是拒绝，是把决定挂起 48 小时。这 48 小时里不回复、不见人、不做决定，只做核查。理由是：offer 带来的兴奋会让人只搜索支持自己的证据——确认偏误在"终于有人要我了"这个时刻达到峰值，两天足以让激素落地。

### 2.2 核心功能清单

1. **OFFER 立案** — 把口头 offer 落成 8 个字段（签约主体、岗位职级、汇报对象、薪资构成、试用期、答复期限、竞业条款、期权细节），第一次让"我拿到了什么"变成一页可读的东西
2. **48 小时冷静闸** — 立案完成即计时，答复按钮置灰两天，期间只开放查证不开放决定
3. **主体核查** — 工商、股权、司法、行政处罚四项自动拉取，识别空壳、代持、失信、劳务派遣
4. **钱袋推演** — 融资节奏、客户集中度、社保基数、裁员方式，推断这家公司还能撑多久、会不会突然降本
5. **岗位考古** — 抓同一岗位的历史招聘信息，看在挂时长、薪资区间变化、要求变化，判断是新增编制还是填不完的坑
6. **人链验证** — 给定 5 个必问对象（直属上级、同组同事、前任、协作方、离职半年以上的人）和一套只能问事实的问法
7. **硬红线扫描** — 七条一票否决项逐条核验，命中即红灯，不给"综合评估"的余地
8. **信源分级** — 每条信息按可信度打级，报告末尾给出总体置信度，低置信结论强制标"仅假设"
9. **红黄绿灯报告** — 一页纸输出：四维分数、红线结果、三条最大风险、一句结论、以及"什么情况下结论要改"
10. **谈条件清单** — 每个黄灯项自动生成可谈判项与书面化话术，把口头承诺转成条款
11. **条款转换器** — 36 条常见口头承诺 → 合同写法的对照表（调薪、主导权、加班、远程、职级、期权）
12. **岗位留任图谱** — 反查同岗位近三年历任在任时长，中位数低于 12 个月直接标高危
13. **入职 90 天回填** — 第 90 天推送 12 道题，算"当初判断准确率"，校准判据权重
14. **谈判节奏表** — 按答复期剩余天数排优先级：先查什么、先问谁、哪一天必须给答复

## 三、竞品与差异化分析

### 3.1 同类替代品对比

| 竞品 | 优点 | 缺点 | 与本产品定位差异 |
|------|------|------|----------------|
| 脉脉 / 看准网 | 样本量大，有具体到部门、领导的情绪细节 | 公司会公关删帖；发声的多是极端体验者；无法验证；时效性差 | 本产品只把匿名帖当"线索源"，不当"证据源"——看到"拖欠工资"，动作是去查仲裁案件 |
| 天眼查 / 企查查 | 工商司法数据权威、更新及时 | 只给数据不给判据，看完一堆信息仍然不知道该不该去 | 本产品把数据接到"你的风险敞口"上，每个数字都对应一条可承受性判断 |
| 猎头 | 知道岗位内情，甚至知道前任为什么走 | 成交才收费，利益与用户严格相反；他会告诉你"这机会很难得" | 本产品不成交、不返佣、不做内推，收益只来自用户的付费 |
| 知乎 / 小红书测评 | 有长篇细节，能读出氛围 | 写的人多是极端体验者，中间 80% 的普通员工不发声 | 本产品用结构化问法去取那沉默的 80% 的说法 |
| OfferShow / 薪资爆料 | 薪资样本多，能校准报价 | 只看钱，不看公司质量、岗位稳定性、上级水平 | 本产品把薪资放进"总包风险"里算，而不是单独看数字 |
| 职业规划师 / 求职辅导 | 能给具体建议，有人情味 | 靠个人经验，不可复核；常与培训机构绑定，有卖课动机 | 本产品每条结论可回溯到具体事实与权重，可被用户复核 |
| 通用 AI 助手 | 能快速总结公开信息 | 把匿名帖当事实；最后必然落到"看你自己"，等于没答 | 本产品强制信源分级，且必须给三选一结论 |

### 3.2 差异化优势与护城河

**核心差异：别的工具告诉你"这家公司怎么样"，本产品告诉你"这家公司有哪些你扛不住的东西"。**

这不是话术差别，是产品结构的差别。前者需要一个"客观好坏"标准，而那个标准不存在；后者只需要用户自己回答一个问题："这七条里，哪几条我受不了？"

第二个差异是**敢给结论**。几乎所有求职类工具最后都落到"这要看你自己"，因为给结论要担责。本产品必须三选一，并且要写明"什么情况下结论会翻转"。敢下判断，是用户愿意付费的直接原因。

诚实评估护城河：**中等偏浅，但有两处会随时间变深。**

容易被抄的部分：四表模板、七条红线、36 条条款对照、报告版式。任何做过 HR SaaS 的团队两个月能复刻一遍。

难抄的两处：

1. **岗位留任图谱**——需要持续抓取同一公司同一岗位的历史招聘信息，并交叉验证历任在任时长。这个数据以年为单位积累，且越用越准，后来者从零开始就要等三年。
2. **判据校准库**——每一份 90 天回填都在修正"哪条信号真的预测了崩塌"。三年后这套权重表是别人拿不到的样本，也是产品唯一的复利来源。

还有一层不那么显性但更值钱的：**只陈述事实、不下判决的表达体系**。它决定了这类产品能不能活过第一封律师函——这件事抄不走，因为抄的人通常第一年就被起诉了。

## 五、核心模块详解

### 5.1 OFFER 立案与 48 小时闸

**职责**：把一份口头 offer 变成 8 个可核查的字段，并把决定推迟两天。

| 字段 | 为什么必须填 | 常见陷阱 |
|------|-------------|---------|
| 签约主体 | 决定你的合同相对方、社保缴纳地、仲裁管辖地 | 面试在 A 座写字楼，合同签的是 B 公司（子公司 / 劳务派遣 / 外包） |
| 岗位与职级 | 决定你在内部的实际权限和对外title | 口头说"总监"，合同写"高级经理"；职级代码缺失 |
| 汇报对象 | 决定你每天和谁打交道，以及谁决定你的绩效 | 只写"向老板汇报"——可能意味着没有中层，你直接面对最大压力源 |
| 薪资构成 | 决定实际到手与未来调薪基数 | 总包 40 万，其中 12 万标着"绩效，视公司效益发放" |
| 试用期 | 决定前 3-6 个月的风险敞口 | 6 个月试用 + 80% 薪资 + 试用期不缴社保 |
| 答复期限 | 决定你有多少核查时间 | "明天中午前必须回复"——多数情况下是可以谈的 |
| 竞业条款 | 决定你离开时能不能带走这三年 | 竞业范围写"整个互联网行业"，补偿金按最低工资 |
| 期权 / 股权 | 决定你是不是在为一个无法兑现的数字打工 | 行权价、成熟期、回购条款、加速条款四项缺任何一项 |

**48 小时闸的机制**：立案完成即开始计时，答复按钮置灰。

| 参数 | 规则 |
|------|------|
| 时长 | 48 小时，不可跳过，不可缩短 |
| 期间可做 | 查证、提问、约人聊、读合同 |
| 期间不可做 | 回复 HR、签字、口头承诺、向家人宣布决定 |
| 提前解锁 | 只有一种情况：命中硬红线（此时不需要再想，直接进入拒绝流程） |
| 到期提示 | 推送一句："两天前你很想签，现在还一样想吗？" |

设计依据：拿到 offer 的 24 小时内，人处在"被选中"的兴奋里，此时搜索信息的目的是自我确认，不是自我证伪。48 小时足以让情绪落地，也刚好在多数公司可以接受的延期范围内。

### 5.2 主体核查

**职责**：先确认你要签的那家公司，真实存在且真实在经营。

| 核查项 | 看什么 | 危险信号 | 处理 |
|--------|--------|---------|------|
| 工商主体 | 成立年限、注册资本实缴比例、经营范围、参保人数 | 认缴 1000 万实缴 0；号称 300 人但参保 12 人 | 与 offer 宣称的规模逐项对照 |
| 股权结构 | 大股东变更频率、股权质押、代持痕迹、外资/VIE 架构 | 近两年大股东换了三次；全部股权已质押 | 标黄，追问变更原因 |
| 司法风险 | 被执行人、失信记录、劳动争议案件数与年份分布 | 近两年劳动争议案件数量陡增 | 高概率对应欠薪或裁员纠纷 |
| 行政处罚 | 行业处罚、税务、环保、消防 | 主营业务被处罚后仍在继续经营 | 直接转入红线第 4 条 |
| 融资 / 上市 | 最后一轮时间、金额、投资方、是否 down round | 超过 24 个月无新融资且未盈利 | 转入钱袋推演算现金跑道 |

**劳动争议案件的年份分布，是全系统最强的单一信号。** 一家公司三年前有 2 起劳动纠纷是正常的；今年突然出现 11 起，且集中在同一个季度——这比任何一条匿名评价都准确。

### 5.3 钱袋推演

**职责**：回答一个具体问题——这家公司会不会在我入职一年内突然降本。

| 指标 | 怎么算 | 意味着什么 |
|------|--------|-----------|
| 现金跑道 | （最近一轮融资额 + 已知年营收）÷ 月均人力成本 | 少于 9 个月 = 高危，你入职即可能赶上第一轮优化 |
| 融资间隔 | 距上一轮融资的月数 | 超过 24 个月且未盈利 = 现金紧张，正在靠营收硬扛 |
| 客户集中度 | 前五大客户营收占比 | 超过 60% = 丢一个大客户就要裁一轮 |
| 社保基数 | 实际缴纳基数 ÷ 实际工资 | 低于 60% = 在压人力成本；且你的经济补偿金按低基数算 |
| 应收周转 | 应收账款 ÷ 月均营收 | 天数变长 = 回款变差，工资可能开始延后 |
| 裁员史 | 近三年是否裁过、怎么裁的 | 用 N+1 还是变相逼退，决定了这家公司的底线在哪里 |

**最后一项权重最高。** 判断一家公司怎么对待人，不要看它怎么说文化，看它上一次裁员怎么裁的——是当天给 N+1 送人走，还是把人调到边缘岗位逼着自离。这个选择没有中间地带。

### 5.4 岗位考古

**职责**：搞清楚这个位置是怎么空出来的，以及它曾经空过几次。

核心方法：把同一公司同一岗位的历史招聘信息拉成时间轴。

| 信号 | 怎么读 | 判定 |
|------|--------|------|
| JD 在挂时长 | 这个岗位挂了多久 | 超过 6 个月持续在挂 = 要么流动性极大，要么根本没编制（在收集简历） |
| 薪资区间变化 | 同一岗位历史区间对比 | 区间下调 = 在压成本；区间上调 = 招不到人，标准有问题 |
| 要求变化 | 职责描述是否反复修改 | 一年改三版 = 内部对这个岗位没想清楚，你进去要替他们想 |
| 前任在任时长 | 反查历任在岗时间 | 中位数 < 12 个月 = 高危；< 6 个月 = 红灯 |
| 编制归属 | 正式 HC / 项目制 / 外包 | 项目制 = 项目结束你就结束 |
| 空缺原因 | 新增 / 补缺 / 前任离职 | 补缺必须追问：前任为什么走、去了哪 |

**现场追问话术（只能这样问）**：

> "这个岗位是新增编制，还是补缺？如果是补缺，上一任在这里做了多久、现在在做什么？"

这个问题问完，对方的停顿长度就是答案。回答流畅且给出具体人名去向的，通常没问题；开始讲"他个人原因""家里有事"的，基本可以标黄。

### 5.5 人链验证

**职责**：用五个必问对象，把"公司氛围"这类形容词换成可核对的事实。

| 对象 | 怎么找到 | 只能问这些（问事实，不问评价） |
|------|---------|------------------------------|
| 直属上级 | 面试时直接索取："能安排我和未来的直属上级聊 20 分钟吗" | 这个岗位过去两年换过几个人 / 上一任现在在做什么 / 团队今年的目标是什么、现在完成到几成 |
| 同组同事（非面试官） | 要求"和未来同事聊聊"，指定非面试流程内的人 | 你上周最晚几点走 / 你这个季度的绩效目标是什么 / 你入职时团队几个人，现在几个人 |
| 前任 | 招聘平台与职场社交反查 | 你离开的真实原因是什么 / 你走的时候这个岗位交接给了谁 |
| 协作方（跨部门） | 面试流程中通常能遇到 | 和他们部门合作最常卡在哪个环节 / 他们的需求平均多久能排上 |
| 离职半年以上的人 | 前同事网络 | 你走之后公司有哪些变化 / 如果再来一次你还会去吗（仅作参考，不作证据） |

**整个产品的枢纽是这一句话：不问评价，只问事实。**

问"公司文化怎么样"，得到的是形容词，而形容词无法核验。问"你上周最晚几点走"，得到的是数据。四个数据点凑起来，比二十条匿名评价更接近真相。

### 5.6 硬红线扫描

**职责**：用七条开关，把"综合评估"这种和稀泥的做法彻底堵死。

| # | 红线 | 核验方法 |
|---|------|---------|
| 1 | 近 12 个月有欠薪或延迟发薪 | 问 2 个在职者 + 查劳动争议案件的时间分布 |
| 2 | 社保公积金未按实际工资缴纳，且拒绝写入合同 | 直接问 HR 要缴纳基数，看是否愿意写进 offer 或补充协议 |
| 3 | 公司或实际控制人有未履行的失信被执行记录 | 查司法信息 + 裁判文书网 |
| 4 | 主营业务在无牌照或已被处罚的状态下继续经营 | 查行政处罚记录 + 对照经营范围 |
| 5 | 签约主体与实际用工主体不一致且无法合理解释 | 对照合同主体、办公地点、汇报线三者 |
| 6 | 试用期超过法定上限，或试用期不缴社保 | 对照劳动合同法第十九条逐字核 |
| 7 | 要求签空白合同、阴阳合同、自愿放弃社保承诺书 | 现场逐条读合同文本，不接受"这个就是标准模板" |

命中任意一条 → 报告直接判定红灯，**不进入四维评分**。

设计依据：**红线不是加权项，是开关。** 一旦允许加权，"月薪多给 8000"就能把"拖欠工资"抵消掉。但现实里这两件事从不对冲——欠薪造成的伤害，不会被高薪补偿，只会被掩盖。

### 5.7 信源分级与置信度

**职责**：让报告上的每一条结论都能被追问"你凭什么这么说"。

七级阶梯，从高到低：

| 级 | 信源 | 权重 | 能否计入评分 |
|----|------|------|-------------|
| 1 | 你自己看到的事实（工商、司法、财报、合同文本、办公现场） | 1.0 | 是 |
| 2 | 在职且无利益关系的人（非同部门、非 HR、非招聘官） | 0.9 | 是 |
| 3 | 已离职超过 6 个月的人 | 0.8 | 是 |
| 4 | 公开可验证数据（JD 历史、招投标、专利、行政处罚） | 0.7 | 是 |
| 5 | 匿名社区（脉脉、看准、知乎） | — | 否，只生成假设 |
| 6 | 面试官与 HR 的说法 | — | 否，这是卖方陈述 |
| 7 | 你自己的直觉 | — | 否，可记录不可计分 |

**置信度 = 高权重证据条数 ÷ 结论依赖的总条数**

| 置信度 | 区间 | 报告处理 |
|--------|------|---------|
| 高 | ≥ 70% | 结论可直接执行 |
| 中 | 40-70% | 结论附"建议补证项" |
| 低 | < 40% | 全部结论标"仅假设，补证后重算" |

**核心规则：匿名帖只能告诉你"去查什么"，不能告诉你"结论是什么"。**

看到"这家公司拖欠工资"，正确动作是去查仲裁案件的时间分布、去问两个在职者；错误动作是把"欠薪"两个字直接抄进报告。前者是调查，后者是转述谣言——而绝大多数求职判断，就死在把线索当结论这一步。

### 5.8 红黄绿灯报告

**职责**：一页纸，三个选项，一句结论。

报告固定六个区块：

1. **你拿到了什么** — 8 个立案字段的摘要，一眼看清合同实质
2. **四维分数** — 生存、稳定、增值、环境，各 0-5 分，必须标出最低的那一维
3. **红线结果** — 七条逐条标"通过 / 命中 / 无法核验"
4. **三条最大风险** — 按「发生概率 × 你承受不了的程度」排序，只给三条
5. **结论** — 去 / 谈条件再去 / 不去，三选一，禁止"看你自己"
6. **翻转条件** — "如果 X 变成 Y，结论要改"

**四维评分的权重规则**：

| 维度 | 是否可调 | 说明 |
|------|---------|------|
| 生存分 | **不可调低** | 公司能不能活下去，不由用户偏好决定 |
| 稳定分 | **不可调低** | 岗位会不会消失，同上 |
| 增值分 | 用户自定 | 有人要成长，有人要稳定，权重自己给 |
| 环境分 | 用户自定 | 有人能扛高压，有人不能，权重自己给 |

这条规则是产品的价值观落点：**客观的东西不许改，主观的权重自己定。** 它同时解决了"值不值得太主观没法标准化"这个难题，和"产品凭什么替我定义好工作"这个伦理问题。

评分不看总分，只看短板。任一维 ≤ 1 分，结论不得为"去"。

### 5.9 谈条件清单与条款转换器

**职责**：把黄灯变成可谈判项——绝大多数 offer 的问题不是"去不去"，是"怎么谈"。

| 黄灯项 | 可谈判项 | 必须书面化到什么程度 |
|--------|---------|---------------------|
| 薪资低于预期 | 签字费 / 入职 6 个月调薪评估 | offer letter 里写明"调薪评估时间与幅度下限" |
| 职级模糊 | 职级代码与汇报对象姓名 | 合同或附件写明职级与汇报人 |
| 试用期 6 个月 | 缩短至 3 个月 / 试用期 100% 薪资 | 写进合同试用期条款 |
| 加班无规则 | 调休规则、加班认定标准 | 写进员工手册并索取该页复印件 |
| 期权无细节 | 行权价、成熟期、回购条款、加速条款 | 要求看期权协议全文后再签 |
| 汇报线不清 | 双线汇报时明确主汇报人 | 邮件确认并保存 |
| 远程 / 弹性口头承诺 | 每周远程天数 | 写进 offer 或补充协议 |

**话术原则：不说"我不信任你们"，说"我想把我们的约定写清楚，避免以后理解不一致"。** 同一件事，前者是质疑，后者是专业。而愿意把这些写下来的公司，本身就是一条正向信号。

条款转换器（36 条对照表节选）：

| 口头承诺 | 可执行的写法 |
|---------|-------------|
| "半年后给你调薪" | "双方同意于 2027 年 1 月 31 日前完成薪资评估，调整幅度不低于 10%" |
| "这个项目你主导" | "负责 XX 项目，对项目范围、排期与人员配置有决定权，直接向 CTO 汇报" |
| "我们不怎么加班" | "工作日 19:00 后及周末加班按 1:1 调休，当季度内使用" |
| "做得好的话会有期权" | "授予 X 股期权，行权价 Y，四年成熟，满一年后按月成熟，离职后 90 天内可行权" |
| "试用期表现好可以提前转正" | "试用期 3 个月，考核通过后次月转正，试用期薪资为转正后的 100%" |

### 5.10 入职 90 天回填

**职责**：让这套判据在三年后真的准，而不是永远停在第一版。

第 90 天推送 12 道题，3 分钟填完：

- 报告里判断"会加班"，实际加了吗
- 报告里标黄的三条风险，哪几条真的发生了
- 当时以为最不重要的那一维，现在觉得重要吗
- 如果重新选一次，还会去吗

回填奖励：解锁一次免费核验额度。

**回填率是这个产品的生命线。** 没有回填，所有判据都只是"看起来有道理"的猜测，和匿名评价没有本质区别；有回填，三年后这套权重表就是别人拿不到的东西。

## 六、用户流程

```
拿到 offer（答复期 3-7 天）
  │
  ├─ ① 立案：填 8 个字段 + 传 offer 文本 → 生成一页"我拿到了什么"
  │        └─ 签约主体与办公地不一致 → 立即标黄，追问原因
  │
  ├─ ② 48 小时闸门关闭：答复按钮置灰，只开放查证
  │        └─ 命中硬红线 → 提前解锁，直接进入拒绝流程
  │
  ├─ ③ 自动核查（4 小时内出初稿）
  │        ├─ 主体核查：工商 / 股权 / 司法 / 参保 / 处罚
  │        ├─ 岗位考古：JD 历史 / 在挂时长 / 薪资区间变化
  │        └─ 钱袋推演：融资节奏 / 客户集中 / 裁员方式
  │
  ├─ ④ 人链验证（48 小时内完成至少 3 个必问对象）
  │        └─ 只拿到形容词、没拿到事实 → 该项标"未验证"
  │
  ├─ ⑤ 硬红线扫描 → 命中任一 → 直接出红灯报告，流程终止
  │
  ├─ ⑥ 四维打分 + 用户给主观权重（生存/稳定不可调低）
  │        └─ 任一维 ≤1 分 → 结论不得为"去"
  │
  ├─ ⑦ 出报告：去 / 谈条件再去 / 不去
  │
  ├─ ⑧ 黄灯 → 生成谈条件清单 + 话术 → 按剩余天数排谈判顺序
  │        └─ 对方拒绝一切书面化 → 该项从黄灯降为红灯
  │
  └─ ⑨ 答复 → 入职

入职后（第 90 天）
  │
  ├─ 12 道回填题 → 计算"当初判断准确率"
  ├─ 偏差记入个人校准档案 → 下次核验时前置提示
  └─ 解锁一次免费核验额度
```

## 七、商业模式

### 7.1 定价区间

**单次核验 199 元；年费 399 元（3 次核验 + 谈条件陪跑 + 回填解锁）。**

定价依据不是成本，是替代参照：一次错误跳槽的显性成本是 3-6 个月工资（试用期被辞、快速再跳、空窗期），隐性成本是 6-12 个月的职业节奏。199 元是"少踩一次坑"的价格，不是"信息服务"的价格。

**不做免费版。** 这个产品一半的质量来自人链验证——免费用户不会真的去约前任聊 20 分钟，跳过这一步的报告等于一份包装精美的天眼查截图，用了没效果反而砸口碑。

### 7.2 销售渠道

- **脱敏报告样本传播**：只发一种内容——"我查了给我 offer 的这家公司，发现三件 HR 没提的事"。具体的事实清单比任何方法论都好传。
- **时间节点投放**：金三银四、秋招、年底绩效季。这三个窗口的用户密度是平时的五倍，且都处在同样的决策焦虑里。
- **不做信息流投放**。这类决策靠"身边人踩过坑"传播，投放拉来的是围观者，不是付费者。

### 7.3 盈利模式

| 收入 | 说明 |
|------|------|
| 单次核验 | 主收入，199 元一份完整报告 |
| 年费订阅 | 399 元，3 次核验 + 谈条件陪跑 + 回填解锁 |
| 条款对照库 | 免费公开，作为获客资产和信任背书 |
| **不做** | 不做猎头返佣、不做企业招聘服务、不做"内推" |

最后一条是商业模式的底线：**一旦从企业端收钱，"帮你判断该不该去"就必然变成"帮你判断该去哪家客户"。** 这个利益冲突没有中间状态。

## 八、落地路径

### 8.1 五大落地难点

| 难点 | 具体表现 | 应对 |
|------|---------|------|
| 数据获取难 | 工商 API 收费、JD 历史难抓、参保人数经常缺失 | MVP 只做免费可查的四项；JD 历史先靠用户传截图，第二版再做自动化 |
| 决策窗口太短 | 用户只有 3-7 天，没有耐心填 40 个字段 | 立案压到 8 个字段、6 分钟；自动核查 4 小时出初稿 |
| 标准化难 | "值不值得"因人而异，打不出统一的分数 | 客观两维不可调，主观两维由用户给权重 |
| 合规风险 | 说某公司"别去"可能被告商业诋毁 | 只陈述可核验事实 + 用户自己的权重；不下定性判决；每条结论附信源等级 |
| 回填率低 | 入职后没人愿意回来填，校准库永远是空的 | 回填解锁免费额度；只发 12 题、3 分钟做完；不追问、不推销 |

第四条是这类产品真正的生死线。一条可行的表达纪律：报告里绝不出现"这家公司不行""不建议去"这类句子，只出现"以下事实与你的权重对照后，结论是……"。把判决权留在用户手里，产品只负责把事实摆整齐。

### 8.2 MVP 最小可行产品

**只做两表一扫描：主体表 + 岗位考古 + 七条红线。**

砍掉：钱袋推演（需要财务数据，公开渠道算不准）、人链验证（需要人工陪跑）、条款转换器、90 天回填。

保留：8 字段立案 + 48 小时闸 + 主体核查（工商/司法免费可查）+ JD 在挂时长判断 + 七条红线 + 一页报告。

形态可以只是一个网页加一份 PDF 报告。验证周期 4 周，一个人力。

### 8.3 第一步验证

**最关键假设**：入职后发现的坑，有相当比例是"当初查一下就能发现"的。

**验证方法**：找 30 个最近 6 个月内入职新公司的人做回溯访谈，只问一个问题——

> "入职后你发现了哪些当初不知道、但入职前其实能查到的事？"

不问"你需要这个产品吗"，只统计有多少条坑本来是可以避开的。

**通过标准**：

- 30 人里 **≥18 人（60%）** 能说出至少一条"可查未查"的关键信息
- 其中 **≥10 条** 能归入四张表的某一项（说明四表结构确实覆盖了主要风险）
- 让 10 个正在拿 offer 的人付 99 元做一次，**≥6 人**因此改变了决定或谈判条件

低于 60%：说明大部分坑是不可预知的，产品命题要重做——从"入职前尽调"改为"入职后 90 天止损"。这是两条完全不同的路，越早分清越好。

## 九、风险与预期反馈

### 9.1 预期负面吐槽

| 吐槽 | 背后的真实问题 | 应对 |
|------|--------------|------|
| "这些东西我根本查不到" | 数据可得性是最大质疑 | 报告每项标"已查证 / 未查证 / 无法查证"，未查证的给出具体查法 |
| "太麻烦了，我就想签" | 决策疲劳，且已经做了三个月功课 | 立案只有 8 个字段 6 分钟，其余全自动；重活留给系统 |
| "去问同事会不会显得我不信任公司" | 社交顾虑，怕影响 offer | 提供专业问法脚本，把质疑包装成对工作的关心 |
| "万一是好公司，我错过了" | 损失厌恶，怕自己作没了机会 | 报告给的从来不是二选一，"谈条件再去"覆盖了大半黄灯情形 |
| "你说的这些不一定准" | 对判断本身的不信任 | 每条结论挂信源等级；报告末尾给置信度；低置信直接写明"仅假设" |
| "查完是红灯，可我还是想去" | 现实里情感和处境的因素无法消除 | 出"如果你一定要去"的次优方案：先谈条件、设 3 个月观察点、保留退路 |
| "这不就是背调吗" | 概念混淆 | 背调是企业查你，验厂是你查企业，方向完全相反 |

最后一条要讲清楚，它其实就是产品名的由来——**买方派人到工厂去看生产线，这个动作叫验厂；现在是你要把自己投进去，当然应该先去验一遍。**

## 十、边界与原则

| 不做 | 原因 |
|------|------|
| 不回答"这家公司好不好" | 同一家公司对不同人是不同答案，只回答"对你有哪几条风险" |
| 不做企业端服务 | 从企业收钱，就无法中立地评价企业 |
| 不做个人背景调查 | 那是企业的事，且涉及隐私与合规 |
| 不代理薪资谈判 | 谈判是人的事，产品只给清单和话术 |
| 不给法律意见 | 只提示"这一条建议问律师"，不出结论 |
| 不预测公司未来 | 只算现金跑道与风险敞口，不预测生死 |
| 不用匿名信息作为证据 | 匿名信息只能生成假设，不能支撑结论 |
| 不替用户做最终决定 | 结论给建议，签字的手永远是用户的 |
| 不做公司红黑榜 | 榜单必然被公关，且对个体没有意义 |
| 不因为用户坚持而改结论 | 可以给次优方案，但不能假装红灯是绿灯 |

## 十一、配置示例

### 三种典型人群的权重配置

| 参数 | 求稳型（30+，有房贷） | 求进型（25-30，无负担） | 过渡型（被动离职，急需上岸） |
|------|---------------------|----------------------|---------------------------|
| 生存分权重 | 0.35 | 0.20 | 0.30 |
| 稳定分权重 | 0.30 | 0.20 | 0.25 |
| 增值分权重 | 0.15 | 0.40 | 0.10 |
| 环境分权重 | 0.20 | 0.20 | 0.35 |
| 硬红线容忍度 | 零容忍 | 零容忍 | 零容忍 |
| 可接受试用期 | ≤ 3 个月 | ≤ 6 个月 | ≤ 3 个月 |
| 可接受加班 | 每周 ≤ 8 小时 | 每周 ≤ 15 小时 | 每周 ≤ 10 小时 |
| 现金跑道最低要求 | ≥ 18 个月 | ≥ 12 个月 | ≥ 9 个月 |
| 岗位前任在任时长 | ≥ 24 个月 | ≥ 12 个月 | ≥ 12 个月 |
| 结论倾向 | 谈条件再去 | 去 | 去，但设 3 个月止损点 |

**硬红线零容忍是唯一不可调的参数**，三种人群完全一致。这个一致性本身就是一种表达：有些底线不该因为你更需要这份工作就降低。
