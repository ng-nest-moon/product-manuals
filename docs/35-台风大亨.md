# 台风大亨 — 产品功能说明书

## 一句话定义

模拟经营游戏，玩家扮演"台风之神"，从热带扰动开始培养自己的台风，吸收能量、规划路径、登陆造风，用毁灭值解锁更强大的台风能力。

---

## 一、架构总览

```
台风养成
 ├── 命名系统 ── 自定义台风名称
 ├── 成长面板 ── 风速/气压/风圈半径/移动速度
 ├── 进化树 ── 热带扰动 → 热带风暴 → 强台风 → 超强台风
 └── 轮回传承 ── 气旋记忆传给下一代

路径地图
 ├── 海面能量区 ── 暖水区吸收能量
 ├── 陆地登陆点 ── 选择登陆地点
 └── 环境干扰 ── 季风/高压脊/地形摩擦

登陆事件
 ├── 破坏结算 ── 建筑/树木/交通损失 → 毁灭值
 ├── 连锁事件 ── 暴雨→洪水→山体滑坡
 └── 人类反应 ── 预警发布/撤离/救援

养成经济
 ├── 毁灭值商店 ── 解锁新能力/部件
 ├── 台风图鉴 ── 收集历史台风
 └── 成就系统

观众模式
 ├── 回放已生成台风路径
 └── 台风云图可视化
```

---

## 二、核心功能清单

1. **台风创造与命名** — 从热带扰动之种开始，自定义台风名称，开启养成
2. **成长养成** — 在地图海面移动吸收暖水能量，提升风速、扩大风圈、降低气压
3. **进化树** — 四级进化：热带扰动→热带风暴→强台风→超强台风，每级解锁新能力
4. **路径规划** — 分析环境因素（高压脊、季风、地形），规划最优登陆路径
5. **登陆事件链** — 登陆触发连锁事件，根据登陆点特征产生不同破坏组合
6. **毁灭值结算** — 按破坏程度奖励毁灭值，用于商店消费
7. **轮回传承** — 台风消散后气旋记忆保留，部分能力和未了心愿遗传给下一世
8. **商店系统** — 用毁灭值解锁台风部件、特殊能力、外观特效
9. **台风图鉴** — 收集各世代的台风记录，查看历史路径和能力
10. **观众模式** — 回放台风完整生命周期，生成可视化云图

## 三、核心模块详解

### 3.1 台风养成

**职责：** 管理台风的成长全生命周期，从种子到消散

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 命名系统 | 玩家自定义台风名称 | 最多 6 个中文字符或 12 个英文字符 |
| 成长面板 | 实时显示风速/气压/风圈半径/移动速度 | 数据随位置和能量摄入动态变化 |
| 进化树 | 四级进化路线 | 每级需累计能量达到阈值；超强台风需特殊条件 |
| 轮回传承 | 消散后生成台风之种 | 保留 30% 能量上限、解锁能力、未完成心愿 |

进化能量阈值：

| 等级 | 名称 | 能量阈值 | 解锁能力 |
|------|------|---------|---------|
| 1 | 热带扰动 | 0 | 基础移动 |
| 2 | 热带风暴 | 100 | 风圈扩展、命名权 |
| 3 | 强台风 | 300 | 连锁事件触发、风眼可视化 |
| 4 | 超强台风 | 600 | 双风眼、路径分支、终极技能 |

### 3.2 路径地图

**职责：** 提供世界沙盘，玩家规划台风移动路线

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 海面能量区 | 暖水区为台风供能 | 水温越高能量吸收越快；冷水区能量衰减 |
| 陆地登陆点 | 选择登陆位置 | 不同地形（平原/山地/沿海城市）破坏计算不同 |
| 环境干扰 | 自然力影响路径 | 高压脊阻挡绕行、季风加速/偏航、地形摩擦减速 |
| 路径规划 | 玩家拖拽设定移动方向 | 受环境干扰影响，非精确控制 |

### 3.3 登陆事件

**职责：** 台风登陆后的事件结算系统

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 破坏结算 | 按风速/降雨/风暴潮计算损失 | 建筑/树木/交通/农业四类分别结算 |
| 连锁事件 | 触发次生灾害 | 暴雨→洪水→山体滑坡，概率受地形和降雨量影响 |
| 人类反应 | 登陆前人类方采取行动 | 预警等级→撤离范围→救援力量，影响最终毁灭值 |
| 城市记忆 | 被登陆过的城市后续升级防御 | 下次登陆同一城市阻力更大，毁灭值更难获取 |

### 3.4 轮回传承

**职责：** 台风轮回系统的核心——气旋记忆一代传一代

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 台风之种 | 消散后生成的下一代基础 | 基础能量上限继承 30% |
| 能力遗传 | 上一世的能力部分保留 | 随机 1-2 项能力继承，其余重置 |
| 未了心愿 | 完成愿望获得额外奖励 | 心愿列表如："吹到青藏高原""穿越赤道""登陆南极" |
| 圆满消散 | 完成全部心愿后特殊结局 | 解锁世代专属皮肤、称号、特效 |
| 城市记忆传递 | 子代台风对城市的"印象"保留 | 被防御过的城市攻坚有额外策略提示 |

## 四、用户流程

```
开局：获得热带扰动之种
  │
  ├─ 命名台风
  │
  ├─ 海面养成阶段
  │   移向暖水区 → 吸收能量 → 风速提升
  │   → 进化触发（热带风暴/强台风/超强台风）
  │   遭遇环境干扰需调整路径
  │
  ├─ 路径规划阶段
  │   分析高压脊/季风/地形
  │   选择最佳登陆地点
  │
  ├─ 登陆阶段
  │   触发登陆事件链
  │   连锁次生灾害
  │   人类预警与救援
  │
  ├─ 结算阶段
  │   计算四类破坏 → 毁灭值奖励
  │   记录此世记忆与未了心愿
  │
  └─ 轮回阶段
       台风消散 → 生成台风之种
       传承能力与心愿 → 开启下一世
```

## 五、应用场景

### 场景一：新手开局——第一次当台风

用户获得第一颗种子，命名"巴威"。在引导下移向暖水区吸收能量，从热带扰动进化为热带风暴，登陆一个沿海小镇，获得第一笔毁灭值。台风消散后生成第二代种子，带着"更强"的遗传能力开始新轮回。

### 场景二：挑战极限——冲击超强台风

用户已有多个世代的积累，尝试冲击最高进化等级。需要精确规划路径，避开高压脊，在多个暖水区长时间停留蓄能。成功后解锁"双风眼"形态，登陆时触发史无前例的连锁事件链。

### 场景三：心愿收集——圆满消散

用户专注完成台风的未了心愿。此世愿望是"吹到青藏高原"——需穿越大陆，克服地形摩擦和能量衰减，在高原上完成最后的登陆。成功后此世"圆满消散"，解锁世代专属称号"高原之风"。

## 六、边界声明

| 不做 | 原因 |
|------|------|
| 严谨气象模拟 | 物理准确度让位于游戏性，不做真实气象预报类产品 |
| 写实灾难表现 | 避免真实伤亡画面，破坏结算使用卡通/数据化表达 |
| 多人对战模式 | 单人养成体验，无实时对战 |
| 移动端首发 | 路径规划等操作需要大屏精度，优先 PC/主机 |
| 内购/抽卡 | 买断制，解锁靠游戏内毁灭值而非付费 |
| 真实国家立场 | 地图使用虚构大陆，不涉及真实政治边界 |
