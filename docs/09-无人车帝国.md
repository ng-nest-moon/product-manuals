# 无人车帝国 — 产品功能说明书

## 一、一句话定义

购买不同型号的纯电动无人驾驶车辆，投放进城市自动接单赚钱。管理充电、保养、车队扩张，应对随机事件，逐步打造自己的自动驾驶出行帝国。

**视角**：俯视2D城市地图，车辆在道路上自动行驶、接客、返航充电。

---

## 二、核心循环

```
购买新车 → 投放城市自动接单 → 赚取收入
              ↓
     电量消耗 → 低于20%自动返航充电
     里程累积 → 达到保养里程需停运保养
              ↓
     收入再投资：买车 / 建充电站 / 解锁城市 / 升级配件
              ↕
       随机事件打断（政策/事故/天气/竞争）
```

---

## 三、核心功能清单

1. **车辆购买** — 使用金币直接购买不同型号的无人驾驶车辆
2. **自动接单** — 车辆投放后自动在街接单运营，无需玩家干预
3. **电量管理** — 车辆消耗电量，低于20%自动返航充电，充电期间停运
4. **充电方式** — 公共慢充/公共快充/换电/自建充电站，成本与速度各不同
5. **保养系统** — 每行驶一定里程需保养，恢复车况值，避免故障停运
6. **车况值** — 随里程衰减，影响收益系数和故障概率
7. **车型系统** — 多种车型，各有专属任务类型、属性参数和稀有度
8. **养成系统** — 每辆车独立等级、技能树、配件装备、外观涂装
9. **城市扩张** — 多城市解锁，各有独有特性影响运营策略
10. **城市特性** — 每座城市有不同的补贴政策、乘客密度、地形路况
11. **自建充电站** — 一次性投资降低长期充电成本
12. **充电站升级** — 从慢充桩逐步升级到快充桩再到换电站
13. **随机事件** — 政策调整、竞争对手、安全事故、天气变化、大客户包车等
14. **离线收益** — 关闭游戏后车辆继续运营，上线时收取离线收入
15. **钻石系统** — 付费货币，用于加速建造、限定涂装、限定配件

## 四、车辆系统

### 4.1 车型一览

所有车辆均为纯电动无人驾驶，不同车型因**硬件配置（电池/传感器/载货空间）** 不同而具备不同功能。

| 城市通勤车 | D~C | 40kWh | 200km | 20kWh | 日常短途载客 | 新手起步 |
| 电动货厢车 | C~B | 60kWh | 250km | 24kWh | 同城配送 | 货运入门 |
| 商务巡航车 | B | 80kWh | 400km | 20kWh | 机场专线 | 稳定营收 |
| MPV载客车 | B~A | 100kWh | ~357km | 28kWh | 团体出行 | 单趟高收 |
| 豪华旗舰车 | A | 120kWh | 500km | 24kWh | VIP接待 | 高端路线 |
| 无人接驳小巴 | A | 150kWh | 300km | 50kWh | 固定班线 | 稳定流水 |
| 极速轿跑 | A~S | 80kWh | ~267km | 30kWh | 限时挑战 | 高风险高回报 |
| 重载货运车 | S | 200kWh | ~364km | 55kWh | 大宗货运 | 货运天花板 |
| 超长礼宾车 | S | 150kWh | ~429km | 35kWh | 婚庆包车 | 单笔收益王 |
| 长途房车 | S | 250kWh | ~556km | 45kWh | 跨城旅行 | 解锁后期内容 |

### 4.2 专属任务类型

| 车型 | 任务类型 | 接单方式 | 收益特点 |
|------|---------|---------|---------|
| 城市通勤车 | 日常短途载客 | 自动匹配，随时接 | 单价低但单量稳定 |
| 电动货厢车 | 同城配送 | 订单池自选 | 无评分压力，按时送达有额外奖励 |
| 商务巡航车 | 机场/商务专线 | 提前预约制 | 等待时间长但单价高 |
| MPV载客车 | 团体出行 | 多人拼单，自动组队 | 按人头计费，单趟收入高 |
| 豪华旗舰车 | VIP接待 | 需达到评分门槛解锁 | 高额车费+小费，可解锁城市隐藏区域 |
| 无人接驳小巴 | 固定路线班车 | 设定路线后自动循环 | 稳定流水但增长平缓 |
| 极速轿跑 | 限时极速挑战 | 倒计时制限时任务 | 超高奖励，失败扣信誉 |
| 重载货运车 | 大宗货运 | 预约制大单 | 单笔体量大，耗时较长 |
| 超长礼宾车 | 婚庆/活动包车 | 预约制长时段占用 | 单笔收益天花板 |
| 长途房车 | 跨城长途旅行 | 需解锁对应城市 | 多日行程，沿途触发事件 |

### 4.3 养成系统（每辆车独立）

```
每辆车 ─┬─ 等级（接单赚经验，提升基础收益倍率）
        ├─ 技能树（3条路线选1）
        ├─ 装备槽 ─┬─ 电池（容量+）
        │           ├─ 传感器（接单范围+）
        │           ├─ 电机（能耗-）
        │           └─ 车载系统（评分+）
        ├─ 外观涂装（特殊加成）
        ├─ 自定义名称
        └─ 车况值（需保养维护）
```

### 4.4 技能树示例

**城市通勤车：**
```
Lv.5   ─  节能驾驶（能耗-15%） 或  智能调度（接单范围+10%）
Lv.10  ─  耐用底盘（车况衰减-20%） 或  好评系统（评分+0.5）
Lv.15  ─  超级省心（离线收益+20%） 或  高峰加成（高峰期收入+15%）
```

**极速轿跑：**
```
Lv.5   ─  弹射起步（接单响应速度+30%） 或  空气动力（能耗-10%）
Lv.10  ─  赛道模式（限时任务时限+15%） 或  智能避障（事故概率-50%）
Lv.15  ─  氮气加速（偶尔触发双倍速送达） 或  改装电机（极速+20%）
```

## 五、电量与充电系统

### 5.1 电量消耗

```
实际电耗 = 基础百公里电耗 × 天气系数 × 载重系数 × 路况系数

天气系数：晴天 1.0 / 雨天 1.1 / 雪天 1.2 / 高温开空调 1.15
载重系数：空载 1.0 / 半载 1.05 / 满载 1.1
路况系数：通畅 1.0 / 拥堵 1.15 / 山路 1.2
```

电量低于20%时车辆自动返航充电，充电期间停运。

### 5.2 充电方式

| 方式 | 时长 | 单价 | 充满通勤车(40kWh) | 特点 |
|------|------|------|------------------|------|
| 公共慢充 | 4小时 | ¥0.6/kWh | ¥24 | 夜间省钱首选 |
| 公共快充 | 1小时 | ¥1.2/kWh | ¥48 | 白天补电，成本翻倍 |
| 换电 | 5分钟 | ¥2.0/kWh | ¥80 | 最快但最贵 |

### 5.3 自建充电站

| 等级 | 投资额 | 成本降至 | 解锁条件 |
|------|-------|---------|---------|
| L1 慢充×2 | ¥10,000 | ¥0.4/kWh | 车队≥3台 |
| L2 慢充×4+快充×1 | ¥50,000 | ¥0.3/kWh | 车队≥10台 |
| L3 快充×4+慢充×4 | ¥200,000 | ¥0.2/kWh | 车队≥30台 |

## 六、保养系统

### 6.1 保养周期与费用

| 等级 | 间隔里程 | 费用 | 耗时 | 恢复车况 |
|------|---------|------|------|---------|
| 小保养 | 10,000km | ¥500 | 30分钟 | +5% |
| 中保养 | 30,000km | ¥2,000 | 1小时 | +15% |
| 大保养 | 60,000km | ¥8,000 | 2小时 | +30% |

### 6.2 车况值与故障

```
新车车况：100%
每行驶100km：车况 -0.05%

车况 < 50%：收益系数 ×0.9
车况 < 30%：收益系数 ×0.7，故障概率大幅上升
车况 < 10%：强制停运，必须大保养

故障概率 = (100% - 当前车况) × 0.1%（每100km判定一次）
```

## 八、经济系统

### 8.1 货币
- **金币**：基础货币，用于购车、升级、充电、保养、保险
- **钻石**：付费货币，用于加速建造、限定涂装、限定配件

### 8.2 收入公式
```
单笔收入 = 基础价 × 距离系数 × 车型系数 × 评分系数 × 时段系数 × 城市系数
```

### 8.3 每日成本结构
```
充电费 + 保养摊销 + 保险 + 停车费 + 故障维修费
```

## 九、随机事件系统

| 事件 | 触发条件 | 效果 | 玩家应对 |
|------|---------|------|---------|
| 政策调整 | 随机 | 某城市抽成比例临时±10% | 调整该城市车辆投放策略 |
| 竞争对手降价 | 车队规模达标 | 订单分流，收入下降 | 选择跟进或保持高价 |
| 技术突破 | 车辆总里程达标 | 解锁新配件或新车型 | 立即购买研发 |
| 安全事故 | 车况过低触发 | 停运+罚款 | 选择保险方案或自费 |
| 恶劣天气 | 随机 | 订单量↑速度↓能耗↑ | 调整充电策略 |
| 大客户包车 | 限时出现 | 超高收益大单 | 需满足车型要求 |
| 城市活动 | 定时触发 | 某区域订单暴增 | 预先调配车辆 |
| 车辆召回 | 特定车型触发 | 免费升级但需停运 | 安排其他车补位 |

## 十、玩家决策树

```
每天 → 查看车队状态
        ↓
 ┌────┴────┐
 ↓          ↓
电量足    电量不足 → 选择充电方式（省钱or省时间）
 ↓          ↓
继续运营   充电中停运，其他车补位
 ↓
检查车况 → 提前保养 vs 再跑跑
 ↓
收入到账 → 再投资：买车 / 建充电站 / 解锁城市 / 升级配件
```

**核心策略选择**：
- 铺量（多买便宜车）vs 精营（少量高端车）
- 投资充电站降本 vs 先扩张车队抢收入
- 高峰期快充抢单 vs 慢充省钱
- 提前保养保效率 vs 撑到快故障再修

## 十三、成功标准

| 指标 | 目标值 |
|------|-------|
| 核心循环流畅度 | 玩家前15分钟完成首次购车→接单→充电→再投资闭环 |
| 车型差异化感知 | 玩家能清晰感知不同车型的不同用途 |
| 经济模型可持续 | 合理策略下新车回本周期在300~400天（游戏内时间） |
| 随机事件丰富度 | 每2~3天至少触发1次有意义的事件决策 |
