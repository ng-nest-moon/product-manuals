# 无人车帝国 — 产品功能说明书

## 一句话定义

购买不同型号的纯电动无人驾驶车辆，投放进城市自动接单赚钱。管理充电、保养、车队扩张，应对随机事件，逐步打造自己的自动驾驶出行帝国。

**视角**：俯视2D城市地图，车辆在道路上自动行驶、接客、返航充电。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：喜欢放置策略类的模拟经营玩家（20-40 岁）**

| 维度 | 描述 |
|------|------|
| 游戏习惯 | 玩过模拟经营、放置类、策略类游戏 |
| 典型游戏 | 开罗系列、星露谷物语（经营部分）、Mini Metro |
| 单次游戏时长 | 15-30 分钟碎片时间 |
| 底层心理 | 喜欢"看着自己的系统自动运转"的掌控感 |

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 模拟经营游戏缺乏"车队管理"的垂直题材 |
| **刚需** | 玩家需要"离线也有收益"的放置体验 |
| **改善型** | 现有经营游戏车辆种类单一，缺乏差异化养成 |
| **改善型** | 城市之间的策略差异不足，换城市等于换皮肤 |

## 二、解决方案与核心功能

### 2.1 解决方案概述

无人车帝国是一个俯视2D的无人驾驶车队管理游戏。玩家购买车辆、投放城市自动接单、管理充电和保养、应对随机事件，逐步扩张车队。

核心设计：
- **放置核心** — 车辆自动运营，关闭游戏也有离线收益
- **深度养成** — 每辆车独立等级、技能树、配件、涂装
- **城市差异** — 每个城市有独特政策、乘客密度、地形特征
- **随机事件** — 政策调整、竞争对手、安全事故持续挑战玩家策略

### 2.2 核心功能清单

1. **车辆购买** — 金币直接购买不同型号的无人驾驶车辆（明码标价，无抽卡）
2. **自动接单** — 车辆投放后自动在街接单运营，无需玩家干预
3. **电量管理** — 车辆消耗电量，低于20%自动返航充电
4. **充电方式** — 公共慢充/快充/换电/自建充电站，成本与速度各不同
5. **保养系统** — 每行驶一定里程需保养，恢复车况值
6. **车况值** — 随里程衰减，影响收益系数和故障概率
7. **车型系统** — 10种车型，各有专属任务类型和属性参数
8. **养成系统** — 每辆车独立等级、技能树、配件装备、外观涂装
9. **城市扩张** — 多城市解锁，各有独有特性影响运营策略
10. **自建充电站** — 一次性投资降低长期充电成本，可持续升级
11. **随机事件** — 政策调整、竞争对手、安全事故、大客户包车等
12. **离线收益** — 关闭游戏后车辆继续运营

## 三、竞品与差异化分析

| 竞品 | 优点 | 缺点 | 差异 |
|------|------|------|------|
| 开罗游戏系列 | 像素风模拟经营，休闲有趣 | 深度浅，缺乏长期养成 | 无人车帝国每辆车独立养成 |
| 星露谷物语 | 内容丰富，经营+社交 | 不是车队主题 | 垂直聚焦无人车管理 |
| Mini Metro | 极简策略，路线规划 | 无养成、无经济系统 | 无人车帝国有完整经济循环 |
| 放置类手游 | 离线收益，碎片时间 | 缺乏策略决策 | 无人车帝国有充电/保养/城市选择策略 |

**差异化优势：** 无人驾驶车队的垂直题材 + 每辆车独立养成 + 城市差异化策略。

## 四、架构总览

```
购买新车 → 投放城市自动接单 → 赚取收入
              ↓
     电量消耗 → 低于20%自动返航充电
     里程累积 → 达到保养里程需停运保养
              ↓
     收入再投资：买车 / 建充电站 / 解锁城市 / 升级配件
              ↕
       随机事件打断（政策/事故/天气/竞争）
```

## 五、核心模块详解

### 5.1 车型系统

10 种车型，从 D 级到 S 级稀有度：城市通勤车（D~C）、电动货厢车（C~B）、商务巡航车（B）、MPV载客车（B~A）、豪华旗舰车（A）、无人接驳小巴（A）、极速轿跑（A~S）、重载货运车（S）、超长礼宾车（S）、长途房车（S）。

每种车型有专属任务类型（日常短途载客/同城配送/机场专线/团体出行/VIP接待/固定班线/限时挑战/大宗货运等），形成差异化定位。

### 5.2 养成系统（每辆车独立）

- **等级**：接单赚经验，提升基础收益倍率
- **技能树**：每条路线 3 个分支选 1（如节能驾驶 vs 智能调度、耐用底盘 vs 好评系统）
- **装备槽**：电池（容量+）、传感器（接单范围+）、电机（能耗-）、车载系统（评分+）
- **外观涂装**：特殊加成，限定涂装可用钻石购买
- **车况值**：需保养维护

### 5.3 电量与充电

电耗受天气、载重、路况系数影响。电量低于 20% 自动返航。

公共慢充（4h，¥0.6/kWh）→ 公共快充（1h，¥1.2/kWh）→ 换电（5min，¥2.0/kWh）三种公共方式。自建充电站 L1-L4 逐级升级，可降到 ¥0.2/kWh 或换电 ¥1.0/kWh。

### 5.4 保养与车况

小保养（10,000km，¥500，+5%车况）→ 中保养（30,000km，¥2,000，+15%）→ 大保养（60,000km，¥8,000，+30%）。车况 < 50% 收益 ×0.9，< 30% 收益 ×0.7 且故障概率上升。

### 5.5 城市系统

8 个城市（武汉→成都→深圳→上海→北京→重庆→迪拜→东京），各有特性。武汉补贴高路况复杂，上海高端乘客密集，重庆山路电耗高但轿跑灵活，东京监管严客单价极高。

### 5.6 随机事件

政策调整、竞争对手降价、技术突破、安全事故、恶劣天气、大客户包车、城市活动、车辆召回共 8 类事件定时或条件触发，考验玩家应对能力。

### 5.7 经济系统

双货币：金币（基础，购车/升级/充电/保养）和钻石（付费，加速建造/限定涂装/配件）。单笔收入 = 基础价 × 距离系数 × 车型系数 × 评分系数 × 时段系数 × 城市系数。

## 六、用户流程

```
每天 → 查看车队状态
   ↓
电量足 → 继续运营
电量不足 → 选择充电方式（省钱or省时间）
   ↓
检查车况 → 提前保养 vs 再跑跑
   ↓
收入到账 → 再投资
   └─ 铺量（多买便宜车）vs 精营（少量高端车）
   └─ 投资充电站降本 vs 先扩张车队抢收入
   └─ 高峰期快充抢单 vs 慢充省钱
```

## 七、商业模式

| 付费模式 | 说明 |
|---------|------|
| 买断制 | 游戏本体付费（30-50 元） |
| 钻石内购 | 加速建造、限定涂装、限定配件（非数值必需） |

**关键原则：** 不出抽卡，所有车辆明码标价。钻石不提供其他获取方式（不设广告看视频获取）。离线收益足够正常推进，不设体力限制。

## 八、落地路径

### 8.1 MVP（V1.0）

1 个城市（武汉）+ 3 种车（通勤车/货厢车/MPV）+ 充电保养 + 基础升级。目标：核心循环打通，玩家前 15 分钟完成首次购车→接单→充电→再投资闭环。

### 8.2 后续迭代

V1.1：商务车+豪华车 + 技能树 + 配件系统
V1.2：第 2~3 个城市 + 城市特性 + 随机事件
V1.3：高阶车型 + 海外城市 + 完整数值平衡

### 8.3 第一步验证

**最关键的假设：** 玩家愿意为"车队管理"这个垂直题材付费。

**验证方法：** 做一个可玩原型（1 城市 + 1 天的运营循环），邀请放置/经营类玩家试玩，测试是否愿意玩第二遍。

## 九、风险与预期反馈

| 预期槽点 | 应对方案 |
|---------|---------|
| "和开罗差不多" | 每辆车独立养成+城市差异是核心差异 |
| "没驾驶感" | 定位策略管理，不做驾驶模拟 |
| "后期无聊" | 随机事件和城市解锁保持新鲜感 |
| "有内购" | 钻石非必需，不出抽卡 |

## 十、边界声明

| 不做 | 原因 |
|------|------|
| 真实驾驶模拟 | 聚焦策略管理而非驾驶操作 |
| 多人联机/对抗 | 保持单人策略体验的纯粹性 |
| 真实地图数据 | 使用虚构城市，避免与现实对标 |
| 车辆内购抽卡 | 明码标价购买，不设概率抽卡 |
