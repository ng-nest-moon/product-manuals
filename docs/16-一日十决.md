# 一日十决 — 产品功能说明书

## 一句话定义

> 一款游戏化的决策训练工具，通过每日 10 道随机题目帮助用户提升概率直觉、风险判断力和认知偏误识别能力。

---

## 一、架构总览

```
用户层
 ├── 今日道场
 │    ├── 概率校准题（4道）
 │    ├── 风险选择题（3道）
 │    ├── 认知偏误题（2道）
 │    └── 连环事件题（1道，隔天）
 ├── 角色系统
 │    ├── 四项属性面板
 │    ├── 等级与解锁
 │    └── 成就系统
 ├── 数据看板
 │    ├── 偏差画像
 │    ├── 周报
 │    └── 历史趋势
 └── 云端（可选）
      ├── 好友对战
      └── 自定义题库
```

---

## 二、核心功能清单

1. **今日道场** — 每天生成 10 道混合题型的决策训练，约 10 分钟完成
2. **概率校准** — 用有标准答案的统计题训练用户对数字和概率的直觉
3. **风险选择** — 用无标准答案的情境题让用户练习在不确定条件下的权衡
4. **认知偏误** — 用情景识别题帮助用户发现并对抗常见的思维陷阱
5. **连环事件** — 用多步分支故事模拟选择产生连锁反应的肉鸽体验
6. **角色面板** — 用四项属性（校准力、决策速度、风险意识、抗偏差力）追踪用户成长
7. **等级解锁** — 通过累积经验值逐步解锁新题型和新模式
8. **成就系统** — 记录用户的行为风格并授予称号
9. **周报** — 每周生成决策训练报告，包含偏差分析和改进建议
10. **每日闭环** — 完成训练后显示得分、经验、明日预告，维持连续签到

---

## 三、核心模块详解

### 3.1 今日道场

**职责：** 每天提供 10 道随机混合题，覆盖 4 种题型，是产品的核心使用场景。

| 功能点 | 说明 | 规则 |
|--------|------|------|
| 每日出题 | 从题库中抽取 10 道题组成当日训练 | 4 校准 + 3 风险 + 2 偏误 + 1 连环（连环隔天出现，当日则为 5+3+2） |
| 题目难度 | 根据用户等级匹配难度 | Lv.1-3 出简单/中等题，Lv.4+ 开始出现困难题 |
| 限时机制 | 每题有倒计时（30-45 秒） | 闪电模式限时 10 秒，Lv.6 解锁 |
| 实时反馈 | 选完即显示正确答案或分析 | 校准题显示正确答案；风险题显示期望值和风格分析；偏误题显示讲解；连环题显示结局 |
| 连击奖励 | 连续答对/自洽可获额外分数 | 连续 3 题正确触发 ×1.2 倍率 |

### 3.2 四种题型

| 题型 | 数量/日 | 有无标准答案 | 核心机制 | 训练目标 |
|------|---------|-------------|---------|---------|
| 概率校准题 | 4 道 | ✅ 有 | 从统计题库抽题，选完即显示正确答案和来源 | 校准概率直觉 |
| 风险选择题 | 3 道 | ❌ 无 | 显示期望值，用户凭偏好选择，记分看自洽性 | 认识自身风险偏好 |
| 认知偏误题 | 2 道 | ✅ 有 | 展示包含偏误的情景，用户识别偏误类型 | 识别思维陷阱 |
| 连环事件题 | 1 道（隔天） | ❌ 无 | 三连分支选择，生成结局和风格分析 | 体验选择连锁反应 |

#### 3.2.1 概率校准题规则

| 项目 | 说明 |
|------|------|
| 题目来源 | 从可信统计数据（权威报告、学术研究、官方数据）提炼 |
| 计分方式 | 准确命中目标区间 +10 分，偏差 1 个区间 +5 分，偏差 2 个以上 +0 分 |
| 反馈内容 | 正确答案 + 计算过程 + 生活启示 |
| 题库范围 | 科技、健康、经济、历史、体育、自然等多领域 |

#### 3.2.2 风险选择题规则

| 项目 | 说明 |
|------|------|
| 题目来源 | AI 根据模板生成情境 + 自动计算期望值 |
| 计分方式 | 无对错之分，按"期望值理性 + 自洽性 + 决策速度"三维度评分 |
| 反馈内容 | 用户风格标签（保守/平衡/激进）+ 期望值比较 + 现实类比 |
| 题型子类 | 日常类（时间分配）、金钱类（投资博弈）、职业类（发展选择） |

#### 3.2.3 认知偏误题规则

| 项目 | 说明 |
|------|------|
| 偏误池 | 沉没成本、确认偏误、锚定效应、可得性启发、框架效应、过度自信等 |
| 计分方式 | 正确识别 +10 分，错误 +0 分但显示教学 |
| 反馈内容 | 偏误名称 + 常见表现 + 对抗方法 |
| 难度递进 | 低级：提示偏误列表 → 中级：不提示 → 高级：情景含多重偏误 |

#### 3.2.4 连环事件题规则

| 项目 | 说明 |
|------|------|
| 结构 | 3 道连续题，第 2/3 题根据上题选择动态变化 |
| 结局数量 | 4 种（根据隐藏命运值总和触发） |
| 计分方式 | 无分数，记录风格标签和结局成就 |
| 重复机制 | 同一条事件线 7 天内不重复 |
| 现实映射 | 结算时给出"你的这次风格对应现实中的什么决策倾向" |

---

### 3.3 角色系统

**职责：** 将用户的训练成果量化呈现，驱动长期留存。

| 功能点 | 说明 | 规则 |
|--------|------|------|
| 四项属性面板 | 校准力 / 决策速度 / 风险意识 / 抗偏差力 | 每次答题后更新，值域 0-100 |
| 等级与经验值 | 全局等级，决定解锁内容 | 每 100-500 XP 升一级，共 10 级 |
| 成就系统 | 决策行为的里程碑称号 | 如「冷静机器」「赌徒」「大师校准」 |
| 连续签到 | 每日完成道场即签到 | 连续天数影响 XP 倍率 |

**等级解锁表：**

| 等级 | 解锁内容 | 升级所需经验 |
|------|---------|------------|
| Lv.1 | 基础校准 + 风险选择 | 初始 |
| Lv.2 | 偏误识别题 | 100 XP |
| Lv.3 | 周报功能 | 250 XP |
| Lv.4 | 连环事件 | 500 XP |
| Lv.5 | 对决模式（与一周前的自己比） | 800 XP |
| Lv.6 | 闪电限时模式 | 1200 XP |
| Lv.7 | 自定义出题 | 1800 XP |
| Lv.8 | 平行宇宙（同一题体验另一选项） | 2500 XP |
| Lv.9 | 好友对战 | 3500 XP |
| Lv.10 | 完整决策画像 PDF 报告 | 5000 XP |

---

### 3.4 数据看板

**职责：** 提供训练数据可视化，帮助用户追踪进步。

| 功能点 | 说明 | 规则 |
|--------|------|------|
| 偏差画像 | 分析用户长期偏差模式 | 每周更新，显示"你总是高估/低估什么" |
| 周报 | 每周 7 天训练总结 | Lv.3 解锁，含属性变化、发现、建议 |
| 历史趋势 | 属性值随时间的变化曲线 | 可查看 1 个月/3 个月/全部 |
| 风格标签 | 根据长期行为打上的决策风格标签 | "保守守成型""激进冒险者""平衡大师"等 |

## 四、用户流程

### 4.1 核心流程：每日道场

```
打开 App → 进入「今日道场」

第 1 题（概率校准 · 30 秒）
  选择 → 显示正确答案 + 得分 + 讲解

第 2 题（风险选择 · 45 秒）
  选择 → 显示期望值 + 风格分析 + 自洽得分

第 3 题（认知偏误 · 40 秒）
  选择 → 显示正确偏误 + 教学 + 对抗方法

第 4-9 题（混合排列，难度递增）

第 10 题（连环事件 · 3 步 · 肉鸽高潮）
  三步选择 → 结局结算 → 风格标签

→ 今日结算
  总得分 + 经验值 + 属性变化 + 连续签到 + 明日预告
```

### 4.2 周报流程

```
周日晚 21:00 推送通知 → 进入周报：
  ├─ 本周总览（题量、得分、签到）
  ├─ 四项属性变化
  ├─ 本周发现（偏差模式、强弱点）
  ├─ 新成就（如有）
  └─ 下周建议（专项训练推荐）
```

## 五、应用场景

### 场景一：通勤决策训练

用户每天早上地铁上打开 App 完成 10 道题。每题 30-45 秒的节奏适配碎片化场景。完成后"今日发现"让用户全天带着一个"决策觉察"生活。

### 场景二：重要决策前的思维热身

用户在做重大选择（跳槽、投资、购房）前，先刷 10 道题激活理性思维模式。风险选择题帮助用户意识到自己当前的风险偏好是保守还是激进。

### 场景三：朋友之间的决策风格对比

Lv.9 解锁后，用户可以和好友做同一组题比分数和风格标签。周报可分享到社交平台。

## 六、边界声明

| 不做 | 原因 |
|------|------|
| 不做真实人生决策记录 | 定位是训练场，不是复盘工具 |
| 不做任务/待办管理 | 与 Habitica 等习惯工具定位不同 |
| 不做社交动态流 | 仅好友对战，不做聊天/广场 |
| 不做离线题库 | 题目由 AI 动态生成，需联网 |
| 不做深度故事线 | 连环事件限 3 题，不做长篇叙事 |

## 七、配置示例

### 配置一：新手上路

```yaml
等级: Lv.1
每日题量: 10
题目难度: 简单为主
限时: 关闭
题型池: 仅校准 + 风险选择
连环事件: 关
```

### 配置二：进阶训练

```yaml
等级: Lv.4
每日题量: 10
题目难度: 中等 + 少量困难
限时: 标准（30-45 秒）
题型池: 全题型
连环事件: 开启（隔天）
```

### 配置三：地狱周

```yaml
等级: Lv.6+
每日题量: 15
题目难度: 困难为主
限时: 闪电（15 秒/题）
题型池: 全题型 + 多重偏误
连环事件: 每日出现
自定义出题: 启用
```
