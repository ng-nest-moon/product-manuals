# 深界测绘局 — 产品功能说明书

## 一句话定义

第一人称洞穴生存探索游戏，屏幕无 UI/无地图/无导航，玩家必须用真实纸笔手绘地图才能生存和返回。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：喜欢硬核生存和探索游戏的玩家**

| 维度 | 描述 |
|------|------|
| 游戏习惯 | 玩过深海迷航/漫漫长夜/黑暗森林等生存探索游戏 |
| 期望 | 真正的生存恐惧——不是怪物，而是"找不到回去的路" |
| 单局时长 | 30 分钟到数小时（取决于地图大小和玩家画图速度）|
| 底层心理 | 享受"自己解决问题"的真实成就感 |

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 游戏内的地图/导航让"迷路"不真实 |
| **刚需** | 玩家寻求"脱 UI"的沉浸体验 |
| **改善型** | 生存游戏大多威胁来自外部（怪物/环境），缺少"迷路"本身作为威胁 |

---

## 二、解决方案与核心功能

### 2.1 解决方案概述

深界测绘局的屏幕完全无 UI、无地图、无导航、无指南针。玩家在现实世界用纸笔手绘洞穴结构来导航。唯一的定位手段是洞穴中的辨位石碑。火把燃尽必须返回，生物靠近必须静止。迷路和资源耗尽意味着存档永久作废。

核心设计：
- **零 UI 导航** — 屏幕不提供任何位置/方向/距离信息
- **手绘地图** — 现实纸笔，游戏不记录不验证
- **单存档+永久死亡** — 迷路/资源耗尽 → 存档作废
- **程序生成洞穴** — 每次开档结构不同

### 2.2 核心功能清单

1. **洞穴探索** — 第一人称，全黑暗，火把照明
2. **纸笔地图** — 无任何 UI 辅助，必须现实纸笔画图
3. **辨位石碑** — 唯一位置确认手段
4. **呼吸值系统** — 按键频率/移动速度影响被生物察觉概率
5. **生存资源** — 火把/绳索/口粮，出发前权衡携带
6. **单存档永久死亡** — 存档作废必须重开
7. **程序化洞穴生成** — 每次结构不同的迷宫

## 三、竞品与差异化分析

| 竞品 | 优点 | 缺点 | 差异 |
|------|------|------|------|
| 深海迷航 | 探索感强 | 有地图有 UI | 深界零 UI，纸笔画图 |
| 漫漫长夜 | 硬核生存 | 有地图 | 地图需要自己画 |
| 黑暗森林 | 无 UI 探索 | VR 限定 | 深界是桌面+纸笔 |

**差异化优势：** 零 UI + 纸笔手绘 + 单存档永久死亡。

## 五、核心模块详解

### 5.1 纸笔地图系统

游戏屏幕无坐标、无指南针、无小地图、无当前位置提示。玩家必须在现实世界用纸笔画出洞穴结构。唯一的定位手段：每个区域一块刻有名称的石碑，玩家需靠已有地图判断石碑位置是否对得上。火把燃烧时才能看清环境并画图，火把熄灭后无法获取新信息。

### 5.2 呼吸值系统

按键频率+鼠标急转幅度→呼吸值上升。生物朝呼吸值高的方向移动。角色呼吸声渐重（无 UI 条，靠听觉判断）。静止操作一段时间呼吸值归零。

### 5.3 生存资源

火把（每根约 15 分钟，限带 3 根）、绳索（约 10 米，限带 2 条）、口粮（每份 1 天，限带 5 份）。地面补给站有限，用后不补。

### 5.4 存档与死亡

单存档位。自动保存（离开营地和进入新层时）。迷路/火把全灭+断粮→判定死亡→存档删除。成功绘制完整地图并返回地面→游戏结束。

## 六、用户流程

```
开始新游戏 → 营地选择携带资源
  ↓
进入洞穴（光线消失，纸笔画图）
  ↓
探索循环：前进→观察→画图→岔路→石碑校准位置
  ↓
危机：呼吸升高→生物靠近→静止/绕行/逃跑
  ↓
火把燃尽前返回（靠手绘地图）
  ↓
补给 → 再次出发 → 直到全地图绘制完成
```

## 八、落地路径

### 8.1 MVP

程序洞穴生成（至少 3 层）+ 火把照明 + 纸笔导航（无 UI）+ 辨位石碑 + 单存档自动保存 + 一个声敏生物。

### 8.2 第一步验证

**最关键假设：** 玩家在没有 UI 地图的情况下愿意用纸笔画图。

**验证方法：** 做一个极简原型（3 个洞室相连的迷宫），不提供任何引导。测试者进入后观察：是否有人自动开始找纸笔。如果 > 50% 的测试者掏出纸笔而不是直接硬闯，假设成立。

## 九、风险与预期反馈

| 预期槽点 | 应对方案 |
|---------|---------|
| "没地图玩不了" | 就是设计——纸笔就是地图 |
| "太难了" | 洞穴结构保证有规律，画图熟了就能过 |
| "需要准备纸笔麻烦" | 这本身就是门槛——过滤不适合的玩家 |
| "存档没了太坑" | 永久死亡是核心设计，不是 bug |

## 十、边界声明

| 不做 | 原因 |
|------|------|
| 战斗系统 | 核心是探索与恐惧 |
| 角色成长/技能树 | 唯一成长的是玩家的画图能力 |
| 叙事/剧情 | 故事由玩家探索经历生成 |
| 联机/多人 | 单人沉浸 |
| VR 版本 | MVP 不做 |
| 麦克风声敏 | 改用呼吸值系统 |
| 成就系统 | 核心驱动力是生存本身 |
