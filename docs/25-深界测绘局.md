# 深界测绘局 — 产品功能说明书

## 一句话定义

> 第一人称洞穴生存探索游戏，屏幕无UI/无地图/无导航，玩家必须用真实纸笔手绘地图才能生存和返回。

---

## 一、架构总览

```
用户层
 ├── 洞穴探索
 │    ├── 自由漫行（第一人称）
 │    ├── 火把照明系统
 │    └── 环境交互（标记、投石听声、测距）
 ├── 纸笔地图
 │    ├── 玩家手绘（现实世界纸笔）
 │    ├── 辨位石碑（游戏内唯一位置确认手段）
 │    └── 无任何游戏内定位辅助
 ├── 生存资源
 │    ├── 火把（可燃尽，影响可视范围和画图时间）
 │    ├── 绳索（影响可下探深度）
 │    └── 口粮（影响可探索时长）
 ├── 生物威胁
 │    ├── 声敏生物（由呼吸值驱动，非麦克风）
 │    └── 幽闭恐怖氛围（无跳杀）
 ├── 存档与死亡
 │    ├── 单存档位
 │    ├── 自动保存（不可手动SL）
 │    └── 迷路/资源耗尽 → 角色死亡 → 存档作废
 └── 世界生成
      ├── 每次开档洞穴结构完全随机
      └── 资源分布随机，不可预测
```

---

## 二、核心功能清单

1. **洞穴探索** — 第一人称自由漫行，完全黑暗环境，依靠火把照明观察洞穴结构
2. **纸笔地图** — 游戏屏幕不提供任何定位信息，玩家必须在现实世界用纸笔画图记录路径
3. **辨位石碑** — 每个区域有唯一石碑标记区域名称，帮助玩家在自绘地图上校准位置
4. **呼吸值系统** — 按键频率和移动速度影响角色呼吸急促程度，呼吸越急促越易被生物察觉
5. **生存资源管理** — 火把、绳索、口粮三种资源，每次出发前必须权衡携带方案
6. **单存档永久死亡** — 角色死亡或物资耗尽无法返回 → 存档作废，必须重开
7. **程序化洞穴生成** — 每次开档洞穴拓扑结构和资源位置完全随机，保证重玩价值

## 三、核心模块详解

### 3.1 洞穴探索

**职责：** 提供第一人称探索体验，营造幽闭恐惧氛围，玩家通过观察环境特征建立认知地图

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 自由漫行 | WASD移动，鼠标环视 | 无冲刺、无跳跃、无攀爬 |
| 火把照明 | 手持火把照明前方扇形区域 | 火把随时间燃烧变短，最终熄灭；熄灭后屏幕几乎全黑 |
| 环境观察 | 查看岩壁纹理、洞穴宽度、岔路数量和形状 | 无任何高亮、标记或提示 |
| 投石听声 | 向黑暗区域投掷石子，通过回声判断空间大小 | 消耗石子（有限数量） |
| 绳索使用 | 在垂直洞穴入口固定绳索，标记已探索深度 | 绳索长度有限，每条绳子使用后标记深度 |

### 3.2 纸笔地图

**职责：** 游戏的导航核心——不画图则无法返回，屏幕不提供任何形式的自动地图或位置提示

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 手绘地图 | 玩家在现实世界用纸笔画下洞穴结构 | 游戏不记录、不验证玩家的地图 |
| 零UI导航 | 屏幕无坐标、无指南针、无小地图、无当前位置提示 | 完全依靠玩家的记忆和纸笔记录 |
| 辨位石碑 | 每个区域设置一块刻有名称的石碑 | 玩家需靠已有地图判断石碑位置是否和自己画的对得上 |
| 火把与画图 | 火把燃烧时才能看清环境并画图 | 火把熄灭后无法获取新环境信息 |

### 3.3 呼吸值系统

**职责：** 替代麦克风声敏方案，将玩家现实紧张程度映射为游戏内被生物感知的风险

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 呼吸值积累 | 键盘按键频率 + 鼠标急转幅度 → 呼吸值上升 | 呼吸值随时间缓慢下降（深呼吸恢复） |
| 生物感知 | 生物朝呼吸值高的方向移动 | 呼吸值越高，生物移动速度越快 |
| 反馈提示 | 角色呼吸声逐渐加重（游戏中） | 无UI指示条，玩家通过听觉判断自己状态 |
| 静止消音 | 停止操作一段时间后呼吸值归零 | 无威胁时玩家可通过静止来摆脱追踪 |

### 3.4 生存资源

**职责：** 限制每次探索的深度和时长，迫使玩家在探索欲与生存保障之间做抉择

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 火把 | 提供照明，燃烧时才能辨路和画图 | 每根燃烧约15分钟游戏内时间；背包限带3根 |
| 绳索 | 用于垂直洞穴下行和标记返回路线 | 每条约10米，背包限带2条 |
| 口粮 | 提供体力维持探索续航 | 每份供1天消耗，背包限带5份 |
| 地面补给站 | 出发点有限量补给箱 | 初始提供3火把+2绳+5口粮，用尽后不再补充 |

### 3.5 存档与死亡

**职责：** 营造不可逆的后果感，让每次探索决策都有真实分量

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 单存档位 | 游戏中只有一个存档位 | 不可手动创建多个存档 |
| 自动保存 | 每次离开地面营地和每次进入新层深时自动保存 | 无手动保存选项 |
| 死亡判定 | 火把全灭且在黑暗中断粮 → 判定为迷路死亡 | 无复活机制，存档删除 |
| 完成判定 | 成功绘制完整洞穴地图并返回地面 | 系统提示结束，玩家可选择开新档 |

### 3.6 程序化洞穴生成

**职责：** 保证每次开档地图结构和资源分布不同，维持重玩价值

| 功能点 | 说明 | 规则 / 约束 |
|--------|------|-------------|
| 拓扑生成 | 洞穴通道网络、岔路数量、深度层级随机生成 | 确保至少有1条可达底层的路径 |
| 资源分布 | 火把/绳索/食物补给点位置随机 | 保证入口层至少1处补给 |
| 石碑位置 | 辨位石碑数量固定但位置随机生成 | 每层至少1块、至多3块 |
| 生物巢穴 | 声敏生物聚集区域随机分布 | 深层更密集 |

## 四、用户流程

```
开始新游戏
  │
  ├─ 步骤 1：出发准备
  │    在营地选择携带的火把、绳索、口粮数量
  │    （默认满配，可主动减负换取移动速度）
  │
  ├─ 步骤 2：进入洞穴
  │    第一层洞口出现，光线逐渐消失，进入黑暗
  │    玩家开始在现实纸笔上画下初始地形
  │
  ├─ 步骤 3：探索循环
  │    前进 → 观察环境 → 纸上画图 → 遇到岔路
  │    → 跟随直觉/分析地图 → 遇到石碑 → 校准位置
  │    → 燃烧火把 → 燃烧口粮 → 继续或返回
  │
  ├─ 步骤 4：危机子流程
  │    呼吸值升高 → 听到生物动静 → 选择静止/绕行/逃跑
  │    → 若逃跑导致迷路 → 寻找石碑定位
  │    → 若火把耗尽且迷失 → 死亡 → 存档作废
  │
  ├─ 步骤 5：返回地面
  │    依靠手绘地图原路返回 → 到达营地
  │    → 补给 → 整理地图 → 决定是否再次出发
  │
  └─ 结束：完成
       绘制完整洞穴地图并确认所有区域已探索
       → 游戏结束画面（展示探索数据统计）
```

## 五、应用场景

### 场景一：新手第一次下洞

> 玩家进入游戏，洞口还有光明。走了几步后光线消失，屏幕几乎全黑。玩家下意识按TAB看地图，什么都没有。翻找按键设置发现没有「地图键」。玩家才意识到——需要自己拿纸笔画。

玩家掏出笔记本画下第一个十字路口。标记左侧塌方、右侧有滴水声。深入后发现岔路越来越多，开始后悔没有在纸上标记走过的路。火把燃烧过半时决定返回，靠着歪歪扭扭的地图找到了洞口——产生真实的成就感。

### 场景二：深陷重围

> 玩家已探索到第4层，火把还剩半根。呼吸值因连续探索较高，听到生物在附近活动的声音。玩家选择熄灭火把原地静止——黑暗中屏幕完全无光，只能听声辨位。

生物逐渐远去后，玩家重新点亮火把，发现自己紧张中在纸上多画了一个岔路。开始怀疑当前位置，最近的石碑在哪里？地图上无法确认自己的准确位置——焦虑感真实上升。

### 场景三：老手的最后一役

> 已经重开了7个存档，玩家逐渐熟练。这次携带2根火把、1条绳、4份口粮，轻装上阵。目标：直接冲刺最底层。

玩家快速画出每个关键路口的拓扑结构，不再纠结细节，只记录路线和石碑位置。靠着前几次的经验和对洞穴生成模式的直觉，在火把即将耗尽时找到了底层石碑。确认完成了全地图绘制后安全返回地面——游戏结束。

## 六、边界声明

| 不做 | 原因 |
|------|------|
| 战斗系统 | 核心体验是探索与生存恐惧，非武力对抗 |
| 角色成长/技能树 | 唯一成长的是玩家自己的画图能力和方向感 |
| 叙事/剧情 | 故事由玩家自己的探索经历自然生成 |
| 联机/多人 | 单人沉浸体验，多人会破坏孤独感和恐惧感 |
| VR版本 | 范围过大，MVP阶段不纳入 |
| 麦克风声敏 | 技术上不可靠（键盘/鼠标/环境噪音干扰），改用呼吸值系统 |
| 中文/英文以外语言 | 游戏内文本极少（仅石碑名称），MVP阶段不需求额外本地化 |
| 成就/奖杯系统 | 核心驱动力是生存行为本身，不需要外部奖励机制 |
