# 地震救援 — 产品功能说明书

## 一句话定义

俯视图即时策略救援模拟游戏——地震发生后，你是指挥官，在时间、物资、信息三重压力下调派救援力量，处理连锁灾害，做出艰难取舍，在被掩埋的城市的命运走向终局之前拯救更多生命。

---

## 一、系统架构总览

```
表现层（俯视图城市 + 指挥面板）
 ├── 俯视图地图 —— 城市区域 / 建筑状态 / 单位位置 / 灾害扩散
 ├── 指令面板 —— 派遣 / 侦察 / 救援 / 灭火 / 救治 / 运输
 ├── 事件弹窗 —— 条件触发的事件 + 2-4 个选项
 ├── 状态 HUD —— 倒计时 / 幸存者统计 / 资源概览 / 评级预估
 └── 战报系统 —— 评分结果 / 时间线复盘 / 决策回顾

核心系统（6 大模块）
 ├── 地图系统 —— 多城市主题 / 多图层（地表+地下+环境）/ 建筑体系
 ├── 单位系统 —— 5 大类 20+ 单位 / 经验成长 / 技能树 / 士气疲劳 / 永久伤亡
 ├── 灾害引擎 —— 地震破坏 / 余震 / 次生灾害链 / 动态扩散
 ├── 事件引擎 —— 条件触发 / 多层分支 / 道德困境 / 外部势力（上级/媒体/国际援助）
 ├── 资源系统 —— 7 类物资 / 质量等级 / 多维经济 / 完整补给链
```

## 二、核心功能清单

1. **俯视图城市指挥** — 以俯视图视角在一座受损城市中调派救援力量，点击建筑查看详情、框选单位下达指令
2. **多城市主题** — 沿海城市、山城、平原都会、工业城市、古城等 5 种以上主题，每种主题灾害表现和救援策略不同
3. **多层次地图** — 地表建筑+道路、地下空间（地铁/管廊/地下室）、基础设施网络（电力/供水/通信/燃气）三层联动
4. **动态灾害系统** — 地震破坏 → 余震二次坍塌 → 次生灾害链（火灾蔓延/燃气爆炸/危化品泄漏/水淹），无人处理的灾害持续恶化
5. **20+ 单位类型** — 搜救类、医疗类、消防/危化类、工程类、后勤/指挥类五大类别，各有独立职能
6. **单位成长体系** — 经验升级 + 专精技能树 + 装备配置 + 士气/疲劳管理 + 永久伤亡
7. **条件触发事件** — 灾害链事件、人物故事线、道德困境、上级指令、媒体舆论、国际援助六大类事件
8. **时间三重压力** — 全局倒计时 + 每个幸存者独立存活倒计时 + 单位行动需要时间，三管齐下制造紧迫感
9. **真实物资体系** — 7 类物资分质量等级，多维经济（拨款/捐赠/保险/国际援助），完整补给链（外部→仓库→前线）
10. **天气与昼夜** — 雨雪高温大风影响救援效率，夜间视野降低需照明设备，天气可动态变化
11. **社会与治安** — 民众恐慌/哄抢/谣言，需分配力量维持秩序，投入治安过少则局势失控
12. **完整灾后收尾** — 幸存者安置、防疫消杀、心理干预、重建规划，影响最终评分
13. **综合评分+详细战报** — S/A/B/C/D/E 六级评级 + 幸存者统计/时间线复盘/决策回顾/单位表现
14. **局外成长** — 指挥官技能树 / 基地建设 / 图鉴收集 / 成就系统 / 全局统计
15. **三种游戏模式** — 单人战役、自由模式（参数自定义随机生成）、挑战模式（特殊条件限制）
16. **全难度系统** — 预设（简单/普通/困难/专家）+ 自定义（逐项调节）+ 动态难度（自动适配）

## 三、指挥阶段详解

### 3.1 简报阶段

**场景：** 指挥中心大屏 / 电子地图 / 灾害评估报告

**流程：**

| 环节 | 内容 | 玩家操作 |
|------|------|---------|
| 灾情简报 | 地震震级、震中位置、预估受灾范围、天气情况 | 阅读报告 |
| 地图概览 | 显示城区分区、已知建筑状态（部分信息隐藏） | 查看地图 |
| 初始部署 | 选择初始单位放置位置、分配初始物资 | 拖拽部署 |
| 确认开始 | 确认部署完成后地震"正式发生" | 点击开始 |

### 3.2 黄金救援期（指挥阶段前半段）

**时间：** 前 1/2 全局时间

**特征：** 信息最不完整、受困者存活率高、外部援助未到

**典型操作循环：**

```
① 侦察区域 → ② 发现受困者 → ③ 派遣救援队 → ④ 救出 → ⑤ 医疗队救治
                ↘ 发现火情 → 派遣消防队
                ↘ 发现危化品 → 派遣危化组
```

**核心矛盾：** 资源少、信息少、要做的事最多。先救容易救的还是先去找最难救的？

**关键节点：**

| 节点 | 选择 | 影响 |
|------|------|------|
| 首批单位去哪 | 人口密集区 / 关键设施 / 随机 | 初期幸存者救出率 |
| 侦察策略 | 全面侦察 / 重点侦察 / 边救边探 | 信息获取速度 vs 救援时间 |
| 空投物资接收 | 立即派人 / 等顺路 / 放弃 | 物资到账时间 |
| 第一次余震 | 撤出危险区 / 继续救援 | 单位安全 vs 救援进度 |

### 3.3 攻坚期（指挥阶段后半段）

**时间：** 后 1/2 全局时间

**特征：** 信息较完整、受困者陆续进入重伤/死亡、增援到达、次生灾害扩散

**典型操作循环：**

```
① 评估剩余幸存者分布 → ② 分配增援力量 → ③ 处理紧急事件
                                          ↘ 控制次生灾害
                                          ↘ 攻坚高难度废墟
```

**核心矛盾：** 救剩下的人越来越难（时间/资源成本递增），是否值得投入？

**关键节点：**

| 节点 | 选择 | 影响 |
|------|------|------|
| 增援分配 | 补充前线 / 开新战线 / 替换疲劳单位 | 全局效率 |
| 重大次生灾害 | 全力控制 / 放弃受灾区域 / 局部控制 | 灾害蔓延范围 |
| 物资紧缺 | 优先医疗 / 优先破拆 / 向外界求援 | 不同单位效率 |
| 上级命令 | 服从 / 抗命 / 协商 | 外部评价 vs 自主权 |
| 媒体关注 | 主动回应 / 冷处理 / 利用舆论争取资源 | 外部支持度 |

### 3.4 收尾阶段

**场景：** 倒计时逼近 / 伤亡已成定局 / 幸存者安置

**流程：**

| 环节 | 内容 |
|------|------|
| 停止大规模搜救 | 时间不足以再进行有效救援 |
| 转为安置与防疫 | 建立安置点、消杀、分发生活物资 |
| 灾情评估 | 统计伤亡、损失、次生灾害控制情况 |
| 撤离准备 | 组织幸存者转移、设备回收 |

**核心矛盾：** 是最后一搏去救可能还活着的人，还是转向收尾提高灾后评分？

## 五、随机事件系统

### 5.1 事件类型

| 类型 | 举例 | 呈现方式 |
|------|------|---------|
| 灾害链 | 余震→燃气泄漏→爆炸→火灾 | 弹窗+后续需手动处理 |
| 人物故事 | 发现一位被困教师保护着学生 | 多阶段叙事选择 |
| 道德困境 | 救 5 个轻伤还是 1 个重伤 | 弹窗 2-3 选项 |
| 上级指令 | "立即优先救援学校区域" | 弹窗 + 抗命后果 |
| 媒体舆论 | 记者报道你们的进展 | 影响后续外部支持 |
| 国际援助 | 外国救援队到达，但需协调 | 弹窗+手动安排 |

### 5.2 触发规则

```
触发 = 条件判断 + 概率抽取

条件类型：
  ├── 时间触发 —— 游戏进行到第 X 分钟
  ├── 状态触发 —— 某区域损毁达阈值 / 某单位到达某地
  ├── 连锁触发 —— 前置事件完成后激活后续
  └── 随机触发 —— 在条件池中按权重抽取

频次：每局 5-8 次事件（低频率高质量）
```

### 5.3 事件链示例

```
事件 A：余震发生
  ├─ 选「立即撤离」→ 单位安全，但错过救援窗口
  └─ 选「继续救援」→ 触发事件 B

事件 B：建筑二次坍塌，队员被困
  ├─ 选「派另一队救援」→ 消耗时间，队员救出
  ├─ 选「自救」→ 队员受伤概率高
  └─ (连锁) 事件 C：队员家属质问
```

### 5.4 外部影响系统

| 外部势力 | 影响机制 | 玩家应对 |
|----------|---------|---------|
| 上级 | 下达命令 / 撤职威胁 / 资源调配权 | 服从 / 抗命 / 谈判 |
| 媒体 | 正面/负面报道 → 社会捐赠增减 | 主动联系 / 冷处理 |
| 国际援助 | 额外单位+物资 / 协调成本 | 接受 / 拒绝 / 有条件接受 |

### 6.3 技能树（专精方向示例）

以救援队为例：

```
救援队 Lv.3 → 选择专精：
  ├── 破拆专精
  │     ├── 液压破拆（破拆速度 +20%）
  │     ├── 混凝土切割（重度废墟效率 +30%）
  │     └── 支撑加固（二次坍塌保护 +40%）
  │
  ├── 狭小空间救援
  │     ├── 管道穿行（可进入狭窄管道）
  │     ├── 绳索技术（高空/深井救援）
  │     └── 微型破拆（精准破拆减少二次伤害）
  │
  ├── 高空救援
  │     ├── 云梯操作（高层建筑救援）
  │     ├── 索降技术（快速下降）
  │     └── 高空稳定（大风天作业能力）
  │
  └── 水上救援
        ├── 潜水救援（淹没区域搜救）
        ├── 充气艇操作（水面运输）
        └── 水下破拆（水下障碍清除）
```

### 6.4 永久伤亡

- 单位在执行危险任务时可能受伤
- 轻伤：治疗后恢复，士气下降
- 重伤：需野战医院救治，恢复后可能永久降低属性
- 阵亡：永久损失，装备回收，其他单位士气大幅下降
- 阵亡单位经验可部分继承给新补充的单位

### 6.5 增援时间线

| 时间点 | 增援内容 |
|--------|---------|
| 开局 | 救援队×2、医疗队×1、消防队×1 |
| 第 3 分钟 | 救援队×1、工程组×1 |
| 第 6 分钟 | 医疗队×1、物资运输组×1 |
| 第 9 分钟 | 重型设备组×1、通讯组×1 |
| 国际援助（特定时间） | 外国救援队×2、野战医院×1 |

## 七、多周目与重玩价值

| 功能 | 说明 |
|------|------|
| 随机生成 | 每局城区布局、建筑分布、受困情况、事件池随机，无重复 |
| 事件分支 | 同一事件的不同选择导向完全不同的后续 |
| 多结局 | 评分 S/A/B/C/D/E 各有不同叙事结尾 |
| 指挥官技能树 | 多局积累经验点，解锁新技能影响后续开局 |
| 基地建设 | 局外基地升级影响局内初始状态 |
| 图鉴收集 | 已遭遇灾害/单位/事件的档案记录，隐藏内容待发现 |
| 成就系统 | 特殊条件解锁成就徽章 |
| 挑战模式 | "黄金72小时""孤城""夜袭""物资归零"等特殊限制 |
| 难度解锁 | 通关解锁更高难度和特殊开局天赋 |
| 全局统计 | 总救援人数、总游戏时长、各单位使用频率等数据 |

## 八、竞品分析与差异策略

### 8.1 竞品格局

|------|------|---------|---------|---------|---------|---------|
| The Big One（1990） | 城市管理RTS | ★★ | ★★ | ★★★ | ★ | ★★ |
| 灾难大师（手游） | 多灾种策略 | ★★ | ★★ | ★★ | ★ | ★★ |
| Operator（itch.io） | 极简调度 | ★ | ★ | ★★★ | ★★★ | ★★ |
| Earthquake Rescue Beta | 教育模拟 | ★★★ | ★★ | ★ | ★ | ★★ |
| 急难先锋系列 | 综合应急 | ★★ | ★★★ | ★★ | ★ | ★★★ |
| 911 Operator | 接警调度 | ★ | ★ | ★★ | ★★★ | ★★ |
| 玩命救援模拟（手游） | 多灾种经营 | ★★ | ★★ | ★ | ★ | ★ |
| Rescue Ops Simulator（Steam） | 第一人称搜救 | ★★ | ★★★ | ★★★ | ★★ | ★★★ |

**共同短板：** 要么做"通用救援"不专攻地震，要么做了地震但操作浅（点一下单位自动完成）。没有一款在地震救援的垂直领域做深做透。

**我们的定位：** 在地震救援这个细分赛道上做到最专业，同时通过深度可调系统兼顾不同玩家。

### 8.2 五大差异点

#### 差异一：地震破坏模型深度

| 竞品做法 | 我们的做法 |
|---------|-----------|
| 建筑随机倒塌，不分类型 | 按建筑结构分类：砖混/框架/钢结构/老宅，每种倒塌模式不同（pancake/倾斜/悬挑/粉碎性） |
| 损伤只分完好/倒塌两态 | 结构完整性百分比：80%→60%→40%→20%→倒塌，不同阈值触发不同风险 |
| 地震是一次性事件 | 余震概率模型：根据主震级+地质条件计算余震序列，可预测但不可精确预报 |
| 土壤不考虑 | 土壤液化系统：砂土地震后液化，建筑倾斜下沉，救援难度大幅增加 |
| 无视建筑内部 | 内部结构模拟：房间布局、家具位置影响受困者位置和救援路径 |

**深度可调：** 简单模式用随机倒塌，专家模式开启完整地震物理模型。

#### 差异二：微观救援操作（战术级）

竞品普遍是"派单位→等待→完成"的黑箱。我们拆开黑箱：

```
普通游戏：  派救援队 → 等待 10 秒 → 救出 3 人 ✓

我们的做法：
阶段一：抵达评估
  └─ 评估废墟结构 → 稳定 / 不稳定（有二次坍塌风险）

阶段二：选择切入方案
  ├─ 顶部切入（安全但慢）
  ├─ 侧面切入（均衡）
  └─ 底部切入（快但危险）

阶段三：破拆执行
  ├─ 消耗行动力逐步推进
  ├─ 可能触发坍塌风险 → 选择加固 / 撤离
  └─ 破拆进度可视化

阶段四：接触受困者
  ├─ 评估伤情（轻伤/重伤/危重）
  └─ 选择救出顺序 → 逐个救出

阶段五：移交医疗
  └─ 分类标记 → 不同颜色标记不同紧急程度
```

**深度可调：** 简单模式"一键救援"，专家模式逐层操作。

#### 差异三：信息不对称与侦察

| 竞品做法 | 我们的做法 |
|---------|-----------|
| 所有建筑信息直接显示 | 三层迷雾：地图迷雾（未探索区域）+建筑迷雾（外部可见内部不知）+人员迷雾（只能听到声音不确定位置） |
| 不需要侦察 | 多手段侦察：目视（速度快信息少）/无人机（范围大精度中）/搜救犬（精度高范围小）/生命探测仪（定位准但慢） |
| 信息 100% 准确 | 信息可信度系统：不同侦察手段返回的信息带置信度标记（确认/存疑/推测） |

#### 差异四：受困者个体化

竞品的受困者是数字，我们的受困者是"人"：

- 每个受困者有名字、年龄、身份
- 人物关系网：受困者之间可能有关系（父女/师生/邻居），救出一人后可获得其他受困者线索
- 救出/未救出都有结局交代：战报中看到未被救出者的名字和故事，强化情感冲击
- 救援队员心理反应：大规模伤亡影响队员士气，可能导致 PTSD 事件

**深度可调：** 简单模式受困者为数字统计，普通模式显示姓名年龄，专家模式开启完整人物关系网。

#### 差异五：垂直深度自由调节

| 维度 | 简单（默认） | 普通 | 专家 |
|------|------------|------|------|
| 地震破坏 | 随机简化 | 按建筑类型 | 完整物理模型+土壤液化 |
| 救援操作 | 一键完成 | 2-3 步操作 | 完整五阶段破拆 |
| 信息迷雾 | 全部可见 | 建筑迷雾 | 完整三层迷雾+置信度 |
| 受困者 | 数字统计 | 显示姓名年龄 | 完整人际关系+故事 |
| 物资管理 | 自动分配 | 手动调配 | 完整补给链+护送 |
| 天气影响 | 关闭 | 开启 | 动态天气+预报 |

玩家可在设置中逐项独立调节，每条设置附带一句话说明它的影响。新手从"简单"起步，熟悉后逐步向"专家"过渡。

## 九、边界声明

| 不做 | 原因 |
|------|------|
| 3D 画面 | 俯视图 2D 是核心风格，降低美术成本 |
| 真实物理模拟 | 抽象化灾害模型，重玩法轻模拟 |
| 多人在线 | 单人指挥游戏，不设计联机模式 |
| 内购/抽卡 | 买断制或一次性付费 |
| 真实城市地图 | 虚构城市主题，避免真实地理数据合规问题 |
| UGC 编辑器 | MVP 阶段不开放自制关卡 |
| 移动端首发 | 以 PC 端为主，移动端后续考虑 |
| 多语言首发 | MVP 仅中文 |
