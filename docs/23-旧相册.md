# 旧相册 — 产品功能说明书

## 一句话定义

暖色调老照片质感的本格怀旧探索游戏——翻开一本旧相册，走进 80-90 年代的记忆场景。触碰旧物，唤醒一段段"活过来的老照片"。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：80-90 年代出生的人（30-45 岁）**

| 维度 | 描述 |
|------|------|
| 身份 | 80 后、90 初，有明确年代记忆 |
| 使用场景 | 晚上独自一人，想"怀旧"一下 |
| 情感需求 | 想回到那个简单的年代待一会儿，不是伤感，是温暖 |
| 游戏习惯 | 不一定玩游戏，可能只是"试试看" |

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 80-90 年代怀旧是消费力强且有明确情感需求的题材 |
| **刚需** | 市场上缺少"沉浸式年代探索"产品（不只是图片/视频） |
| **改善型** | 怀旧类手游/内容流于表面（一张张图翻过去） |
| **改善型** | 经历过那个年代的人想带孩子"看爸妈小时候" |

---

## 二、解决方案与核心功能

### 2.1 解决方案概述

旧相册是一个第一人称 3D 场景的怀旧探索游戏。玩家翻开一本旧相册，走进 8 个年代场景。触碰旧物触发"照片活了"的记忆动画演出。

核心设计：
- **老照片视觉系统** — 暖黄调、胶片颗粒、暗角、下午四点的金色光线
- **8 章记忆场景** — 筒子楼→校门口→游戏厅→卧室→老街→溜冰场→过年→告别
- **物品交互触发记忆** — 每个物品唤醒一段 5-15 秒的动画+配音
- **配音独白** — 轻声口吻，像自己跟自己说话
- **图鉴收集** — 6 类 52 张记忆照片，凑齐解锁"时光特辑"动画

### 2.2 核心功能清单

1. **老照片视觉系统** — 暖黄/颗粒/暗角/光晕
2. **8 章记忆场景** — 每章 3-5 分钟探索内容
3. **物品交互触发记忆** — 触碰→5-15 秒动画演出+配音
4. **配音独白** — 轻声口吻，不是朗诵腔
5. **环境音沉浸** — 蝉鸣、电扇、电视剧声、街头叫卖
6. **图鉴收集** — 6 类各 8-10 张记忆照片，凑齐解锁"时光特辑"
7. **隐藏彩蛋** — 只有真 80 后才懂的冷门细节
8. **组合触发** — 先后拿两物触发深层记忆
9. **"咔嚓"拍照** — 自定义相册
10. **结局走马灯** — 通关后逐张翻过

## 三、竞品与差异化分析

| 竞品 | 优点 | 缺点 | 差异 |
|------|------|------|------|
| 怀旧短视频/图文 | 传播快 | 碎片化，深度不够 | 旧相册是沉浸式 3D 探索，非被动消费 |
| 模拟经营类怀旧游戏 | 有玩法 | 非纯粹怀旧 | 旧相册没有玩法，只有探索和感受 |
| 老照片修复/上色工具 | 实用 | 无情感体验 | 旧相册是情感体验产品 |

**差异化优势：** immersive 3D 沉浸 + 年代细节真实性 + 情感落点温暖不煽情。

## 五、核心模块详解

### 5.1 8 章场景（每章 3-5 分钟）

**第 1 章 家·筒子楼**：黑白电视盖钩花布（全家看《西游记》）、缝纫机（妈妈改校服）、铁皮暖壶（外婆说"别碰烫"）、吊扇（躺凉席上看它转）。

**第 2 章 校门口**：辣条五毛一包、干脆面集水浒卡、三八线、橡皮筋"小皮球"、眼保健操广播。

**第 3 章 游戏厅**：街机搓拳皇 97 大招、游戏币一块钱四个、录像厅五毛看《大话西游》。

**第 4 章 我的卧室**：墙上小虎队海报、磁带机铅笔倒带、课本涂鸦圣斗士、贴纸收集本。

**第 5 章 老街**：新华书店站半小时、报刊亭《童话大王》《故事会》、冰棍车白糖冰棍三分。

**第 6 章 溜冰场/KTV**：四轮旱冰鞋、筒灯球光斑、点歌本《真心英雄》画五颗星。

**第 7 章 过年**：鞭炮、压岁红包、黑白→彩电换新看 1997 春晚赵本山。

**第 8 章 告别**：搬家空房间、毕业黑板写"再见"、毕业照后来再没见过。

### 5.2 交互系统

观察（对准 2 秒）→ 拿起（E 键）→ 记忆演出（动画+配音+环境音）→ 照片解锁加入图鉴。

组合触发：先拿 A 再拿 B（关联物品）触发连锁回忆，如粉笔+橡皮筋→"课间十分钟"。

隐藏触发：无提示角落细节，盯着看 2 秒才触发。

"咔嚓"拍照（F 键）：截取当前画面加入自定义相册。

### 5.3 记忆演出设计

5-15 秒封闭动画段落。画面转为更暖的记忆滤镜。半透明形象出现"小时候的你"和"当年的他们"。配音腔调是轻声回忆："我记得这台电视……" 结束回到当前场景，物品对应照片加入图鉴。

## 六、用户流程

```
翻开相册（主界面）→ 选一张照片 → 进入对应章节
  ↓
自由探索 WASD+鼠标 → 发现物品 → 交互触发记忆
  ↓
隐藏/组合触发 → 图鉴解锁
  ↓
8 章全完成 → 结局走马灯
  └─ 所有照片翻过 + "谢谢你还记得它们"
```

| 付费模式 | 定价 | 依据 |

## 八、落地路径

### 8.1 MVP

老照片视觉 post-processing + 第 1 章·筒子楼完整场景 + 玩家移动环顾 + 物品交互 + 1 条记忆演出 demo + 相册主界面。

### 8.2 第一步验证

**最关键假设：** 物品交互→记忆演出这个闭环能唤起情感共鸣。

**验证方法：** 做一个"筒子楼"场景 demo，招募 10 个 80 后试玩。关键指标：是否有人会在某个物品前"停一下"而不是机械地交互完所有物品就走。如果有人停下超过 5 秒，说明场景唤起了真实共鸣。

## 九、风险与预期反馈

| 预期槽点 | 应对方案 |
|---------|---------|
| "就是看图片" | 3D 场景可自由探索，比看图片沉浸 |
| "我的童年不是这样" | 8 章覆盖最广泛共性的年代记忆 |
| "太煽情了" | 配音和文案控制"温暖"而非"伤感" |
| "玩法在哪" | 没有玩法，只有探索和感受 |

---

## 十、边界声明

| 不做 | 原因 |
|------|------|
| 像素风格 | 与老照片写实质感冲突 |
| 战斗/动作/解谜 | 纯探索怀旧 |
| 多人联机 | 怀旧是私人的 |
| 内购抽卡 | 买断制 |
| UGC 编辑器 | MVP 不做 |
| 移动端首发 | 3D 需要性能 |
| 强行煽情 | 落点是温暖的回望 |
