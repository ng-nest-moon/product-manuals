# 旧相册 — 产品功能说明书

## 一句话定义

暖色调老照片质感的本格怀旧探索游戏——翻开一本旧相册，走进 80-90 年代的记忆场景。触碰旧物，唤醒一段段"活过来的老照片"，收集一代人共同的流行文化记忆碎片。

---

## 二、核心功能清单

1. **老照片视觉系统** — 暖黄调、胶片颗粒、暗角、柔光晕，模拟 80 年代老照片质感，画面永远有下午四点的金色光线
2. **8 章记忆场景** — 从童年到告别，每章一个可自由探索的 3D 场景，每个场景约 3-5 分钟探索内容
3. **物品交互触发** — 触碰旧物触发"照片活了"的记忆动画演出，每次 5-15 秒
4. **配音独白** — 每段记忆配轻声口吻的配音，像"你"在心里跟自己说话，不是朗诵腔
5. **环境音沉浸** — 蝉鸣、电扇嗡嗡声、远处电视剧声、自行车铃铛、街头叫卖声
6. **图鉴收集系统** — 6 大类各 8-10 张记忆照片收集，凑齐一类解锁一段"时光特辑"完整动画
7. **隐藏彩蛋** — 只有真 80 后才懂的冷门细节（墙上某部冷门动画的海报、犄角旮旯的老物件）
8. **组合触发** — 先后拿起两个物品触发更深层记忆链（如拿起粉笔 + 橡皮筋 → 跳皮筋回忆）
9. **"咔嚓"拍照** — 玩家可在场景中按快门，把触动自己的画面保存进自定义相册
10. **相册主界面** — 主菜单就是一本书页泛黄的旧相册，每章对应一张不同年代的照片
11. **结局走马灯** — 通关后所有解锁的照片以走马灯形式逐张翻过，落点温暖而不煽情

## 三、模块详解

### 3.1 章节结构

#### 3.1.1 第1章：家·筒子楼

**场景描述：** 走廊堆满杂物，各家门口放煤炉，公共水池传来哗哗水声。走进家门，客厅狭小，黑白电视上盖着钩花布。

| 可交互物品 | 触发记忆 |
|-----------|---------|
| 黑白电视 | 全家围坐看《西游记》，孙悟空三打白骨精 |
| 缝纫机 | 妈妈脚踩缝纫机的声音，她在改你的校服 |
| 铁皮暖壶 | 外婆往暖壶里灌开水，说"别碰，烫" |
| 吊扇 | 夏天躺凉席上盯着吊扇转，慢慢睡着 |
| 搪瓷缸 | 爸爸用搪瓷缸泡茶，缸底印着"先进工作者" |
| 墙上奖状 | 小学第一次考双百，爸妈高兴了一星期（隐藏触发） |
| 铁皮青蛙 | 上紧发条看它蹦哒，能玩一下午 |

**环境音：** 走廊邻居炒菜声、公共水池水声、收音机评书声、远处蝉鸣。

---

#### 3.1.2 第2章：校门口

**场景描述：** 铁栅栏校门、传达室老头、门口一溜小摊。地上画着跳房子格子，操场传来广播体操音乐。

| 可交互物品 | 触发记忆 |
|-----------|---------|
| 辣条（五毛一包） | 放学买一包，和小伙伴分着吃，辣得吸溜嘴 |
| 干脆面 + 卡片 | 拆开就是为了里面的水浒卡，面给同桌吃 |
| 粉笔 | 下课在黑板上画"三八线"，谁过线谁请客 |
| 橡皮筋 | 女生跳皮筋"小皮球，架脚踢" |
| 值日表 | 轮到你值日那天，要早到半小时洒水扫地 |
| 眼保健操广播 | "为革命保护视力，预防近视……"（隐藏触发） |
| 课本（包书皮） | 新学期发新书，回家用挂历纸包书皮 |

**环境音：** 课间打闹声、广播体操口令、小贩叫卖"冰棍——雪糕——"。

---

#### 3.1.3 第3章：游戏厅

**场景描述：** 昏暗的房间，排排列街机屏幕闪着光，烟雾缭绕。墙上手写海报"拳皇97 新到"。隔壁录像厅门口小黑板写着今日放映。

| 可交互物品 | 触发记忆 |
|-----------|---------|
| 街机摇杆 | 搓"下前下前拳"发大招，围观的人比玩的还急 |
| 游戏币 | 一块钱四个，技术差三分钟就没了 |
| 录像厅售票口 | 五毛看一场，周星驰的《大话西游》看了三遍 |
| 手写海报 | 红纸黑字"今日上映：逃学威龙" |
| 租书摊 | 一本《七龙珠》翻到烂，排队等下一卷（隐藏触发） |

**隐藏彩蛋：** 街机屏幕里能看到你在打《拳皇97》，选八神庵放大招的像素动画。

**环境音：** 街机按键啪啪声、角色必杀技音效、录像厅传来打斗声。

---

#### 3.1.4 第4章：我的卧室

**场景描述：** 十几平的小房间，墙上贴满海报，书桌上堆着课本和漫画，抽屉里藏着磁带和贴纸。

| 可交互物品 | 触发记忆 |
|-----------|---------|
| 墙上海报（小虎队） | 省下早餐钱买海报，贴在床头，觉得他们太帅了 |
| 磁带机 | 用铅笔倒带，听《爱》听了上百遍 |
| 课本涂鸦 | 语文书空白处画了圣斗士，被老师抓到 |
| 贴纸收集本 | 各种不干胶贴纸——还珠格格、灌篮高手 |
| 抽屉里的小纸条 | 上课传的纸条，叠成方形"你收到请回复"（隐藏触发） |

**隐藏彩蛋：** 翻课本涂鸦时，某页下面画了一行小字"**喜欢 XX 的第 38 天"。

**环境音：** 窗外小伙伴喊"下来玩"、磁带转动声、自行车铃声。

---

#### 3.1.5 第5章：老街

**场景描述：** 一条不宽的老街，两边是梧桐树。新华书店玻璃柜台、报刊亭挂满杂志、修车摊老头在打气、冰棍车白色箱子绑在自行车后座。

| 可交互物品 | 触发记忆 |
|-----------|---------|
| 新华书店柜台 | 站在柜台前看《新华字典》附赠的附录，一站半小时 |
| 报刊亭 | 买《童话大王》《故事会》，封面插图现在还记得 |
| 修车摊 | 自行车扎胎了，修车大爷补胎，你蹲旁边看 |
| 冰棍车 | 白糖冰棍三分，绿豆五分，用嘴嗦着吃 |
| 二八大杠 | 偷骑爸爸的车，个子矮只能掏裆骑 |

**环境音：** 自行车铃铛声、报摊收音机放歌、远处爆米花机"嘭"一声。

---

#### 3.1.6 第6章：溜冰场/KTV

**场景描述：** 溜冰场灯光昏暗，筒灯球旋转洒下光斑，音响放着小虎队。隔壁 KTV 包间有人吼《心太软》。

| 可交互物品 | 触发记忆 |
|-----------|---------|
| 旱冰鞋 | 四轮旱冰鞋，初学者扶着栏杆一步步挪 |
| 筒灯球 | 光斑在墙上转，你假装自己是明星在开演唱会 |
| 点歌本 | 厚厚一本手写歌单，翻到《真心英雄》画了五颗星 |
| 麦克风 | 第一次在大家面前唱歌，腿在抖 |

**环境音：** 溜冰鞋擦地的刷刷声、音乐混响、隔壁跑调的歌声。

---

#### 3.1.7 第7章：过年

**场景描述：** 奶奶家，桌上摆满炸货，窗外零星鞭炮声，电视里放着春晚。墙上挂着日历——1997。

| 可交互物品 | 触发记忆 |
|-----------|---------|
| 鞭炮 | 拿香去点，跑慢了震得耳朵嗡嗡响 |
| 压岁红包 | 姥姥塞过来，嘴上说"不要不要"手已经接住了 |
| 黑白→彩电 | 那年奶奶家换了彩电，看春晚赵本山觉得颜色真好看 |
| 糖葫芦 | 外面糖衣咬下去嘎嘣脆，酸得眯眼睛 |
| 日历 | 撕日历是每天早上的仪式感（隐藏触发） |

**隐藏彩蛋：** 电视里放的是 1997 年春晚——赵本山《红高粱模特队》，你可以站着看完一小段。

**环境音：** 鞭炮声忽远忽近、春晚笑声、厨房炸丸子的滋啦声。

---

#### 3.1.8 第8章：告别

**场景描述：** 搬家/毕业——老房子空了，地板上只有搬家留下的纸屑痕迹。你站在门口最后看一眼。或者是毕业那天，教室里桌椅搬空，黑板上写着"再见"。

| 可交互物品 | 触发记忆 |
|-----------|---------|
| 空房间 | 这里曾经是家，现在只剩下回声 |
| 黑板上的字 | "毕业了，常回来看看"——鼻子一酸 |
| 地上的粉笔头 | 最后一节课，没人去捡 |
| 毕业照 | 每个人都在笑，后来有些人再没见过 |
| 门 | 走出去，关上，回不去了 |

**情绪落点：** 路过每个场景的"回忆快照"快速闪过，最后一幕回到翻开相册的手——你慢慢合上相册。

**环境音：** 空旷房间的风声、远处模糊的嬉笑声、快门声。

### 3.2 视觉风格

| 参数 | 设定 |
|------|------|
| 主色调 | 暖黄（#E8D5B7）、琥珀（#C49A6C）、旧米色（#F5E6D0） |
| 对比度 | 偏低，模拟老照片褪色感 |
| 颗粒度 | 中等胶片颗粒，轻微噪点 |
| 暗角 | 四角渐暗，聚焦视线于画面中心 |
| 光晕 | 柔光，模拟老镜头的光晕散射 |
| 光照 | 永远下午四点的金色斜阳，长影子 |
| 过渡效果 | "照片闪烁" + 相纸撕裂边缘 + 手动过片声 |
| UI 字体 | 仿手写体 + 老式打印体混排，不要像素风 |

### 3.3 交互系统

#### 3.3.1 显性交互（发微光）

- 物品周围有暖色微光，玩家走近光增强
- 按 E 拿起，物品旋转展示
- 配音开始："我记得这个……"
- 画面淡出到记忆演出，再淡出回到当前

#### 3.3.2 隐藏交互（无提示）

- 某个角落有一张不起眼的糖纸，玩家走近盯着看 2 秒才触发
- 触发后：画面没太大动静，但相册里多了一张照片
- 这类交互不强制，纯给探索型玩家的惊喜

#### 3.3.3 组合触发

- 先拿起物品 A，再拿起物品 B 且 A 还在手上
- 触发条件：A 和 B 在设定上有关联
- 例：粉笔 + 橡皮筋 → "课间十分钟：女生跳皮筋，男生在边上捣乱"
- 例：干脆面 + 水浒卡 → "拆开面的第一件事就是翻卡"
- 例：磁带 + 铅笔 → "用铅笔把卷进去的磁带转出来"

#### 3.3.4 "咔嚓"拍照

- 玩家在任何时候可按快门键（F）
- 当前画面被截取，以"拍立得"相框效果加入自定义相册
- 自定义相册可翻看、可删除
- 通关后自定义相册和游戏相册一起在走马灯中展示

### 3.5 记忆演出设计

每段记忆演出是一个 **封闭动画段落**，玩家不能操作，沉浸观看。

| 要素 | 说明 |
|------|------|
| 时长 | 5-15 秒，不长不短，刚好唤起画面就结束 |
| 画面 | 场景转为"记忆滤镜"——更暖、更软、边缘模糊 |
| 人物 | "小时候的你"和"当年的他们"以半透明形象出现 |
| 音效 | 环境音渐变到当年的声音（电视声、叫卖声、蝉鸣） |
| 配音 | 成年后的你轻声说："我记得……" 然后一两句话 |
| 结束 | 画面渐淡回当前场景，刚才拿起的物品在相册里多了一张照片 |

**配音风格示例（不是朗诵腔，就是自己在回忆）：**

> "我记得这台电视。那时候《西游记》一放，整条巷子都能听到片头曲。我搬个小板凳坐最前面，一集都不想错过。"

> "五毛一包的辣条，和小伙伴分着吃。辣得吸溜嘴，但谁都不肯少吃一口。"

## 四、用户流程

```
翻开相册（主界面）
  │
  ├─ 选择一张照片 → 进入对应章节场景
  │     │
  │     ├─ 自由探索（WASD 移动，Mouse 环顾）
  │     ├─ 发现微光物品 → 靠近 → 观察/拿起
  │     │    └─ 记忆演出（动画 + 配音 + 环境音）
  │     │         └─ 照片解锁 → 加入图鉴
  │     ├─ 发现隐藏触发 → 盯着看 → 照片解锁
  │     ├─ 先后拿起组合物品 → 连锁记忆演出
  │     ├─ 按 F 拍照 → 自定义相册追加
  │     └─ 探索完成后 → 退出照片 → 回到相册
  │
  ├─ 翻到下一张照片 → 下一章
  │
  └─ 全部 8 章完成 → 结局走马灯
       ├─ 所有解锁照片按顺序翻过
       ├─ 自定义照片穿插其中
```

## 五、应用场景

### 场景一：一个人的怀旧夜晚

> 晚上十一点，戴着耳机，躺沙发上打开游戏。走进筒子楼，看到那台黑白电视，拿起铁皮暖壶，听到外婆的声音。没哭，但嘴角不自觉上扬了。翻到卧室那章，看到课本涂鸦，笑了出来——想起被老师抓到办公室的那天。一个多小时走完全部 8 章，合上相册，心里暖暖的。

### 场景二：80 后聚会时的"接力怀旧"

> 朋友来家里，看到游戏打开相册界面。一人说"点这个点这个"，记忆演出开始。"对对对！我当年也这样！""你还记得那个吗？……" 变成接力讲当年故事。游戏变成了一场社交怀旧的引子。

### 场景三：带着孩子"看爸妈小时候"

> 你坐在旁边，孩子握着鼠标探索。走到小卖部，拿起干脆面，你告诉他"爸爸小时候为了集齐水浒卡，连续吃了一个月干脆面"。孩子问"水浒卡是什么？" 你翻出手机搜图片给他看。游戏不再是游戏，是两代人之间的对话。

## 六、边界声明

| 不做 | 原因 |
|------|------|
| 像素风格 | 已确定老照片写实风，像素与"老照片质感"定位冲突 |
| 战斗/动作/解谜 | 纯探索怀旧，不加入任何玩法干扰沉浸 |
| 多人联机 | 单人沉浸式体验，怀旧是私人的事 |
| 内购抽卡 | 买断制，不搞任何付费设计 |
| UGC 编辑器 | MVP 不开放自制场景/物品 |
| 移动端首发 | 3D 场景需性能，优先 PC 和主机 |
| 实时联网 | 全程离线可玩，不需要服务器 |
| 强行煽情 | 不刻意催泪，落点是"温暖的回望"而不是"回不去的伤感" |

## 八、落地原则

**三条核心原则：**

1. **细节必须真实**
   - 每一件物品、每一个场景都要有真实的年代依据
   - 不臆造"看起来像 80 年代"的东西
   - 请真实 80 后做细节审核员

2. **不催泪，只唤醒**
   - 记忆演出的情绪基调是"温暖的笑"而不是"感伤的哭"
   - 配音语气是"我记得……"而不是"再也回不去了……"
   - 结局落点是"你还记得它们，它们就还在"

3. **节奏是慢的**
   - 玩家走路速度是"散步"不是"赶路"
   - 没有倒计时、没有目标催促
   - 让玩家想停就停、想走就走
