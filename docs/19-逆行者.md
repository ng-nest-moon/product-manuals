# 逆行者 — 产品功能说明书

## 一句话定义

> 卡通风格的逆向动作平台跳跃游戏——整个世界的时间都在倒流，只有你的意识是清醒的。在倒带的世界中奔跑、跳跃、穿梭，每一次通关都是一次回到起点的逆行之旅。

---

## 一、架构总览

```
表现层（横向卷轴 2D 关卡 + HUD）
 ├── 关卡视图 —— 横向滚动的 2D 关卡场景 / 粒子时间特效
 ├── 角色控制 —— 移动 / 跳跃 / 交互 / 冲刺
 ├── HUD —— 时间流速指示器 / 收集计数 / 关卡进度
 └── 过场动画 —— 章节起止的叙事演出

逆向时间引擎
 ├── 事件录制系统 —— 录制关卡内所有物体的运动轨迹
 ├── 逆向回放系统 —— 将录制的轨迹反向播放
 ├── 玩家隔离层 —— 玩家操作不受逆向影响
 ├── 分层时间系统 —— 不同物体可处于不同时间层级
 └── 时间流速调节 —— 正向 / 逆向 / 暂停 / 变速

关卡系统
 ├── 5 大世界 —— 每世界引入一种新增向规则
 ├── 30+ 关卡 —— 每关 1~3 分钟，逐步增加复杂度
 ├── Boss 战 —— 每世界末尾的逆向 Boss 挑战
 └── 隐藏关卡 —— 收集要素解锁的额外挑战

物体系统
 ├── 敌人体系 —— 10+ 种逆向行为敌人
 ├── 机关体系 —— 平台 / 门 / 尖刺 / 传送带
 └── 交互物体 —— 可拾取 / 可推动 / 可触发

收集成长系统
 ├── 时间碎片 —— 关卡中的主要收集品
 ├── 角色外观 —— 解锁皮肤和特效
 └── 关卡评价 —— 时间 / 收集 / 死亡次数综合评级

叙事层
 ├── 开场设定 —— 世界为何在倒流
 ├── 章节叙事 —— 每世界开闭的动画片段
 ├── 环境叙事 —— 关卡场景中的细节暗示
 └── 终局反转 —— 回到起点的意义揭示

数据层
 ├── 关卡数据 —— 关卡布局 / 物体初始状态 / 事件时间线
 ├── 玩家数据 —— 收集进度 / 解锁外观 / 关卡评级
 └── 设置数据 —— 画面 / 音效 / 控制配置
```

---

## 二、核心功能清单

1. **逆向时间引擎** — 关卡内所有物体（敌人、机关、平台）的运动轨迹录制后逆向回放，玩家操作不受影响
2. **5 大世界** — 逐层叠加逆向规则：逆走 → 逆物理 → 逆因果 → 逆自己 → 混响
3. **30+ 关卡** — 每关 1~3 分钟短平快节奏，逐步增加复杂度
4. **Boss 战** — 每世界末尾一场逆向规则下的 Boss 战
5. **10+ 敌人类型** — 每种敌人有独特的逆向行为模式
6. **时间碎片收集** — 关卡内的主要收集品，用于解锁外观
7. **角色外观系统** — 解锁不同的角色皮肤和特效
8. **关卡评级** — 根据通关时间、收集率、死亡次数给出 S~D 评级
9. **隐藏关卡** — 全收集或特殊条件解锁的额外挑战
10. **叙事驱动** — 完整的故事线，通关心灵治愈

## 三、核心模块详解

### 3.1 逆向时间引擎

**职责：** 驱动整个游戏的核心机制——万物倒流，唯你清醒。

#### 3.1.1 核心原理

| 概念 | 说明 |
|------|------|
| 事件录制 | 每个关卡在后台预录制一段"正向时间线"，记录所有物体的位置、状态变化（约 15~30 秒） |
| 逆向回放 | 玩家进入关卡时，录制的时间线从终点向起点回放 |
| 玩家隔离 | 玩家的操作完全独立于时间线，不受逆向影响 |
| 循环 | 回放结束后自动循环回到终点，形成持续逆向播放 |

#### 3.1.2 分层时间系统

| 层级 | 说明 | 示例 |
|------|------|------|
| 全局逆向 | 关卡中大多数物体的默认时间层，始终逆向运行 | 敌人倒退行走、子弹回收 |
| 时间锚定 | 少数物体不受时间影响，保持静止 | 固定平台、背景装饰 |
| 玩家同步 | 与玩家操作同步的物体 | 可推动的箱子（推一下动一下） |
| 变速层 | 以不同速度逆向运行 | 快速回收的弹幕 vs 慢速倒退的敌人 |

#### 3.1.3 可视化反馈

| 效果 | 说明 |
|------|------|
| 粒子拖尾 | 所有逆向运动的物体带有柔和光晕粒子拖尾，方向指向其运动来源 |
| 时间光晕 | 画面边缘随逆向流速闪烁微光 |
| 逆向音效 | 音效反转播放，形成独特的"倒带"听觉体验 |
| 时间指示器 | HUD 上的漩涡状图标表示当前时间流向 |

### 3.2 角色系统

**职责：** 玩家操控的角色和操作方式。

#### 3.2.1 角色设定

| 项目 | 内容 |
|------|------|
| 名称 | 小回（Rewind） |
| 外观 | 圆润 Q 版小女孩，穿连帽外套，兜帽上有钟表齿轮图案 |
| 特征 | 身边围绕顺时针旋转的微弱光粒，与世界的逆向形成对比 |
| 能力 | 奔跑、跳跃（可二段跳）、冲刺、交互 |

#### 3.2.2 操作

| 操作 | 说明 |
|------|------|
| 方向键 / 摇杆 | 左右移动、上下攀爬 |
| A/跳跃 | 跳跃，空中再按一次二段跳 |
| B/冲刺 | 短距离冲刺，可空中使用，有冷却 |
| 交互键 | 推动物体、触发机关 |

#### 3.2.3 外观系统

| 皮肤 | 解锁方式 | 特效 |
|------|---------|------|
| 默认·小回 | 初始赠送 | 金色光粒 |
| 星辰旅者 | 第 2 世界通关 | 蓝色星尘拖尾 |
| 糖果大师 | 收集 50 碎片 | 彩色糖粒飘落 |
| 雨夜行者 | 第 4 世界通关 | 雨滴反向上升 |
| 时光编织者 | 全碎片收集 | 钟表齿轮环绕全身 |
| 真·逆行者 | 全 S 评级 | 全身轮廓逆向发光 |

### 3.3 关卡系统

**职责：** 5 个世界，每世界引入一种新增向规则，关卡逐步组合。

#### 3.3.1 世界一览

| 世界 | 主题 | 新增规则 | 关卡数 | Boss |
|------|------|---------|--------|------|
| 第 1 世界 | 逆走 | 敌人动作反向 | 6 | **倒退巡逻官**——固定路线巡逻的巨型机械，需要利用它倒退的间隙通过 |
| 第 2 世界 | 逆物理 | 重力/浮力/弹力反向 | 7 | **逆流之眼**——悬浮眼球boss，发射的重力波会局部反转重力方向 |
| 第 3 世界 | 逆因果 | 机关触发顺序反向 | 7 | **因果齿轮**——必须先踩终点开关，再逆序激活所有前置机关才能露出弱点 |
| 第 4 世界 | 逆自己 | 玩家部分操作反向 | 6 | **镜像小回**——复制你的操作但完全镜像反转，你必须战胜"反自己" |
| 第 5 世界 | 混响 | 以上规则随机组合 | 6 | **时间巨兽**——所有规则同时生效，最终战 |

#### 3.3.2 第 1 世界「逆走」

**核心规则：** 敌人的运动轨迹反向播放。

示例关卡：

| 关卡 | 设计 |
|------|------|
| 1-1 逆走初体验 | 一只史莱姆在平台上左右后退。平台很短，等它退到边缘跳过去即可 |
| 1-2 弹幕回收 | 炮台向固定方向发射弹幕，弹幕飞行后**收回到炮口**。你要站在弹幕消失的位置等它回收后前进 |
| 1-3 后退军团 | 三个士兵在不同的路线上倒退巡逻，需要观察它们的后退节奏找到安全路径 |
| 1-4 回收之桥 | 间歇喷泉把一块块平台碎片喷向空中拼成桥，碎片飞回后桥断开。你要在桥完整时冲过去 |
| 1-5 混乱路口 | 多种敌人混合，需要在移动平台上来回躲避 |
| 1-Boss 倒退巡逻官 | 巨型机械在长方形场地四边倒退巡逻，发射的激光也会回收。场地中有掩体，需要利用掩体观察巡逻节奏，在激光回收的瞬间移动 |

#### 3.3.3 第 2 世界「逆物理」

**核心规则：** 物理法则反向——水往天上流，物体向上落。

| 关卡 | 设计 |
|------|------|
| 2-1 逆流瀑布 | 瀑布从下往上喷涌，水滴逆向上升。你可以踩着上升的水滴作为平台跳上去 |
| 2-2 反向弹力 | 弹力花会把你吸向地面而不是弹起。跳到弹力花上方会被拉下，利用这个机制到达下层平台 |
| 2-3 水上逆行 | 水面有一颗颗气泡从空气中凝结并落入水中（逆向：气泡从水底升到水面→破裂→消失）。你需要踩着尚未破裂的气泡通过水面 |
| 2-4 逆转之塔 | 垂直关卡，从顶部出发向底部终点前进。所有掉落平台逆向"上升"——你等它们升上来再站上去 |
| 2-5 重力迷城 | 局部重力区交替出现，一个区域重力向上，一个区域重力正常 |
| 2-Boss 逆流之眼 | Boss 悬浮在空中，间歇性发射重力波。重力波击中区域后重力反转（天花板变地板）。需要利用重力反转到达 Boss 位置攻击它 |

#### 3.3.4 第 3 世界「逆因果」

**核心规则：** 机关触发顺序反向——先看到结果，再触发原因。

| 关卡 | 设计 |
|------|------|
| 3-1 先开门再踩 | 一扇门已经打开，你需要走到门另一边的机关上把门"关上"（实际上是逆向解锁）才能让门保持开启状态通过 |
| 3-2 逆向电梯 | 电梯已经在顶层，你走进电梯，电梯先下降再上升——逆向理解：上升→停靠→下降 |
| 3-3 通道重组 | 移动平台已经在终点等待，你站上去后它向起点移动——你被送到起点的过程中，原本拦路的障碍"逐个消失"（逆向：障碍逐个出现时你已通过） |
| 3-4 碎镜重圆 | 一面已经碎裂的镜子，你接近时碎片飞回拼好，拼好的瞬间映出隐藏通道的位置 |
| 3-5 因果链 | 多组机关连环触发，需要找到最末端的结果逆向反推触发顺序 |
| 3-Boss 因果齿轮 | 场地中央一个巨型齿轮，齿轮周围有 5 个开关。Boss 的弱点在齿轮中心，但只有在 5 个开关被按正确顺序触发时才会暴露。你必须从齿轮的最终状态（弱点已暴露）逆向推理正确的触发顺序 |

#### 3.3.5 第 4 世界「逆自己」

**核心规则：** 玩家的部分操作被镜像反转。

| 规则 | 说明 |
|------|------|
| 左右反转 | 按左向右走，按右向左走 |
| 跳跃反转 | 按跳跃键触发的是"反跳"——原地微蹲（在特定机关上有用） |
| 交互反转 | 交互键变为"反交互"——推开变成拉近 |

但世界中有 **"清醒区域"** ——规则短时间内恢复正常，提供喘息和操作窗口。

| 关卡 | 设计 |
|------|------|
| 4-1 镜像初临 | 简单的直线关卡，只有左右反转。沿途有方向提示箭头 |
| 4-2 反转跳跃 | 需要利用"反跳"踩中下沉机关，然后在清醒区域正常跳跃通过 |
| 4-3 混乱支配 | 左右反转 + 跳跃反转混合，中间穿插清醒区域 |
| 4-4 全反转 | 所有操作反转，包括交互 |
| 4-5 节奏切换 | 规则在"正常"和"全反转"之间按固定节奏切换，你需要跟上节奏 |
| 4-Boss 镜像小回 | Boss 是你的镜像复制体，完全复制你的操作但镜像反转。你往左它往右，你跳它蹲。你必须利用清醒区域的短暂时间攻击它，同时注意不要让镜像把你逼入死角 |

#### 3.3.6 第 5 世界「混响」

**核心规则：** 前 4 世界的规则随机混合。

| 关卡 | 规则组合 |
|------|---------|
| 5-1 逆走 + 逆物理 | 敌人倒退 + 重力局部反转 |
| 5-2 逆因果 + 逆自己 | 机关先结果后触发 + 玩家操作反转 |
| 5-3 三重奏 | 逆走 + 逆物理 + 逆因果 |
| 5-4 全方位 | 四种规则同时生效，但都有所削弱（强度减半） |
| 5-5 混响长廊 | 每 10 秒随机切换一种规则组合 |
| 5-Boss 时间巨兽 | Boss 会周期性改变当前生效的规则组合。它有三个阶段：第一阶段只激活一种规则、第二阶段两种、第三阶段四种同时低强度生效 |

### 3.4 敌人与机关

**职责：** 提供逆向规则下的挑战和平台跳跃的障碍。

#### 3.4.1 敌人总览

| 敌人 | 逆向行为 | 首次出现 |
|------|---------|---------|
| 史莱姆 | 左右倒退弹跳 | 1-1 |
| 炮台 | 弹幕飞出后收回 | 1-2 |
| 巡逻兵 | 倒退巡逻 | 1-3 |
| 飞行眼 | 逆向随机漂移 | 1-4 |
| 尖刺花 | 从地面逆向钻出（先出现再缩回） | 2-1 |
| 气泡鱼 | 从水面下"飞回"空中（逆向跳跃） | 2-3 |
| 引力怪 | 改变局部重力方向 | 2-4 |
| 时序守卫 | 在结果位置出现，然后逆向走回触发位置 | 3-1 |
| 镜面守卫 | 位置与玩家成镜像 | 4-2 |
| 混响兽 | 按固定节奏切换逆向行为模式 | 5-3 |

#### 3.4.2 机关总览

| 机关 | 逆向行为 |
|------|---------|
| 移动平台 | 从终点向起点移动 |
| 断裂桥 | 碎片从深渊飞回拼合→完整→再断裂循环 |
| 开关门 | 门先打开，踩开关后"关上" |
| 喷泉平台 | 碎片向上喷出拼成平台→平台完整→碎片落下回收 |
| 重力区 | 正常/反转重力交替 |
| 清醒区 | 解除当前世界的逆向规则，持续 3~5 秒 |
| 弹力花 | 将玩家吸向地面 |
| 上升水滴 | 水滴逆向上升形成平台 |
| 逆向传送带 | 将玩家向反方向输送 |

### 3.5 收集与成长

**职责：** 提供收集驱动和反复挑战的动力。

#### 3.5.1 时间碎片

每关散落 5 个时间碎片，总共 150+ 个。

| 类型 | 外观 | 位置 |
|------|------|------|
| 普通碎片 | 金色发光齿轮 | 关卡常规路径上 |
| 隐藏碎片 | 蓝色发光齿轮 | 需要逆向规则才能到达的隐藏位置 |
| 挑战碎片 | 红色发光齿轮 | 在危险区域，需要精准操作获取 |

#### 3.5.2 关卡评级

| 评级 | 条件 |
|------|------|
| S | 通关时间 < 关卡设计时间的 80% + 全收集 + 死亡 0 次 |
| A | 通关时间 < 100% + 全收集 + 死亡 < 3 |
| B | 通关时间 < 120% + 收集 ≥ 3 |
| C | 通关 |
| D | 通关但死亡 ≥ 10 |

全关卡 S 评级解锁隐藏关卡和最终隐藏外观。

#### 3.5.3 隐藏关卡

| 解锁条件 | 关卡名 | 说明 |
|---------|--------|------|
| 全收集（所有碎片） | 逆时回廊 | 所有规则以最大强度同时生效，没有任何辅助提示 |
| 全 S 评级 | 终点即起点 | 一场特殊的叙事关卡——全程只有步行，没有敌人没有机关，世界在"正向播放"中恢复正常，你和角色一起看到一切复原的样子 |

### 3.6 叙事系统

**职责：** 讲述一个关于失去、逆行与重获的温暖故事。

#### 3.6.1 故事大纲

> 小回（Rewind）生活在钟楼镇，镇中央的"时光钟塔"是所有人的时间信标。
>
> 一场意外导致钟塔崩坏，镇上的时间开始倒流——不是在修复，而是在"遗忘"。人们忘记当天做过的事，事物回到损坏前的状态又被再次损坏，循环往复。
>
> 只有小回不受影响。她要逆向穿过 5 个区域，到达钟塔顶端，修复钟塔核心。每通过一个区域，对应区域的钟塔齿轮重新开始正向转动。
>
> 当她到达塔顶时，却发现钟塔核心只需要**被重置**——不是修复，而是让一切回到开始的地方。钟塔倒转的代价是她进入钟塔后的记忆会被清除。
>
> 最终，小回拉动重置杆。世界恢复正常。小回站在钟楼镇的入口，一切如常，她微笑着走进去，准备重新经历这一天——"因为真正重要的东西，值得再经历一次。"

#### 3.6.2 章节过场

| 世界 | 过场内容 |
|------|---------|
| 开场 | 动画展示钟塔崩坏、时间开始倒流、镇上人们开始倒退行动。小回发现自己不受影响，决定前往钟塔 |
| 第 1 世界后 | 钟塔第一个齿轮开始正向转动。小回看到镇上有人短暂恢复了正常 |
| 第 2 世界后 | 第二个齿轮转动。她看到一个小女孩在逆向人群中正向奔跑——是小时候的自己 |
| 第 3 世界后 | 第三个齿轮转动。小回记忆闪回：原来钟塔的崩坏是因为她小时候贪玩损坏了核心 |
| 第 4 世界后 | 第四个齿轮转动。小回看到了真相——进入塔顶的代价是遗忘 |
| 第 5 世界后 | 塔顶，最终过场。小回的选择 |
| 结局 | 重置完成，小回站在镇口，阳光明媚，她微笑着走进去 |

#### 3.6.3 环境叙事

关卡场景中隐藏着细节，暗示故事真相：

| 位置 | 细节 |
|------|------|
| 1-3 背景 | 倒退行走的人群中，有一个小女孩正向奔跑（幼年小回） |
| 3-2 电梯 | 电梯壁上刻着模糊的文字："如果一切能重来……" |
| 4-4 镜面 | 镜子中映出的不是小回，而是小时候的她 |
| 5-5 长廊 | 墙上有 5 幅画，分别是小回 5 个年龄段的场景，第 5 幅是空白 |
| Boss 战背景 | 每次 Boss 战中，背景中钟塔的对应齿轮会从静止开始转动 |

## 五、应用场景

### 场景一：单人沉浸式体验

> 玩家在一个下午打开游戏，一口气通关 5 个世界

每关 1~3 分钟，总游戏时长约 2~3 小时（初次通关）。节奏紧凑，每关只教一个核心概念，玩家不断获得"原来如此"的瞬间。关卡设计遵循"教学 → 练习 → 挑战 → Boss"的循环，始终保持心流。

### 场景二：速通与挑战

> 核心玩家追求全 S 评级、全收集、速通

关卡短小精悍，适合反复挑战。评级系统提供明确的复玩目标。每关的最佳路线往往需要充分利用逆向规则，而非蛮干。潜在的自发速通社区活动。

### 场景三：直播与视频

> 主播直播通关过程

每世界有明确的视觉 hook：逆流瀑布、弹幕回收、破碎重建等画面效果好，适合剪辑。Boss 战的"镜像小回"和第 5 世界的规则混合效果有节目效果。叙事反转（代价是遗忘）适合情感向剪辑。

### 场景四：关卡编辑（后续扩展）

> 玩家自制关卡分享

逆向时间引擎的规则足够简洁且可组合，适合做成简易关卡编辑器。提供预置的敌人、机关和时间线设置，玩家可以创作和分享自定义关卡。

## 七、边界声明

| 不做 | 原因 |
|------|------|
| 随机生成关卡 | 逆向规则需要精确设计事件序列，随机化破坏可玩性 |
| 联机多人 | 时间逆向的同步成本极高，且与单人叙事体验冲突 |
| 付费内购 | 一次性买断制，无体力/抽卡/订阅 |
| 复杂技能树 | 核心乐趣在逆向规则，而非数值成长 |
| 剧情分支结局 | 单线叙事保证情感冲击力的一致性 |
| 开放世界 | 关卡制能更精确地控制教学节奏和难度曲线 |
| 手机端（首发） | 精确的平台跳跃操作在触屏上体验不佳 |
| 时间倒流控制（由玩家触发） | 世界本身就在倒流，玩家控制的是角色而非时间 |
| 死亡惩罚 | 即时重生，鼓励反复尝试 |
