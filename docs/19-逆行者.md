# 逆行者 — 产品功能说明书

## 一句话定义

卡通风格的逆向动作平台跳跃游戏——整个世界的时间都在倒流，只有你的意识是清醒的。在倒带的世界中奔跑、跳跃、穿梭，每一次通关都是一次回到起点的逆行之旅。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：喜欢平台跳跃和创意机制的游戏玩家**

| 维度 | 描述 |
|------|------|
| 身份 | 玩过蔚蓝/超级肉肉哥/Braid 的玩家 |
| 喜好 | 机制驱动的平台跳跃、时间操控玩法 |
| 单局时长 | 每关 1-3 分钟，总游戏时长 2-3 小时 |
| 底层心理 | 享受"理解规则→掌控规则"的心流体验 |

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | Braid 之后缺少"时间逆向"为核心机制的平台跳跃游戏 |
| **刚需** | 玩家想要机制创新而非换皮关卡 |
| **改善型** | 卡通画风的平台跳跃有稳定受众但精品不多 |
| **改善型** | 玩家希望有情感力量（叙事驱动）而非纯动作挑战 |

---

## 二、解决方案与核心功能

### 2.1 解决方案概述

逆行者的核心是"世界倒流，玩家正常"——关卡内所有物体（敌人、机关、平台）的时间线逆向回放，只有玩家不受影响。5 大世界层层叠加逆向规则。

核心设计：
- **逆向时间引擎** — 关卡预录正向时间线 → 玩家进入时逆向回放
- **5 大世界 × 叠加规则** — 逆走 → 逆物理 → 逆因果 → 逆自己 → 混响
- **30+ 关卡** — 每关 1-3 分钟短平快节奏
- **情感叙事** — 关于失去、逆行与重获的治愈故事

### 2.2 核心功能清单

1. **逆向时间引擎** — 关卡内物体逆向回放，玩家操作不受影响
2. **5 大世界** — 逆走/逆物理/逆因果/逆自己/混响
3. **30+ 关卡** — 每关 1-3 分钟，逐步叠加复杂度
4. **Boss 战** — 每世界末尾逆向 Boss 战
5. **10+ 敌人类型** — 每种有独特逆向行为模式
6. **时间碎片收集** — 每关 5 个，全收集解锁隐藏关卡
7. **外观系统** — 解锁角色皮肤和特效
8. **关卡评级** — S~D，全 S 解锁隐藏结局
9. **2 个隐藏关卡** — 全收集解锁"逆时回廊"，全 S 解锁"终点即起点"
10. **叙事驱动** — 完整故事线，通关心灵治愈

## 五、核心模块详解

### 5.1 逆向时间引擎

**核心原理：** 每个关卡在后台预录制 15-30 秒正向时间线 → 玩家进入时时间线从终点向起点回放 → 回放结束后循环。玩家操作完全独立。

**分层时间系统：** 全局逆向（敌人倒退、子弹回收）、时间锚定（固定平台保持静止）、玩家同步（可推动箱子）、变速层（不同速度逆向运行）。

### 5.2 5 大世界

**第 1 世界「逆走」**：敌人运动轨迹反向。示例：弹幕从炮口发射后收回——站在弹幕消失位置等它回收后前进。Boss：倒退巡逻官。

**第 2 世界「逆物理」**：物理法则反向——水往天上流，物体向上落。瀑布逆向上升成为平台，弹力花吸向地面。

**第 3 世界「逆因果」**：机关触发顺序反向——先看到结果再触发原因。门已经打开，走到另一边的机关上把门"关上"才能通过。

**第 4 世界「逆自己」**：玩家操作被镜像反转（左/右/跳跃/交互）。内有"清醒区域"提供短暂正常操作窗口。Boss：镜像小回。

**第 5 世界「混响」**：所有规则混合叠加，每 10 秒随机切换组合。

### 5.3 叙事

小回（Rewind）生活在钟楼镇，时光钟塔崩坏后时间开始倒流。她逆向穿过 5 个区域到达塔顶，发现核心只需要"重置"——代价是她进入塔后的记忆会被清除。她拉动重置杆，世界恢复正常，她微笑着重新走进钟楼镇——"因为真正重要的东西，值得再经历一次。"

## 六、用户流程

```
开场动画（60s）→ 第 1 世界「逆走」（6 关+Boss）→ 齿轮 1 转动
  ↓
第 2 世界「逆物理」（7 关+Boss）→ 齿轮 2 转动
  ↓
第 3 世界「逆因果」（7 关+Boss）→ 齿轮 3 转动
  ↓
第 4 世界「逆自己」（6 关+Boss）→ 齿轮 4 转动
  ↓
第 5 世界「混响」（6 关+Boss）→ 齿轮 5 转动
  ↓
塔顶：拉动重置杆 → 记忆清除 → 回到镇口 → 结局
  ↓
通关后：自由选关 / 补收集 / 刷 S / 隐藏关卡
```

## 八、落地路径

### 8.1 开发优先级

P0：逆向时间引擎（录制+回放+玩家隔离）→ 1 世界完整关卡（6 关+Boss）→ 角色控制。

P1：第 2-5 世界 → 全部关卡 + Boss → 叙事过场。

P2：收集系统 + 外观解锁 + 评级系统 + 隐藏关卡 + 全 S 解锁真结局。

### 8.2 第一步验证

**最关键假设：** 玩家能在短时间内理解"世界倒流我正常"的核心机制。

**验证方法：** 做一个单一关卡的 demo（类型类似 1-2 弹幕回收）邀请 20 人试玩。如果 > 70% 在 30 秒内理解了核心机制并表达"有趣"，假设成立。

## 九、风险与预期反馈

| 预期槽点 | 应对方案 |
|---------|---------|
| "和 Braid 一样" | 逆行者是动作平台跳跃（非解谜），世界持续逆流而非由玩家操控 |
| "太难了" | 轻松模式（流速 0.8x + 无限滞空辅助）首发即提供 |
| "关卡重复感" | 每世界叠加新规则，5 种完全不同体验 |

## 十、边界声明

| 不做 | 原因 |
|------|------|
| 随机生成关卡 | 逆向规则需要精确设计 |
| 联机多人 | 时间逆向同步成本极高 |
| 付费内购 | 买断制 |
| 手机端首发 | 精确操作在触屏体验不佳 |
| 时间倒流由玩家触发 | 世界本身就在倒流 |
| 死亡惩罚 | 即时重生，鼓励反复尝试 |
