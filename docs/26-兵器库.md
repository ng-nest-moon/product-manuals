## 二、核心功能清单

1. **时间线主线** — 11 个时代的水平时间轴，支持缩放 / 跳转 / 连续自动播放，每个时代展示兵器总量、代表性兵器和关键历史事件
2. **时代展厅** — 进入时代后以 2.5D 俯视布局展示兵器群，配时代概览、技术突破、关键战役
3. **兵器详情** — 标准化参数面板 + 3D 模型 + 历史叙事，每件兵器包含完整的技术数据和人文背景
4. **3D 模型交互** — 360° 旋转 / 缩放 / X 光透视 / 线框 / 透明模式，支持视角自由切换
5. **拆解工坊** — 逐层拆解至最小零件，附工作原理动画（枪机运作 / 炮闩开闭 / 发动机循环）
6. **射击 / 操作模拟** — 核心枪械的扳机 / 换弹 / 后坐力模拟，坦克视角驾驶操作，弹道轨迹展示
7. **兵器对比** — 2-4 件兵器并排对比，自动提取共有参数，差异值高亮标注
8. **技术演进树** — 可视化展示某一技术脉络（如：弓 → 弩 → 火绳枪 → 燧发枪 → 后装线膛枪 → 自动步枪）
9. **智能搜索** — 支持名称 / 年代 / 产地 / 类型 / 时代 / 参数范围多维度组合搜索
10. **兵器图谱** — 11 大类树状结构浏览，逐级下钻
11. **兵器词典** — 200+ 专业术语释义（口径 / 膛线 / 倍径 / 翼载 / 排水量 / CEP / MIRV / ERA / APS …）
12. **我的兵器集** — 收藏 / 标注 / 笔记 / 自定义兵器集，可分享
13. **时间线剧场** — 精选兵器在关键战役中的动画场景重现（如：克雷西战役长弓 vs 弩、库尔斯克虎式 vs T-34）
14. **主题套装** — 按主题聚合兵器（"改变历史走向的 10 件兵器"、"中国造"、"二战名枪"、"科幻成真"）

## 三、模块详解

### 3.1 时间线主线

主界面核心交互。一条贯穿古今的水平时间轴，由 11 个时代区块组成。

#### 3.1.1 时代划分

| 时代 | 时间跨度 | 兵器数量 | 关键事件锚点 |
|------|---------|---------|------------|
| 原始时代 | ~300 万年前 – 3000 BC | ~20 件 | 石器打制技术、火的使用、弓箭发明 |
| 青铜时代 | 3000 – 1000 BC | ~30 件 | 青铜冶炼、战车、马拉战车 |
| 古典时代 | 1000 BC – 5 世纪 | ~50 件 | 马镫传播、秦弩、罗马军团、投石机 |
| 中世纪 | 5 世纪 – 15 世纪 | ~60 件 | 马镫普及、十字弓、板甲、回回炮 |
| 火器革命 | 10 世纪 – 18 世纪 | ~50 件 | 火药西传、火绳枪、燧发枪、红衣大炮 |
| 工业革命 | 19 世纪 | ~60 件 | 线膛枪、后装炮、铁甲舰、加特林 |
| 一战 | 1914 – 1918 | ~80 件 | 马克沁机枪、坦克、毒气、战斗机 |
| 二战 | 1939 – 1945 | ~150 件 | 突击步枪、航母、原子弹、喷气机 |
| 冷战 | 1947 – 1991 | ~200 件 | 洲际导弹、核潜艇、喷气战斗机、直升机 |
| 现代 | 1991 – 今 | ~150 件 | 无人机、精确制导、隐身、高超音速 |
| 未来 | 概念 / 实验 | ~30 件 | 激光武器、电磁轨道炮、太空武器、AI 自主武器 |

#### 3.1.2 交互规则

| 功能点 | 说明 | 规则 / 约束 |
|-------|------|-----------|
| 水平滚动 | 手指或鼠标横向拖动时间轴 | 支持触屏 + 鼠标 + 键盘方向键 |
| 缩放到时代 | 点击时代封面进入该时代展厅 | 退出展厅返回时间线当前位置 |
| 缩放到年份 | 双指缩放（触屏）或滚轮（鼠标） | 最大放大到"年"级别，最小缩到"时代"级别 |
| 锚点事件 | 关键节点以图标标记（⚔️战役 / 🔧发明 / 👤人物） | 点击锚点弹出速览卡片 |
| 连续播放 | 播放按钮启动自动前进 | 速度可调（1x / 2x / 4x），自动暂停于每个时代的起始点 |
| 全局搜索 | Ctrl+K 唤出搜索框 | 搜索后跳转到对应兵器在时间线上的位置 |

### 3.2 时代展厅

进入时代后的兵器群展示界面。

#### 3.2.1 展厅布局

| 区域 | 内容 | 交互 |
|------|------|------|
| 顶部横幅 | 时代名称、年份跨度、一句话时代特征 | 无交互 |
| 左侧信息卡 | 时代概览（战争形态、技术突破、社会背景） | 可收起 / 展开 |
| 中央主区 | 兵器群以 2.5D 俯视网格排列 | 点击兵器进入详情，支持缩放和拖拽 |
| 右侧列表 | 该时代所有兵器的文字列表（按年份排序） | 可滚动，点击跳转到对应兵器位置 |
| 底部导航 | 上一时代 / 回到时间线 / 下一时代 | 一键跳转 |

#### 3.2.2 展厅内容构成

| 信息模块 | 内容 |
|---------|------|
| 时代概览 | 年份跨度、战争形态描述、社会技术背景 1-2 段 |
| 技术突破列表 | 该时代出现的兵器技术革命（如：膛线的发明） |
| 关键战役 | 2-3 场代表性战役，每场关联该时代的核心兵器 |
| 代表人物 | 兵器设计师 / 军事家 / 改革者 |
| 兵器数量统计 | 按子分类统计件数 |

### 3.4 拆解工坊

核心互动模块，专注于兵器内部结构的学习体验。

| 功能点 | 说明 | 规则 / 约束 |
|-------|------|-----------|
| 逐层拆解 | 按装配层级由外到内逐层拆解 | 每次点击展开一层，不可跳层 |
| 零件标注 | 每个零件显示名称 + 功能说明 | 点击零件弹出详情卡片 |
| 反向组装 | 按顺序将零件装回 | 计时模式可选 |
| 工作动画 | 拆解过程中关键机构的运作动画 | 可暂停 / 慢放 / 循环 |
| 零件高亮 | 当前正在讲解的零件高亮 + 连线到标注 | 配合历史叙事同步 |
| 难度分级 | 基础拆解（5-10 步） / 专业拆解（20-50 步） | 步数因兵器复杂度而异 |

对核心兵器提供模拟操作体验。

| 兵器类型 | 模拟内容 | 交互要素 |
|---------|---------|---------|
| 枪械 | 瞄准、扳机、换弹、后坐力、弹道 | 准星、扳机键、换弹键、视角晃动、弹道轨迹线 |
| 火炮 | 装填、瞄准、击发、后坐行程 | 高低机 / 方向机手轮、拉火绳、炮弹出膛动画 |
| 坦克 | 驾驶员视角驾驶、炮手瞄准射击 | 方向盘 / 操纵杆、炮塔旋转、瞄准分划 |
| 投石机 | 装弹、拉绳、释放 | 拉绳蓄力、角度调节、抛物线轨迹 |

#### 3.5.1 射击模拟参数

| 参数 | 规则 |
|------|------|
| 后坐力反馈 | 视角后移 + 准星上跳，后坐力大小与口径 / 枪重相关 |
| 弹道轨迹 | 根据口径 / 初速 / 风偏计算抛物线和下坠 |
| 换弹动效 | 依据真实换弹动作拆帧（如：AK 拉机柄 / AR-15 空仓挂机） |
| 精度模拟 | 依据该枪械真实散布数据设定准星散布范围 |

### 3.6 兵器对比

#### 3.6.1 对比规则

| 功能点 | 说明 | 规则 / 约束 |
|-------|------|-----------|
| 选择兵器 | 从收藏或搜索中添加 2-4 件兵器 | 最大 4 件同时对比 |
| 自动匹配参数 | 系统自动提取共有字段 | 非同类型兵器仅比较共有通用参数 |

## 六、应用场景

### 6.1 军事爱好者深度探索
利用时间线主线系统学习兵器发展史，从石器到高超音速的完整脉络。收藏感兴趣的兵器，构建个人兵器知识体系。

### 6.2 游戏 / 影视创作参考
游戏设计师了解特定时代的兵器外观和参数，用于角色装备和场景设计。影视编剧查询历史时期相关的兵器细节，确保作品准确度。

### 6.3 教育科普
学生通过时间线直观理解技术演进与社会变革的关系。教师可利用兵器对比和演进树展示技术发展的逻辑脉络。

### 6.4 模型收藏爱好者
通过 3D 拆解和参数面板深入了解兵器内部构造，辅助模型制作。对比不同型号的细节差异。

### 6.5 知识竞赛 / 内容创作
快速检索兵器参数和历史战绩，为问答、文章、视频提供素材。智能引用和关联推荐帮助内容创作者发现新话题。

## 八、边界声明

| 不做什么 | 说明 |
|---------|------|
| 不提供实时武器库存 / 军力对比 | 仅做历史与科普，不做当下军力分析和国家排名 |
| 不涉及武器制造图纸 / 工艺细节 | 只展示公开的科普级参数和外观，不包含制造数据 |
| 不包含真实武器交易信息 | 不涉及买卖、估价、交易撮合、供应商 |
| 不做暴力 / 血腥渲染 | 互动体验侧重机械原理和历史认知，非暴力模拟 |
| 不接入实时战争 / 冲突数据 | 保持中立历史视角，不追踪实时冲突动态 |
| 不提供武器改装 / 制作教学 | 严禁涉及武器制造、改装、违禁内容 |
| 3D 模型为科普精度 | 不追求军工级精度，满足视觉认知和原理理解即可 |
| 不存储用户生物特征 | 用户账号仅存收藏和偏好，不强制注册 |
