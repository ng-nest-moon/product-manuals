# 兵器库 — 产品功能说明书

## 一句话定义

每一件兵器都是人类智慧的锋芒——沿万年时间轴前行，亲手"触摸"从石斧到高超音速的每一次进化。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：军事爱好者、历史爱好者、兵器模型玩家**

| 维度 | 描述 |
|------|------|
| 身份 | 对兵器/军事史感兴趣的非专业爱好者 |
| 当前可用产品 | 维基百科（零散、无交互）、纸质图鉴（静态）、游戏（不是科普）|
| 底层需求 | 在一个地方系统性地了解兵器 + 能"看"和"把玩" |

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 兵器知识分散在各平台，没有系统化的垂直产品 |
| **刚需** | 爱好者想要"交互式"而非"图文式"的兵器体验 |
| **改善型** | 现有 3D 模型展示缺少历史和参数维度 |
| **改善型** | 兵器对比和技术演进缺少直观工具 |

---

## 二、解决方案与核心功能

### 2.1 解决方案概述

兵器库是一个沿万年时间轴排列的交互式兵器百科全书。核心：时间线主线→时代展厅→兵器详情（3D 模型/参数/参数/拆解/模拟）→跨时代工具（对比/演进树/图谱/搜索/词典）。

### 2.2 核心功能清单

1. **时间线主线** — 11 时代的水平时间轴，放大到年级别
2. **时代展厅** — 2.5D 俯视布局展示兵器群
3. **兵器详情** — 标准化参数面板 + 3D 模型 + 历史叙事
4. **3D 交互** — 旋转/缩放/X 光/线框/剖视/拆解
5. **拆解工坊** — 逐层拆解至最小零件+工作原理动画
6. **射击/操作模拟** — 枪械扳机/换弹/后坐力，坦克驾驶
7. **兵器对比** — 2-4 件并排对比，差异高亮
8. **技术演进树** — 可视化技术传承脉络
9. **智能搜索** — 名称/年代/产地/类型/参数范围
10. **兵器词典** — 200+ 专业术语释义
11. **我的兵器集** — 收藏/标注/笔记/自定义集

## 三、竞品与差异化分析

| 竞品 | 优点 | 缺点 | 差异 |
|------|------|------|------|
| 维基百科 | 内容全 | 零散无系统 | 兵器库沿时间线组织+3D 交互 |
| 军事杂志/图鉴 | 图文精美 | 静态无交互 | 兵器库有 3D 拆解和模拟 |
| 游戏（坦克世界等） | 有驾驶 | 不是科普 | 兵器库是百科全书定位 |

**差异化优势：** 时间线主线+3D 交互+拆解模拟+兵器对比的四维体验。

## 五、核心模块详解

### 5.1 时间线主线

11 时代：原始→青铜→古典→中世纪→火器革命→工业革命→一战→二战→冷战→现代→未来。支持水平滚动、缩放到年级别、锚点事件（战役/发明/人物）、连续自动播放。

### 5.2 兵器详情

标准化参数面板（通用+类型专用参数）+ 3D 模型（360° 旋转/缩放/X 光/线框/剖视/拆解）+ 历史叙事（研发背景/实战记录/评价）+ 衍生信息（改进型号/产量/服役时间线）。

### 5.3 拆解工坊

逐层拆解至最小零件（每次展开一层）→ 反向组装（可选计时）→ 工作动画（可暂停/慢放/循环）→ 零件高亮标注。

### 5.4 兵器对比

2-4 件并排对比 → 自动提取共有参数 → 差异>10% 高亮 → 雷达图/柱状图可视化 → 保存对比集。

## 八、落地路径

### 8.1 MVP

时间线骨架 + 100 件核心兵器（每时代 10-15 件，完整参数+图文）+ 基础详情页 + 搜索 + 图谱 + 收藏。

### 8.2 第一步验证

**最关键假设：** 有人愿意为"系统化的兵器知识交互产品"付费。

**验证方法：** 做 1 个时代的完整 demo（二战，20 件兵器+3D 模型+参数），邀请 50 个军事爱好者试用。如果 > 40% 表示"会买"，需求成立。

---

## 九、风险与预期反馈

| 预期槽点 | 应对方案 |
|---------|---------|
| "800 件太多了记不住" | 按时间线/分类浏览降低认知负荷 |
| "3D 模型不够精细" | 科普精度足够，军工级不是目标 |
| "不如 Wiki" | Wiki 零散无交互，兵器库系统+可操作 |
| "暴力/敏感" | 兵器是科普和历史视角，非暴力渲染 |

## 十、边界声明

| 不做 | 原因 |
|------|------|
| 实时军力对比 | 仅做历史科普 |
| 制造图纸/工艺 | 只展示公开科普级参数 |
| 武器交易信息 | 不涉及买卖估价 |
| 暴力血腥渲染 | 侧重机械原理和历史认知 |
| 接入实时冲突数据 | 中立历史视角 |
| 武器制作教学 | 严禁违禁内容 |
