# 程序员生涯 — 产品功能说明书

## 一句话定义

像素风程序员生涯模拟游戏，Star-Office-UI 那样的像素场景和角色演出——从小学上微机课到终局人生，上课、写代码、背锅、被裁、创业，每个选择画面都演给你看。

---

## 一、游戏架构总览

```
表现层（像素场景 + 角色演出）
 ├── 场景系统 —— 教室 / 网吧 / 宿舍 / 工位 / 会议室 / 医院……
 ├── 角色精灵 —— 玩家像素小人，外观随状态变化（发际线、穿着、表情）
 ├── 对话气泡 —— NPC 说话用气泡弹出，带像素头像
 ├── 选择面板 —— 选项以像素卡片形式弹出在屏幕底部
 └── 状态 HUD —— 顶部常驻属性条 + 年龄 / 职位 / 经济状况

生命周期（9 幕）
 ├── 第一幕：小学时代 —— 电脑启蒙、网吧、小升初
 ├── 第二幕：初中三年 —— 第一次搜"怎么做网站"、中考分水岭
 ├── 第三幕：高中三年 —— 文理分科、高考、选专业
 ├── 第四幕：大学四年 —— 每学期关键选择，×8 学期
 ├── 第五幕：毕业季 —— 简历、面试、Offer、租房
 ├── 第六幕：初级程序员 —— 入职试用期、背锅、第一次绩效
 ├── 第七幕：中级进阶 —— 独立负责、带新人、跳槽窗口
 ├── 第八幕：资深困局 —— 架构决策、管理岔路、35 岁危机
 └── 第九幕：终局 —— 创业 / 大神 / 管理 / 转行 / 躺平 / burnout

属性系统（8 项，0-100）
 ├── 💻 编程能力 —— 决定技术天花板
 ├── 🗣️ 沟通协作 —— 影响面试、汇报、撕逼
 ├── 💪 身体素质 —— 低于 20 触发健康危机
 ├── 👁️ 行业视野 —— 影响技术判断和风口识别
 ├── 💰 经济状况 —— 工资 + 存款 + 副业 + 股票
 ├── 🤝 人脉资源 —— 影响内推、合作、创业
 ├── 📚 学习能力 —— 影响新技术掌握速度
 └── ❤️ 心态幸福感 —— 低于 15 触发 burnout

隐藏属性
 ├── 🧬 发际线 —— 开局随机，压力加速掉发
 ├── 🐛 Bug 率 —— 编程能力 × 状态，决定事故概率
 ├── 📛 职场口碑 —— 影响跳槽背调、晋升推荐
 └── ⏰ 工时累积 —— 长期加班触发健康 debuff

结局（12 种）
 ├── 🏆 创业 IPO、技术大神、人生赢家
 ├── 🥈 中层管理、海外润成、大厂高 P 退休、独立开发者
 ├── 🥉 躺平养老
 ├── 💀 Burnout 退场、被裁 N+1、代码一生
 └── 🎲 彩蛋结局（开源封神 / 考公上岸 / 继承家业）
```

## 二、核心功能清单

1. **像素场景演出** — 每一幕有独立场景，角色在场景中走动、敲键盘、躺平，用画面推进故事
2. **角色外观演化** — 像素小人随年龄和状态变化：发际线后退、黑眼圈加深、衣服从 T 恤到格子衫
3. **选择即演出** — 选项以像素卡片弹出，选中后角色做出对应动作反馈（点头/挠头/崩溃趴桌）
4. **8 维属性系统** — 每次选择增减属性，不达标锁死某些发展路线
5. **技术栈积累** — 学过的语言/框架变成技能标签，影响能去哪家公司、接什么项目
6. **随机事件弹窗** — 突发状况以微信消息、邮件、猎头电话、体检报告等形式弹出来，限时做选择
7. **时间翻篇动画** — 每幕结束时翻页转场，角色年龄增长、外观老去
8. **12 种结局 + 回顾走马灯** — 通关展示结局像素画面 + "你的一生"关键节点回顾
9. **多周目收集** — 未解锁结局显示为剪影，成就徽章系统驱动重复游玩
10. **隐藏事件** — 特定属性组合或极品操作触发隐藏剧情
11. **NPC 系统** — 每一幕有对应 NPC 出场：爸妈、老师、同学、室友、Leader、HR、猎头……

## 五、随机事件系统

事件以日常通讯弹窗形式出现：

| 弹窗形式 | 示例 |
|---------|------|
| 微信消息 | 老板："这个需求今晚要" |
| 邮件通知 | "公司组织架构调整通知" |
| 猎头电话 | "张先生，有个机会您考虑吗" |
| 体检报告 | "颈椎退行性变，建议减少久坐" |
| 银行短信 | "工资到账 28000.00 元" |

触发规则：阶段必发 + 属性阈值触发 + 随机池抽取 + 前序选择连锁触发。

## 六、多周目与重玩价值

| 功能 | 说明 |
|------|------|
| 结局收集 | 12 种结局，未解锁显示剪影 + 问号 |
| 隐藏提示 | "你错过了某个隐藏事件"（不告诉你怎么触发） |
| 随机变量 | 每局初始因子不同（高考分数、发际线基因、事件池） |
| 成就系统 | 像素徽章：第一个 PR / 通宵冠军 / 被裁达人…… |
| 难度模式 | 普通 / 困难（属性需求更高、事件更狠） |
| 开局天赋 | 二周目解锁："科二代""天赋异禀""家里有矿" |

## 七、边界声明

| 不做 | 原因 |
|------|------|
| 实时联网对战 | 单机单人剧情 |
| 真实编程 IDE | 选择驱动，不模拟实际写代码 |
| 3D 画面 | 像素风是核心卖点 |
| 多语言首发 | MVP 仅中文 |
| 内购抽卡 | 买断制或一次性付费 |
| UGC 编辑器 | MVP 不开放自制剧情 |
