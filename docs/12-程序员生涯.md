# 程序员生涯 — 产品功能说明书

## 一句话定义

像素风程序员生涯模拟游戏——从小学上微机课到终局人生，上课、写代码、背锅、被裁、创业，每个选择画面都演给你看。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：正在或曾经做过程序员的人（22-40 岁）**

| 维度 | 描述 |
|------|------|
| 身份 | 在职程序员、前程序员、计算机专业学生 |
| 游戏习惯 | 像素风、叙事驱动、选择分支游戏 |
| 情感基础 | 对自己的职业路径有复杂情感——既有成就感又有焦虑 |
| 底层心理 | 看别人的人生以反思自己的选择 |

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 程序员"回头看"自己的职业选择，有大量情绪共鸣 |
| **刚需** | 市场上缺少程序员题材的像素风叙事游戏 |
| **改善型** | 12 种结局提供情感出口，比现实更安全的"如果当初" |
| **改善型** | 多周目机制满足收集欲，驱动重复游玩 |

---

## 二、解决方案与核心功能

### 2.1 解决方案概述

程序员生涯用 9 幕叙事讲完一个程序员从小学到终局的一生。每一幕有独立像素场景，角色在场景中走动、敲键盘、躺平，用画面推进故事。

核心设计：
- **选择驱动** — 每次选择影响 8 维属性和后续剧情
- **像素演出** — 不只有文字，角色有动作、场景有变化
- **共鸣优先** — 每个程序员都能找到自己
- **12 种结局** — 创业 IPO、技术大神、burnout、被裁……都是真结局

### 2.2 核心功能清单

1. **像素场景演出** — 每一幕独立场景，角色走动、敲键盘、躺平
2. **角色外观演化** — 发际线后退、黑眼圈加深、衣服变化
3. **选择即演出** — 选项弹出后角色做出对应动作反馈
4. **8 维属性系统** — 编程/沟通/健康/视野/经济/人脉/学习/心态
5. **技术栈积累** — 学过的语言/框架变成技能标签
6. **随机事件弹窗** — 微信消息、邮件、猎头电话、体检报告限时选择
7. **12 种结局 + 回顾走马灯** — 结局动画 + 关键节点回顾
8. **多周目收集** — 未解锁结局显示剪影，成就徽章系统
9. **隐藏事件** — 特定属性组合触发隐藏剧情
10. **NPC 系统** — 爸妈、老师、同学、室友、Leader、HR、猎头

## 三、竞品与差异化分析

| 竞品 | 优点 | 缺点 | 差异 |
|------|------|------|------|
| 人生重开模拟器 | 自由度高，轻量 | 纯文字无演出 | 程序员生涯有像素场景演出 |
| 中国式家长 | 像素风，家庭题材 | 只到高考结束 | 程序员生涯覆盖完整程序员生涯 |
| 太多选择 | 剧情丰富 | 不够程序员垂直 | 每个选择都是程序员才懂的梗 |

**差异化优势：** 程序员垂直题材 + 像素演出 + 9 幕完整生命周期 + 12 种真实结局。

## 四、架构总览

```
表现层（像素场景 + 角色演出）
  ├─ 场景系统（教室/网吧/宿舍/工位/会议室/医院……）
  ├─ 角色精灵（像素小人，外观随状态变化）
  ├─ 对话气泡（NPC 说话带像素头像）
  ├─ 选择面板（选项以像素卡片弹出）
  └─ 状态 HUD（属性条 + 年龄/职位/经济）

生命周期（9 幕）
  小学 → 初中 → 高中 → 大学 → 毕业 → 初级 → 中级 → 资深 → 终局

属性系统（8 项 0-100 + 隐藏属性）
  编程 / 沟通 / 健康 / 视野 / 经济 / 人脉 / 学习 / 心态
  隐藏：发际线 / Bug 率 / 职场口碑 / 工时累积

结局（12 种）
  创业 IPO / 技术大神 / 人生赢家 / 中层管理 / 海外润成 / 大厂退休
  独立开发者 / 躺平养老 / Burnout / 被裁 / 代码一生 / 彩蛋
```

## 五、核心模块详解

### 5.1 9 幕生命周期

**第一幕：小学时代** — 电脑启蒙、网吧、小升初。NPC：妈妈、微机老师、同学。关键分歧：是否在小学接触到电脑。

**第二幕：初中三年** — 第一次搜"怎么做网站"、中考分水岭。若触发"编程兴趣"则后续有早熟加成。

**第三幕：高中三年** — 文理分科、高考、选专业。初中编程启蒙 + 高中竞赛 → 天才少年路线。

**第四幕：大学四年** — 8 学期 × 2-3 事件，从 C 语言听不懂到秋招毕业。锁定技术方向和路线。

**第五幕：毕业季** — 简历、面试、Offer、租房。多轮选择决定第一份工作。

**第六幕：初级程序员** — 入职试用期、第一次线上事故、首次绩效。方向定型（前端/后端/算法/测试等）。

**第七幕：中级进阶** — 独立负责模块、带新人、跳槽窗口、副业萌芽。随机事件池：空降领导、裁员、期权解锁等。

**第八幕：资深困局** — 架构决策、管理岔路、35 岁危机。决定终局走管理 vs 专家路线。

**第九幕：终局** — 12 种结局判定 + 像素动画演出 + "你的一生"走马灯回顾。

### 5.2 随机事件系统

事件以日常通讯弹窗形式出现：微信消息（老板"这个需求今晚要"）、邮件（架构调整通知）、猎头电话、体检报告、银行短信、新闻推送。

触发规则：阶段必发 + 属性阈值触发 + 随机池抽取 + 前序选择连锁触发。

### 5.3 多周目

12 种结局收集（未解锁显示剪影 + 问号）、随机变量（每局初始因子不同）、成就徽章系统、难度模式（普通/困难）、二周目开局天赋解锁。

## 六、用户流程

```
开局 → 小学时代 → 选择 → 属性变化
  ↓
初中 → 高中 → 大学（8 学期）
  ↓
毕业季 → 找工作 → Offer 选择
  ↓
初级 → 中级 → 资深（随机事件穿插）
  ↓
终局 → 结局判定 → 像素动画 → 走马灯回顾
  ↓
解锁结局剪影 → 尝试新路线 → 多周目
```

## 七、商业模式

| 付费模式 | 定价 | 依据 |
|---------|------|------|
| Steam 买断制 | 48-68 元 | 像素风叙事游戏的定价区间 |
| 首发折扣 | 36-48 元 | 首周促销 |

**盈利模式：** 纯买断，无内购、无 DLC。多周目内容一次买断包含。

## 八、落地路径

### 8.1 MVP

P0：像素场景渲染（教室/宿舍/工位 3 场景打通 demo）→ 角色精灵 → 选择分支逻辑打通 9 幕 → 8 维属性系统 → HUD 显示。

### 8.2 第一步验证

**最关键假设：** 程序员愿意为"看别人的程序员人生"付费。

**验证方法：** 做一个纯文字版 demo（3 幕：大学→毕业→初级），发到 V2EX/即刻。统计完整体验率 > 50% 则需求成立。

## 九、风险与预期反馈

| 预期槽点 | 应对方案 |
|---------|---------|
| "像素太简陋" | 像素是核心风格，不做 3D |
| "选择不够多" | 每幕 6-9 关键节点，百种组合路径 |
| "技术细节不真实" | 找真实程序员顾问校验内容 |
| "结局太扎心" | 12 种结局有好的也有坏的，取决于你的选择 |

---

## 十、边界声明

| 不做 | 原因 |
|------|------|
| 实时联网对战 | 单机单人剧情 |
| 真实编程 IDE | 选择驱动，不模拟实际写代码 |
| 3D 画面 | 像素风是核心卖点 |
| 多语言首发 | MVP 仅中文 |
| 内购抽卡 | 买断制 |
| UGC 编辑器 | MVP 不开放自制剧情 |
