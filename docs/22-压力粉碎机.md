# 压力粉碎机 — 产品功能说明书

## 一句话定义

测出你的性格，说出你的压力，变成怪物砸个粉碎。

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：需要快速解压的都市人（16-35 岁）**

| 维度 | 描述 |
|------|------|
| 身份 | 打工人、学生、高压环境下的年轻人 |
| 使用场景 | 下班后/复习间隙/被气到后，花 3-5 分钟打一局 |
| 底层心理 | 有压力但不想跟人聊，需要一种"不说出来但也能发泄"的方式 |
| 现有解法 | 打游戏（但普通游戏不能把压力变成怪物） |

### 1.2 真实痛点分级

| 需求类型 | 痛点 |
|---------|------|
| **刚需** | 日常压力缺少健康的具象化发泄方式 |
| **刚需** | 市面上没有"把压力变成怪物砸碎"的产品 |
| **改善型** | 写日记太安静，运动太累，玩游戏不直接 |
| **改善型** | 把压力说出来本身就具有宣泄价值 |

---

## 二、解决方案与核心功能

### 2.1 解决方案概述

压力粉碎机 = 性格测试 + 压力输入 + 怪物生成 + 战斗发泄。

核心设计：
- **性格测试（5 题）** — 爆裂型/执念型/敏感型/斗士型/飘忽型
- **压力输入（你自己说）** — 文本+分类，决定怪物主题
- **怪物生成** — 性格×分类 决定外观和 AI 行为
- **战斗竞技场** — 8 种破坏工具，摧毁压力怪物

### 2.2 核心功能清单

1. **性格测试** — 5 道场景题，判定 5 种性格类型
2. **压力输入** — 自由文本（1-50 字）+ 6 类标签（工作/钱/感情/健康/社交/其他）
3. **怪物生成** — 性格×分类 决定外观、AI 行为、弱点
4. **战斗竞技场** — Canvas 2D 实时战斗
5. **8 种破坏工具** — 大锤/球棒/喷火器/手榴弹/武士刀/雷击/电锯/火箭筒
6. **怪物 AI** — 5 种攻击模式（冲撞/锁链/分裂/反击/瞬移）
7. **销毁反馈** — 粒子爆炸、屏幕震动、慢动作、大字拟声词、S/A/B/C 评分
8. **连击系统** — combo 叠加倍率
9. **记录存档** — localStorage 保存摧毁历史和统计看板

## 三、竞品与差异化分析

| 竞品 | 优点 | 缺点 | 差异 |
|------|------|------|------|
| 解压小游戏（粉碎类） | 简单直接 | 无个性化 | 压力粉碎机的怪物根据你的压力和性格生成 |
| 性格测试 | 了解自己 | 不解决情绪 | 压力粉碎机测试后直接发泄 |
| 日记 App | 记录情绪 | 安静不宣泄 | 压力粉碎机砸碎它 |

**差异化优势：** 性格测试+压力具象化+战斗发泄的三段式独有问题。

## 五、核心模块详解

### 5.1 性格测试（5 题）

场景题示例：排位赛连输三把（换武器继续/停下来录像/换游戏）；朋友意见不同（开怼/心里不舒服/无所谓）。
5 种性格：爆裂型（冲动直接，锤子+50%/HP+1）、执念型（仔细，连击窗口+0.5s/暴击+15%）、敏感型（范围伤害+30%/闪避延长）、斗士型（球棒击退+100%/受伤后攻击提升）、飘忽型（攻速+30%/移速+20%）。

### 5.2 压力输入

文本 1-50 字 + 分类单选。示例："领导让我周末加班"→ 工作类→ 喋喋不休闹钟怪+文件堆护甲。"花呗还不上"→ 钱类→ 裂开钱袋魔像+硬币弹幕。

### 5.3 怪物生成

性格决定 AI：爆裂=冲撞（蓄力冲锋，冲撞后硬直 1.5s）、执念=锁链+追踪弹（有固定长度）、敏感=分裂弹幕（本体血低）、斗士=格挡反击（黄光窗口可破防）、飘忽=瞬移背刺（落地前摇 0.3s）。

分类决定视觉：工作（灰/橙+文件闹钟）、钱（金/绿+硬币钱袋）、感情（粉/紫+心形锁链）、健康（白/红+镜子针管）、社交（蓝/灰+气泡手机）、其他（黑+抽象黏液）。

### 5.4 战斗

8 种工具：大锤→球棒→喷火器→手榴弹→武士刀→雷击→电锯→火箭筒，按累计摧毁次数逐步解锁。

5 心 HP，combo 系统（2 秒重置），击中无敌帧 1 秒。S 级条件：0 损失+20 秒内+最高 combo>10。

### 5.5 三原则

压力由玩家自己说（不推断）；破坏必须爽（震动+音效+慢动作）；不制造新压力（无排名/任务/氪金）。

## 六、用户流程

```
打开 → 性格测试（5 题）→ 展示性格卡片
  ↓
输入压力 + 选分类 → 生成怪物
  ↓
战斗（移动鼠标 + 切换工具攻击）
  ↓
怪物 HP=0 → 慢动作击破 → 评分 → 结果页
  ↓
记录存档 / 再来一次
```

## 八、落地路径

### 8.1 MVP

性格测试（5 题）+ 压力输入 + 3 种怪物 AI（冲撞/分裂/瞬移）+ 3 种工具（大锤/球棒/喷火器）+ 基础击破反馈。

### 8.2 第一步验证

**最关键假设：** 用户愿意花 1 分钟输入"今天什么让我烦"。

**验证方法：** 做一个纯文字版（无战斗），3 步：测试→输入→看到怪物图片。统计输入完成率。

## 九、风险与预期反馈

| 预期槽点 | 应对方案 |
|---------|---------|
| "输入压力太矫情" | 可选跳过，直接生成随机怪物 |
| "战斗太简单" | 累计次数提升怪物强度 |
| "不就打地鼠" | 8 种工具手感不同 + AI 行为差异 |

## 十、边界声明

| 不做 | 原因 |
|------|------|
| 真实心理诊断 | 不提供医疗建议 |
| 用户数据上传 | 仅存本地 |
| 社交/排行榜 | 不制造新压力 |
| 充值/内购 | 所有工具可游玩解锁 |
| 成瘾设计 | 无每日任务/连续签到 |
| 广告 | 战斗中不出现 |
