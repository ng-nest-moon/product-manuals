# 压力粉碎机 — 产品功能说明书

## 一句话定义

测出你的性格，说出你的压力，变成怪物砸个粉碎。

---

## 适龄建议

12 岁以上

---

## 一、系统架构总览

```
用户流程
 ├── 欢迎页 —— 一句话引导，开始按钮
 ├── 性格测试 —— 5 道场景题，推断玩家行为类型
 ├── 压力输入 —— 文本框 + 分类标签，定义今日压力源
 ├── 怪物生成 —— 性格 × 分类 → 生成对应怪物
 ├── 战斗竞技场 —— 玩家用工具摧毁怪物，怪物会反击
 └── 销毁结果 —— 评分 + 特效 + 记录存档

核心模块
 ├── 性格引擎 —— 题面 + 计分规则 + 5 种性格类型
 ├── 压力映射器 —— 输入文本 + 分类 → 怪物外观与行为
 ├── 怪物 AI —— 5 种攻击模式（冲撞/锁链/分裂/反击/瞬移）
 ├── 工具系统 —— 8 种破坏武器，不同操作与伤害逻辑
 ├── 战斗引擎 —— HP/连击/冷却/粒子/震动/慢动作
 └── 记录系统 —— localStorage 存档，按日汇总

数据层
 ├── 性格档案 —— 玩家性格类型与偏好参数
 ├── 摧毁记录 —— 日期/压力描述/分类/工具/评分
 ├── 工具解锁 —— 基于累计摧毁次数逐步开放
 └── 统计看板 —— 压力分类分布、工具使用频率、评分趋势
```

---

## 二、核心功能清单

1. **性格测试** — 5 道日常场景题，判定玩家属于爆裂型/执念型/敏感型/斗士型/飘忽型
2. **压力输入** — 自由文本框 + 6 类标签（工作/钱/感情/健康/社交/其他）
3. **怪物生成** — 性格×分类 决定怪物外观、AI 行为、弱点
4. **战斗竞技场** — Canvas 2D 实时战斗，玩家可移动、攻击、闪避
5. **8 种破坏工具** — 大锤/球棒/喷火器/手榴弹/武士刀/雷击/电锯/火箭筒
6. **怪物攻击** — 5 种攻击模式，被击中扣血、连击中断、屏幕红闪
7. **销毁反馈** — 粒子爆炸、屏幕震动、慢动作、大字拟声词、S/A/B/C 评分
8. **连击系统** — 连续命中叠加 combo 倍率，断连重置
9. **工具解锁** — 累计摧毁次数解锁新工具，激励持续使用
10. **摧毁记录** — localStorage 存档，按日期汇总展示
11. **统计看板** — 压力类型分布、最爱武器、最高评分

## 三、模块详解

### 3.1 性格测试

#### 3.1.1 测试规则

5 道题，每题 2-3 个选项，无对错之分，全部答完即时出结果。

**题面设计原则：** 不用心理学术语，用日常场景让玩家自然选择。

| 题号 | 场景 | 选项 A | 选项 B | 选项 C |
|------|------|--------|--------|--------|
| 1 | 排位赛连输三把 | 换把武器继续干（爆裂型） | 停下来看录像找问题（执念型） | 不玩了换个游戏（飘忽型） |
| 2 | 朋友跟你意见不同 | 直接开怼直到他服（斗士型） | 心里不舒服但不说（敏感型） | 无所谓都可以（飘忽型） |
| 3 | 桌上很乱的时候 | 忍不了立刻收拾（执念型） | 乱但我知道东西在哪（飘忽型） | 无视继续做事（敏感型） |
| 4 | 遇到一个很难的挑战 | 先干了再说（爆裂型） | 想清楚所有可能再动手（执念型） | 先看看别人怎么做的（斗士型） |
| 5 | 被人莫名其妙骂了 | 十倍骂回去（斗士型） | 难受一整天（敏感型） | 关我屁事（飘忽型） |

#### 3.1.2 计分与结果

统计每个类型的命中次数，最高者为最终性格类型。

| 性格 | 核心特征 | 战斗加成 |
|------|---------|---------|
| 爆裂型 | 冲动直接，先做后想 | 锤子伤害 +50%，HP +1 |
| 执念型 | 仔细专注，不放过细节 | 连击判定窗口延长 0.5s，暴击率 +15% |
| 敏感型 | 在意感受，容易受伤 | 范围伤害 +30%，闪避无敌帧延长 |
| 斗士型 | 好胜不服，喜欢对抗 | 球棒击退 +100%，被击后攻击力短暂提升 |
| 飘忽型 | 随性洒脱，不拘一格 | 攻速 +30%，移动速度 +20% |

### 3.2 压力输入

#### 3.2.1 交互流程

```
[性格测试完成] → 展示性格卡片 → [确定，开始毁灭]
                                    ↓
                          ┌────────────────────┐
                          │ 今天什么让你烦？    │
                          │ [________________] │
                          │                    │
                          │ 工作  钱  感情     │
                          │ 健康  社交  其他   │
                          │                    │
                          │ [  生成压力怪物  ] │
                          └────────────────────┘
```

#### 3.2.2 输入规则

| 字段 | 规则 | 说明 |
|------|------|------|
| 压力描述 | 纯文本，1-50 字 | 显示在怪物头顶，作为战斗中的标签 |
| 分类 | 单选，6 选 1 | 决定怪物视觉主题和行为倾向 |

**示例输入：**

| 输入文本 | 分类 | 怪物外观主题 |
|---------|------|-------------|
| 领导让我周末加班 | 工作 | 喋喋不休的闹钟怪 + 文件堆护甲 |
| 花呗还不上 | 钱 | 裂开钱袋魔像，掉落硬币弹幕 |
| 对象已读不回 | 感情 | 缠绕心形触手怪，会发射追踪飞吻弹 |
| 体检报告有问题 | 健康 | 裂痕镜子幻影，攻击会复制自身 |
| 不知道毕业干什么 | 社交 | 问号云团，分裂成小问号 |
| 今天啥都不想干 | 其他 | 黑色黏团史莱姆，软塌塌但打不死 |

### 3.3 怪物生成规则

怪物由 **性格类型** × **压力分类** 共同决定。

#### 3.3.1 性格决定 AI 行为

| 性格 | 怪物攻击方式 | 弱点 |
|------|------------|------|
| 爆裂型 | **冲撞** — 蓄力后朝玩家猛冲，地面留裂纹 | 冲撞后硬直 1.5s，背后攻击暴击 |
| 执念型 | **锁链减速 + 追踪弹** — 伸出锁链限制走位 | 锁链有固定长度，拉远距离可扯断 |
| 敏感型 | **分裂弹幕** — 吐出小块弹幕覆盖范围 | 本体血量低，优先击杀本体即可 |
| 斗士型 | **格挡反击** — 概率格挡并反打一拳 | 格挡时有黄色闪光窗口，可破防 |
| 飘忽型 | **瞬移背刺** — 消失后出现在玩家背后 | 瞬移有 0.3s 落地前摇，可预判攻击 |

#### 3.3.2 分类决定视觉主题

| 分类 | 基础配色 | 特征元素 |
|------|---------|---------|
| 工作 | 灰/橙色 | 文件、闹钟、键盘、工牌 |
| 钱 | 金/绿色 | 硬币、钞票、钱袋、账单 |
| 感情 | 粉/紫色 | 心形、触手、面具、锁链 |
| 健康 | 白/红色 | 镜子、针管、体重秤、温度计 |
| 社交 | 蓝/灰色 | 气泡、眼睛、手机、话筒 |
| 其他 | 黑/彩色 | 抽象几何、黏液、乱码 |

#### 3.3.3 怪物属性公式

```
基础 HP = 60 + (性格系数 × 10) + (玩家当前累计摧毁次数 × 2)

性格系数:
  爆裂型 = 4  执念型 = 3  敏感型 = 2  斗士型 = 3  飘忽型 = 1

攻击力 = 基础 10 + (性格系数 × 2)
攻击间隔 = 基础 2.5s - (性格系数 × 0.1s)，最少 1.5s
移动速度 = 基础 1.0 + (飘忽型 0.5 / 其他 0)
```

### 3.4 战斗竞技场

#### 3.4.1 竞技场布局

```
┌──────────────────────────────────────┐
│  ❤❤❤❤❤    压力：领导让我周末加班    │ ← 顶部 HUD
│                                      │
│       ┌──────────────────┐           │
│       │                  │           │
│       │   压力怪物        │           │
│       │   ← 攻击         │           │
│       │                  │           │
│       └──────────────────┘           │
│                                      │
│          ← 玩家 →                    │
│                                      │
│  🔫 ⚾ 🔥 💣 🗡️ ⚡ 🔪 🚀    │ ← 底部工具栏
│  COMBO x8      🎯 2400     ❤❤❤❤❤  │
└──────────────────────────────────────┘
```

#### 3.4.2 玩家操作

| 操作 | 方式 | 说明 |
|------|------|------|
| 移动 | 鼠标在画布移动 | 玩家角色跟随鼠标位置移动 |
| 攻击 | 取决于当前工具 | 点击/拖拽/按住 不同手势 |
| 切换工具 | 数字键 1-8 或点击底部图标 | 即时切换，无 CD |

#### 3.4.3 战斗规则

| 规则 | 说明 |
|------|------|
| 玩家血量 | 5 颗心，被击中扣 1 颗，心归零战斗失败 |
| 无敌帧 | 被击中后 1 秒无敌，屏幕闪红提示 |
| 连击系统 | 每次命中重置连击计时器（2s），combo 叠加 |
| combo 倍率 | x1=100%, x5=150%, x10=200%, x20=300% |
| 冷却系统 | 手榴弹 3s / 雷击 8s / 火箭筒 5s，其他武器无 CD |
| 失败处理 | 怪物保留当前血量，弹「再来一次」，不重置 |

#### 3.4.4 评分标准

| 评分 | 条件 |
|------|------|
| S | 0 损失心 + 20 秒内击杀 + combo 最高 > 10 |
| A | 损失 ≤ 2 心 + 30 秒内击杀 |
| B | 击杀但未满足 A/S |
| C | 失败后补刀击杀 |

### 3.6 怪物攻击行为详解

#### 3.6.1 攻击通用规则

- 进入战斗 2 秒后怪物开始攻击
- 每次攻击后有 1.5-3 秒冷却（取决于性格）
- 怪物不会回血
- HP < 30% 时进入狂暴：攻速 +30%，攻击模式变化

#### 3.6.2 各性格攻击模式

**爆裂型 — 冲撞：**

```
蓄力 1s（地面红圈预警）→ 朝玩家直线冲锋
被击中：扣 1 心，击退
冲撞后硬直 1.5s（背部攻击必暴击）
狂暴后：连续冲撞 2 次
```

**执念型 — 锁链 + 追踪弹：**

```
伸出锁链（可被移动扯断，拉扯 3s 后自动断裂）
锁链存在期间发射 3 枚追踪弹
追踪弹飞行速度慢，可绕圈闪避
狂暴后：锁链不自动断裂，需攻击锁链本身
```

**敏感型 — 分裂弹幕：**

```
吐出 5-8 枚小弹幕，扇形扩散
弹幕 HP 低（1 锤击碎）
本体持续生成弹幕
狂暴后：分裂出 1 个子体（HP 为本体 30%）
```

**斗士型 — 格挡反击：**

```
站立姿态，概率格挡正面攻击（格挡率 30%）
格挡成功 → 黄光闪过 → 立即反击一拳（不可闪避）
破防方法：背后攻击 / 范围武器（喷火器/手榴弹）
狂暴后：格挡率 50%，反击带击退
```

**飘忽型 — 瞬移背刺：**

```
消失（0.5s 隐身）→ 出现在玩家背后（0.3s 落地前摇）
前摇期间攻击可打断背刺
狂暴后：连续瞬移 2 次再攻击
```

### 3.7 销毁反馈

#### 3.7.1 击破流程

```
怪物 HP = 0
  → 时间减速至 30% 速度（持续 2 秒）
  → 怪物裂开，碎片粒子飞散（20-30 块碎片）
  → 屏幕震动（强度 10px，持续 0.5s）
  → "💥 BOOM!" 大字覆盖屏幕中央（缩放动画）
  → 评分弹出（S/A/B/C，金/银/铜/灰色）
  → 粒子烟花（评分越高越密集）
  → 恢复速度，自动进入结果页
```

## 五、边界声明

| 不做 | 原因 |
|------|------|
| 真实心理诊断 | 游戏目标是解压，不提供任何心理评估或医疗建议 |
| 用户数据上传 | 所有数据仅存本地 localStorage |
| 社交/排行榜 | 不比较摧毁数量，避免制造新压力 |
| 充值/内购 | 所有工具通过游玩解锁，不设付费墙 |
| 成瘾设计 | 无每日任务/限时奖励/连续签到 |
| 广告 | 战斗中不插广告，不打断破坏体验 |
| 账号系统 | 无需注册登录，打开即玩 |
| AI 生成敏感内容 | 压力输入有基础敏感词过滤 |

## 八、落地原则

**三条核心原则：**

1. **压力来源必须是玩家自己说的**
   - 性格只决定怪物怎么打，不推断玩家有什么压力
   - 玩家不说，游戏不猜

2. **破坏必须爽**
   - 每一次攻击都有明确反馈（震动/音效/粒子/数字）
   - 最后一击必须有仪式感（慢动作 + 大爆炸）
   - 工具之间手感必须不同，不能换皮

3. **不制造新压力**
   - 没有每日任务、没有排名、没有氪金
   - 输了可以无限重来，怪物不恢复血量
   - 玩家的敌人只有自己输入的那句话
