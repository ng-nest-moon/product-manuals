# 小树洞 — 产品功能说明书

## 一句话定义

不做妈妈，只把妈妈从"人肉执行器"的角色里解放出来，让她重新做回那个孩子愿意靠近的人。

---

## 适龄建议

6岁以上

---

## 一、目标用户与痛点分析

### 1.1 核心用户画像

**主要用户：妈妈（28-40 岁）**

| 维度 | 描述 |
|------|------|
| 年龄 | 28-40 岁，多为 80 后末到 90 后 |
| 家庭 | 双职工家庭，6-12 岁孩子正在小学阶段 |
| 收入 | 中产，家庭月收入 2-5 万 |
| 教育观 | 关注科学育儿，读过育儿书，知道"不该吼"但忍不住 |
| 日常痛点 | 每天催起床、催刷牙、催写作业、催睡觉——重复 20+ 次/天 |
| 深层焦虑 | 怕自己情绪失控影响孩子心理，怕孩子输在习惯上，怕被说"你当妈的怎么带的孩子" |
| 技术接受度 | 会用智能手机，但不喜欢复杂配置，需要"开箱即用" |

**次要用户：孩子（6-12 岁）**

| 维度 | 描述 |
|------|------|
| 年龄 | 6-12 岁小学阶段 |
| 日常体验 | 被安排、被催促、被纠正——一天内接收大量负面反馈 |
| 心理需求 | 渴望被尊重、被理解、有自己的空间 |
| 行为特征 | 对游戏化机制敏感，对"说教"免疫，容易被故事和角色吸引 |

### 1.2 真实痛点分级

| 需求类型 | 痛点 | 用户行为证据 |
|---------|------|-------------|
| **刚需** | 每天催 20+ 次起床/吃饭/写作业/睡觉，妈妈精力被消耗殆尽 | 妈妈们在小红书/宝妈群高频吐槽"催不动" |
| **刚需** | 亲子冲突频发，妈妈吼完又后悔，孩子哭完更抗拒 | "每次写作业都要吵架"是社交平台永恒热门话题 |
| **刚需** | 孩子写作业分心、磨蹭，必须有大人全程盯着 | "不盯着就不写"是核心痛点 |
| **改善型** | 孩子不会表达情绪，用哭闹/顶嘴/打人发泄 | 妈妈知道要"情绪引导"但没时间没方法 |
| **改善型** | 妈妈希望培养孩子自主能力，但不信任孩子能做好 | "放手"和"失控"之间的焦虑 |
| **猎奇伪需求** | 让孩子"爱上学习" | 学习本身有枯燥的部分，产品目标不是让学习变好玩 |

## 二、解决方案与核心功能

### 2.1 解决方案概述

小树洞不做"更好的妈妈"，它只做一件事：**把消耗妈妈的事情接走，把只有妈妈能做的事情留给她。**

具体来说，系统接管三类任务：
- **催促/提醒** — 起床、刷牙、写作业、洗澡、睡觉，由榜样角色用故事和游戏代替妈妈的唠叨
- **监控/纠正** — 作业专注度、课文朗读、走神检测，由 AI 实时执行，妈妈退出"人肉监控"角色
- **冲突缓冲** — 当亲子冲突爆发，AI 在 3 秒内给妈妈一句孩子接得住的话，降低对抗烈度

妈妈只做三件事：起床时一个拥抱、睡前的 10 分钟真心话、每周日的家庭会议主持。

### 2.2 核心功能清单

1. **晨间/晚间流程** — 榜样角色用故事和邀请代替催促，覆盖起床/刷牙/吃饭/洗澡/睡觉
2. **注意力训练** — 作业拆解 + 番茄钟 + 课文高亮跟读 + 专注能量条可视化
3. **榜样学院** — 内置多个儿童榜样角色，每个角色有独立性格和"我当年也是这样"的故事库
4. **秘密基地** — 孩子可以对 AI 说任何话，不评判不传话，重大情绪信号匿名反馈家长
5. **情绪翻译器** — 冲突实时识别，AI 给家长一句孩子接得住的表达方式
6. **故事医生** — 输入具体行为问题，AI 自动生成隐喻故事
7. **反向课堂** — 孩子教 AI 学东西，AI 认真当学生并给予反馈
8. **家庭英雄榜** — 全家每周评选"超能力"——孩子改、家长也改
9. **成长博物馆** — 自动收集成长瞬间（第一次自己刷牙、读完一本书的录音……）
10. **家长看板** — 冲突趋势、专注时长趋势、进步信号而非告状
11. **三阶段引擎** — 根据家庭状态自动切换破冰/重建/共生模式

## 三、竞品与差异化分析

### 3.1 同类替代品对比

| 竞品 | 类型 | 优点 | 缺点 | 与本产品定位差异 |
|------|------|------|------|----------------|
| 洪恩系列 | 学习启蒙 APP | 内容制作精良，孩子爱玩 | 偏学科知识，不解决亲子关系 | 小树洞管习惯和情绪，不管学习 |
| 小花生 | 阅读打卡社区 | 宝妈社群活跃，阅读记录完善 | 纯工具，无情感陪伴 | 小树洞有 AI 角色陪伴和情绪翻译 |
| 儿童番茄钟 / 闹钟 | 硬件 | 物理设备不伤眼，简单 | 只能定时，不能互动，孩子不买账 | 小树洞是角色陪伴型虚拟助手 |
| 家长自己"硬催" | 无产品 | 成本为 0 | 消耗亲子关系，效果越来越差 | 小树洞替代催促角色，修复关系 |
| AI 陪伴玩具（火火兔等） | 硬件 | 有语音互动 | 无家庭系统视角，不能翻译情绪 | 小树洞是全家系统，连接家长和孩子 |

### 3.2 差异化优势与护城河

| 优势 | 说明 | 可模仿性评估 |
|------|------|-------------|
| 角色陪伴型交互 | 榜样角色用"我当年也是这样"的故事代替说教 | 中等——需要大量优质故事内容积累 |
| 情绪翻译器 | 冲突瞬间给家长精准表达 | 高——单点功能容易复制 |
| 秘密基地 + 匿名反馈 | 孩子专属空间，AI 不评判不传话 | 低——信任机制和匿名边界设计需要深度理解亲子关系 |
| 三阶段引擎 | 根据家庭状态自动调整策略 | 中等——阶段划分容易，但每个阶段的触发判断需要数据积累 |
| 家庭系统视角 | 不只是管孩子，是全家人一起改 | 低——竞品都是儿童单点工具，很少有家庭系统设计 |

**核心护城河：** 数据+信任。孩子对"秘密基地"的信任一旦建立，迁移成本极高。妈妈对情绪翻译器的个性化适配依赖越久，越离不开。

## 四、系统架构总览

```
用户层
 ├── 家长端（规则配置 + 情绪翻译 + 数据看板）
 └── 孩子端（榜样角色 + 游戏化流程 + 秘密基地）

核心层
 ├── 晨夕岛 —— 早晨唤醒 + 晚间安睡，榜样角色用故事陪伴
 ├── 注意力森林 —— 作业拆解 + 番茄钟 + 课文陪读 + 专注曲线
 ├── 榜样学院 —— 榜样角色"现身说法"的示范引擎
 ├── 秘密基地 —— 孩子专属树洞，不评判不传话
 ├── 情绪翻译器 —— 冲突瞬间给家长一句话
 ├── 故事医生 —— 不讲道理讲故事，隐喻故事生成器
 ├── 反向课堂 —— 让孩子当老师教 AI
 ├── 家庭英雄榜 —— 全家一起变好的游戏化系统
 └── 成长博物馆 —— 不存分数，存成长瞬间

数据层
 ├── 行为日志 —— 每个环节的完成情况与耗时
 ├── 情绪曲线 —— 孩子的情绪波动趋势
 ├── 专注曲线 —— 有效学习时间与注意力变化
 └── 家庭互动指标 —— 冲突频次、正向互动频次

阶段引擎
 ├── 破冰期（第1-2周）—— 降低对抗，建立信任
 ├── 重建期（第3-6周）—— 恢复专注，家长退场
 └── 共生期（第7周起）—— 全家一起变得更好
```

## 五、核心模块详解

### 5.1 晨夕岛

每天两次最紧张的时段——早上出门和晚上睡觉——由榜样角色替代妈妈当"唤醒者"。

#### 5.1.1 晨间唤醒流程

| 时间 | 触发 | 榜样角色行为 | 妈妈角色 |
|------|------|-------------|---------|
| 前夜 | 孩子选好明日穿搭 | "你选好了明天穿什么，截图发我，明早我叫你" | 只需要确认 |
| 起床 | 到设定时间 | 角色渐进唤醒："早安小太阳，今天我们有三件事要完成——打败瞌睡虫、刷牙挑战、准时出门" | 坐在餐桌前，孩子出来时说"早上好" |
| 刷牙 | 进入卫生间 | 计时挑战开启，角色语音同步："我小时候刷牙也超快，2分钟你能刷完吗？" | 不参与 |
| 出门 | 倒计时5分钟 | "还有5分钟传送门就要关了哦" | 检查书包，开门 |

**叫醒方式配置：**

```
- 语音角色：小兔姐姐 / 学霸哥哥 / 小宇宙 / 艾拉公主 / 自定义
- 唤醒强度：温柔型 / 激励型 / 幽默型
- 渐醒时长：5分钟 / 10分钟 / 15分钟
```

#### 5.1.2 晚间安睡流程

| 环节 | AI 行为 | 妈妈角色 |
|------|--------|---------|
| 洗澡提醒 | "洗澡时间到，今天的浴室故事是——《会说话的小鱼》" | 此刻可以做自己的事 |
| 刷牙 | 和早上同步，切换夜间柔和语调 | 不参与 |
| 收拾书包 | AI 逐项提醒："语文作业装好了吗？明天有体育课要带跳绳" | 最终检查 |
| 上床 | 角色晚安故事 | 如果愿意，妈妈来讲；如果不愿意，AI 来讲 |
| 入睡 | 5分钟催眠引导语音 | 关灯+一个拥抱 |

---

### 5.2 注意力森林

解决"读课文分心、写作业必须盯着"的核心模块。

#### 5.2.1 课文陪读模式

| 当前痛点 | 方案 |
|---------|------|
| 你坐旁边盯着，她有压力 | AI 在屏幕上显示课文，当前句子高亮，语音识别跟随朗读自动推进 |
| 走神了没人拉回来 | 3秒检测到无声→当前句闪烁→第5秒角色小声提醒："我等你哦" |
| 读错了你纠正→她顶嘴不读了 | AI 在整段读完后统一提示："第三行有个字藏起来了，你能找到它吗？"——不是打断，是游戏 |
| 读得磕巴她挫败 | AI 只记录流利度曲线给自己看，不给孩子看分数，说"比昨天又顺了一点点" |

#### 5.2.2 作业番茄钟

- 孩子参与设定：每段写多少分钟（默认8分钟写+2分钟休）
- 写的过程中不说话、不批评、不夸——只倒计时
- 走神了：计时器不停——休息时间被走神吃掉了，她需要自己决定是否拉回来
- 完成目标后：解锁今日奖励碎片

**专注能量条：**

```
今日专注力 ║▓▓▓▓▓▓▓░░░░░║ 65%
比昨天     ↑ +8%
连续专注   ⚡ 12分钟
今日已攒    ⭐ 3颗
```

---

### 5.3 榜样学院

核心设计：**不是"你应该向某某学习"，而是"ta 当年也遇到过这个困难，ta 是这样走过来的"。**

#### 5.3.1 榜样角色库

| 角色 | 性格 | 擅长领域 | 适合场景 |
|------|------|---------|---------|
| 小兔姐姐 | 温柔耐心 | 阅读、坚持 | 晨起、睡觉、读课文 |
| 学霸阿哲 | 理性有条理 | 数学、计划、清单 | 写作业、收拾书包 |
| 小宇宙 | 热血不服输 | 体育、挑战 | 克服困难、起床 |
| 艾拉公主 | 优雅自信 | 情绪管理、礼仪 | 控制脾气、餐桌礼仪 |
| 代码猫 | 聪明古怪 | 逻辑、创造力 | 反向课堂、解题 |

#### 5.3.2 "我当年也是这样"故事库

每个榜样角色都有一套"童年故事"，在对应场景自动触发：

| 场景 | 角色故事 |
|------|---------|
| 不想起床 | "阿哲以前也起不来，后来他发明了一个办法——闹钟响的时候，在心里数到3就坐起来，就3秒。他试了7天才成功。" |
| 读课文卡住 | "小兔姐姐小时候读课文也磕巴，她发现一个秘密——同一篇课文读3遍之后就会变得很顺。她试了，是真的。" |
| 作业不想写 | "小宇宙最讨厌的就是写作业，但他跟自己打赌——只要先写5分钟，5分钟之后如果还不想写，就可以停下来。结果每次5分钟到了他都停不下来。" |

#### 5.3.3 孩子自主选择角色

- 孩子可以选一个最喜欢的角色当"固定学姐/学长"
- 选定了就不能轻易换（跨过厌烦期才能建立信任）
- 角色会"认得"孩子——记得她昨天做了什么、上周有什么进步

---

### 5.4 秘密基地

#### 5.4.1 孩子端体验

- 入口：只有孩子知道怎么打开（特定图案、语音口令）
- 空间感：一个看得见的"小房子"界面，她在里面可以：
  - 说话/打字——AI 只倾听、不评判
  - 画画/涂鸦——表达情绪
  - 写"不想让妈妈知道的话"
- AI 回应原则：
  - 不说"你应该""你不该"
  - 先说"听起来你很难过""如果是我我也会生气"
  - 永远站在她这边，但不是挑拨她跟你的关系

#### 5.4.2 匿名反馈机制

AI 检测到以下信号时，匿名反馈给家长看板：

| 信号 | 反馈方式 |
|------|---------|
| "我不想活了""我讨厌自己" | 紧急预警，建议立即沟通 |
| 连续3天情绪低落 | "最近她提到学校压力比较多，可能跟她聊聊会好" |
| "妈妈根本不懂我" | 不会告状，但会在家长看板提示"最近她可能需要一些独处陪伴" |
| 普通日常分享 | 不反馈——那是属于她的安全感 |

---

### 5.5 情绪翻译器

在冲突瞬间，家长情绪上头、大脑空白时，AI 在 3 秒内给出一个**孩子接得住**的表达。

| 你想表达 | 你容易说成 | AI 翻译成 |
|---------|-----------|---------|
| 我担心你迟到 | 你怎么这么慢 | "我有点担心我们来不及，要不要加快一点？" |
| 作业错了 | 你怎么又错了 | "这题看起来有点不对劲，要不要再检查一遍？" |
| 她顶嘴让你受伤 | 你什么态度 | "你刚才的语气让我有点难过，你是有不开心的事吗？" |
| 她磨蹭不写作业 | 你到底写不写 | "我看到你还没开始，是卡在哪了吗？" |
| 她哭了 | 别哭了有什么好哭的 | "我知道你现在很难过，我在这陪你" |

**触发方式：**
- 家长佩戴耳机/手机震感提示
- 不打断对话——AI 静默推送一条文本，家长看了一眼决定用不用
- 用完后可反馈"有用/没用"，AI 学习哪种话术对孩子更有效

---

### 5.6 故事医生

不讲道理，只讲故事。孩子顶嘴、打人、撒谎、发脾气时——不是训她，而是让 AI 给她讲一个隐喻故事。

**故事生成规则：**

| 行为 | 故事原型 | 隐喻 |
|------|---------|------|
| 顶嘴 | 小刺猬的故事 | 小刺猬用刺推开所有人最后发现没人靠近了 |
| 打人 | 小火山的秘密 | 小火山每次喷发都会伤害身边的朋友 |
| 撒谎 | 小木偶的礼物 | 撒谎让朋友不再相信她，她却不知道什么时候失去了信任 |
| 不刷牙 | 蛀牙菌王国 | 蛀牙菌在牙齿上建了游乐场，越不刷牙它们越开心 |

**原则：**
- 不讲"你看这小刺猬是不是跟你一样"
- 讲完就结束了，让孩子自己消化
- 如果孩子主动问"它后来怎么样了"，AI 再继续
- 家长也可以请 AI 生成一个特定故事，睡前念给孩子听

---

### 5.7 反向课堂

让她当老师，AI 当不会的学生。

**场景示例：**

| 孩子 | AI 学生 |
|------|--------|
| "我教你背这首诗" | "好难啊，我记不住第一句" |
| "我教你叠纸飞机" | "我折到第三步就不会了，能再讲一遍吗？" |
| "这是我们班的游戏规则" | "我没听懂，你能再解释一次吗？" |
| "这道题我会做" | "为什么这里要除2？我不懂" |

**设计要点：**
- AI 不是装笨，是真诚地"没有你帮忙我做不到"
- 当孩子教会了 AI，AI 会说"你讲得比我老师还清楚"
- 孩子的讲解录音自动存进成长博物馆

---

### 5.8 家庭英雄榜

不是只让孩子改，是全家一起玩。

**每周主题：**

| 周 | 全家主题 | 孩子超能力 | 妈妈超能力 | 爸爸超能力 |
|----|---------|-----------|-----------|-----------|
| 1 | 早起挑战 | 自己起床 | 不催 | 不赖床 |
| 2 | 情绪控制 | 被打断了不哭 | 忍住不吼 | 多陪玩 |
| 3 | 餐桌礼仪 | 吃三口青菜 | 不做饭时长脸 | 不玩手机 |
| 4 | 作业自主 | 自己开计时器 | 不去旁边坐 | 辅导不生气 |

**每周日晚家庭会议：**
1. AI 主持展示本周每个人的英雄积分
2. 投出本周"超级英雄"
3. 奖励：可以选明天吃什么 / 决定周末去哪 / 今天晚上少洗一次碗
4. 下周主题全家投票

**积分规则：**
- 孩子做到一次 +1 分
- 妈妈做到一次 +1 分
- 爸爸做到一次 +1 分
- **全家人一起做到**额外奖励 +3 分（合作分）

### 5.9 成长博物馆

不存分数、不存排名。**存只有她有的东西。**

| 收藏品 | 来源 | 形式 |
|--------|------|------|
| 第一次自己主动刷牙 | 妈妈打卡 | 日期+勋章 |
| 写的第一首小诗 | 她输入/妈妈输入 | 文字+她画的插图 |
| 第一次完整读完一本书的录音 | 注意力森林自动录制 | 录音+书名 |
| "今天我在学校帮了同学" | 她自己说/老师反馈 | 文字 |
| 教会 AI 一道题的录音 | 反向课堂自动录制 | 录音 |
| 每月的朗读对比 | 注意力森林自动生成 | 两段录音+时间轴 |

**AI 会说的话：**
- "这是三个月前的你，那时候每天早上还要妈妈叫——现在你已经可以自己起床了"
- "你看你教会了 AI 5 道题，你已经是小老师了"
- "这一年你读了 12 本书，比去年多了 5 本"

### 5.10 三阶段引擎

系统根据家庭状态自动调整模式和推荐重点。

#### 5.10.1 破冰期（第1-2周）

| 目标 | 降低对抗，让孩子愿意接受系统 |
|------|---------------------------|
| 启动模块 | 晨夕岛 + 秘密基地 + 反向课堂 |
| 暂不开启 | 注意力森林、家庭英雄榜（作业和规则类模块延后） |
| 妈妈任务 | 只做一件事：每天睡前 10 分钟专属陪伴，不催不骂不评判 |
| 预期效果 | 孩子对榜样角色建立信任，愿意尝试配合 |

#### 5.10.2 重建期（第3-6周）

| 目标 | 恢复专注力，妈妈退出人肉监控角色 |
|------|-------------------------------|
| 启动模块 | 注意力森林 + 榜样学院 + 情绪翻译器 |
| 妈妈任务 | 写作业时退出房间，只检查结果；冲突时用翻译器 |
| 预期效果 | 专注时长提升、每天冲突次数下降 |

#### 5.10.3 共生期（第7周起）

| 目标 | 全家一起变得更好，系统进入自动运转 |
|------|----------------------------------|
| 启动模块 | 家庭英雄榜 + 故事医生 + 成长博物馆 |
| 妈妈任务 | 每周家庭会议主持，日常由系统执行 |
| 预期效果 | 家庭正向互动 > 对抗频次，系统成为"家庭一员" |

## 七、商业模式

### 7.1 定价区间

| 付费模式 | 定价区间 | 依据 |
|---------|---------|------|
| 月订阅 | 39-69 元/月 | 同类育儿工具（小花生会员 29 元/月、洪恩包月 49 元/月） |
| 年订阅 | 299-499 元/年 | 相当于每月 25-42 元，年度优惠 30-40% |
| 家庭版（双孩） | 年费 +99 元 | 二胎家庭附加账号 |
| 终身版 | 999-1499 元 | 面向重度用户，相当于 2-3 年年费 |

**用户心理价位：** 妈妈们每月为"省心"愿意支付的金额大约在 50-80 元（相当于一杯奶茶钱），年费超过 500 元会觉得"贵"但"可以接受"。

### 7.2 销售渠道

| 渠道 | 方式 | 优先级 |
|------|------|--------|
| 应用商店（iOS/Android） | 自然搜索 + ASO | ★★★★★ 核心下载渠道 |
| 小红书 | 妈妈真实体验分享、痛点场景种草 | ★★★★★ 核心传播渠道 |
| 宝妈微信群 | 口碑裂变、拼团优惠 | ★★★★ 低成本获客 |
| 抖音/视频号 | 情景短剧（催作业 vs 不催）、效果对比 | ★★★★ 精准投放 |
| 母婴 KOL 合作 | 产品试用 + 真实体验视频 | ★★★ 品牌建设 |
| 线下 | 绘本馆、亲子机构、早教中心推荐 | ★★ 辅助渠道 |

**种子用户获取方式：** 宝妈群免费内测→口碑裂变→首批付费用户。

### 7.3 盈利模式

| 收入来源 | 说明 | 预期占比 |
|---------|------|---------|
| 订阅费 | 月/年/终身 订阅 | 70% 核心收入 |
| 家庭版附加账号 | 二胎/多孩家庭的额外收费 | 10% |
| 定制角色/皮肤 | 限定榜样角色、节日主题装扮 | 8% 增值收入 |

**不做：** 广告变现（破坏信任，孩子端绝对不出现任何广告）、数据售卖。

## 八、落地路径

### 8.1 五大落地难点

| 难点 | 详细描述 | 缓解策略 |
|------|---------|---------|
| 用户教育成本 | 妈妈们需要理解"不是又一个学习 APP，是帮我管情绪和习惯的" | 前三日引导流程 + 场景化 onboarding |
| AI 对话质量 | 孩子端的回应必须精准，一次"不恰当回应"可能摧毁秘密基地的信任 | 严格的安全边界 + 情绪敏感度优化 |
| 定价与付费意愿 | 育儿工具付费习惯尚未普及 | 先用免费破冰期让用户体验价值，再引导付费 |
| 竞品模仿压力 | 情绪翻译器、故事医生等单点功能易被大厂复制 | 强化家庭系统整合度，靠数据积累做护城河 |
| 合规与隐私 | 涉及儿童数据，受未成年人保护法规范 | 端侧处理 + 最小化数据收集 + 透明隐私政策 |

### 8.2 MVP 最小可行产品

**MVP 范围：** 只做破冰期能跑的模块。

| 功能 | MVP 做法 | 非 MVP（后续再做） |
|------|---------|------------------|
| 晨夕岛 | 1 个榜样角色（小兔姐姐），固定唤醒流程 | 多角色选择、自定义唤醒强度 |
| 秘密基地 | 语音/文字输入 + 基础倾听模型，无绘画功能 | 涂鸦、画板、房间装扮 |
| 家长看板 | 显示基础冲突趋势和专注趋势 | 详细的数据分析和 PDF 导出 |
| 情绪翻译器 | 预设话术库 30 条 + 手动触发 | AI 自动识别冲突并推送 |
| 反向课堂 | AI 扮演固定学生角色 | 多个 AI 学生、学科分类 |
| 家庭英雄榜 | 不 MVP（依赖多用户） | 第二版再上线 |

**最低试错成本估算：**
- 开发：2 人（1 前端 + 1 AI/后端）× 2 个月 ≈ 8-10 万
- AI 模型调用 + 服务器：月均 2000-5000 元
- 首批 100 个种子用户测试：0 元（宝妈群内测）

### 8.3 第一步验证

**最关键假设：** 妈妈愿意为"不用每天催孩子"付费。

**最低成本验证方法：**

| 步骤 | 做法 | 判断标准 |
|------|------|---------|
| 1. 痛点确认 | 在 3 个宝妈群发起投票："如果有个 APP 能在你催作业的时候帮你接话，你愿意用吗？" | 超过 60% 的宝妈选"愿意试试" |
| 2. 付费意愿验证 | 做一个 1 分钟原型视频（用话术演示情绪翻译器），让用户"预付 1 元锁定内测资格" | 超过 50 人预付，说明付费意愿成立 |
| 3. 留存验证 | MVP 上线后，追踪 7 日留存率 | 7 日留存 > 40% 才继续投入 |

**验证通过/不通过标准：**
- ✅ 通过：超 50 人预付 + 7 日留存 > 40%
- ❌ 不通过：没人预付 → 要么定价过高，要么痛点不够痛 → 重新定位或放弃

## 九、风险与预期反馈

### 9.1 预期负面吐槽

| 预期槽点 | 用户画像 | 应对方案 |
|---------|---------|---------|
| "不就是个闹钟吗，换个皮肤就要收费？" | 只看介绍没深入用的泛用户 | 突出情绪翻译器和秘密基地——闹钟不要钱，帮你管控情绪才要钱 |
| "AI 讲的故事很敷衍，没什么用" | 重度使用后失望 | 持续优化故事生成模型，初期人工精选故事库兜底 |
| "孩子新鲜两天就不用了" | 孩子对角色失去兴趣 | 三阶段引擎自动推进内容深度，不断解锁新故事和新互动 |
| "这不就是让孩子跟 AI 说话，逃避跟妈妈沟通？" | 传统的家长 | 产品设计原则第一条：AI 不替代妈妈，秘密基地的匿名反馈反而能帮妈妈了解孩子 |
| "性价比不高，我还是自己吼吧" | 价格敏感型 | 免费破冰期让用户先体验效果，看到行为改善后才引导付费 |
| "数据安全吗？孩子隐私怎么办？" | 关注隐私的家长 | MVP 阶段就上线隐私说明页，承诺端侧处理敏感数据 |

## 十、边界与原则

| 不做 | 原因 |
|------|------|
| 摄像头监控/视频监控 | 侵犯隐私，让孩子更抗拒，且不是解决亲子关系的方向 |
| 替代妈妈陪伴 | 系统是辅助，睡前拥抱、真心对话永远是妈妈的工作 |
| 用惩罚等级吓唬孩子 | 产品底线是"正向引导"，不制造恐惧 |
| 给孩子贴诊断标签 | 不输出"你孩子可能是 ADHD/对立违抗"之类的内容 |
| 社交/游戏化上瘾设计 | 不使用无限滚屏、连续奖励等成瘾机制 |
| 学校成绩排名 | 不录入考试成绩，不跟同龄人比较 |
| 取代真实社交 | AI 陪伴是补充，不是替代现实中的人际关系 |
| 医疗级别的心理诊断 | 检测到严重信号只做预警，不提供诊断 |

**三条不能违反的底线：**

1. **不替代妈妈——只接走消耗**
   - 做提醒、计时、检查、记录
   - 妈妈做陪伴、拥抱、倾听、睡前那 10 分钟真心话

2. **不制造"被监控"的感觉**
   - 家长能看到趋势，看不到秘密基地的对话内容
   - 孩子知道"秘密基地是安全的"

3. **目标不是"听话"，是"不需要管也能自己运转"**
   - 最终状态不是孩子服从系统
   - 而是孩子自己学会了管理注意力、表达情绪、承担责任

## 十二、开发优先级

### 第一周 —— 晨夕岛 + 秘密基地

- 晨间唤醒流程（角色语音、渐醒、刷牙挑战）
- 榜样角色库（首批 3 个角色及故事）
- 秘密基地基础版（文字/语音输入、不评判响应模型）
- 晚间安睡流程（洗澡提醒、晚安故事播报）

### 第二周 —— 注意力森林 + 反向课堂

- 课文陪读模式（高亮跟读、语音识别、走神检测）
- 作业番茄钟（定时/专注能量条/奖励碎片）
- 反向课堂（学生 AI 对话模型）
- 成长博物馆基础版（自动收录成长瞬间）

### 第三周 —— 情绪翻译器 + 故事医生

- 情绪识别引擎（冲突场景识别）
- 翻译器话术库 + 个性化学习
- 故事医生（隐喻故事生成模型）
- 家长端看板（冲突趋势/专注趋势）

### 第四周 —— 家庭英雄榜 + 阶段引擎

- 家庭英雄榜（积分/投票/周主题）
- 三阶段引擎（破冰→重建→共生）
- 家规共创（家庭会议主持模块）
- 家长端完整看板（进步信号推送）
- 成长博物馆完整版（月度对比生成）
