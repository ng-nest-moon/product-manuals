## 文档结构

每份产品说明书遵循统一格式：

- **一句话定义** — 秒懂产品是什么、解决什么问题
- **架构总览** — 功能模块的树状结构
- **核心功能清单** — 产品做什么的完整列表
- **模块详解** — 每个模块的职责、流程、配置
- **用户流程** — 从开始到结束的完整路径
- **应用场景** — 典型使用场景
- **边界声明** — 明确不做什么

## 使用

基于 Node.js 自定义构建，本地预览：

```bash
npm install
npm run dev
```

打开浏览器访问 `http://localhost:3000`。
