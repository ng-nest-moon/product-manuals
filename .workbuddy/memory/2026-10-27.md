- 需求：基于 `docs/02-我来当老师.md` 写一篇微信公众号文章，结尾带指向 GitHub Pages 的链接。
- 产出目录：`articles/`（新建，与 docs/ 说明书分离，避免被 build.js 当成产品页处理）。
  - `articles/02-我来当老师-公众号文章.md`：正文 Markdown 版，便于二次编辑。

- Pages 链接规则（来自 `scripts/build.js`）：`BASE_PATH=/product-manuals`，产品页为 `/product-manuals/manuals/{nn}-{产品名}/`。
  本文使用 <https://ng-nest-moon.github.io/product-manuals/manuals/02-我来当老师/>（已实测可访问）。
- 注意：公众号正文外链不可点击，链接需放「阅读原文」，正文内保留可长按复制的纯文本 URL。
